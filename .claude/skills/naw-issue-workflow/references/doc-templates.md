# Issue Docs Templates

## 対象ファイル

- `00_チケット内容.md`
- `01_要件定義.md`
- `02_基本設計.md`
- `03_詳細設計.md`
- `04_テスト設計.md`
- `05_テスト詳細設計.md`
- `06_タスクリスト.md`
- `07_gitコミット.md`
- `08_動作確認.md`

## 共通ルール

- `01` `02` `04` にはソースコードやファイルパスを書かない
- `03` `05` は実装対象ファイルとテスト対象ファイルを具体化してよい
- `08` には実際に確認した内容だけを書く
- 不明点や仕様差分は参照実装を読んだ結果として明記する

## `00_チケット内容.md`

```markdown
# タイトルの内容

## 概要

## 説明

## その他
```

## `01_要件定義.md`


## `06_タスクリスト.md`

```markdown

- [ ] `00_チケット内容.md` を作成

- [ ] `03_詳細設計.md`〜`05_テスト詳細設計.md` を作成

## 実装

- [ ] 実装タスクを列挙

## テスト

- [ ] テストタスクを列挙

## 動作確認

- [ ] 動作確認を記録

## PR・レビュー

- [ ] PR を作成
```
