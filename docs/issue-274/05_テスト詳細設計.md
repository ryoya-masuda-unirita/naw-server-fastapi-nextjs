# 05_テスト詳細設計

テストはすべて `waha-emulator/tests/` に置く。`cd waha-emulator && uv run pytest` で実行する。

## 共通（`tests/conftest.py`）

- `make_settings(**overrides)`: `Settings(_env_file=None, WAHA_AUTHKEY="waha-key", ...)`
- `ScriptedLlmClient`: 決めた差分を返す・例外を投げる・`asyncio.Event` で待つ、を指定できる偽の LLM。受け取ったメッセージを記録する
- `emulator_client` フィクスチャ: `create_app()` を lifespan 付きで起動し、`httpx.ASGITransport` の `AsyncClient` を返す
- API のパスは `/WahaServer/servicerun/api` を前置する
