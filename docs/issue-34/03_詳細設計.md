## `.githooks/pre-push`

```bash
#!/usr/bin/env bash
set -euo pipefail

# git push 実行時にGitが自動的に呼び出すフック。
# backend/ 配下のPythonコードに対してRuffのフォーマッター・リンターを適用し、
# 修正が入った場合は直前のコミットに畳み込んでからpushを継続する。

BACKEND_DIR="$(git rev-parse --show-toplevel)/backend"

if [ ! -d "$BACKEND_DIR" ]; then
  exit 0
fi

cd "$BACKEND_DIR"

echo "[pre-push] Running ruff format..."
uv run ruff format .

echo "[pre-push] Running ruff check --fix..."
if ! uv run ruff check --fix .; then
  echo "[pre-push] ruff check found issues that could not be auto-fixed. Please fix them manually and try again."
  exit 1
fi

cd "$(git rev-parse --show-toplevel)"

if [ -n "$(git status --porcelain -- backend)" ]; then
  echo "[pre-push] Ruff made changes. Amending them into the current commit..."
  git add -A -- backend
  git commit --amend --no-edit
  echo "[pre-push] Amended. Continuing push with the fixed code."
fi

exit 0
```

`set -euo pipefail`により、途中でエラーが起きた場合は即座にフックが失敗しpushが中断される。

## `.github/workflows/backend-tests.yml`（追記するジョブ）

```yaml
  lint:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: backend
    steps:
      - uses: actions/checkout@v4

      - name: Install uv
        uses: astral-sh/setup-uv@v8.3.0
        with:
          enable-cache: true

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: uv sync --locked

      - name: Check formatting
        run: uv run ruff format --check .

      - name: Run lint
        run: uv run ruff check .
```

既存の`unit-tests`・`integration-tests`ジョブと同じ`on.push`トリガーを共有するため、`lint`ジョブはトリガー条件を追加で書く必要はない（同一ワークフローファイル内に追加するため）。

## 実装時の確認事項

- `.githooks/pre-push`には実行権限（`chmod +x`）を付与する
- `git commit --amend --no-edit`は、pushしようとしているコミットがまだリモートに存在しない前提で安全に動作する。既にリモートにあるコミットをamendするケースは通常のpre-push実行フローでは発生しない（amend対象は常にpush直前のローカルHEAD）
