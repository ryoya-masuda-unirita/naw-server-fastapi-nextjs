# 動作確認

## 注意：本ドキュメントは旧方式（`.githooks/pre-push`）の記録であり、無効

以下は当初の`.githooks/pre-push`方式で実施した動作確認の記録だが、**実際には確認方法に不備があった**。

`git log`（ローカル）ではamend後のコミットに見えていたが、`git ls-remote`でリモートの実態を確認したところ、実際にpushされていたのは**amend前の、フォーマット崩れが残った内容**だった。Gitの`pre-push`フックは「pushする内容（SHA）」をフック実行前に確定するため、フック内で`git commit --amend`しても、その修正はpushに反映されない。

この問題を受け、`pre-commit`フレームワーク方式（コミット時に自動修正）に設計変更した（詳細は`01_要件定義.md`〜`03_詳細設計.md`を参照）。新方式での動作確認は再実装後に本ドキュメントを上書きする。
