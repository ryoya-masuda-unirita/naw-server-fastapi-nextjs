## ローカルでのpre-pushフック動作確認

`.githooks/pre-push`を有効化した状態で、意図的にフォーマット崩れ・未使用import（`import os`）を含むファイルをコミットしてpushした。

```
$ git push
[pre-push] Running ruff format...
1 file reformatted, 71 files left unchanged
[pre-push] Running ruff check --fix...
Found 1 error (1 fixed, 0 remaining).
[pre-push] Ruff made changes. Amending them into the current commit...
[feature/issue-34 4a20cbe] test: 意図的なフォーマット崩れ・未使用importを追加（フック動作確認用）
 Date: Mon Jul 6 15:59:51 2026 +0900
 1 file changed, 5 insertions(+)
[pre-push] Amended. Continuing push with the fixed code.
To github.com:ryoya-masuda-unirita/naw-server-fastapi-nextjs.git
   7870139..24a412c  feature/issue-34 -> feature/issue-34
```

- コミットハッシュが変わっている（`amend`により直前のコミットに畳み込まれた。新しいコミットは作られていない）
- 差分を確認したところ、フォーマット崩れが修正され、未使用の`import os`が削除されていた
- ユーザーの追加操作なしでpushが完了した

確認後、この検証用コミットは`git reset --hard`で取り除き、`git push --force-with-lease`で本チケットの成果物のみの状態に戻した。
