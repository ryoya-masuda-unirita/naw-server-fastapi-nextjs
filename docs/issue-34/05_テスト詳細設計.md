# 05_テスト詳細設計

本チケットはツール導入であり新規テストコードはない。以下の手順で動作確認する。

## ローカルでのpre-pushフック確認手順

```bash
git config core.hooksPath .githooks
chmod +x .githooks/pre-push

# 意図的にフォーマット崩れを作る
cd backend
echo "def   foo( ):pass" >> app/routers/health.py
git add app/routers/health.py
git commit -m "test: 意図的なフォーマット崩れ"

# push（フックが自動修正しamendするはず）
git push

# 確認
git log -1 --stat   # amendされたコミットになっているか
git diff HEAD~1 HEAD -- app/routers/health.py  # health.pyの変更が消えている（差し戻された）か確認
```

上記は動作確認用の一時的な変更であり、確認後は`git reset --hard`等で元に戻す（health.pyへのテスト用変更は本チケットの成果物に含めない）。

## GitHub Actionsでの確認

```bash
git push origin feature/issue-34
gh run list --branch feature/issue-34 --limit 3
gh run view <run-id> --json jobs --jq '.jobs[] | {name, conclusion}'
```

`lint`ジョブが`success`になっていることを確認する。
