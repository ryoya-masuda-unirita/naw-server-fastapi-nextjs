# 05_テスト詳細設計

本チケットはツール導入であり新規テストコードはない。以下の手順で動作確認する。

## ローカルでのpre-commitフック確認手順

```bash
cd backend
uv sync
uv run pre-commit install

# 意図的にフォーマット崩れ・未使用importを作る
echo -e "import os\n\n\ndef   foo( ):pass" >> app/routers/health.py
git add app/routers/health.py
git commit -m "test: 意図的なフォーマット崩れ・未使用importを追加（フック動作確認用）"
# → pre-commitがruff-format/ruffで修正し、コミットは失敗するはず
# → 差分（health.pyが自動修正されていること）を確認する

git add app/routers/health.py
git commit -m "test: 意図的なフォーマット崩れ・未使用importを追加（フック動作確認用）"
# → 2回目は修正不要なので成功するはず

git push

# リモートの実態を確認する（git logだけでなくls-remoteで確認するのが重要）
git ls-remote origin refs/heads/feature/issue-34
git show <上記のSHA>:backend/app/routers/health.py
# → 修正済みの内容がリモートに反映されていることを確認する
```

上記は動作確認用の一時的な変更であり、確認後は`git reset --hard`＋`git push --force-with-lease`等で元に戻す（health.pyへのテスト用変更は本チケットの成果物に含めない）。

## GitHub Actionsでの確認

```bash
git push origin feature/issue-34
gh run list --branch feature/issue-34 --limit 3
gh run view <run-id> --json jobs --jq '.jobs[] | {name, conclusion}'
```

`lint`ジョブが`success`になっていることを確認する。
