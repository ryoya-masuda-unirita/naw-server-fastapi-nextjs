# ユーザー管理API（CRUD・プロフィール）の実装

## 概要

JWT 認証基盤（Issue #7）の次ステップとして、ユーザー管理 API を FastAPI に移植する。

## 説明

### 移植対象エンドポイント

| エンドポイント | 説明 |
|---|---|
| GET /api/admin/users | ユーザー一覧取得（ページング・検索・ロールフィルタ） |
| POST /api/admin/users | ユーザー作成（初期パスワード自動生成） |
| PATCH /api/admin/users/{userId} | ユーザー更新（名前・ロール・パスワードリセット） |
| DELETE /api/admin/users/{userId} | ユーザー削除 |
| GET /api/users/profile | ログイン中ユーザーのプロフィール取得 |
| PATCH /api/users/profile | プロフィール更新（パスワード変更） |

### 移植元

- バックエンド: `~/Documents/naw-server/src/main/java/com/example/naw/api/UserController.java`
- フロントエンド: `~/Documents/secuaigent-client/src/app/features/users/`
