# 要件定義：ユーザー管理 API（CRUD・プロフィール）

## 背景

JWT 認証基盤（Issue #7）が整備済みで、認証ユーザーの特定とロール情報が取得できる状態にある。
本 Issue では Spring Boot 版 `UserController.java` を FastAPI に移植し、管理者によるテナント内ユーザーの CRUD と、一般ユーザー自身のプロフィール参照・更新を実装する。

---

## 機能要件

### 1. ユーザー一覧取得（管理者）

- エンドポイント: `GET /api/admin/users`
- `X-Tenant-ID` ヘッダーで絞り込む（他テナントのユーザーは取得不可）
- ページング: `page`（0 始まり）・`size`・`sort` クエリパラメータ
- テキスト検索: `searchText`（`login_id` と `name` の部分一致、大文字小文字無視）
- ロールフィルタ: `role`（`USER` / `ADMIN` / `SYSTEM`、省略時は全ロール）
- グループ除外フィルタ: `excludeGroupId`（今回は受け取るが機能しない、グループ機能は別 Issue）
- レスポンス: ページング付きユーザー一覧

### 2. ユーザー作成（管理者）

- エンドポイント: `POST /api/admin/users`
- リクエスト: `loginId`（必須）・`name`（必須）・`role`（必須）・`loginKey`（任意）
- テナントのパスワードポリシーに基づいて初期パスワードを自動生成する
- `password_histories` に bcrypt ハッシュで保存する
- `is_required_password_reset = true` で作成する
- 同一テナント内に同一 `loginId` が存在する場合は 400 エラー
- レスポンス: ユーザー情報 + `initialPassword`（平文）+ `passwordExpiredAt`

### 3. ユーザー更新（管理者）

- エンドポイント: `PATCH /api/admin/users/{userId}`（`userId` = `users.login_id`）
- リクエスト: `name`・`role`・`loginKey`（すべて任意）・`resetPassword`（bool、任意）
- 指定されたフィールドのみ更新する（PATCH セマンティクス）
- `resetPassword: true` の場合: テナントポリシーに基づく新パスワードを生成し `password_histories` に追加、`is_required_password_reset = true` にセット
- レスポンス: ユーザー情報 + `initialPassword`（パスワードリセット時のみ non-null）+ `passwordExpiredAt`（同上）

### 4. ユーザー削除（管理者）

- エンドポイント: `DELETE /api/admin/users/{userId}`（`userId` = `users.login_id`）
- `password_histories` は `ON DELETE CASCADE` で連動削除
- 該当ユーザーが存在しない場合でもエラーにしない（冪等）
- レスポンス: 204 No Content

### 5. プロフィール取得（ログイン中のユーザー）

- エンドポイント: `GET /api/users/profile`
- JWT から `login_id` を取得して自分のユーザー情報を返す
- レスポンス: ユーザー情報（パスワード除く）

### 6. プロフィール更新（ログイン中のユーザー）

- エンドポイント: `PATCH /api/users/profile`
- リクエスト: `password`（任意）
- パスワード変更のみ（名前・ロール等の変更はこのエンドポイントでは不可）
- `password` が指定された場合: `password_histories` に追加し `is_required_password_reset = false` にセット
- レスポンス: ユーザー情報（パスワード除く）

---

## 非機能要件

- 全エンドポイント: JWT による認証が必要（`Authorization: Bearer <token>`）
- `/api/admin/users/**`: `ADMIN` ロールのユーザーのみアクセス可能（SYSTEM ロールも含む）
- `X-Tenant-ID` ヘッダー必須（全エンドポイント）
- パスワードは常に bcrypt でハッシュ化して保存する
- 初期パスワード生成はテナントのパスワードポリシー（`pw_policy_*` カラム）に従う

---

## スコープ外

- CSV インポート機能（`POST /api/admin/users/import`・`GET /api/admin/users/import/{jobId}`）
- フロントエンドの React 移植
- グループ機能（`excludeGroupId` フィルタ、グループ管理者権限チェック）
