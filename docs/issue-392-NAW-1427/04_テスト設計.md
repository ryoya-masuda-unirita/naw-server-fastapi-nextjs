# 04_テスト設計

## テスト方針

並べ替えの操作が画面から無くなること、一覧の取得条件が変わらないことを確かめる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 並べ替えが無い | ファイル一覧の絞り込み領域を表示する | 「並べ替え」のラベルも、並べ替えの選択肢も出ない |
| 2 | 他の絞り込みが残る | 同じ領域を表示する | 検索・更新者・期間・設定・件数・ページ送りは出る |
| 3 | 既定の並び順 | 初期状態の絞り込み条件で API パラメータを作る | `sort=updatedAt,desc` になる |
| 4 | 並べ替えの変換が残る | 並べ替えの項目を指定した条件で API パラメータを作る | 更新者名順が `userId` に変換される（これまでのテスト） |
| 5 | 画面での確認 | クラウド・ローカルの学習データ詳細を開く | 並べ替えが出ず、一覧が更新日時の新しい順で出る。絞り込み領域の並びが崩れない |
