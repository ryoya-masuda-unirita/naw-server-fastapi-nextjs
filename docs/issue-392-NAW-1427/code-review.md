## 詳細

### 1. 誤ってコミットされたバックアップファイル（🔴 致命的）→ 対応済み

`sed -i -E '...'` を使ったとき、macOS の `sed` が `-E` を「バックアップの拡張子」と読み、`06_タスクリスト.md-E` を作っていた。`git rm` で削除した。同じ手順で他にバックアップファイルが残っていないか、`git ls-files` で確認した。タスクリストの項目は、Python で書き換えてチェックし直した。

### 2. 並べ替えの条件と API 変換が残っている（🔵 提案）→ 対応済み

意図して残している。移植元の NAW-1427 も、並べ替えを作り直すときのために、一覧の条件・既定の並び順・API への変換を暫定対応として残した。ただし理由がコードに書かれていないと、不要コードに見える。`mapFileSortFieldToApi` のコメントに理由（NAW-1427、移植元と同じ暫定対応）を書いた。削除はしない。

### 3. テストの書き方（🔵 提案）→ 対応済み

`prettier` を設定なしで実行したため、ダブルクォートになっていた。隣のファイルと同じ `--single-quote --print-width 100` で整形し直した。

### 4. describe 名と初期の `sort` の確認（🔵 提案）→ 一部対応

- describe 名を `検索と絞り込み` に直した。中身は検索と学習設定の絞り込みのテストで、並べ替えのテストは無かった。
- 初期の取得条件が `sort=updatedAt,desc` であることは、`training-data-detail.test.tsx` の既存テスト（初期の取得条件が page 0・size 10・更新日時の降順であること）が確かめている。テストの追加は不要と判断した。`08_動作確認.md` にその旨を書いた。
