# 05_テスト詳細設計

## 対象ファイル

| ファイル | 内容 |
|---|---|
| `frontend/src/components/features/admin/training-data/training-data-filters.test.tsx`（新規） | No.1・2。`TrainingDataFilters` を描画する |

## テストケース

- テスト名は英語、意図は日本語の docstring（`/** */` コメント）で書く（`test('does not render a sort input', ...)` など）
- No.1: `getByText('並べ替え')` が無いこと、`data-testid` が `training-data-file-sort` で始まる要素が無いことを確かめる
- No.2: 検索入力・ページ送り・件数の表示が出ることを確かめる（残した部品が消えていないことの確認）
- i18n は既存のテストと同じ初期化を使う。props は最小の固定値で渡す

## 確認方法

- `cd frontend && npx vitest run src/components/features/admin/training-data`
- 並べ替えを外す前のコードでは、No.1 が失敗することを確かめてから実装する（テストが機能していることの確認）
