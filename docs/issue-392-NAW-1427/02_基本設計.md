# 02_基本設計

## 変更対象

- 学習データ詳細のファイル一覧の絞り込み領域（並べ替えの操作がある部分）
- その絞り込み領域を使う、ファイル一覧の画面
- 並べ替えの操作に関するテスト

## 画面 / API 変更概要

- 画面: 絞り込み領域から「並べ替え」のラベルと選択肢を外す。他の絞り込み・ページ送りの並びは崩さない
- API: 変更しない。並べ替えの指定は、これまでの既定（更新日時の新しい順）のまま送る
- 並べ替えの項目と API への変換は、画面から呼ばれなくなっても残す

## 影響範囲

- 利用者: 並べ替えの操作がなくなる。一覧の並びは、既定の更新日時の新しい順で固定される
- 他の画面: 並べ替えの操作は他の一覧と共通部品を使っているが、共通部品は変更しない
- 並べ替え用の表示文言: 他で使われていなければ、使われなくなったコードとして扱いを決める（残す理由は暫定対応のため）

## 移植方針

- 移植元と同じく、画面から操作だけを外し、条件・既定の並び順・API への変換は残す
- 並べ替えの操作を前提にしていたテストは、「並べ替えの選択肢を持たないこと」を確かめるテストに置き換える
- 未確認: 並べ替え用の表示文言とラベルを、削除するか残すか。移植元が文言を残しているかは、設計承認後の詳細設計で確認する
