# 学習データ詳細のファイル一覧から並べ替えを外す（NAW-1427）

## 概要

学習データ詳細画面のファイル一覧にある「並べ替え」の操作を画面から外す。

## 説明

- GitHub Issue: #392
- 移植元チケット: NAW-1427（関連: NAW-1428）
- 移植元の理由:
  - クラウドの「更新者名順」は server が users.id（UUID）で並べるため、名前の順にならない
  - ローカルはローカル用サーバーが並べ替えを受け取らないため、どれを選んでも順が変わらない
  - 並べ替えはもともと無かった機能という開発メンバの判断に従い、効かない操作を画面から外す
- 移植元は、一覧の条件・既定の並び順（クラウドは更新日時の新しい順）・API への変換を、並べ替えを作り直すときのために暫定対応として残している
- 参照コミット: a6ccdd30e, e949b95b4（`secuaigent-ref`）
