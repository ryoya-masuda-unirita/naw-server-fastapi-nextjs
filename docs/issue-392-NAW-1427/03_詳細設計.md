# 03_詳細設計

## 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `frontend/src/components/features/admin/training-data/training-data-filters.tsx` | 「並べ替え」のラベルと `FormSortInput` を外す。並べ替え用の props（`sortOptions` `sortField` `sortOrder` `onSortFieldChange` `onSortOrderChange`）と、`FormSortInput`・`SortOption` の import を削除する |
| `frontend/src/components/features/admin/training-data/training-data-files-view.tsx` | `SORT_OPTIONS` と、`TrainingDataFilters` に渡していた並べ替えの props・ハンドラ、使われなくなる import（`SortOption` `TrainingDataFileSortField`）を削除する |
| `frontend/public/i18n/ja.json`・`en.json` | `LEARNING_DATA.SORT_UPDATED_BY`・`LEARNING_DATA.SORT_LEARNING_STATUS` を削除する |

## 変更しないもの（暫定対応として残す）

- `training-data-files-helper.ts` の `mapFileSortFieldToApi` と `toFileListApiParams` の sort 変換
- `training-data.types.ts` の `TrainingDataFileSortField` と、フィルターの `sortField` / `sortOrder`
- `training-data-store.ts` の初期値（`updatedAt` / `desc`）。API には `sort=updatedAt,desc` が送られ続ける
- `LEARNING_DATA.SORT_LABEL`・`LEARNING_DATA.SORT_UPDATED_AT`: フォルダ一覧（`routes/admin/training-data/training-data.tsx`）が使っているため残す
- 共通部品 `FormSortInput`: 他の一覧が使っているため変更しない

## 注意点

- 並べ替えのラベルと入力を外すと、絞り込み領域の並びが詰まる。折り返しの崩れがないかを画面で確認する
- `SORT_OPTIONS` の固定文言「学習データの表示名順」は、`SORT_OPTIONS` ごと消える
- #375（PR #379）は同じ `training-data-files-view.tsx` と `training-data-filters.tsx` の近くを触る。コンフリクトは、後からマージする側で解消する
- `SORT_LEARNING_STATUS` は、#375 の学習設定の削除でも触る可能性がある。先に消えていても、このPRの変更は影響を受けない
