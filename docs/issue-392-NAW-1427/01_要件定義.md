# 01_要件定義

## 背景

学習データ詳細のファイル一覧には並べ替えの操作があるが、選んでも順が変わらない、または名前の順にならない選択肢が含まれる。移植元は、効かない操作を利用者に見せないため、並べ替えを画面から外した。こちらの React 版は並べ替えの操作が残っているので、移植元に揃える。

## 機能要件

- 学習データ詳細のファイル一覧に、並べ替えの操作（項目・昇順降順の選択）を表示しない
- ファイル一覧の並び順は、これまでの既定のとおり更新日時の新しい順にする
- 一覧の絞り込み（検索・期間・更新者・設定）とページ送りは、これまでどおり使える
- クラウド・ローカルのどちらのフォルダでも、同じ画面にする

## 非機能要件

- 並べ替えを作り直すときに使えるよう、一覧の条件の並べ替えの項目と、API への変換は残す（移植元と同じ暫定対応）
- 既存の画面の表示と操作を、並べ替えの操作以外は変えない

## スコープ外

- 並べ替えの再実装、更新者名順の修正（NAW-1428）
- 学習設定の列・絞り込みの削除（#375 で扱う）
- ローカルのフォルダのファイル操作（#390 で扱う）
