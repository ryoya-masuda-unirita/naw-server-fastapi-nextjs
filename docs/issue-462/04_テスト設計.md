# 04_テスト設計

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1〜7 | 分割（移植元と同じ） | 短い文・区切り・分割長の超過・長い文・末尾の区切り・途中の空・空の文章 | 移植元の `ContentSplitter` と同じ結果 |
| 8 | 分割長の検証 | 未指定・空・100・10000・99・10001・0・負・数値でない・空白・全角 | 範囲内は整数、それ以外は 400 |
| 9 | テキストの取り出し | UTF-8・BOM・Shift_JIS・HTML・未対応形式・文字コード不明 | 取り出せる／400 |
| 10 | 登録のベクトル化 | 3 部分に分かれる文章を登録 | 3 回埋め込み、`add_rows` が 1 回（`fileid`・内容・順序）、`TokenUsage` に合計トークンと種別 |
| 11 | 既定の分割長 | `splitLength` を省略 | 既定の 1000 で、短い文章は 1 部分 |
| 12 | 不正な分割長 | 99・10001・abc | 400。埋め込み・保存・ファイル・ストレージが残らない |
| 13 | 未対応形式 | PDF | 400。ストレージ・記録が残らない |
| 14 | 埋め込みの失敗 | Bedrock が失敗 | 400。ストレージ・記録・使用量が残らず、後始末（ベクトル削除）が呼ばれる |
| 15 | 保存の失敗 | `add_rows` が失敗 | エラー。ストレージ・記録が残らず、後始末が呼ばれる |
| 16 | 従来どおり（pgvector でない） | VDB が https | 記録だけ作られる |
| 17 | 従来どおり（埋め込みなし） | 埋め込みの接続先がない | 記録だけ作られる |
| 18 | 空のファイル | 中身が空 | 記録だけ作られ、ベクトルは保存されない |
| 19 | 削除 | 登録済みファイルを物理削除 | ファイルの ID でベクトルが削除される |
| 20 | 削除の失敗 | ベクトルの削除が失敗 | 400。ファイルとストレージが残る |
| 21 | 差し替え | ファイルを添付して更新 | 古い ID のベクトルが削除され、新しい ID のベクトルが保存される |
| 22 | メタデータだけの更新 | 表示名だけ更新 | ベクトルに触れない |
| 23 | 回帰 | 既存のテストをすべて実行する | 既存のファイル・インデックスのテストの結果が変わらない |
