# 03_詳細設計

## 変更対象ファイル

| ファイル | 変更 |
|---|---|
| `server/app/core/file_vectorization.py`（新規） | `validate_split_length`・`split_content`（移植元 `ContentSplitter` の移植）・`extract_text`（Tika の代わり。テキスト系）・`resolve_vdb`・`resolve_target`・`delete_vectors`・`FileVectorizer`（`add`・`remove`）・`build_vectorizer` |
| `server/app/core/file_creation.py` | `create_file_record` に、任意の引数 `vectorizer` を足す。ストレージへの保存のあと、DB に記録する前に `vectorizer.add` を呼ぶ。失敗したら、ストレージを消し、`vectorizer.remove` を呼ぶ |
| `server/app/services/file_service.py` | `create_file`・`update_file`（置換）で、分割長を検証し、`build_vectorizer` を作って渡す。`delete_file` で、ストレージ・DB より先に、ベクトルを消す |
| `server/tests/unit/test_file_vectorization.py`（新規） | 分割・検証・取り出しのテスト |
| `server/tests/integration/test_file_vectorization_api.py`（新規） | 登録・失敗・差し替え・削除の API のテスト |

追加学習（`index_service` の `additionalLearning`）の `create_file_record` の呼び出しは、`vectorizer` を渡さないので、変わらない。

## 流れ（登録）

1. `validate_split_length(form.split_length)`（範囲外・数値でないなら 400）
2. インデックスの確認・クレジットの確認（既存）
3. `build_vectorizer`: `resolve_target` が、pgvector の VDB 接続先（`find_by_tenant_id_and_type(VDB)` の id が最小、RAG の検索と同じ選び方）と、フォルダの埋め込みの接続先（`AZURE_OPENAI_EMBEDDING`・`BEDROCK_EMBEDDING` の id が最小）を返す。どちらかがなければ `None`（従来どおり）
4. `create_file_record`: ストレージに保存 → `vectorizer.add` → DB に記録
5. `vectorizer.add`: `extract_text` → `split_content` → 空でない部分ごとに埋め込み（Bedrock か Azure）→ `PgVectorStoreClient.add_rows`（表がなければ作る）→ `TokenUsage` を追加（コミットは、DB への記録と同時）
6. 失敗: ストレージを削除し、`vectorizer.remove`（`delete_by_file_id`。失敗しても、元のエラーを隠さない）

## 削除・差し替え

- `delete_file`: `resolve_vdb` があれば、`delete_vectors` を先に呼ぶ。失敗したら 400 で止まり、ストレージも DB も変わらない（やり直せる）
- `update_file`（ファイルを添付）: 既存の「古いファイルを物理削除 → 新規作成」の流れで、削除でベクトルが消え、新規作成でベクトルが入る。メタデータだけの更新は、ベクトルに触れない

## 分割（`split_content`）

移植元と同じ。区切り `[。.!?！？]` で文に分け（末尾の空の要素は捨てる）、現在の部分の長さ＋次の文の長さが分割長を超えたら、現在の部分を確定する。分割長を超える文は、分割長ごとに強制的に分ける。つないだ文の後ろには `。` を付ける。

## 取り出し（`extract_text`）

- 対応: 拡張子が `.txt .md .markdown .csv .tsv .json .xml .html .htm .log .yaml .yml .ini .conf .rst`、または Content-Type が `text/*`・JSON・XML・YAML・CSV
- 文字コード: UTF-8（BOM 可）→ CP932（Shift_JIS）の順
- HTML・XML は、タグを除いた本文
- それ以外は、`このファイル形式のテキストは取り出せません…` で 400
