# クラウドの学習データ登録で、分割・埋め込み・ベクトルの保存を行う

## 概要

クラウド側の `server/` で、学習データのファイル登録（POST `/api/admin/indexes/{indexId}/files`）に、テキストの取り出し → 分割 → 埋め込み → ベクトルの保存を行う処理を足す。差し替え（PATCH でファイルを添付）と削除（DELETE）でも、ベクトルを入れ替え・削除する。クラウドの RAG を Bedrock だけで動かすための 3 つ目（#460 → #461 → #462）。

## 説明

- 移植元の `FileService.createFile` は、ファイルのテキストを取り出し（Tika）、分割長（100〜10000、既定 1000）で分割し、埋め込みを作ってベクトルストアに保存し、埋め込みのトークンをクレジットに数え、`FilePart` を記録する。失敗すると、保存したストレージの実体を消す
- 移植先の `FileService.create_file` は、ファイルの記録とストレージへの保存だけで、ベクトル化・保存は未移植（`core/file_creation.py` に、スコープ外の注記がある）。そのため、クラウドのフォルダに追加しても、検索の対象になるベクトルができない
- #460（Bedrock の埋め込み）と #461（pgvector の保存・検索）で、部品はそろった

## その他
