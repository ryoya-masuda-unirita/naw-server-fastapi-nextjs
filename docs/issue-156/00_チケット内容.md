# フィードバック「回答数一覧」タブがTypeErrorでクラッシュする（feedbackUserのレスポンス構造が移植元と不一致）

## 概要

管理画面のフィードバック →「回答数一覧」タブを開くと、画面が TypeError でクラッシュする。
backend の `GET /api/admin/feedbackUser` のレスポンス構造が移植元(Spring Boot)と異なり、
frontend が期待する `feedbacks` ラッパーが欠落しているため。

## 説明

- frontend は `data.feedbacks.totalPages` を参照するが、backend の `feedbackUser` は
  `feedbacks` でラップせず `{content, totalElements, number, size}` を直接返しているため
  `data.feedbacks` が undefined になり TypeError
- 移植元 Spring Boot の `FeedbackController` では `feedbackUser`・`feedbackMessage`・
  `feedbackRoom` の3APIすべてが `feedbacks` でラップして返しているが、
  FastAPI移植では **feedbackUser だけラッパーが漏れている**
- さらに、feedback系3APIとも `totalPages`・`numberOfElements` を返しておらず、
  frontendの `totalPages ?? 1` が常に1になるため**ページ送りが機能しない**
  （回答精度評価・チャット満足度タブはラッパーがあるためクラッシュはしないが、同じ理由で
  ページ送りは機能していない）
- 対応: `feedbackUser` に `feedbacks` ラッパーを追加し、feedback系3APIすべてに
  `totalPages`・`numberOfElements` を追加する
