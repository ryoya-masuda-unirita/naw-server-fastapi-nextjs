# 08_動作確認

## 確認環境

- `docker compose` で稼働中のPostgreSQL・Redis・backend・frontend-angularを使用
- 確認方法: AIエージェントが`curl`でAPIを直接呼び出して確認した

## 確認結果

### Step 1: feedbackUser（クラッシュしていたAPI）

```
GET /api/admin/feedbackUser?page=0&size=5
```

```json
{"feedbacks": {"content": [...], "totalElements": ..., "number": 0, "size": 5,
                "totalPages": ..., "numberOfElements": ...}}
```

✅ `feedbacks` ラッパーが付与され、frontendが参照する `data.feedbacks.totalPages` が
   存在する構造になった

### Step 2: feedbackMessage・feedbackRoom（totalPages/numberOfElements追加）

```
GET /api/admin/feedbackMessage?page=0&size=1
  → feedbacks: {totalElements: 3, number: 0, size: 1, totalPages: 3, numberOfElements: 1}

GET /api/admin/feedbackRoom?page=0&size=1
  → feedbacks: {totalElements: 3, number: 0, size: 1, totalPages: 3, numberOfElements: 1}
```

✅ 既存の `feedbacks` ラッパーは維持したまま、`totalPages`・`numberOfElements` が
   正しい値で追加された（`totalElements=3, size=1` → `totalPages=3`）

### Step 3: frontend-angular のプロキシ経由での確認

```
200  GET localhost:4201/api/admin/feedbackUser?page=0&size=5
     feedbacksキー有無: True / totalPages: 1
```

✅ frontend-angular（コンテナ）→backend のプロキシ経由でも同様の構造で返ることを確認した
