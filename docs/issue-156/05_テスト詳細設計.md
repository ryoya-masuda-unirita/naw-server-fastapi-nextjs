# 05_テスト詳細設計

## `backend/tests/integration/test_feedback.py` の変更

既存の `TestGetFeedbackUsers`・`TestGetFeedbackUsersPermission`・`TestTenantIsolation`
（feedbackUser関連）内の `response.json()["content"]` を全て
`response.json()["feedbacks"]["content"]` に置き換える。

```python
# 変更前
content = response.json()["content"]

# 変更後
content = response.json()["feedbacks"]["content"]
```

`test_paginates_results`（feedbackUser）・`test_paginates_feedback_messages`・
`test_paginates_feedback_rooms` にはそれぞれ以下を追加する。

```python
assert body["totalPages"] == <期待値>
assert body["numberOfElements"] == <期待値>
```

具体的な期待値は各テストのデータセット件数・`size`から算出する
（例: `totalElements=6, size=1` → `totalPages=6, numberOfElements=1`）。
