# 02_基本設計

## 変更対象

- `backend/app/schemas/feedback.py`（レスポンススキーマ）
- `backend/app/routers/feedback.py`（`feedbackUser` の response_model・戻り値型）
- `backend/app/services/feedback_service.py`（3APIすべてのレスポンス構築ロジック）

## 画面 / API変更概要

- APIのパス・リクエストパラメータは変更しない
- `feedbackUser` のレスポンスがトップレベルで `feedbacks` にラップされる形に変わる
  （`{content, ...}` → `{feedbacks: {content, ...}}`）
- feedback系3APIすべてのページング部分に `totalPages`・`numberOfElements` フィールドが増える
  （既存フィールドの削除・変更はない）

## 影響範囲

- フィードバック管理画面の3タブ（回答精度評価・チャット満足度・回答数一覧）

## 移植方針

- 移植元(Spring Boot)の `FeedbackController` が3APIとも `Map.of("feedbacks", result)` 等で
  ラップしている構成に `feedbackUser` を合わせる
- `totalPages`・`numberOfElements` は、既存の `PagedUserResponse`／`user_service.py` で
  採用済みの計算式（`math.ceil(totalElements / size)`）をそのまま踏襲する
