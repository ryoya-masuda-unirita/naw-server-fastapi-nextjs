# 03_詳細設計

## 変更対象ファイル一覧

### 変更

| ファイル | 変更内容 |
|---|---|
| `backend/app/schemas/feedback.py` | `PagedFeedbackUserResponse`/`PagedFeedbackMessageResponse`/`PagedFeedbackRoomResponse` に `totalPages`・`numberOfElements` を追加。`feedbackUser` 用の `FeedbackUserListResponse`（`feedbacks`ラッパー）を新規追加 |
| `backend/app/routers/feedback.py` | `get_feedback_users` の `response_model`・戻り値型を `PagedFeedbackUserResponse` → `FeedbackUserListResponse` に変更 |
| `backend/app/services/feedback_service.py` | 3メソッドすべてで `totalPages`・`numberOfElements` を計算して設定。`get_feedback_users` は `FeedbackUserListResponse` でラップして返す |
| `backend/tests/integration/test_feedback.py` | 3APIのレスポンス構造・ページング値を検証するテストを追加/更新 |

## 詳細

### `backend/app/schemas/feedback.py`

- `PagedFeedbackUserResponse`・`PagedFeedbackMessageResponse`・`PagedFeedbackRoomResponse` に
  以下2フィールドを追加する（既存フィールドの並び後ろに追加、破壊的変更なし）
  ```python
  totalPages: int
  numberOfElements: int
  ```
- `feedbackUser` 用に新規クラスを追加する（既存の `FeedbackMessageListResponse`・
  `FeedbackRoomListResponse` と同じ形）
  ```python
  class FeedbackUserListResponse(BaseModel):
      feedbacks: PagedFeedbackUserResponse
  ```

### `backend/app/routers/feedback.py`

- import を `PagedFeedbackUserResponse` → `FeedbackUserListResponse` に変更
- `get_feedback_users` の `response_model` と戻り値型アノテーションを
  `FeedbackUserListResponse` に変更

### `backend/app/services/feedback_service.py`

- 共通のページ数計算 `total_pages = math.ceil(total / query.size) if query.size > 0 else 0`
  を3メソッドそれぞれに追加する（既存の `user_service.py` と同じ式。`services/` 間の呼び出し
  規約上、共通関数化は行わず各メソッドで計算する）
- `get_feedback_users`:
  - `PagedFeedbackUserResponse` 構築時に `totalPages=total_pages`・
    `numberOfElements=len(content)` を追加
  - 戻り値を `PagedFeedbackUserResponse` から `FeedbackUserListResponse(feedbacks=...)` に変更
- `get_feedback_messages`・`get_feedback_rooms`:
  - `PagedFeedbackMessageResponse`・`PagedFeedbackRoomResponse` 構築時に同様に
    `totalPages`・`numberOfElements` を追加（ラッパー自体は変更なし）

## 移植元との対応整理

| 移植元 (Spring Boot) | FastAPI |
|---|---|
| `FeedbackController#getFeedbackUser` の `Map.of("feedbacks", result)` | `FeedbackUserListResponse(feedbacks=...)` |
| Spring Data `Page<T>` の `totalPages`・`numberOfElements` | `math.ceil` による算出・`len(content)` |
