# 03_詳細設計

## `lib/chat/library-content-api.ts`（新規）

```
fetchLibraryBody(libraryId, assistant)
  assistant なし                → NAW GET /api/libraries/{id}/content
  resolveAssistantEndpoint:
    naw     → 同上
    invalid → throw Error('Invalid library content endpoint: {reason}')
    local   → findSecureLocalEndpoint の destination が空なら throw（missing_destination）
              GET {destination}/api/libraries/{id}/content
              headers: X-Server-Auth-Key、skipGlobalErrorToast: true
  戻り値: response.data ?? ''

fetchLibraryContent(libraryId)
  GET /api/libraries/{id}（タイトル・assistant）→ fetchLibraryBody → { title: title ?? '', data }
```
