# 04_テスト設計

## テスト方針

自動テスト（Vitest + MSW）と、実物の server-local（`onprem/`）に対する手動の通しテストで確認する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | ライブラリ本文（NAW） | アシスタントなし／SAAS_CHAT／本文なし | NAW の `data` を返す（なければ空文字） |
| 2 | ライブラリ本文（SECURE） | LOCAL_SERVER あり | ローカルの URL へ `X-Server-Auth-Key` 付きで取得 |
| 3 | ライブラリ本文（不正） | endpoints が空 | `Invalid library content endpoint: no_endpoint` |
| 4 | ライブラリ詳細＋本文 | タイトルあり／null | タイトルとローカル（NAW）の本文。null は空文字 |
| 5 | 通し：preflight | Origin 付き OPTIONS | `x-server-auth-key` を許可 |
| 6 | 通し：送信 | SECURE アシスタントで送信 | server-local の SSE が回答になる（Echo） |
| 7 | 通し：読み込み | ルームを開き直す | `POST /api/messages/contents` で本文を取得し user/assistant が復元 |
| 8 | 通し：認証キー違い | 違うキーでライブラリ本文 | 401（`ApiError`） |

送信・本文取得・トークンなし・接続情報不正は #283 の `store/messages-store.test.ts` で網羅済み。
