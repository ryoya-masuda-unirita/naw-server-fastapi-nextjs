# 02_基本設計

## 変更対象

- バックエンドの自動デプロイフロー（マイグレーション自動実行ステップの追加）
- バックエンドのコンテナイメージ（マイグレーション実行に必要な定義一式を含める）
- デプロイに使う実行ロールの権限（一時的なタスク実行、および関連するロール受け渡しの権限）
- シードデータ投入手順のスクリプト化（既存の手動手順を1本の実行可能スクリプトに集約）
- インフラ運用ドキュメントの更新（手動手順からスクリプト実行手順への置き換え）

## 画面 / API 変更概要

- 画面・APIの変更はなし（インフラ・CI/CD・運用スクリプトのみの変更）

## 影響範囲

- バックエンドの自動デプロイ所要時間（マイグレーション実行分、若干増加する）
- バックエンドコンテナイメージの内容（マイグレーション実行に必要な定義一式を追加するため、イメージサイズが微増する）
- 単一インスタンス構成のコンピューティングリソース（常時稼働中のサービスと、一時的なマイグレーション実行が同時に載る瞬間が発生するため、リソース不足によるスケジューリング失敗の可能性を考慮し、一時実行側のリソース割り当ては小さく抑える）
- デプロイ実行ロールの権限範囲（一時的なタスク実行権限が追加される）

## 移植方針

本Issueは移植（Spring Boot/Angularからの機能移植）ではなく、このリポジトリ独自のCI/CD・インフラ運用の改善のため、対応する移植元は無い。
