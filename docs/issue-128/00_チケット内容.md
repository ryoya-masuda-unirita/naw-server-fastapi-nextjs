# グループ管理 詳細画面をReactに移植する

## 概要

グループ（チーム）管理 詳細画面（`/admin/groups/:id`。所属ユーザー・所属アシスタント・所属テンプレートの 3 タブ）を Angular（`secuaigent/client` の `features/admin/management/group-list/group-detail/`）から React（`frontend/`）に移植する。Issue #128。

## 説明

- 対象: `group-detail.component`（シェル・ヘッダーのメニュー・編集/削除ダイアログ）、`group-detail-users`／`-assistants`／`-templates` とそれぞれの filter・table、`group-users.store`／`group-assistants.store`／`group-templates.store`、各 `*-api.service`、`group-api.mappers`
- スコープ外: `/admin/groups/:id/members`（legacy）は #293
- 土台は #277（ルート・ガード）・#278（共通 UI）・#279（API パス・型）。作りは #124・#125・#122・#127・#136 の完成例に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）

## その他

- 移植先は Issue 本文の `routes/app/admin/groups/` ではなく、#277 の仮ファイル `frontend/src/routes/admin/groups/group-detail*.tsx`（export 名は維持）
- Issue 本文の `~/Documents/secuaigent-client` は古い。移植元は `~/Documents/unirita-develop-pj/secuaigent-ref/client`
