# 04_テスト設計

| 観点 | 内容 |
|---|---|
| シェル | チーム名の見出し・タブの並び・タブ切替で URL が変わる・`/templates` 直開きでタブが選ばれる |
| 編集 | 名前変更が PATCH される（trim）・空／101 文字はエラーで送信しない・失敗でトーストとダイアログ残し |
| 削除 | 確認 → DELETE → 一覧へ戻る。グループ管理者には削除メニューが出ない |
| 所属ユーザー | 表示（権限・クレジット・「—」）・初期クエリ・検索・自分の行のメニュー不可・権限変更・個別削除・選択削除（自分を除く）・追加（候補は `excludeGroupId`） |
| 所属アシスタント | 表示（サーバー・モデル・カテゴリ・履歴・追加日時）・初期クエリ・個別削除・追加 |
| 所属テンプレート | 表示・検索・選択削除・追加 |
| マッパー・util | `parseSpringPage`・`mapGroup*`・`matchesCurrentUser` |
