# 03_詳細設計

## 判断と理由（移植元を正としたうえで、React で変えた点）

1. **タブを離れたら条件・選択を捨てる**: 移植元の store は `providedIn: 'root'` で、同じグループなら条件が残る。一方フィルター部品は自分の検索語・並べ替えを持っていて、戻ると空に戻る（検索欄は空なのに前回の絞り込みが効く不整合が起きる）。#122 の一覧と同じく、離れる・グループが変わる時点で `reset()` する
2. **システムプロンプトはテキストで出す**: 移植元は `[innerHTML]`（Angular が危険な要素を除いて HTML として出す）。React では HTML として解釈せず、文字列のまま `whitespace-break-spaces` で出す（XSS を避ける。`<tag>` を含むプロンプトも見える）
3. **取得中のスピナー**: 移植元は読み込みのたびに `isLoading`。`isFetching` を使い、追加・削除後の読み直しでもスピナーが出る
4. **変更後の読み直し**: 移植元の `await load()` に合わせ、`onSuccess` で `invalidateQueries` の Promise を返し、`mutateAsync` が読み直しの完了を待つ。トースト・ダイアログ閉じはその後
5. **削除の `Promise.all`**: 1 件でも失敗したら全体を失敗として扱い、読み直しも選択解除もしない（移植元と同じ）
6. **行の削除ボタンのクリックが行の選択も切り替える**: 移植元の `app-table-list-item` は行クリックで選択を切り替え、削除アイコンは `stopPropagation` しない。共通部品 `TableListItem` も同じ作りなので、そのまま揃えた
7. **`animate-fade-in`**: 移植元でも CSS に定義がなく何も起きないクラス。見た目に影響しないが、クラス名は移植元どおり残した
8. **所属用語辞書の列**: 移植元でもコメントアウトされているため出さない。情報ブロック（`INFO_TITLE`）も同じ

## API

| 用途 | メソッド・パス | 備考 |
|---|---|---|
| 詳細 | `GET /api/admin/groups/{id}` | 失敗したら名前は空 |
| 更新 | `PATCH /api/admin/groups/{id}` `{ name }` | |
| 削除 | `DELETE /api/admin/groups/{id}` | 204 |
| 所属ユーザー | `GET .../users?page&size&searchText&role&sort&includeUsage=true` | `role` は `ADMIN`／`USER`。応答 `PagedGroupMemberResponse`（`number` あり） |
| 追加・権限・削除 | `POST .../users {userIds}`・`PATCH .../users/{id} {groupAdmin}`・`DELETE .../users/{id}` | 204 |
| 所属アシスタント | `GET .../assistants?page&size&search&type&categoryId&sort` | `sort` は `addedAt`／`name`／`server`／`category`（backend 対応済み） |
| 所属テンプレート | `GET .../prompt-templates?page&size&search&sort` | `sort` は `addedAt`／`name` |
| 追加の候補 | `GET /api/admin/users`（`searchText=&role=` 必須）・`/api/admin/assistants`・`/api/admin/prompt-templates` | すべて `excludeGroupId`・size 50 |
| カテゴリの選択肢 | `GET /api/admin/assistant-categories` | 既存の `useAssistantCategories` |

backend の size 上限は 100（グループ内の一覧）。画面は 25 件なので問題ない。

## 入力チェック

- チーム名: 空文字は required、101 文字以上は maxlength。空白だけの値は通り、送信時の trim で空になる（移植元の `Validators` と同じ。#122 と共通の `validateGroupName`）
- 自分自身の降格: ラジオに「管理者」しか出さない。念のため送信時にも `CANNOT_DEMOTE_SELF` を出す

## 自分自身の判定

`matchesCurrentUser`（移植元 `auth.helpers`）。行の `id`・`userId`・`name`・`displayName` のいずれかが、ログインユーザーの `id`・`name` と一致すれば自分。
