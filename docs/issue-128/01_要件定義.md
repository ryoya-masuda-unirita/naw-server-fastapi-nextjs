# 01_要件定義

## 目的

チーム詳細画面を移植元と同じ見た目・文言・操作・入力チェックで React に移す。

## 機能要件

### シェル（`/admin/groups/:id`）

- ヘッダーにチーム名（`GET /api/admin/groups/{id}`）と、所属ユーザー／所属アシスタント／所属テンプレートの 3 タブ（URL の最後の区間で選択。`/admin/groups/:id` は `/users` へ移る）
- モバイルは戻るボタンでチーム一覧へ
- 右上の編集アイコンのメニュー: 「チームの設定を編集」、グループ管理者だけのユーザー（`isGroupAdminOnly`）には出さない「チームを削除」
- 編集ダイアログ: 名前必須・100 文字以内。保存時に trim。成功・失敗はトースト
- 削除は確認ダイアログ → 成功したらトーストを出して一覧へ

### 所属ユーザー

- 検索・権限（全て／チームの管理者／一般）・並べ替え（追加日時・表示名・権限、昇順/降順）・上のページ送り・下のページ送り。1 ページ 25 件
- 表: 表示名・権限・請求期間内クレジット（無ければ「—」）。行のチェックボックス・全選択
- 行のメニュー（権限の編集・ユーザーを削除）。ログインユーザー自身の行はメニュー不可
- 追加: 未所属ユーザー（最大 50 件）の複数選択ダイアログ。選ぶまで「追加」不可
- 権限編集: 一般／管理者のラジオ。自分自身の降格は不可
- 削除: 確認ダイアログ。選択削除では自分自身を除く

### 所属アシスタント

- 検索・接続サーバー・カテゴリ・並べ替え（追加日時・名前・サーバー・カテゴリ）。1 ページ 25 件
- 表: 表示名と説明・サーバー・AIモデル・カテゴリ・履歴共有・追加日時。行の削除ボタン、選択削除
- 追加: 未所属アシスタント（最大 50 件）の複数選択ダイアログ

### 所属テンプレート

- 検索・並べ替え（追加日時・名前）。1 ページ 25 件
- 表: 名前と説明・システムプロンプト・更新日時。行の削除ボタン、選択削除
- 追加: 未所属テンプレート（最大 50 件）の複数選択ダイアログ

## 非機能要件

- 文言は i18n 辞書を使う（キーは追加しない）
- backend の応答の形の差は `docs/issue-279/api-backend-diff.md` を参照（このチケットで使う `GroupMemberUserResponse` の `loginKey` は読まない）
