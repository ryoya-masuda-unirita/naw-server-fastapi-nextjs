## 移植元との対応

| 移植元（Angular） | React |
|---|---|
| `GroupDetailComponent`（`router-outlet`） | `GroupDetailPage`（`<Outlet />`）。子ルートは #277 で定義済み |
| `GroupXxxStore`（signalStore、API 呼び出し込み） | Zustand（条件・選択）＋ TanStack Query（一覧・変更） |
| `MatDialog` + `DialogComponent` | 共通 `Dialog`（開いている間だけ描画） |
| `DropdownService` のヘッダーメニュー | `dropdownService` ＋ `position: fixed` のメニュー |

## 共通ファイルへの変更

- `hooks/use-group-list.ts`: `GROUP_LIST_QUERY_KEY`・`GROUP_OPTIONS_QUERY_KEY` を export（詳細の変更後に一覧のキャッシュを捨てるため）
- `components/features/admin/groups/group-add-dialog.tsx`: 入力チェックを `group-name-validation.ts` へ切り出して共有（挙動は変えない）
- `mocks/handlers/admin-groups.ts`: `GET /api/admin/groups/:groupId` の既定の応答を追加
