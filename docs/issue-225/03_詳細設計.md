# 03_詳細設計

## 新規: `backend/app/core/sort.py`

Spring Data の `SortHandlerMethodArgumentResolver`（Pageable の `sort` 解釈）に相当する共通処理。複数の router・repository から使う純粋な計算処理なので `core/` に置く。

- `SortOrder`（frozen dataclass）: `property: str`、`descending: bool`
- `parse_sort(sort: str | Sequence[str]) -> list[SortOrder]`
  - 各値を `,` で分割し、前後の空白を除いて空の要素を捨てる
  - 最後の要素が `asc` / `desc`（大文字小文字無視）なら方向とし、残りをキーとする。それ以外ならすべてキー・昇順
  - キーが残らない値は無視する
- `sort_query(default: str) -> Callable[..., list[SortOrder]]`
  - FastAPI の `Depends` に渡す依存関数を返す。クエリパラメータ `sort: list[str] = Query([default])` を受け、`parse_sort` の結果が空なら `parse_sort(default)` を返す
  - 既定値が OpenAPI に表示されるよう、`Query` の既定値にも `default` を使う
- `build_order_by(orders, columns, *, fallback, tie_breaker, tie_breaker_ascending=False) -> list[Any]`
  - `columns.get(order.property, fallback)` を各 order の方向で並べる
  - 最後に `tie_breaker` を加える。方向は先頭 order と同じ（`tie_breaker_ascending=True` なら常に昇順）
  - `orders` が空なら、最終キーは昇順
- `find_order(orders, property) -> SortOrder | None`: 指定キーの最初の order を返す（利用クレジット順の判定用）

## 変更: `backend/app/core/credit_quota.py`

- `is_sort_by_total_credits(orders: Sequence[SortOrder]) -> bool`: いずれかの order が `totalCredits` なら True（移植元 `isSortByTotalCredits` の `anyMatch` と同じ）
- `validate_total_credits_sort(orders, include_usage)`: 引数を `list[SortOrder]` に変更

## router（`sort: str = Query(...)` → `sort: list[SortOrder] = Depends(sort_query(既定値))`）

| ファイル | エンドポイント | 既定値 |
|---|---|---|
| `routers/users.py` | `GET /api/admin/users` | `created_at,desc` |

| `routers/groups.py` | `GET /api/admin/groups/{group_id}/users` | `name,asc` |
| `routers/groups.py` | `.../assistants`・`.../prompt-templates` | `addedAt,desc` |

| `routers/files.py` | `GET /api/admin/indexes/{index_id}/files` | `updatedAt,desc` |
| `routers/prompt_templates.py` | `GET /api/admin/prompt-templates`（`sort.strip() or DEFAULT_ADMIN_SORT` を削除） | `DEFAULT_ADMIN_SORT` |

## service（`sort: str` → `sort: list[SortOrder]`、手書きの `split(",")` を削除）

- `UserService.get_users`
  - `_parse_role(role) -> UserRole | None` を追加。`None`・空白のみは `None`、`UserRole(role)` が `ValueError` なら `HTTPException(400, detail=f"不正なroleです: {role}")`（`FileService._parse_status` と同じ形式）
  - 利用クレジット順: `find_order(sort, TOTAL_CREDITS_SORT_PROPERTY)` があり請求期間があれば、`[クレジット合計(その order の方向), User.name asc, User.id(同方向)]`
  - それ以外: `build_order_by(sort, _SORTABLE_COLUMNS, fallback=User.created_at, tie_breaker=User.id)`
  - 不要になる `_resolve_sort_column` を削除し、テストを `_SORTABLE_COLUMNS` の参照に置き換える
- `GroupService.list_groups` / `list_group_users` / `list_group_assistants` / `list_group_prompt_templates`: `sort` をそのまま repository に渡す
- `AssistantService.list_admin_assistants`: `_SORT_ALIASES` を削除し、別名は repository の対応表に移す
- `IndexService.list_indexes`・`FileService.list_files`・`PromptTemplateService.get_admin_prompt_templates`: `sort` をそのまま repository に渡す

## 対応表の型

SQLModel の列属性は mypy 上は Python の値型として解釈されるため、既存コード（`UserService._SORTABLE_COLUMNS`）と同じく `dict[str, Any]` とする。
