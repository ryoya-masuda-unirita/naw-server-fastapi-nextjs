# #188 issue-188 Terraformでの導入と定義

## 概要

AWSマネジメントコンソールで構築する想定だったSQS/S3リソース（#187）を、Terraformコード（`infra/`）としてコード化し、IaC管理下に置く。

## 説明

- マネジメントコンソールでの手動構築（#187）は行わず、#186（LocalStack対応）実装と参照実装（Spring Boot版 `application.yml` / `SqsConfig.java`）の想定仕様を元に、Terraformコードから直接dev環境にSQS/S3を定義する
- `infra/` 配下にSQSキュー（メイン＋DLQ）・S3バケットのリソース定義を追加する
- ECSタスクロール（新規）にSQS/S3への権限を付与するIAM定義を追加する
- 今回のスコープは「コード化 + `terraform plan` での確認」まで。`terraform apply`（実際のAWSリソース作成）はユーザーが実施する
- #187は本チケットでのTerraform化をもって、内容を包含する形でクローズする（PRの `Closes` に #187 と #188 の両方を指定する）
