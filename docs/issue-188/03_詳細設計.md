# 03_詳細設計

## 実装対象ファイル

### 新規

- `infra/sqs.tf`
  - `aws_sqs_queue.user_import` : メインキュー
    - `name = "${var.project_name}-user-import-jobs-queue"`
    - `visibility_timeout_seconds = 300`（参照実装 `application.yml` の想定値に準拠）
    - `redrive_policy` で `aws_sqs_queue.user_import_dlq` に `maxReceiveCount = 3` で紐付け
  - `aws_sqs_queue.user_import_dlq` : DLQ
    - `name = "${var.project_name}-user-import-jobs-queue-dlq"`
- `infra/s3_user_import.tf`
  - `aws_s3_bucket.user_import` : ユーザーインポートCSV用バケット
    - `bucket = "${var.project_name}-user-import-jobs"`
    - `force_destroy = true`（既存`s3.tf`の`frontend`バケットに合わせる。dev環境の使い捨てを想定）
  - `aws_s3_bucket_public_access_block.user_import` : パブリックアクセス全面ブロック（`s3.tf`の`frontend`と同じ4項目を`true`）
- `infra/iam.tf`（追記）
  - `aws_iam_role.ecs_task` : ECSタスクロール（新規）。`assume_role_policy`は既存`ecs_task_execution`と同じ`ecs-tasks.amazonaws.com`向け
  - `aws_iam_role_policy.ecs_task_sqs_s3` : インラインポリシー
    - SQS: `sqs:SendMessage` / `sqs:ReceiveMessage` / `sqs:DeleteMessage` / `sqs:GetQueueAttributes` を `aws_sqs_queue.user_import.arn` に限定
    - S3: `s3:GetObject` / `s3:PutObject` / `s3:DeleteObject` を `"${aws_s3_bucket.user_import.arn}/*"` に限定
- `infra/variables.tf`（追記）
  - 追加変数無し（キュー名・バケット名は`project_name`から導出するため既存変数のみで足りる）
- `infra/ecs.tf`（変更）
  - `aws_ecs_task_definition.backend` に `task_role_arn = aws_iam_role.ecs_task.arn` を追加
  - `container_definitions` の `environment` に以下を追加
    - `AWS_S3_BUCKET_NAME` = `aws_s3_bucket.user_import.bucket`
    - `AWS_SQS_QUEUE_URL` = `aws_sqs_queue.user_import.url`
- `infra/outputs.tf`（追記）
  - `output "user_import_bucket_name"` : `aws_s3_bucket.user_import.bucket`
  - `output "user_import_queue_url"` : `aws_sqs_queue.user_import.url`

## 変更しないファイル

- `infra/route53.tf` 系、`infra/acm.tf`、`infra/cloudfront.tf`：本チケットのスコープ外
- `infra/s3.tf`（既存frontendバケット）：変更しない。新規バケット定義は別ファイル`s3_user_import.tf`に分離する（既存ファイルへの無関係な追記を避けるため）

## 実施内容

1. `infra/sqs.tf` を新規作成し、メインキュー・DLQを定義する
2. `infra/s3_user_import.tf` を新規作成し、ユーザーインポート用バケットを定義する
3. `infra/iam.tf` に `ecs_task` ロールとインラインポリシーを追記する
4. `infra/ecs.tf` の `aws_ecs_task_definition.backend` に `task_role_arn` と環境変数2件を追加する
5. `infra/outputs.tf` にキューURL・バケット名の出力を追加する
6. `terraform fmt` でフォーマットを整える
7. `terraform validate` で構文エラーが無いことを確認する
8. `terraform plan` を実行し、意図した差分（新規リソース4〜5件の追加のみ、既存リソースの意図しない変更が無いこと）を確認する
