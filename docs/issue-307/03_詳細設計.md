- `server-local/app/clients/naw_api_client.py`（このリポジトリ）: スタブ作成の応答 `data.id`、タイトル更新 `{"title": ...}`

## 実装対象ファイル

### `backend/app/models/library.py`

- `Library.title` を `str | None`（`sa.String(255)`, nullable）にし、`content` を削除する
- `LibraryContent`（`library_contents`）を追加する。`library_id`（UUID, PK, FK `libraries.id` `ON DELETE CASCADE`）・`tenant_id`（String(32), FK `tenants.id` `ON DELETE CASCADE`）・`content`（Text, NOT NULL）・`created_at`・`updated_at`（既存のライブラリと同じく `DateTime(timezone=True)`、`server_default=now()`、`updated_at` は `onupdate`）

### `backend/alembic/versions/issue307_split_library_contents.py`（新規）

- `revision = "issue307"`、`down_revision = "023"`
- `upgrade()`
  1. `library_contents` を作る（制約名は移植元どおり）
  2. `INSERT INTO library_contents (library_id, tenant_id, content, created_at, updated_at) SELECT id, tenant_id, content, created_at, updated_at FROM libraries WHERE content IS NOT NULL`
  3. 移行元と移行先の件数を数え、違えば `RuntimeError` で失敗させる（移植元の `RAISE EXCEPTION` 相当。トランザクションごと戻る）
  4. `batch_alter_table("libraries")` で `title` を nullable にし、`content` を削除する（PostgreSQL では通常の `ALTER TABLE`、SQLite ではテーブルを作り直す）
- `downgrade()`
  1. `libraries.content`（Text, nullable）を追加する
  2. `UPDATE libraries SET content = (SELECT lc.content FROM library_contents AS lc WHERE lc.library_id = libraries.id)`（PostgreSQL・SQLite の両方で動く相関サブクエリ）
  3. `UPDATE libraries SET title = 'ライブラリ' WHERE title IS NULL`（戻した後はタイトル必須のため、スタブに既定のタイトルを入れて残す。既定のタイトルは移植元・backend のライブラリ生成で使う `ライブラリ` と同じ）
  4. `title` を NOT NULL に戻し、`library_contents` を削除する

### `backend/app/repositories/library_content_repository.py`（新規）

- `find_by_library_id_and_tenant_id(library_id, tenant_id, session) -> LibraryContent | None`
- `exists_by_library_id_and_tenant_id(library_id, tenant_id, session) -> bool`

### `backend/app/repositories/library_repository.py`

- `find_page`: 条件に `Library.title.is_not(None)` を加える（移植元 `titleIsNotNull`）
- `find_by_room_id_and_tenant_id`: 同じくタイトルが NULL の行を除く（移植元はサービスで除くが、結果は同じ）
- `create_with_content(library, content, session) -> Library`（新規）: ライブラリを追加して `flush` し、本文を追加して 1 回で `commit` する（移植元 `persistLibrary`）。`flush` を挟むのは、ORM の関連を定義していないため、外部キーの親（ライブラリ）を先に INSERT させるため

### `backend/app/repositories/assistant_endpoint_repository.py`

- `find_with_tenant_endpoints_by_assistant_id(assistant_id, tenant_id, session) -> list[tuple[AssistantEndpoint, TenantEndpoint]]`（新規）: アシスタントの全エンドポイント（モデル名と API キーを含む）を `endpoint_id` 昇順で返す。移植元は JPA のリスト（順序指定なし）の先頭のモデルを使うため、backend は決まった順にする

### `backend/app/schemas/library.py`

- `LibraryCreateRequest`（`messageId`）・`LibraryTitleUpdateRequest`（`title`）を追加する（文言は移植元どおり。空白だけは `field_validator` で弾く）
- `LibraryIdResponse`（`id`）: 既存の `LibraryUpdateResponse` を、スタブ作成・タイトル更新・更新の共通の応答として使う（名前はそのまま）
- `LibraryAssistantResponse`（`id`・`type`・`includeHistory`・`model`・`endpoints`）を追加する。`endpoints` はメッセージのスキーマの `EndpointResponse` を使う
- `LibraryGetResponse` を `id`・`title`（`str | None`）・`messageId`・`userId`・`createdAt`・`updatedAt`・`assistant`（`LibraryAssistantResponse | None`）・`hasNawContent` に変える

### `backend/app/services/library_service.py`

- `get_library`: 閲覧確認（既存）→ メッセージ（テナント・ID）→ アシスタント（メッセージのアシスタント ID があるとき）→ エンドポイント → 本文の有無、の順に取り、`LibraryGetResponse` を組む
- `get_library_content`: `LibraryContentRepository.find_by_library_id_and_tenant_id` で読む。無ければ 404 `Library content not found`
- `create_library_stub`（新規）: メッセージを探し無ければ 404 `Message not found` → `require_owned_room`（移植元 `requireCanWriteRoom`）→ `Library(title=None)` を保存して ID を返す
- `update_library_title`（新規）: 既存の `_get_library_or_404` → `_require_owned_room_for_library` → タイトルを更新して保存し ID を返す
- 一覧・ルーム一覧の応答は、リポジトリでタイトル NULL を除くため型上も `str` のまま渡す（`title or ""` ではなく、除外済みであることを型で表すため `assert` はせず、`LibraryPageItemResponse.title` を `str` のままにしてリポジトリで保証する）

### `backend/app/routers/libraries.py`

- `POST ""`（`create_library`）・`PATCH "/{library_id}/title"`（`update_library_title`）を追加する。どちらも 200 で `{"data": {"id": ...}}`

### `backend/app/services/message_service.py`・`backend/app/services/llm_chat_service.py`

- `_persist_library`: `LibraryRepository.save(Library(..., content=...))` を `LibraryRepository.create_with_content(Library(...), content, new_session)` に変える
