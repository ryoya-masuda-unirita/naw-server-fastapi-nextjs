# 05_テスト詳細設計

## `backend/tests/integration/test_migration_issue307.py`（新規・No.1〜3）

- インメモリ SQLite に、移行前の `libraries`（`title` NOT NULL・`content` あり）を `sa.Table` で作る（外部キー先は使わないため外部キーは張らない）
- マイグレーションのファイルを `importlib` で読み込み、`MigrationContext.configure(connection)` と `Operations.context(...)` の中で `upgrade()`・`downgrade()` を呼ぶ
- `test_upgrade_moves_content_to_library_contents`: 本文あり・本文 NULL のライブラリを入れて upgrade。本文テーブルに本文ありの 1 件だけが同じテナント・作成日時・更新日時で入り、`libraries` に `content` 列が無く、`title` が nullable になる
- `test_downgrade_restores_content_and_fills_null_title`: upgrade 後にスタブ（タイトル NULL・本文なし）を足して downgrade。本文が戻り、本文なしは NULL、スタブのタイトルは `ライブラリ`、`library_contents` が無い、`title` が NOT NULL に戻る
- `test_upgrade_then_downgrade_keeps_data`: 往復で本文・タイトルが移行前と同じ
- `test_revision_follows_head_023`: `revision == "issue307"`・`down_revision == "023"`
