# 05_テスト詳細設計

## 実行コマンド

```bash
cd backend

# mypy: 対象範囲のエラーが0件になることを確認
uv run mypy app tests

# pytest: 既存テストへの非回帰を確認
uv run pytest tests/unit -q

# ruff: Lintの非回帰を確認
uv run ruff check app tests
```
