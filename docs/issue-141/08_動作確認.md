## 確認環境

本Issueは型注釈・不変条件の明示による修正のみで、画面・APIの実行時挙動を変更しないため、ブラウザ操作による動作確認は行わない。自動テスト（pytest）と `uv run mypy` / `uv run ruff` の実行結果で代替する（この点はタスク実施者からの指示に基づく）。

## 確認手順

```bash
cd backend

# 1. mypy対象範囲のエラーが0件になることを確認
uv run mypy app tests

# 2. 既存テストへの非回帰を確認
uv run pytest tests/unit -q

# 3. Lintの非回帰を確認
uv run ruff check app tests
```
