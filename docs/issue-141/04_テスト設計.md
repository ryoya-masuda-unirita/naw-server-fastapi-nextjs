# 04_テスト設計

## テスト方針

本Issueは型注釈・不変条件の明示による修正のみで、既存の実行時ロジックを変更しないため、以下の2種類で確認する。

- `uv run mypy app tests`の実行結果が0件になること（#140完了時点で残っていた2件の実バグ疑いが解消されること）
- 既存の自動テスト（`pytest tests/unit`）に回帰がないこと（`assert`追加・型注釈追加が実行時挙動に影響しないことの確認）

新規のユニットテストは追加しない。`IndexService.additional_learning`・`MessageService.send_message`の該当ロジックは、修正前後で分岐条件・代入内容が変わらないため、既存のテストケースでの非回帰確認で十分と判断した。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | mypy対象範囲のエラー解消 | `uv run mypy app tests`を実行する | `Success: no issues found in 195 source files`（0件） |
| 2 | 既存テストの非回帰 | `uv run pytest tests/unit -q`を実行する | 修正前と同じ件数（249件）が全件成功する |
| 3 | Lintの非回帰 | `uv run ruff check app tests`を実行する | 検出なし |
