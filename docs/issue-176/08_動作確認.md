# 08_動作確認

## 確認環境

- ブラウザ・実機での確認は行わず、自動テスト（pytest、インメモリ SQLite + fakeredis、ストレージは一時ディレクトリ）のみで代替する
  - 他の作業と共有しているローカルの Postgres / Redis / backend サーバーを起動・変更しないため
- 実行ディレクトリ: `backend/`（`.env` はメイン作業ツリーの `backend/.env` をコピーしたもの）

## 確認手順

1. 修正前のコード（`schemas/file.py` の変更を戻した状態）で `test_files.py` を実行し、追加テストが失敗することを確認
2. 修正後のコードで `uv run pytest tests/integration/test_files.py -v` を実行
3. 修正後のコードで `uv run pytest -q`（全件）を実行
4. code-review 指摘対応（`name` 必須チェックをサービス層へ移動）後、対応前の実装で 401 テストが失敗することを確認し、2・3 を再実行
