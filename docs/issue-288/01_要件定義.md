# 01_要件定義

## 目的

移植元 Angular のビューワー関連の画面・部品を React（`frontend/`）へ、見た目・文言・操作まで揃えて移植する。

## 要件

| # | 要件 | 移植元 |
|---|---|---|
| 1 | ビューワー本体（資料の切り替え・その他メニュー・折りたたみ・Markdown 表示・読み込み／エラー／空の表示・PDF 保存・新しいタブで開く） | `ChatSummaryComponent` |
| 2 | ビューワーの状態（一覧・選択・本文・ライブラリ生成中のストリーミング表示） | `ViewerService` |
| 3 | 本文の取得（NAW／SECURE のローカルサーバー） | `LibraryContentApiService` |
| 4 | 「ライブラリに保存」ダイアログ（名前・タグ・チーム） | `ChatSaveLibraryDialogComponent`・`LibraryService.updateLibraryMetadata` |
| 5 | `/chat/viewer/:chatId`（`?libraryId=` で資料を指定） | `ChatViewerComponent` |
| 6 | `/library/:id`（ライブラリ詳細） | `LibraryDetailComponent` |
| 7 | `/chat/share/:shareId`（共有閲覧。閲覧できない場合の表示を含む） | `ChatSharedComponent` |
| 8 | `/chat-shared-history/:roomId`・`/feedback-preview/:roomId` | `ChatSharedHistoryComponent`・`FeedbackPreviewComponent` |
| 9 | チャットルームの右パネルとモバイルのビューワーにビューワーを差し込む。ライブラリ生成中は回答がなくても右パネルを出す | `ChatDataPanelComponent`・`ChatWindowComponent`・`AdminChatRoomComponent` |

## 判断（移植元と申し送りの食い違い）

- 共有閲覧の `ChatWindow`・`ChatDataPanel` の `isReadOnly`: 申し送りは `access.isReadOnly` を渡すとあったが、移植元のテンプレートは `access.isReadOnly` に関係なく常に `true` を渡している。完璧なクローンのため常に `true` にした（編集可の共有でも入力欄は出ない）

## 範囲外

- SECURE アシスタントの送信先切り替え（#289）。本文の取得は呼び出し口を用意し、既存の `resolveAssistantEndpoint` に従って取りに行く
- サイドバー・入力欄（#285・#286）
