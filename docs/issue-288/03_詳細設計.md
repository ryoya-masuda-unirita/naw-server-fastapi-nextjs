# 03_詳細設計

## viewer-store

移植元 `ViewerService` の signal を同名の state に、メソッドを同名のアクションにした。`libraryStreamToken`・`listRequestToken` は画面に出さない制御値なので store の外（モジュール変数）に持つ。

- `loadList(roomId, { autoSelect })`: 別ルームのストリームは手放す。応答が古ければ捨てる。末尾（最新）の資料を自動選択
- `selectLibrary` / `showLibrary` / `beginLibraryStream` / `append*Delta` / `endLibraryStream` / `abortLibraryStream`: 世代トークンで古い応答・差分を無効化する移植元の仕組みをそのまま移した
- backend の一覧は `title: null` を返しうるため、一覧に取り込むときに空文字にする（移植元の型は `string`）

## 本文の取得（`lib/chat/library-content-api.ts`）

1. `GET /api/libraries/{id}`（タイトルとアシスタント）
2. アシスタントなし／SECURE 以外 → `GET /api/libraries/{id}/content`（NAW）
3. SECURE → `resolveAssistantEndpoint`（#289 と共有する既存関数）でローカルを判定し、`{destination}/api/libraries/{id}/content` を `X-Server-Auth-Key` つきで取得（共通エラートーストなし）。エンドポイントが不正なら例外 → 本文エラー表示

## ChatSummary

- 状態: 折りたたみ・自動折りたたみ・2 つのメニュー（`dropdownService` で 1 つだけ開く）・保存ダイアログ
- 自動折りたたみ: 一覧の取得が済み（`listLoadedRoomId === chatId`）資料が 0 件のとき閉じ、資料が現れたら開く。ライブラリ生成中は自動で開く
- メニュー位置は移植元どおりトリガーの `getBoundingClientRect`（その他メニューは右端を 280px 左へ）
- 「新しいタブで開く」は `/chat/viewer/{chatId}?libraryId={id}`
- Markdown 内のボタンのクリックは PDF 保存（閲覧専用では無効）
- `canSaveLibrary`: 閲覧専用・詳細ページ・生成中・資料 ID なしのときは押せない
- PDF 保存は印刷ウィンドウに `.viewer-markdown` の中身を写す。移植元は `<markdown>` 要素の中身で、React の `MarkdownView` の host が `.viewer-markdown` なので同じ階層になる

## ライブラリに保存

名前（初期値は表示中のタイトル。空白だけなら保存不可）・タグ（`GET /api/libraries/tags`）・チーム（`GET /api/groups`）を `PUT /api/libraries/{id}`（`{ name, tags, groups }`）で保存。成功したら一覧とヘッダーのタイトルを更新して閉じる。失敗時は閉じず、トーストは api-client が出す。

## ページ

- chat-viewer: `loadList` → `?libraryId` があればその資料を選択、一覧になければ `showLibrary`
- library-detail: `showLibrary({ id, title: '' })` → 取得したタイトルを 1 件の選択肢にする。host のクラスは外側の div に移した。`goBack` は移植元でも呼び出し元がないため移植しない
- chat-shared: `resolveShareAccess` → `openSharedRoom`。失敗は「閲覧できない」表示。離れるときは `clearSharedRoomContext()`
- chat-shared-history: `selectRoom`。feedback-preview: `loadMessagesForRoom(roomId, true)` と `selectRoom`（移植元と同じく二重に読む）

## 移植元と変えた点

- PDF 保存の印刷ウィンドウのタイトルは HTML エスケープする（移植元は利用者入力のタイトルをそのまま埋め込む）
- 一覧の `title: null` を空文字にする
