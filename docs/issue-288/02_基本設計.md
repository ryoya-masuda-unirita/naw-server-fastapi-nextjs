# 02_基本設計

## 構成

| 移植元 | React |
|---|---|
| `ViewerService` | `store/viewer-store.ts`（Zustand）。読み込み時に `setLibraryStreamBridge()` へ登録 |
| `LibraryContentApiService` | `lib/chat/library-content-api.ts` |
| `LibraryService.updateLibraryMetadata` | `hooks/use-library-metadata.ts`（TanStack Query の mutation） |
| `LibraryService.loadLibraryItems` | 移植しない（移植元でも呼び出し元がない） |
| `TagsService.loadTags` | 既存の `useLibraryTagOptions`（`hooks/use-library-list.ts`）を再利用 |
| `TeamsService.loadTeams` | 既存の `useTeamsStore`（#287）を再利用 |
| `ChatSummaryComponent` | `components/features/chat/chat-summary.tsx` |
| `ChatSaveLibraryDialogComponent` | `components/features/chat/chat-save-library-dialog.tsx` |
| `printHtmlContent` | `lib/utils/print-html-content.ts` |
| 各ページ | `routes/chat/chat-viewer.tsx`・`routes/chat/chat-shared.tsx`・`routes/library/library-detail.tsx`・`routes/chat-shared-history/*`・`routes/feedback-preview/*`（仮ファイルを置き換え。export 名は変えない） |

## 差し込み

- `ChatDataPanel` の `renderSummary`、`ChatWindow` の `renderViewer` の既定を、ビューワー（`renderChatSummary`）にした。ページ側は何も渡さなくてよい
- ルーム ID が替わったときの一覧の読み込み（`loadList`）は `ChatDataPanel` の effect（移植元と同じ。モバイルのビューワーは hidden のパネルが読んだ一覧を使う）
- `AdminChatRoomPage` の `showViewer` に「このルームのライブラリを生成中」を足した

## 共通ファイルの変更

- `components/features/chat/chat-window.tsx`・`chat-data-panel.tsx`・`routes/chat/chat-room.tsx`（最小限）
- `mocks/handlers/viewer.ts`（新規。ビューワーの API の既定の応答。チャット画面を開くと一覧を読むため必要）
- `index.css`・`routes/index.tsx`・i18n は変更なし（`.viewer-markdown` の CSS も辞書も移植済み）
