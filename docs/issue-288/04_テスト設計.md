# 04_テスト設計

| 対象 | 観点 |
|---|---|
| `viewer-store` | 一覧の自動選択・autoSelect 抑止・title null・空一覧・取得失敗／本文失敗／showLibrary／SECURE ローカル本文／タイトル更新／ストリームの開始・差分・終了・古いトークン・選択による手放し・失敗時の復元／bridge 登録 |
| `print-html-content` | 印刷内容・待ち時間・フォールバック・タイトルのエスケープ・ウィンドウが開けない場合 |
| `ChatSummary` | 表示（タイトル・本文・空・エラー・詳細ページ・閲覧専用・生成中）／折りたたみ／資料の切り替え／新しいタブ／保存（成功・空名・失敗）／生成中は保存不可 |
| ページ | viewer（末尾選択・libraryId 指定・一覧外の libraryId）／library-detail／share（成功・失敗・離脱時のクリア）／shared-history・feedback-preview／chat-room の生成中パネル |
