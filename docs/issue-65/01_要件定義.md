# 01_要件定義

## 背景

Spring Boot版に実装済みのLibrary（チャット内容をMarkdownでまとめた資料）本体機能のうち、取得・更新・削除系のAPIをFastAPIへ移植する。ライブラリの新規生成（LLM呼び出し）は別Controller（LlmController）の責務であり、本対応の対象外とする。

## 機能要件

1. ログインユーザーが「自身が作成した」または「自身の所属グループに共有された」ライブラリの一覧を、ページング・タイトル部分一致・作成者絞り込み・除外作成者絞り込み・タグ絞り込み・ソート指定つきで取得できる。
2. 指定ルームに紐づくライブラリの一覧（id・titleのみ）を取得できる。取得にはそのルームへの閲覧権限（所有者・テナント管理者・共有グループ経由のいずれか）が必要。
3. ライブラリ単体のMarkdownコンテンツ（title・content）を取得できる。取得可否は「紐づくメッセージのルームへの閲覧権限」または「ライブラリ自体の可視性（所有者 or 共有先グループ所属）」のいずれかを満たせばよい。
4. ライブラリの名前・共有先グループ・付与タグを更新できる。共有先グループ・タグは常に完全置換（未指定/空は全解除）。更新できるのは紐づくルームの所有者本人のみ。
5. ライブラリを削除できる。削除できるのは紐づくルームの所有者本人のみ。削除時、共有先グループ・タグ紐づけはDBのCASCADEで連動削除される。

## 非機能要件

- 一覧取得時、対象ページのタグ・共有グループ情報をN+1にならないようIN句でまとめて取得すること。
- 更新時のグループ・タグの完全置換は、1件ずつのDELETEではなく一括DELETE文で行うこと。
- 既存の`library_tags`・`groups`・`rooms`・`users`テーブル・モデルを流用し、重複するモデルを作らないこと。

## スコープ外

- ライブラリの新規生成（LLM呼び出しによるMarkdown生成）
- フロントエンド（React / Angular）側の対応
- ブラウザでの動作確認（自動テストで代替）
