# Library（ライブラリ本体）取得・更新・削除APIの移植

## 概要

Spring Boot版 (`~/Documents/naw-server`) の Library（ライブラリ本体）機能をFastAPI(`backend/`)に移植する。ライブラリ生成（LLM呼び出しによる新規作成）はLlmController側の責務のため対象外。

## 説明

対象エンドポイント:

- `GET /api/libraries`（自身作成 or 所属グループ共有ライブラリの一覧、ページング、タイトル/作成者/タグ絞り込み）
- `GET /api/libraries/{roomId}/list`（ルーム紐づきライブラリ一覧）
- `GET /api/libraries/{libraryId}`（ライブラリのMarkdownコンテンツ取得）
- `PUT /api/libraries/{libraryId}`（ライブラリ名・共有グループ・タグの更新）
- `DELETE /api/libraries/{libraryId}`（ライブラリ削除）

参照実装:

- Controller: `~/Documents/naw-server/src/main/java/com/example/naw/api/LibraryController.java`
- Service: `~/Documents/naw-server/src/main/java/com/example/naw/service/LibraryService.java`
- Domain: `~/Documents/naw-server/src/main/java/com/example/naw/domain/library/`
- Request/Response: `LibraryGetRequest` / `LibraryListRequest` / `LibraryListPageRequest` / `LibraryUpdateRequest` / `LibraryPageItemResponse` / `LibraryGetResponse` / `LibraryListItemResponse`

## その他

- 対応するNAWチケット番号の記載はIssue本文になし。`issue-65`として対応する。
- 依存先の `library_tags`・`groups`・`rooms`・`users` は移植済み。新規テーブルは `libraries`・`share_libraries`（共有先グループ中間テーブル）・`library_tag_mappings`（タグ紐づけ中間テーブル）。
- 本対応は全自動モードで進行。承認フロー省略・動作確認は自動テストで代替。
