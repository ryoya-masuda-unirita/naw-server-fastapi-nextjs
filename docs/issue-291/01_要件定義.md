# 01_要件定義

## 背景

#134 のチャット履歴一覧から「詳細」を押すと、管理者が対象ユーザーのルームを読み取り専用で閲覧する画面に移る。画面は仮（`NotPortedPage`）のままなので、移植元と同じものにする。

## 機能要件

1. ルート `/admin/chat-history/:roomId`（定義済み）。一覧が `navigate` の `state`（`roomName`・`userName`・`userId`）を渡す。URL 直接アクセスでは state なし
2. ヘッダー: 戻るボタン（`/admin/chat-history` へのリンク、aria-label は `COMMON.BACK`、`data-testid="admin-chat-history-back-button"`）と見出し。見出しは「表示中ルームの名前 || state の roomName || `CHAT_HISTORY.TITLE`」
3. 本体の分岐（この順）: 読み込み中はローディング／403 は `CHAT_HISTORY.DETAIL.FORBIDDEN`／その他の失敗は `CHAT_HISTORY.DETAIL.LOAD_ERROR`／メッセージ 0 件は `CHAT_HISTORY.DETAIL.EMPTY`／それ以外は読み取り専用の `ChatWindow`（ヘッダー非表示）。回答が 1 つでもあれば右に `ChatDataPanel`
4. 開くとき: `openAdminHistoryRoom`（文脈を作り表示中ルームにする）と `loadMessagesForRoom(roomId, true)`
5. 離れるとき: `clearAdminHistoryRoomContext` と `startNewChat`
6. `chat-store` に `openAdminHistoryRoom`・`clearAdminHistoryRoomContext` を追加（#287 の申し送り）

## 非機能要件

- 見た目・文言は移植元のクラス・i18n キーをそのまま使う（辞書に足さない）

## スコープ外

- ビューワー本体（#288）、`chat-window.tsx` の変更
