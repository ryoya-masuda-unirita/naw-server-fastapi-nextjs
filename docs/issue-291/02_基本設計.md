# 02_基本設計

## 構成

| 区分 | ファイル | 移植元 |
|---|---|---|
| ページ | `frontend/src/routes/admin/chat-history/chat-history-detail.tsx`（`AdminChatHistoryDetailPage`） | `chat-history-detail.component.*` |
| store | `frontend/src/store/chat-store.ts`（`openAdminHistoryRoom`・`clearAdminHistoryRoomContext`） | `ChatService` |
| テスト | `chat-history-detail.test.tsx` | `chat-history-detail.component.spec.ts` |

## 判断

- 移植元は `ChatService._sharedRoomContext` を管理者履歴の文脈にも使う。移植先も `sharedRoomContext` を共用する（`useActiveRoom` が ID 照合済み）
- state は `useLocation().state` から読む（移植元の `history.state` 相当）
- 既存部品（`ChatWindow`・`ChatDataPanel`・`IconButton`・`Loading`）をそのまま使い、`chat-window.tsx` は変更しない
