# 05_テスト詳細設計

- `renderApp('/admin/chat-history')` の後に `router.navigate('/admin/chat-history/r1', { state })` で一覧からの遷移を再現する
- メッセージ API は `MESSAGES.LIST`・`MESSAGES.CONTENTS` を `server.use` で差し替える（既定ハンドラーは足さない）
- ChatWindow のヘッダーも（hidden で）描画されるため、見出しは先頭の要素を見る
- 各テストの前に `chat-store`・`messages-store`・`rooms-store` を初期化する
