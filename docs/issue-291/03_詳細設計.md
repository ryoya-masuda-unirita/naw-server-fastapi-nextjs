# 03_詳細設計

## ページ

- `roomId` は `useParams`。`roomId` が変わったときだけ effect で `openAdminHistoryRoom` + `loadMessagesForRoom(roomId, true)`（移植元は params の購読内で実行。state だけの変化では読み込み直さない）
- アンマウント時の cleanup で `clearAdminHistoryRoomContext()` の後に `startNewChat()`（移植元 `ngOnDestroy` と同じ順）
- `displayRoomName = useActiveRoom()?.name || state.roomName`。ルーム一覧にそのルームがあればその名前が優先される（移植元 `activeRoom()?.name || roomName()`）
- `showViewer = messages.some(role === 'assistant')`（移植元と同じ。生成中の条件は #288）
- ルート要素は `flex flex-col h-screen! overflow-hidden bg-white w-full`（移植元のホストクラス）

## store

```ts
openAdminHistoryRoom({ id, name, userId, userName }) // sharedRoomContext = { id, name, isPinned: false, category: 'chat', userId, userName }; activeRoomId = id
clearAdminHistoryRoomContext() // sharedRoomContext = undefined
```
