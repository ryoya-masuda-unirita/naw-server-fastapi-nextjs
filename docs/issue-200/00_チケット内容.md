# 00_チケット内容

- Issue: https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/issues/200
- タイトル: 移植元のモノレポ化に合わせて、AIエージェント向けドキュメント・スキルの参照パスと前提を更新する

## 概要

移植元が GitLab のモノレポ `secuaigent`（`server/`・`client/` のほか `generative-ai-adapter/`・`secuaigent-server-local/`・`secuaigent-infra/`・`e2e-test/` 等の複数プロジェクトを含む）に統合されたが、AIエージェント向けのドキュメント・スキルは旧構成（`~/Documents/secuaigent/{server,client}`・`~/Documents/naw-server`・`~/Documents/secuaigent-client` の別リポジトリ）を前提にしたままになっている。記載のパスはいずれも現存しない。

## 対応内容

- 参照パスを、参照専用の worktree `~/Documents/unirita-develop-pj/secuaigent-ref/{server,client}` に統一する
  - 業務で使う作業ツリー（`~/Documents/unirita-develop-pj/secuaigent`）で `git checkout develop` するとブランチが切り替わってしまうため、`origin/develop` に detached した参照専用 worktree を使う
  - 「develop の最新化」手順を `fetch` + worktree を `origin/develop` に合わせる手順に変更する
- 移植対象はモノレポのうち `server/`（Spring Boot）と `client/`（Angular）だけで、他のディレクトリは別プロジェクトであり移植対象外であることを明記する
- `client/` の git 履歴の記述を更新する（2026-07-13 にモノレポへ取り込み。それ以前の履歴は追えない）
- このリポジトリ自身のパス（`~/Documents/naw-server-fastapi-nextjs` → `~/Documents/personal/naw-server-fastapi-nextjs`）を修正する

## 対象

`.claude/CLAUDE.md`・`AGENTS.md`・`GEMINI.md`・`.cursorrules`（ルート・`backend/`・`frontend/`）、`.claude/agents/`、`.claude/skills/`・`.codex/skills/`、`frontend-angular-sync` の `sync.sh`

## スコープ外

- `docs/issue-*`・`docs/調査結果/` などの過去の記録（当時の状況の記録として残す）
- 移植方針（バックエンド優先等）の見直し、新しく増えたモジュールを移植対象にするかの検討
