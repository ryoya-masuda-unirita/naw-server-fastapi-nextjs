## Step 1: 旧パスが残っていないこと

```
$ git grep -n -E "Documents/(secuaigent[/-]|naw-server)" -- . ':!docs' ':!.claude/settings.json' | grep -v "unirita-develop-pj\|personal/naw-server-fastapi"
（出力なし）
```

✅ 過去の記録（`docs/`）と権限設定以外に旧パスは残っていない

## Step 2: 新しい最新化手順が作業ツリーに影響しないこと

```
$ git -C ~/Documents/unirita-develop-pj/secuaigent fetch origin develop
$ git -C ~/Documents/unirita-develop-pj/secuaigent-ref checkout --detach origin/develop
HEAD is now at 70f578b0 Merge branch 'fix/NAW-1373' into 'develop'
ref: 70f578b0 2026-11-12 / work branch: fix/NAW-1375
```

✅ 参照専用 worktree が `origin/develop` に合い、業務の作業ツリーは作業中のブランチ（`fix/NAW-1375`）のまま変わらない
