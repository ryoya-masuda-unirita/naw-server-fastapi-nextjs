# 04_テスト設計

## テスト方針

設定追加による起動影響と、Azure OpenAI client へ渡す API version の差し替えを単体テストで確認する。外部 Azure への疎通は行わず、既存の `AsyncAzureOpenAI` モックテストで引数を検証する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 設定デフォルト | Azure OpenAI 用環境変数を指定しない | Chat/Embedding 用 API version と Responses 用 API version が現行値になる |
| 2 | 設定上書き | Azure OpenAI 用環境変数を指定する | 指定した値が設定クラスに反映される |
| 3 | Chat Completions | チャット呼び出しで tools を指定しない | Azure client が Chat/Embedding 用 API version で生成される |
| 4 | Responses API | チャット呼び出しで tools を指定する | Azure client が Responses 用 API version で生成される |
| 5 | Embeddings | 埋め込み呼び出しを行う | Azure client が Chat/Embedding 用 API version で生成される |
| 6 | 回帰 | 既存 LLM client 単体テストを実行する | 既存のストリーミング・usage・エラー処理のテストが通る |
