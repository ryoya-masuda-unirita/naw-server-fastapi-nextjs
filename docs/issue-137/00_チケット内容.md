# #137 issue-137 Azure OpenAI設定をFastAPIに追加する

## 概要

Azure OpenAI 呼び出しで使用する FastAPI 側のアプリ設定を追加・整理する。

## 説明

Issue #88 で LLM チャット・埋め込み API は FastAPI に移植済みだが、Azure OpenAI の API バージョン等が `llm_client.py` の定数として固定されており、`backend/app/core/config.py` の設定管理に含まれていない。

移植元 Spring Boot では `application-*.yaml` の `spring.ai.azure.openai.*` 配下に Azure OpenAI の endpoint / api-key / chat deployment / embedding deployment などの設定が存在する。FastAPI 側ではテナントごとの endpoint / api_key / deployment は `tenant_endpoints` と `assistants_endpoints` / `indexes_endpoints` から解決する設計のため、その設計と衝突しない形で、アプリ共通の Azure OpenAI 設定を `Settings` 系クラスへ移す必要がある。

## 参照

- 移植元（バックエンド）: `~/Documents/naw-server/src/main/resources/application-development.yaml`, `application-production.yaml`, `application-local.yaml`
- 移植元（バックエンド）: `~/Documents/naw-server/src/main/java/com/example/naw/llm/`, `~/Documents/naw-server/src/main/java/com/example/naw/api/LlmController.java`
- 移植先の現状: `backend/app/core/config.py`, `backend/app/core/llm_client.py`
- 関連 Issue: #88（LLMチャット・埋め込みAPIを移植）, #28（テナントエンドポイント管理API）, #102（SECURE対応）

## その他

- テナントごとの endpoint / api_key / deployment は既存 DB 管理を維持し、環境変数へ重複移行しない。
- 設定未指定時は現行定数と同じデフォルトで後方互換を保つ。
- 実 Azure OpenAI への疎通確認はスコープ外とする。
