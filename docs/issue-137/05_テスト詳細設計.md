# 05_テスト詳細設計

## 単体テスト

### `backend/tests/unit/test_config.py`

`AzureOpenAISettings` を import し、`.env` に依存しないインスタンス生成ヘルパーを追加する。

追加ケース:

- `test_defaults_to_current_api_versions`
  - `_env_file=None` で `AzureOpenAISettings` を生成する。
  - `api_version == "2024-10-21"` を確認する。
  - `responses_api_version == "2025-04-01-preview"` を確認する。
- `test_reflects_env_overrides`
  - `AZURE_OPENAI_API_VERSION` と `AZURE_OPENAI_RESPONSES_API_VERSION` を指定して生成する。
  - 指定値が各プロパティに反映されることを確認する。

### `backend/tests/unit/test_llm_client.py`

既存の `AsyncAzureOpenAI` patch を利用し、client class の呼び出し引数を確認する。

追加ケース:

- Chat Completions API
  - `get_azure_openai_settings` を patch し、`api_version="chat-version"` を返す。
  - `AzureLlmChatClient.stream_chat(..., tools=None)` を実行する。
  - `AsyncAzureOpenAI` が `api_version="chat-version"` で呼ばれることを確認する。
- Responses API
  - `get_azure_openai_settings` を patch し、`responses_api_version="responses-version"` を返す。
  - `AzureLlmChatClient.stream_chat(..., tools=[ToolConfig(name="web_search")])` を実行する。
  - `AsyncAzureOpenAI` が `api_version="responses-version"` で呼ばれることを確認する。
- Embeddings API
  - `get_azure_openai_settings` を patch し、`api_version="embedding-version"` を返す。
  - `AzureLlmEmbeddingClient.create_embedding(...)` を実行する。
  - `AsyncAzureOpenAI` が `api_version="embedding-version"` で呼ばれることを確認する。

## 実行コマンド

```bash
cd backend
uv run pytest tests/unit/test_config.py tests/unit/test_llm_client.py
uv run ruff check app/core/config.py app/core/llm_client.py tests/unit/test_config.py tests/unit/test_llm_client.py
uv run mypy app/core/config.py app/core/llm_client.py
```

必要に応じて、影響範囲確認として `uv run pytest tests/unit` を追加実行する。
