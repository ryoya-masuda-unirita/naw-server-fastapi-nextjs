# 01_要件定義

## 背景

LLM チャット・埋め込み API は FastAPI 側へ移植済みだが、Azure OpenAI 呼び出し時に使う一部のアプリ共通値がコード定数として固定されている。環境ごとに API バージョンを調整したい場合や、今後 Azure OpenAI のプレビュー API を切り替える場合に、設定管理の一貫性が崩れる。

移植元には Azure OpenAI 関連の設定キーが存在する。一方、FastAPI 版ではテナントごとの接続先や API キー、デプロイ名は DB 管理へ寄せているため、今回の対象はアプリ共通の Azure OpenAI 設定に限定する。

## 機能要件

- Azure OpenAI の Chat Completions API バージョンを環境変数で上書きできること。
- Azure OpenAI の Responses API バージョンを環境変数で上書きできること。
- 環境変数が未指定の場合、現在と同じ既定値で動作すること。
- 既存のチャット、ツール利用、埋め込み呼び出しが設定値を通じて API バージョンを利用すること。
- テナントごとの接続先、API キー、デプロイ名は既存の DB 管理を継続すること。

## 非機能要件

- 設定値を追加しても、アプリ起動時に不要な必須環境変数が増えないこと。
- 単体テスト環境や CI で追加設定が未指定でも失敗しないこと。
- API キーなどの秘密値をログやテスト出力へ露出しないこと。
- 既存の LLM API レスポンス形式、SSE 形式、トークン使用量集計に影響を与えないこと。

## スコープ外

- テナントエンドポイント管理 API の仕様変更。
- Azure OpenAI の endpoint / API キー / deployment を環境変数管理へ移す変更。
- SECURE またはローカル LLM 対応。
- 実 Azure OpenAI への疎通確認。
