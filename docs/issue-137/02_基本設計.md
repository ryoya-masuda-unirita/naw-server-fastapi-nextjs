# 02_基本設計

## 変更対象

Azure OpenAI 呼び出しのインフラ層と設定管理を変更対象とする。既存のサービス層、ルーター、DB モデルは原則変更しない。

## 画面 / API 変更概要

画面および公開 API のリクエスト・レスポンス仕様は変更しない。管理者や利用者から見える挙動も維持する。

内部的には、Azure OpenAI クライアント生成時に使用する API バージョンを固定定数ではなく設定値から取得する。Chat Completions 用と Responses API 用は用途が異なるため、個別の設定値として扱う。

## 影響範囲

影響範囲は LLM チャット、ツール利用時の Responses API、埋め込み API に限定される。いずれも Azure OpenAI クライアント生成時の API バージョン指定だけを変更し、endpoint、API キー、デプロイ名の解決方法は既存のまま維持する。

設定クラスは他の任意設定と同様に、未指定時のデフォルト値を持たせる。これにより、ローカル開発・単体テスト・CI で追加環境変数なしに既存テストが通る状態を保つ。

## 移植方針

移植元の設定体系をそのまま環境変数化するのではなく、FastAPI 版の責務分離に合わせて取り込む。移植元にある endpoint、API キー、deployment はテナント単位の接続情報として既に DB 管理されているため、今回の設定対象から外す。

API バージョンはアプリ共通の実行時設定として整理する。既定値は現行実装と同じ値を採用し、既存挙動を保ったまま環境ごとの上書きを可能にする。
