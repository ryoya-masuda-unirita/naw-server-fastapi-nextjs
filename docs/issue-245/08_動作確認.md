# 08_動作確認

## 確認環境

- macOS（ローカル）、`backend/` で `uv run` を使用
- 自動テストのみ（インメモリ SQLite + fakeredis）。ローカルの Postgres・Redis・backend サーバーは使わない

**ブラウザ・実機確認は行わず、自動テストのみで代替する。** React（frontend）はチャット履歴の送信が未移植のため、履歴添付件数の不一致は画面から再現できない。空文字の本文を含め、受付・LLM への送信内容・保存結果は結合テストで確認した。

## 確認手順

```bash
cd backend
uv run pytest -p no:warnings
uv run pytest -p no:warnings -v tests/unit/test_message_schemas.py tests/unit/test_message_service.py tests/integration/test_messages.py | grep -E "empty_user_input|user_input_is_missing|count_mismatch|history_attachment_count"
uv run mypy app tests
uv run ruff check
uv run ruff format --check
```
