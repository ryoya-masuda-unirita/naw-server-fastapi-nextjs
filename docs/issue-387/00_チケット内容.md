# CloudFront の挙動を secuaigent-infra に揃える

## 概要

CloudFront ディストリビューションと、フロントエンド用 S3 バケットの設定を、移植元（`secuaigent-infra`）に合わせる。親 Issue は #380。

## 説明

- 圧縮（`compress`）と IPv6 を有効にする
- `/api/*` の転送ヘッダを、全許可から限定リストに変える（`Host` を転送すると ALB で問題になる場合があるため確認する）
- 5xx（500・502・503・504）のエラー応答をキャッシュしない（NAW-1338）
- フロントエンド用 S3 バケットに、バージョニングと AES256 暗号化を付ける
- 維持するもの: SPA フォールバック（CloudFront Function）、`/backend/auth/*` と prefix 除去、デフォルト証明書、固定オリジンの CORS
- 除外: エイリアス・ACM（サブドメイン関連。#193・#195 で廃止済み）

## その他

- 移植元: `secuaigent-infra`（`modules/frontend`）
