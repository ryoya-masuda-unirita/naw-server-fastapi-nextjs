# 02_基本設計

## 構成（移植元との対応）

| 移植元（`features/admin/management/training-data/`） | 移植先（`frontend/src/`） |
|---|---|
| `training-data.component`（一覧部分） | `routes/admin/training-data/training-data.tsx`（`TrainingDataPage`） |
| `training-data.component` の作成ダイアログ部分（`openCreateModal`・`createFolderFormTpl`） | `components/features/admin/training-data/training-folder-add-dialog.tsx` |
| `training-folder-form.helper`（作成で使う分） | `.../training-folder-form.ts` |
| `training-api-normalize`（一覧分）・`toViewModel` | `.../training-data-api-normalize.ts` |
| `TrainingDataStore`（一覧の状態） | `store/training-data-store.ts`（Zustand） |
| `TrainingApiService`・`TrainingDataStore.createFolder`・`TrainingFolderModalService` の通信 | `hooks/use-training-data.ts`（TanStack Query） |
| （MSW） | `mocks/handlers/training-data.ts` |

## 方針
- 共通 UI は #278 のものを使う。新規の共通部品は作らない
- 画面は `AdminPageShell` を使わず、`PageHeader` と本文を並べる（移植元 `training-data.component.html` が `app-admin-page-shell` を使っていないため）
- 触った共通ファイルはなし（`mocks/handlers/training-data.ts` は #324 の自動登録）
- `add-training-data-dialog.component` は移植元でどこからも使われていない（ファイル追加は詳細画面の別ダイアログ）ため移植しない
