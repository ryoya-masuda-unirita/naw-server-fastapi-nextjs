# 04_テスト設計

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ確認は行わない。

| 対象 | 観点 |
|---|---|
| 一覧の表示 | カードの内容、件数表示、初期の取得条件（page 0・size 5・updatedAt desc・searchText 空）、0 件で件数表示なし、閲覧・編集で詳細へ遷移 |
| 検索・ページ送り | 検索語が `searchText` で 1 ページ目に戻る、次のページで `page=1` |
| 作成（ローカル） | 案内・サービス ID 欄・作成不可の初期状態、接続先の先頭選択、本文（`get`・`add`・`delete`・`endpointIds`・全グループ）、成功後に一覧の先頭へ追加・件数 +1・ダイアログが閉じる |
| 作成（クラウド） | サービス ID 欄・案内が消える、VDB・埋め込みの 2 件を送る、サービス ID は送らない |
| グループ | 複数ページを全部取って紐づける |
| 入力チェック | ローカルでサービス ID 空 → 必須エラー 3 つ・送信なし・最初の不正項目へスクロール、名前 256 文字 → 文字数エラー・スクロール |
| エンドポイントなし | ローカル・クラウドとも案内を出し作成不可 |
| 失敗・キャンセル | 作成失敗でダイアログと入力を残す、送信中は Esc で閉じない、キャンセルで閉じる |
| 変換・本文 | `tenantEndpoints` → `endpointIds`、種別 → 接続サーバー名、サービス ID はローカルのみ |
