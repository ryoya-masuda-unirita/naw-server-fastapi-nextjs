# 01_要件定義

## 機能要件

### 一覧
- ヘッダー（`LEARNING_DATA.LEARNING_DATA`）。サイドバー切替・言語切替あり、戻る・操作ボタンなし
- 学習先フォルダのカード（フォルダ名・接続サーバー（クラウド／ローカル）・説明）と「閲覧・編集」ボタン（詳細 `/admin/training-data/:id` へ遷移）
- 検索（入力のたびに反映。debounce なし）・並べ替え（更新日時順／学習先フォルダ名順／接続サーバー順、昇順／降順）。条件を変えたら 1 ページ目へ
- 1 ページ 5 件、件数表示（`1-5件 / 7件`）と上下のページ送り（上は最初・最後つき、下は 3 ページ分の番号）
- 0 件でも件数表示を消すだけで、空の案内は出さない（移植元どおり）
- 読み込み中も一覧は出したまま（スピナーなし）
- PC は左上に「学習先フォルダを新規作成」、モバイルは画面下に固定のボタン

### 新規作成ダイアログ
- 名前（必須・255 文字以内）、接続サーバー（ローカル／クラウド）、説明（任意・1000 文字以内）
- ローカル: 案内ボックス、接続先エンドポイントの選択（先頭を初期選択）、学習データ取得・削除・学習用サービス ID（すべて必須）
- クラウド: 案内ボックスとサービス ID 欄は出さない。ベクトル DB・埋め込みモデルの先頭を自動で使う
- 利用できるエンドポイントがなければ `LEARNING_DATA.NO_ENDPOINTS` を出し、作成不可
- 開いた直後は紐づけるグループを全部取る。読み込み中は本文に半透明のスピナーを重ね、作成不可
- 作成ボタンは「読み込み中でない・エンドポイントあり・送信中でない・名前あり・サーバー選択済み・接続先決定済み」のとき押せる。押したあと不正があれば、エラー文言を出して最初の不正な項目までスクロール
- 作成成功: ダイアログを閉じ、一覧の先頭に足して総件数を 1 増やす（取り直さない）。失敗: 共通エラートーストを出し、ダイアログは開いたまま

## 非機能
- 文言は既存の i18n 辞書を使い、キーを足さない
- API の形は backend の実際の応答に合わせる（03 を参照）
