# 学習データ 一覧画面をReactに移植する

## 概要

学習データ 一覧画面（`/admin/training-data`、学習先フォルダのカード一覧と「学習先フォルダを新規作成」ダイアログ）を Angular（`secuaigent/client` の `features/admin/management/training-data/`）から React（`frontend/`）に移植する。Issue #135。

## 説明

- 対象: `training-data.component`（一覧・検索・並べ替え・ページ送り・作成ダイアログ）・`TrainingDataStore` の一覧と作成・`TrainingApiService` の一覧・作成・接続先候補・グループ・`TrainingFolderModalService`・`training-folder-form.helper`・`training-api-normalize`（一覧分）
- スコープ外: 詳細 `/admin/training-data/:id`（#290）。一覧から詳細への遷移だけ移植元どおり
- 土台は #277・#278・#279。#124・#125・#122・#136 の作り方に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）

## その他

- 移植先は #277 の仮ファイル `frontend/src/routes/admin/training-data/training-data.tsx`（export 名 `TrainingDataPage` は維持）
- 移植元に「フォルダの編集ダイアログ」は一覧画面にない（編集は詳細画面のため #290）
