# 05 テスト詳細設計

## 構文木の比較

`origin/develop` の各 `backend/tests/**/*.py` と作業ツリーのファイルについて、次を取り除いた `ast.dump` が一致することを確かめる。

- 関数の戻り値注釈・引数注釈
- 関数・クラス・モジュール先頭の docstring（本体が空になる場合は `pass` に置き換えて比較）
- `import` / `from ... import`（変更前の import が変更後に含まれることは別途確認）

`# type: ignore` はコメントなので構文木に影響しない。`uv run python`（3.12）で実行する。
