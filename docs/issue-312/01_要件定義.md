# 01 要件定義

## 目的

`backend/tests/` の型ヒントの抜けをなくし、`uv run mypy app tests` の `disallow_untyped_defs` / `disallow_incomplete_defs` をテストにも適用する。あわせて #311 で残ったテストの docstring の抜けを埋め、ruff の D ルールをテストにも適用する。

## 要件

| # | 要件 |
|---|---|
| 1 | fixture の引数、fixture の戻り値、テスト関数の戻り値（`-> None`）、補助関数の引数・戻り値に型ヒントを付ける |
| 2 | fixture の型は `AsyncClient`・`AsyncSession`・モデルの型など実際の型を付ける。`Any` は型で表せない場合（parametrize の複雑な値、異種の値を持つ dict）に限る |
| 3 | `pyproject.toml` の mypy `[[tool.mypy.overrides]]`（`tests.*` 対象外）を削除する |
| 4 | `pyproject.toml` の ruff `per-file-ignores`（`tests/**` の D ルール除外）を削除する |
| 5 | docstring の抜け（private の `_` 付き・ネストしたものを含む）に NumPy 形式・日本語で docstring を付ける。テスト関数は日本語 1 行。Google 形式は NumPy 形式に書き換える |
| 6 | コードの挙動は変えない。docstring・型注釈・追加 import を除いた構文木が変更前と一致する |

## 範囲外

- `app/` の変更
- テストの追加・削除
