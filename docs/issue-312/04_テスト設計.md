# 04 テスト設計

挙動を変えない変更のため、テストの追加はしない。次の検査で確認する。

| # | 検査 | 期待 |
|---|---|---|
| 1 | `uv run mypy app tests` | エラー 0 |
| 2 | `uv run ruff check .` | 違反 0（D ルールをテストにも適用） |
| 3 | `uv run ruff format --check .` | 整形済み |
| 4 | `uv run pytest`（`TZ=UTC` あり・なし） | 全件成功 |
| 5 | 構文木の比較（docstring・型注釈・追加 import を除く） | 全ファイルで一致 |
