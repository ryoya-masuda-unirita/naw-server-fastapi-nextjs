# 03 詳細設計

## fixture の型

| fixture | 型 |
|---|---|
| `client` | `AsyncClient` |
| `session` | `AsyncSession`（ジェネレータは `AsyncIterator[AsyncSession]`） |
| `engine` | `AsyncEngine`（`AsyncIterator[AsyncEngine]`） |
| `fake_redis` | `FakeRedis`（`AsyncIterator[FakeRedis]`） |
| `test_tenant`・`tenant` など | `Tenant` |
| `test_user`・`admin_user` など | `User` |
| `*_headers` | `dict[str, str]` |
| `valid_jwt_token` など | `str` |
| `test_user_with_password`・`*_dataset` など | `dict[str, Any]`（値の型が異なる辞書） |
| `override_*`（値を返さないジェネレータ） | `Iterator[None]`（引数側は `None`） |
| `mock_*` | `MagicMock` |

## 補助関数

- `_headers(login_id: str, tenant_id: str) -> dict[str, str]`
- `async` ジェネレータのスタブは `AsyncIterator[...]`
- `patch(...)` を返す補助関数は `AbstractContextManager[Any]`
- `_consume(streaming_response)` は `StreamingResponse.body_iterator` の型が `str | bytes | memoryview` のため `Any`

## pyproject.toml

- 削除: `[[tool.mypy.overrides]] module = ["tests.*"]`（`disallow_untyped_defs = false` など）と関連コメント
- 削除: ruff `per-file-ignores` の `"tests/**" = [D...]`（`tests/unit/conftest.py` の `E402` は残す）
