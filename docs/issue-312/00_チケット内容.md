# backendのテストに型ヒントを付けmypyで強制する

Issue #312

## 概要

backend のテスト（`backend/tests/`）に型ヒントの無い引数・戻り値が約 5,200 か所ある（pytest の fixture の引数など）。#311 で backend 本体（`app/`）は mypy の `disallow_untyped_defs = true` で強制したが、テストは対象外にしていた。テストにも型ヒントを付け、mypy の対象外設定を外す。

## 要件

- fixture の引数・テスト関数の戻り値（`-> None`）に型ヒントを付ける
- 挙動は変えない。`uv run pytest` 全件・mypy・ruff を通す
- 依存: #311（backend の分）

## 同じ PR で対応する追加事項

- #311 で残った `backend/tests/` の docstring の抜け（約 130 か所）に NumPy 形式・日本語の docstring を付ける。付け終えたら ruff の `per-file-ignores`（`tests/**` の D ルール除外）を削除する
