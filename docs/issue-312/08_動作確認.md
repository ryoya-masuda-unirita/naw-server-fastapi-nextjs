## 確認環境

- macOS、Python 3.12（`uv run`）、backend の開発依存の mypy・ruff

## 1. mypy

```
$ uv run mypy app tests

```

## 2. ruff

```
$ uv run ruff check .

$ uv run ruff format --check .
257 files already formatted
```

## 3. pytest 全件

```
$ TZ=UTC uv run pytest -q

$ uv run pytest -q

```
