# 05_テスト詳細設計

## テストファイル

`backend/tests/integration/test_files.py`

## フィクスチャ

`test_credit_usage.py`・`test_indexes.py`のパターンに倣い、以下を用意する。

- `files_tenant`: `Tenant`（`max_usage_based_credits_per_month`を調整可能にし、429テストで上限を作る）
- `files_admin_user` / `files_admin_headers`: テナント管理者ユーザーとJWTヘッダー
- `files_index`: `type=SAAS_GLOBAL`の`Index`（アップロード可能な対象）
- `files_local_index`: `type=LOCAL`の`Index`（400テスト用）
- `file_storage_root`（`tmp_path`ベース）: テスト用に`app.core.file_storage.get_file_storage`をオーバーライドし、`LocalFileStorage(root=tmp_path)`を注入する（`app.dependency_overrides`使用、`test_indexes.py`等の既存オーバーライドパターンに準拠）

## クレジット上限超過（429）シナリオの組み立て

`test_credit_usage.py`の`credit_usage_tenant`+`Plan(max_credits_per_month=...)`+`Subscription(status=ACTIVE)`+`TokenUsage`（当月分の合計が上限を超えるように作成）のパターンを再利用し、`files_tenant`に対して同様のセットアップを行う。

## クラス構成（命名規則: クラス名は英語、docstringで意図を日本語記述）

```python
class TestFilesRouter:
    class TestList:
        async def test_list_files(self, ...): """ファイル一覧を取得できること"""
        async def test_filter_by_display_name(self, ...): """displayNameで絞り込めること"""
        async def test_filter_by_status(self, ...): """statusで絞り込めること"""

    class TestUpload:
        async def test_upload_file(self, ...): """ファイルをアップロードできること"""
        async def test_index_not_found_returns_404(self, ...): """存在しないインデックスへのアップロードは404になること"""
        async def test_local_index_returns_400(self, ...): """LOCALインデックスへのアップロードは400になること"""
        async def test_quota_exceeded_returns_429(self, ...): """当月クレジット上限超過時は429になること"""

    class TestDownload:
        async def test_download_file(self, ...): """アップロード済みファイルをダウンロードできること"""
        async def test_file_not_found_returns_404(self, ...): """存在しないファイルのダウンロードは404になること"""

    class TestUpdate:
        async def test_update_metadata_only(self, ...): """file未添付時はメタデータのみ更新されること"""
        async def test_update_status_deleted_returns_400(self, ...): """status=DELETEDの指定は400になること"""
        async def test_update_with_file_replaces_content(self, ...): """file添付時は既存ファイルが置き換わること"""
        async def test_update_with_file_quota_exceeded_returns_429(self, ...): """file添付更新時も上限超過なら429になること"""

    class TestDelete:
        async def test_soft_delete_marks_status_deleted(self, ...): """論理削除でstatusがDELETEDになること"""
        async def test_physical_delete_removes_record(self, ...): """物理削除でレコードが消えること"""
```
