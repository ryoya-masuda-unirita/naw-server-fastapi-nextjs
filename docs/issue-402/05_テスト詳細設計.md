# 05_テスト詳細設計

## 共通ヘルパー: `server/tests/unit/asgi_disconnect.py`

- `FakeSession`: `commit()` で `asyncio.sleep(0)` してからコミット済みリストへ追加する非同期セッション
- `run_until_client_disconnects(response, disconnect_after)`: `StreamingResponse` を spec_version 2.3 の ASGI として動かし、指定のバイト列を送った直後に `http.disconnect` を返す。終了後、切り離された保存タスクの完了を待つ

## `server/tests/unit/test_llm_chat_service.py`

- `TestStreamChatClientDisconnect::test_persists_token_usage_when_client_disconnects_after_message_stop`
  - 入力 11・出力 7 のチャンクを流し、`message_stop` 直後に切断。`FakeSession` にトークン使用量が 1 件あり、トークン数が一致すること

## `server/tests/unit/test_message_service.py`

- `TestStreamMessageContentClientDisconnect::test_persists_content_and_usage_when_client_disconnects_after_message_stop`
  - 回答「回答」・入力 10・出力 5 のチャンクを流し、`message_stop` 直後に切断。回答の保存が呼ばれ、`FakeSession` にトークン使用量が 1 件あること
