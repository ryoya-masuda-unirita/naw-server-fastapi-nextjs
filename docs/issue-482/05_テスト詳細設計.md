## `generative-ai-adapter/generative-ai-core/tests/test_media_processors.py`（追記）

| テスト | 内容 |
|---|---|
| `test_text_processor_supports_legacy_office_when_tika_enabled` | `.doc`・`.xls`・`.ppt`・RTF・EPUB が対象になる |
| `test_text_processor_excludes_dedicated_formats_when_tika_enabled` | 画像・`.pdf`・`.docx`・`.pptx`・`.xlsx`・octet-stream は対象外 |
| `test_text_processor_keeps_text_only_when_tika_disabled` | 設定なしでは、従来と同じ（`.doc` は対象外） |
| `test_text_processor_extracts_via_tika` | Tika の本文の前後の空白を除いた成功の結果 |
| `test_tika_empty_text_is_parser_failure` | 空の本文は `PARSER_FAILURE` |
| `test_tika_file_problems_map_to_failure_codes` | 415 は `UNSUPPORTED_MIME`、422 は `CORRUPT_FILE` |
| `test_tika_outage_maps_to_parser_failure_without_content` | Tika の障害は `PARSER_FAILURE`、要約にファイルの中身が出ない |
| `test_octet_stream_stays_unsupported_when_tika_enabled` | 判定できないファイルは `UNSUPPORTED_MIME` のまま |
