# #417 issue-417 e2e-spec の専用環境で、画面をビルド済みの静的配信にして負荷による NG をなくす

## 概要

専用環境の画面は Vite の開発サーバーで配信している。並列 2 の通し実行でもアイドル時 CPU 46%・メモリ 1.3GB を使い、backend はほぼ遊んでいる。14-24・14-28・15-08 が負荷で落ちる（単独では OK）。

## 説明

### 対応

- 専用環境の画面を、ビルド済みの静的配信（本番に近い形）に変えて、通し実行を 2 回続けて NG 0（07-16・17-16〜21 を除く）にする

### 受け入れ条件

通し実行（並列 2）を 2 回続けて、07-16・17-16〜17-21 を除き NG 0。
