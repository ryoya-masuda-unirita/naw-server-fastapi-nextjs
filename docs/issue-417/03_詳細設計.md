## 画面の配信

- `frontend.Dockerfile` の 1 段目（node:24-slim）で `npm ci` → `npm run build`。2 段目（nginx:1.27-alpine）が `dist` を配信する。
- `client/.env.production` は `VITE_API_URL` を空、`VITE_AUTH_API_URL` を `/backend` にする（CloudFront 前提）。専用環境は backend を直接呼ぶため、ビルド引数 `VITE_API_URL` を受け、`VITE_API_URL` と `VITE_AUTH_API_URL` の両方に同じ値を環境変数で渡して上書きする（Vite はシェルの環境変数を `.env*` より優先する）。開発サーバーでは `VITE_AUTH_API_URL` が `.env` 経由で同じ値になっていたため、挙動が揃う。
- compose では demo の `frontend` を上書きする。
  - `build`: コンテキスト `./client`、Dockerfile は上記、引数 `VITE_API_URL=http://localhost:${DEMO_BACKEND_PORT}`（`environment` の `VITE_API_URL` はビルド済みでは不要なので `!reset` で消す）
  - `volumes`: `nginx.conf` を `/etc/nginx/conf.d/default.conf` に読み取り専用でマウント
  - `healthcheck`: nginx（alpine）には `wget` があるため、`wget` で `http://127.0.0.1:5173/` を確かめる
  - `ports`・`depends_on` は demo のものを引き継ぐ（コンテナ側のポート 5173 を nginx が待ち受ける）
