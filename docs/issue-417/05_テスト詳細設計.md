# 05_テスト詳細設計

## 実行コマンド（`e2e-spec/` で実行）

| # | コマンド | 見るもの |
|---|---|---|
| 1・2・3 | `npm run env:up` のあと、`curl -s -o /dev/null -w '%{http_code}' http://localhost:55273/` と `.../admin/assistants`（直接アクセス）。ログインして画面が出る | 200。画面が出る。backend の API が通る |
| 4・5 | `npm run spec:all`（並列 2。既定）を 2 回続けて実行 | 集計の NG が 07-16・17-16〜17-21 だけ |
| 6 | 通し実行中に `docker stats --no-stream` | 画面コンテナの CPU・メモリ |
| 7 | 起動前後に `docker ps` で他の環境のコンテナが残っていること | 影響がない |
| 8 | `npm run lint && npm run typecheck` | エラー 0 |

（ホスト側のポートは `e2e-spec/README.md` の既定値に従う。実行時に確認して `08_動作確認.md` に書く）

## 落ちた項目の切り分け

- `npm test -- --workers=1 tests/<該当の spec>` で単独再実行する。単独でも落ちるなら待ち方かテストの不備、単独で通るなら負荷。
- 待ち方の修正を入れたら、その項目を単独で繰り返し（`--repeat-each=5`）通し、あわせて通し実行で再確認する。
