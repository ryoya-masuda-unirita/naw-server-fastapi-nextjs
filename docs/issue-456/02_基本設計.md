# 02_基本設計

## 変更対象

追加ダイアログの「内側のカードの幅」と「ファイル名の列の最小幅」だけ。

## 画面 / API 変更概要

- 原因: 外枠だけを 1200px に広げる設定（大きいダイアログ用）はあるが、中のカードには最大 800px の既定の上限が残り、外枠を広げても中身が広がらない。
- 対応 1: 大きいダイアログ（1200px のもの）では、中のカードの上限を外し、外枠いっぱいまで使えるようにする。このダイアログを使っているのは、現状、追加ダイアログだけ。
- 対応 2: ファイル名の列に最小幅を付ける。ウィンドウが狭く、全列が収まらないときは、列を潰さず、カード内を横スクロールにする。
- 移植元（Angular）にも、この上書きは見当たらない。同じ崩れを持つ可能性が高いが、実機では確かめていない。
- 画面・API の仕様、文言は変えない。

## 影響範囲

- 大きいダイアログを使う画面は、追加ダイアログだけ（他に使う画面はない）。
- 追加ダイアログの表の見た目のみ変わる。
- 自動テスト（e2e-spec）の「データを追加する」共通操作に、表の幅の確認を足す。
