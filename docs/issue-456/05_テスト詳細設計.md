# 05_テスト詳細設計

## 実行

| # | 方法 |
|---|---|
| 1〜3 | 専用環境（別のプロジェクト名・ポート）を worktree の `client/` から起動し、Playwright でログイン → 学習データのフォルダ → 追加ダイアログ → ファイル選択 → 見出しの幅・カードの幅・`scrollWidth` を測り、スクリーンショットを撮る（使い捨てのスクリプト。リポジトリには入れない） |
| 4 | `client/src` の修正を一時的に外して環境を作り直し、`tests/17-training-data.spec.ts -g 17-28` を流して落ちることを確かめる。修正を戻して再ビルドし、通ることを確かめる |
| 5 | `npx vitest run src/components/features/admin/training-data src/routes/admin/training-data`（`client/`）、`npx playwright test tests/17-training-data.spec.ts`（`e2e-spec/`） |
| 6 | `npm run lint && npm run typecheck`（`e2e-spec/`）、`npx eslint`（変更した client のファイル） |

## 回帰テストの置き場所

項目書にない独立したテストは集計に載るか不明なため、追加ダイアログを開く既存の共通操作（`TrainingDataPage.addFile`）に確認を足す。これを使う 17-28・17-32 などが見張る。
