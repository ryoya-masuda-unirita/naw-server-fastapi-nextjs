# 03_詳細設計

## 変更ファイル

| ファイル | 変更 |
|---|---|
| `client/src/index.css` | `.dialog-xl .modal-dialog` に `md:max-w-none` を足す（`.dialog-xl .mdc-dialog__surface` の直後） |
| `client/src/components/features/admin/training-data/training-data-add-modal.tsx` | 表の見出しの「アップロードファイル名」と、各行のファイル名のセルに `md:min-w-32`（128px）を足す |
| `e2e-spec/src/pages/training-data.page.ts` | `expectUploadTableFitsDialog()` を足し、`addFile()` がファイルを選んだ直後に呼ぶ |

## 詳細

- `.modal-dialog` は `width: 100%; max-width: 480px`、md 以上で `max-width: 800px`（`index.css`）。`.dialog-xl .modal-dialog`（クラス 2 つ）で上書きするため、詳細度で勝つ。`max-sm` の挙動は変えない（`md:` に限る）。
- ファイル名の列は `table-list-col-content`（`flex: 1; min-width: 0`）。最小幅を付けると、固定幅の列（合計約 900px）とあわせて、カードが足りないときはカードの `overflow-y: auto` により横スクロールになる。
- `expectUploadTableFitsDialog()`: ダイアログ内の `.table-list-row--header .table-list-label` を測り、各見出しが 40px 以上の幅で、右端が `.modal-content`（内側のカード）の右端を超えないことを確かめる。外枠ではなく内側のカードを基準にするのは、外枠が広くてもカードが狭いと崩れるため。幅 0 の見出しは Playwright が非表示と判定するので、存在（`toBeAttached`）だけを待ち、幅は自前で測る。
