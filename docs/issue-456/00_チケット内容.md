# #456 issue-456 学習データの追加ダイアログで、アップロードファイルの表のレイアウトが崩れる（見出しが縦に積まれ、右端が欠ける）

## 概要

学習先フォルダの「学習データを追加」ダイアログで、ファイルを選ぶと出る表のレイアウトが崩れている。

- 左端の列「アップロードファイル名」の幅が極端に狭く、見出しの文字が 1 文字ずつ縦に積まれる
- 表が右にはみ出し、右端の列の見出しが途切れる（削除のアイコンも欠ける）。表の下に横スクロールバーが出る

## 再現手順

1. 管理者でログインし、「学習データ」画面を開く
2. フォルダを開き、「学習データを追加」を押し、「ファイルを選択」でファイルを 1 つ選ぶ
3. ダイアログ内の表を見る

## 期待する動作

- 見出しが、横書きで読める幅で表示される
- 表の全列が、ダイアログの幅の中に収まる（またはスクロールしても各列の見出し・ボタンが欠けない）
- 削除のボタンが操作できる

## その他

- 移植元（Angular）の同じダイアログと見比べて、移植の差分かどうか確かめる必要がある
- 対象: `client/src/components/features/admin/training-data/`
