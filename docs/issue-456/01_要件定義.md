# 01_要件定義

## 背景

- 学習データの追加ダイアログは、外枠を 1200px の幅で開く。ファイルを選ぶと、アップロードファイル名・表示名・参照資料のリンク・チャンク分割の細かさ・アップロード状況・削除の列を持つ表が出る。
- 表の列の幅は、表示名・リンクが各 240px、チャンクと状況が各 120px と固定で、合わせて約 900px になる。残りをファイル名の列が受け持つ。
- 実際には、外枠が 1200px あるのに、中の表を収めるカードが 736px しかなく、ファイル名の列が 0px に潰れて見出しが縦に積まれ、右の列がはみ出す。

## 機能要件

- 追加ダイアログの表の見出しが、横書きで読める幅で表示される。
- 表の全列が、ダイアログの中に収まる。ウィンドウが狭くて収まらないときは、横スクロールで全列に届き、見出し・削除ボタンが欠けない。
- 削除ボタンが操作できる。
- 他のダイアログの見た目・動作を変えない。

## 非機能要件

- 同じ崩れが再発したときに、自動テストで気づける。

## スコープ外

- 追加ダイアログ以外のダイアログのレイアウト。
- 表の列の構成・文言・入力チェックの変更。
- サーバー側（学習の処理）の変更。
