# 03_詳細設計

## 対象ファイル

### 新規作成

- `backend/app/core/file_creation.py`
  - `ensure_not_local(index: Index) -> None`: `LOCAL`タイプの場合400 `HTTPException`を送出（既存`FileService._ensure_not_local`をそのまま移設）。
  - `async def create_file_record(index, name, display_name, reference, current_user, upload, tenant_id, storage, session, feedback_id=None, room_id=None) -> File`: ストレージ保存＋`File`エンティティ作成（既存`FileService._save_to_storage_and_create`をそのまま移設し、`feedback_id`・`room_id`引数を追加）。

### 変更

- `backend/app/services/file_service.py`
  - `_ensure_not_local`・`_save_to_storage_and_create`を削除し、呼び出し元（`create_file`・`update_file`・`delete_file`）を`file_creation.ensure_not_local`・`file_creation.create_file_record`呼び出しに置き換える。
  - `from app.core import credit_quota, file_creation`をインポートに追加。

- `backend/app/repositories/message_feedback_repository.py`
  - `find_by_id_and_tenant_id(feedback_id: str, tenant_id: str, session: AsyncSession) -> MessageFeedback | None`を追加。

- `backend/app/schemas/index.py`
  - `IndexAdditionalLearningForm`（`feedbackId`・`roomId`を`Form()`で受け取る依存クラス。`FileUploadForm`と同じ形）を追加。

- `backend/app/services/index_service.py`
  - `sync_index() -> None`: 常に`HTTPException(400, "ファイル一括同期機能はローカルAPIサーバしか対応していません。")`を送出。
  - `additional_learning(index_id, tenant_id, current_user, feedback_id, room_id, upload, storage, session) -> None`:
    1. `feedback_id`・`room_id`のどちらか一方のみ指定されていることを検証（両方None・両方指定なら400「追加学習のデータソースが正しく指定されていません。」）。
    2. `IndexRepository.find_by_id_and_tenant_id`でインデックス取得。存在しなければ404。
    3. `file_creation.ensure_not_local(index)`。
    4. `credit_quota.enforce_within_quota(tenant_id, session)`。
    5. `feedback_id`指定時: `name = f"追加学習_{feedback_id}.md"`, `reference = f"フィードバック_{feedback_id}"`。`room_id`指定時: `name = f"追加学習_ルーム_{room_id}.md"`, `reference = f"フィードバック_{room_id}"`。
    6. `file_creation.create_file_record(index, name, "フィードバック学習", reference, current_user, upload, tenant_id, storage, session, feedback_id, room_id)`でファイル作成。
    7. `feedback_id`指定時のみ、`MessageFeedbackRepository.find_by_id_and_tenant_id(feedback_id, tenant_id, session)`で取得し、存在すれば`index_id`を更新し`MessageFeedbackRepository.save`で保存。

- `backend/app/routers/indexes.py`
  - `POST /{index_id}/sync`（204）: `IndexService.sync_index()`を呼ぶだけ。
  - `POST /{index_id}/additionalLearning`（204）: `content: UploadFile = File(...)`・`form: IndexAdditionalLearningForm = Depends()`・`storage: FileStorage = Depends(get_file_storage)`を受け取り、`IndexService.additional_learning(...)`を呼ぶ。

## 補足: splitLengthについて

移植元の`createFile`呼び出しでは`splitLength="3000"`を固定値で渡しているが、`create_file_record`（Issue #87時点の`create_file`同様）はコンテンツ分割（Issue #88スコープ）を実装しておらず`splitLength`を使用しないため、本Issueでも受け渡し・保持は行わない。
