# #92 issue-92 インデックス同期・追加学習APIの移植

## 概要

Issue #66（IndexController 基本CRUD APIの移植）でスコープ外とした、インデックス同期・追加学習APIを移植する。Fileドメイン（Issue #87）とMessageFeedbackが移植済みのため対応可能になった。

## 説明

対象エンドポイント:

- `POST /api/admin/indexes/{id}/sync`
- `POST /api/admin/indexes/{id}/additionalLearning`

参照（移植元、Spring Boot）:

- `~/Documents/naw-server/src/main/java/com/example/naw/api/IndexController.java`（syncIndex, addAdditionalLearning）
- `~/Documents/naw-server/src/main/java/com/example/naw/service/FileService.java`（syncFiles, additionalLearning）

移植先: `backend/app/routers/indexes.py`

実装メモ:

- `syncFiles`: 移植元は常に `BadRequestException("ファイル一括同期機能はローカルAPIサーバしか対応していません。")` を投げるスタブ実装。同様の挙動でよい。
- `additionalLearning`: `feedbackId`/`roomId` のどちらか一方必須というバリデーション、ファイル名・reference文字列の組み立て、既存の `create_file`（Issue #87で移植済み、`backend/app/services/file_service.py`）を利用したファイル登録、`feedbackId` 指定時は `MessageFeedback.index_id` の更新を行う。
- リクエストは `multipart/form-data`（`feedbackId`, `roomId`, `content`）。

## その他

- スコープ: バックエンド（FastAPI）のみ
- NAWチケットとの対応: なし（自動起票Issue）
