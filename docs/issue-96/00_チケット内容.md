# #96 issue-96 SAAS_RAG(ベクトル検索付きアシスタント)対応

## 概要

Message送信・LLM Chat両方でSAAS_RAGタイプのアシスタント（ベクトル検索付き）に対応する。ベクトルDBクライアント層の新規実装が必要。

## 説明

issue-88（LLMチャット・埋め込みAPI移植）・issue-93（メッセージ送信API移植）の両方で、SAAS_RAGは意図的にスコープ外とされていた。基本チャット（SAAS_CHAT）のみが移植済みの状態。

- 移植元（バックエンド）: `~/Documents/naw-server/src/main/java/com/example/naw/service` 配下のRAG/ベクトル検索関連実装
- 移植先: `backend/app/services/message_service.py`, `backend/app/services/llm_chat_service.py`
- 関連Issue: #88, #93（スコープ外節を参照）

## その他

- スコープ（想定）: SAAS_RAGタイプのアシスタントに対するベクトル検索クエリの実行／検索結果をLLMプロンプトへのコンテキストとして組み込み／ベクトルDBクライアント層の新規実装
- 参照調査の結果、`llm_chat_service.py`（移植元`LlmChatService.java`）にはRAG分岐が存在しないため、対応が必要なのは`message_service.py`のみと判明した（詳細は`01_要件定義.md`参照）。
