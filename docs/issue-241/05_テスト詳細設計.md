# 05_テスト詳細設計

すべて `frontend/` をカレントディレクトリとして、CI と同じコマンドを実行する（ローカル環境: Node v24.15.0 / npm 11.12.1）。

| No | コマンド | 確認内容 |
|---|---|---|
| 1 | `npm ci` | 終了コード 0 |
| 2 | `npm run lint` | 終了コード 0、ESLint の指摘なし |
| 3 | `npm run type-check` | 終了コード 0、tsc のエラー出力なし |
| 4 | `npm test -- --run` | 終了コード 0、全テストファイル・全テストが passed |
| 5 | `npm run build` | 終了コード 0、`dist/` に `index.html`・JS・CSS が出力される |
| 6 | `python3 -c "import yaml; yaml.safe_load(open('.github/workflows/frontend-tests.yml'))"`（リポジトリ直下で実行） | 例外が出ない |
| 7 | PR 作成後に `gh pr checks <PR番号> --repo ryoya-masuda-unirita/naw-server-fastapi-nextjs` | 「lint・型チェック・テスト・ビルド」が pass |
