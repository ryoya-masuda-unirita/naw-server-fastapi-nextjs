# 08_動作確認

ブラウザ・実機確認は行わず、CI と同じコマンドを手元で実行した結果と、PR 上で実際にワークフローが走った結果で代替する（画面の変更はない）。

## 確認環境

- macOS（Darwin 27.2.0）
- Node v24.15.0 / npm 11.12.1（CI は `actions/setup-node@v4` の Node 24）
- ブランチ `feature/issue-241`（`origin/develop` から作成）
- 実行日時: 2026-11-12 23:2x JST

## 確認手順

`frontend/` で、ワークフローと同じ順にコマンドを実行し、それぞれの終了コードを確認した。

1. `npm ci`
2. `npm run lint`
3. `npm run type-check`
4. `npm test -- --run`
5. `npm run build`
6. ワークフロー定義の YAML 構文確認
7. PR 作成後に `gh pr checks` で、PR 上の実行結果を確認
