# フロントエンドのPR用CIを追加する

## 概要

`.github/workflows/` には backend の PR 用 CI（`backend-tests.yml`）しかなく、`frontend/` の変更は PR で lint・型チェック・テスト・ビルドが走らない。

## 説明

### 対応

- `frontend/` に変更がある PR（と `develop` への push）で、lint・型チェック・テスト（vitest）・ビルドを実行するワークフローを追加する
- コマンドは `frontend/package.json` のスクリプトに合わせる

## その他

- GitHub Issue: https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/issues/241
- 移植作業ではない（移植元 `secuaigent` に対応するコードはない）。CI 整備のみ
