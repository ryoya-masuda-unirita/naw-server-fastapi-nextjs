# 03_詳細設計

## 新規ファイル: `.github/workflows/frontend-tests.yml`

ファイル名は `backend-tests.yml` と対にする。

### トリガー

```yaml
on:
  pull_request:
    branches: [develop, main]
    paths:
      - "frontend/**"
      - ".github/workflows/frontend-tests.yml"
  push:
    branches: [develop]
    paths:
      - "frontend/**"
      - ".github/workflows/frontend-tests.yml"
```

- `backend-tests.yml` と同様に、ワークフロー自身の変更でも走らせる（設定ミスにすぐ気づくため）
- `backend-tests.yml` の push はブランチ指定なしだが、こちらは Issue の要件どおり develop に絞る

### 権限

```yaml
permissions:
  contents: read
```

### ジョブ `checks`（表示名: lint・型チェック・テスト・ビルド）

- `runs-on: ubuntu-latest`
- `defaults.run.working-directory: frontend`

| # | ステップ名 | 内容 |
|---|---|---|
| 1 | （checkout） | `actions/checkout@v4` |
| 2 | Nodeをセットアップ | `actions/setup-node@v4`、`node-version: 24`、`cache: "npm"`、`cache-dependency-path: frontend/package-lock.json`（`deploy-frontend.yml` と同じ指定） |
| 3 | 依存関係をインストール | `npm ci`（`frontend/package-lock.json` があるため npm を使う） |
| 4 | リンターを実行 | `npm run lint`（`eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0`） |
| 5 | 型チェックを実行 | `npm run type-check`（`tsc --noEmit`。既存スクリプト） |
| 6 | 単体テストを実行 | `npm test -- --run`（`test` スクリプトは `vitest` のウォッチモードのため `--run` を渡す） |
| 7 | ビルドを実行 | `npm run build`（`tsc -b && vite build`。`.env.production` を使い、シークレット不要） |

## 変更ファイル: `.github/workflows/deploy-frontend.yml`

- lint・テストステップの上のコメント「frontend/ のテストを実行するCIワークフローは他にないため、配信前にlint・単体テストを通す」を、`frontend-tests.yml` があることを踏まえた内容に変える。ステップの処理は変えない

## `frontend/package.json`

- 変更なし（`lint` / `type-check` / `test` / `build` スクリプトが揃っている）
