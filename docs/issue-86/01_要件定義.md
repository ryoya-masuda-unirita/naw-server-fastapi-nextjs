# 01_要件定義

## 背景

Spring Boot版には、管理者がテナントに紐づくAzureリソース（Azure OpenAI等）のコストをAzure Cost Management API経由で取得する管理者向けAPIが存在するが、FastAPI版にはまだ移植されていない。テナント管理画面等でのコスト可視化に必要な機能であり、移植対象として起票された。

## 機能要件

- テナント管理者が、自テナントに紐づくリソースのコストを取得できること
- リソースIDを指定してコストを取得できること（リソースが自テナントに属さない場合はエラーとすること）
- 集計期間（開始日時・終了日時）を任意で指定できること。指定しない場合は直近の請求月を対象とすること
- レスポンスはリソースタイプ・日付ごとのコスト一覧（配列）とすること
- 管理者ロール（ADMIN/SYSTEM）以外のユーザーからのアクセスを拒否すること

## 非機能要件

- Azure Cost Management APIへの実際の呼び出しは、このIssue対応のテストでは行わない（自動テストではAzure SDKクライアントをモックする）
- 認証情報（サブスクリプションID、テナントID、クライアントID・シークレット等）は環境変数から読み込むこと。ソースコードに直接書かないこと
- 既存の router:service 1対1規約、N+1回避規約に従うこと

## スコープ外

- Azure Cost Management APIの実クレデンシャルを用いた実環境での動作確認（このIssueでは対応しない。別途インフラ整備後に確認する）
- ブラウザ操作による動作確認（自動テストで代替する）
- コスト情報のフロントエンド表示（別Issueで対応）
