# 03_詳細設計

## 実装対象ファイル

### 新規作成

- `backend/app/core/azure_cost_client.py`
  - `AzureCostQueryResult`（dataclass）: `resource_type`, `usage_date`, `pre_tax_cost`, `currency`
  - `AzureCostClient`: `get_cost_by_resource_id(resource_id, start_date, end_date) -> list[AzureCostQueryResult]`（staticmethod）
    - `ClientSecretCredential`でAzure認証情報を組み立て、`CostManagementClient`でAzure Cost Management APIを呼び出す
    - `start_date`・`end_date`が共にNoneの場合は`timeframe="TheLastBillingMonth"`、共に指定がある場合は`timeframe="Custom"` + `QueryTimePeriod`（片方のみの指定は呼び出し前に`TenantService.query_cost`側で400として弾く。詳細は下記参照）
    - `ResourceId IN [resource_id]`のフィルタ、`ResourceType`でのグルーピング、`PreTaxCost`の`Sum`集計、`Daily`粒度で問い合わせる
    - レスポンス行は固定インデックスではなく、レスポンスの`columns`（列メタデータ）から`totalCost`/`UsageDate`/`ResourceType`/`Currency`の列名で位置を特定してマッピングする（`_map_rows`）。クエリ定義変更等で列順が変わっても誤マッピングしないための対応（code-review指摘#3への対応）。想定列が見つからない場合は`ValueError`、行の列数が列メタデータと不一致の場合はログ出力の上でその行を無視する

### 変更

- `backend/app/core/config.py`
  - `AzureCostSettings`（`BaseSettings`）を追加: `azure_subscription_id`, `azure_resource_group_name`, `azure_tenant_id`, `azure_client_id`, `azure_client_secret_value`（環境変数`AZURE_APP_*`から読み込み）
  - `get_azure_cost_settings()`（`@lru_cache`）を追加
- `backend/app/repositories/tenant_resource_repository.py`
  - `find_by_id_and_tenant_id(resource_id, tenant_id, session) -> TenantResource | None` を追加（リソースID・テナントIDの一致で1件取得。テナント⇔リソースの紐付けチェックに使う）
- `backend/app/schemas/tenant.py`
  - `TenantResourceCostResponse`（`BaseModel`）を追加: `resourceType: str`, `usageDate: date`, `preTaxCost: float`, `currency: str`
- `backend/app/services/tenant_service.py`
  - `query_cost(tenant_id, resource_id, from_, to, session) -> list[TenantResourceCostResponse]` を追加
    - `TenantResourceRepository.find_by_id_and_tenant_id`でリソースの紐付けを検証。見つからない場合は`HTTPException(400)`
    - `from_`/`to`の一方のみが指定された場合は`HTTPException(400)`（Azure Cost Management APIはCustom期間指定時にfrom/to両方を要求するため、Azure呼び出し前に弾く。code-review指摘#2への対応）
    - `from_`/`to`をISO8601としてパース（`_parse_iso_datetime`）。パース失敗時は`HTTPException(400)`
    - `AzureCostClient.get_cost_by_resource_id`を呼び出し、結果を`TenantResourceCostResponse`のリストに変換
- `backend/app/routers/tenants.py`
  - `GET /resources/{resource_id}/cost` を追加。`Depends(require_admin)`で管理者ロールを検証し、`current_user.tenant_id`をテナントIDとして`TenantService.query_cost`を呼び出す
- `backend/pyproject.toml`
  - `dependencies`に`azure-identity`, `azure-mgmt-costmanagement`を追加

## パラメータ仕様

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `resourceId`（パス） | str | 必須 | コストを取得する対象リソースのID（`tenant_resources.id`） |
| `from`（クエリ） | str | 任意 | 集計期間の開始日時（ISO8601形式、`Z`サフィックス許容） |
| `to`（クエリ） | str | 任意 | 集計期間の終了日時（ISO8601形式、`Z`サフィックス許容） |

## エラー仕様

| ケース | ステータス |
|---|---|
| 未認証 | 401 |
| 管理者ロールでない | 403 |
| `resourceId`が認証テナントに属さない・存在しない | 400 |
| `from`/`to`の一方のみが指定されている | 400 |
| `from`/`to`がISO8601形式として解釈できない | 400 |
