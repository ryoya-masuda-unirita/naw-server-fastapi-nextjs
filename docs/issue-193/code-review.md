## 詳細

### 1. e2eテストへの意図しないPrettier整形の混入（🟡 注意）→ 対応済み

`e2e/fixtures/auth.fixture.ts`および全`e2e/*.spec.ts`にテナントID入力欄の`fill()`呼び出しを追加した後、フォーマット確認のため`npx prettier --write "e2e/**/*.ts"`を実行した。しかし`package.json`の`format`スクリプトは`"prettier --write \"src/**/*.{ts,html,scss}\""`であり`e2e/`を含んでいないため、`e2e/`配下は元々このプロジェクトの自動整形ルールでは整形されていなかった。そこへ手動でprettierを実行した結果、テナントID追加とは無関係な改行位置の変更（100文字幅への折り返し・展開）が16ファイルに渡って混入し、本Issueの意図（サブドメイン廃止）と関係のない差分がPRに含まれる状態になっていた。

対応として、`develop`ブランチの元のファイル内容を基準に、テナントID入力の追加（および`login.spec.ts`の必須項目テスト更新・件数変更）のみを整形をかけずに再適用し、無関係な差分を除去した。修正後、`e2e/login.spec.ts`・`e2e/logout.spec.ts`を実バックエンド接続でPlaywright実行し、全件成功することを再確認済み。
