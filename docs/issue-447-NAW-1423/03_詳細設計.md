# 03_詳細設計

対象は `client/src/`。

## 1. `lib/utils/fetch-all-pages.ts`（新規）
- `fetchAllPages(fetchPage, pageSize = 1000)`: `page = 0` から、`fetchPage(page, pageSize)` を呼び、項目を足す。`items.length === 0` か、累計が `total` 以上で止まる。失敗は、そのまま上に出す
- `totalElementsOf(raw, itemCount)`: ページ形式の応答の `totalElements`。配列・`totalElements` なしは、項目数（1 ページで終わる）

## 2. `hooks/fetch-all-users.ts`（新規）
`fetchAllUsers()`: `ADMIN.USERS.LIST` を、`sort: 'name,asc'`・`includeUsage: false` で全ページ取る。`use-tenant.ts` の `useUsageFilterUsers`（#426）の取得ループを、ここに移し、チャット履歴でも使う。`USAGE_FILTER_USER_PAGE_SIZE`（未使用になる）は削除する

- 対応表が取れるまでは `EMPTY_LOOKUP` で `toViewModel`（ID のまま）。スピナーは `listQuery.isFetching` だけ（`isLookupReady` を削除）
