# 08_動作確認

## 確認環境

- macOS ローカル環境
- Python 3.14.6
- `backend/.venv`
- SQLite インメモリDB（`backend/tests/integration/conftest.py`）

## 確認手順

1. `cd backend`
2. `UV_CACHE_DIR=/private/tmp/uv-cache uv run pytest tests/integration/test_rooms.py tests/integration/test_assistants.py`
3. `UV_CACHE_DIR=/private/tmp/uv-cache uv run ruff check app tests`
4. `UV_CACHE_DIR=/private/tmp/uv-cache uv run pytest`

## 確認結果

- `tests/integration/test_rooms.py` で以下を確認した
  - `GET /api/rooms` の一覧取得、ページングバリデーション、`name` 部分一致検索
  - 固定済みルーム優先、同一固定状態内での `updatedAt` 降順
  - `GET /api/rooms/{roomId}` の自ユーザー所有ルーム取得
  - `POST /api/rooms` の作成、255文字超過時のルーム名切り詰め、無効な `assistantId` の400
  - `PATCH /api/rooms/{roomId}` の更新
  - `DELETE /api/rooms/{roomId}` の削除、および関連 `room_pins` のCASCADE削除
  - `POST /api/rooms/{roomId}/pin` の固定、再固定時の冪等成功
  - `DELETE /api/rooms/{roomId}/pin` の固定解除、未固定時404
  - JWT と `X-Tenant-ID` の不一致時403、未認証時401
- `tests/integration/test_assistants.py` で、`rooms.default_assistant_id` に参照されているアシスタント削除時に400となることを確認した
- `UV_CACHE_DIR=/private/tmp/uv-cache uv run ruff check app tests` は `All checks passed!`
- `UV_CACHE_DIR=/private/tmp/uv-cache uv run pytest` は `275 passed` で完了した
