# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | ルーム一覧取得 | 自ユーザーのルームが複数あり、一部が固定済み | 固定済みが先頭、同一固定状態内では `updatedAt` 降順、`content/totalElements/number/size` 形式で返る |
| 2 | ルーム一覧検索 | `name` に部分一致するルームのみ存在 | 大小文字を問わず一致したルームだけ返る |
| 3 | ルーム一覧境界値 | `page < 0` または `size` が 1 未満 / 101 超過 | FastAPI のバリデーションで 422 になる |
| 4 | ルーム単体取得 | 自ユーザー所有のルームを取得する | 200 でルーム詳細が返る |
| 5 | ルーム単体取得権限制御 | 他ユーザー所有ルームIDを指定する | 404 になる |
| 6 | ルーム作成 | 正常な `name` と `assistantId` を指定する | ルームが作成され、`tenant_id`・`user_id`・`default_assistant_id` が保存される |
| 7 | ルーム作成の名前切り詰め | 256文字超の `name` を指定する | 400 ではなく成功し、保存値が255文字に切り詰められる |
| 8 | ルーム作成のアシスタント検証 | 他テナントまたは不存在の `assistantId` を指定する | 400 になる |
| 9 | ルーム更新 | 自ユーザー所有ルームの `name` を更新する | 200 で更新後の値が返り、DBにも反映される |
| 10 | ルーム更新権限制御 | 他ユーザー所有ルームIDを指定する | 404 になる |
| 11 | ルーム削除 | 自ユーザー所有ルームを削除する | 204 で削除され、再取得すると404になる |
| 12 | ルーム削除の副作用 | 固定済みルームを削除する | `room_pins` もFK/CASCADEで削除される |
| 13 | ルーム固定 | 未固定の自ユーザー所有ルームを固定する | 204 で `room_pins` に1件追加される |
| 14 | ルーム固定の冪等性 | 同じルームを2回連続で固定する | どちらも成功し、`room_pins` は1件のまま |
| 15 | ルーム固定権限制御 | 他ユーザー所有ルームIDを指定する | 404 になる |
| 16 | 固定解除 | 固定済みルームを解除する | 204 で `room_pins` から削除される |
| 17 | 固定解除未固定 | ルームは存在するが固定されていない | 404 になる |
| 18 | 固定解除存在確認 | ルーム自体が存在しない | 404 になる |
| 19 | テナント分離 | JWT の tenant と異なる `X-Tenant-ID` を送る | 403 になる |
| 20 | 認証 | トークンなしで各APIを呼ぶ | 401 になる |
| 21 | マイグレーション制約 | `rooms.default_assistant_id` が参照中のアシスタントを削除する | DB上は RESTRICT され、APIは 400 を返す |
| 22 | マイグレーション制約 | テナント削除またはユーザー削除を行う | `rooms` / `room_pins` が CASCADE で削除される |
| 23 | 既存API影響 | ルーム未使用アシスタントを削除する | 既存の削除APIは従来どおり 204 を返す |

## テストレベル

- API/統合テスト: `backend/tests/integration/` に追加し、HTTP レイヤーから CRUD・固定操作・認証認可・DB副作用を確認する
- Repository テスト: 同じく `integration/` で一覧ソート、部分一致検索、CASCADE を実DBで確認する
- Unit テスト: 必須ではないが、固定・固定解除の純粋ロジックを helper に切り出した場合のみ追加する

## 方針メモ

- 既存実装の流儀に合わせ、RouterテストとRepositoryを分離しすぎず `integration` 中心で検証する
- `fastapi-pagination` は今回使わず、既存 `AssistantService` と同様に手動ページネーション結果を検証する
- `frontend-angular` を使ったブラウザ確認は実装フェーズ後の `08_動作確認.md` で扱い、この段階ではテスト設計の対象外とする
