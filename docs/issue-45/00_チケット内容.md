# チャットルーム管理APIの実装

## 概要

チャットルーム（room）のCRUD・固定/解除APIをFastAPIで実装し、`rooms`/`room_pins`テーブルを追加する。後続のメッセージ送受信機能（SSEストリーミング）の土台とする。

## 説明

移植元（`naw-server`）の`RoomController`/`RoomService`/`RoomAccessService`が持つ機能のうち、ルームの一覧取得・単体取得・作成・更新・削除・固定・固定解除をポートする。

管理者向け履歴一覧、フィードバック（評価）、共有（share）、ルーム作成時のテナント月次クレジット上限チェックは、それぞれ依存ドメイン（feedback集計対象/share/plan・subscription・tokenusage）が未移植のため、本Issueの対象外として別Issueに切り出す。
