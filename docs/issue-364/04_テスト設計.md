# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | チーム所属アシスタントのカテゴリ順（昇順） | カテゴリ名 Alpha・Bravo・Charlie のアシスタントがある | Alpha, Bravo, Charlie の順 |
| 2 | 同（降順） | `sort=category,desc` | 逆順 |
| 3 | 複数カテゴリ | Charlie と Alpha を持つアシスタントがある | 先頭カテゴリ（ID昇順）の Charlie の位置に並び、行・総件数が重複しない |
| 4 | 絞り込みとの組み合わせ | 種別で絞り込み＋カテゴリ順 | 絞り込み後の行がカテゴリ順に並ぶ |
| 5 | 管理者向けアシスタント一覧 | `sort=category` | 同様にカテゴリ名順（昇順・降順） |
| 6 | E2E | 項目書 14-55・14-67 | OK |
