# 01_要件定義

## 背景

チーム詳細の所属アシスタント一覧で「カテゴリ順」を選んでも、並びが追加日時順のままになる。移植元はカテゴリ名の並びになる。

## 機能要件

- 所属アシスタント一覧で `sort=category` を指定すると、アシスタントのカテゴリ名で並ぶ（昇順・降順とも）
- 種別（サーバー）などの絞り込みと組み合わせても並べ替えられる
- 複数カテゴリを持つアシスタントでも、一覧の行が重複せず、総件数が変わらない
- 同種の漏れがあるほかの一覧 API があれば、移植元に揃える

## 非機能要件

- 並べ替えは既存の共通処理（`build_order_by`）の対応表に足す形にする
- 同値の行はIDで順序を確定させ、ページ境界で重複・欠落しない

## スコープ外

- カテゴリの絞り込み・種別の絞り込み・検索の挙動の変更
- 並べ替えのキー以外の API 仕様の変更
