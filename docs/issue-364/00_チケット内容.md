# チーム詳細の所属アシスタント一覧でカテゴリ順の並べ替えを移植元に揃える

## 概要

`GET /api/admin/groups/{id}/assistants` の `sort=category` を backend が解釈せず、追加日順に落ちる。移植元は `assistant.categoryMappings.category.name` で並べる。

## 説明

- 対象の項番: 結合テスト項目書 14-55・14-67（`e2e-spec/tests/14-team-management.spec.ts`）
- 並べ替えの共通処理（`app/core/sort.py`）の使い方に合わせる
- 同種の漏れがほかの一覧 API にないかも確かめる
- 原因・移植元の挙動は `docs/issue-316/ng-チーム管理.md` を参照

## その他

目標は移植元の完璧なクローン。
