# 03_詳細設計

## 実装対象ファイル

| ファイル | 変更 |
|---|---|
| `backend/app/repositories/assistant_category_mapping_repository.py` | 並べ替え用の列式 `PRIMARY_CATEGORY_NAME`（アシスタントごとにカテゴリID昇順で先頭のカテゴリ名を返す相関スカラー副問い合わせ）を追加 |
| `backend/app/repositories/group_assistant_repository.py` | `_SORT_COLUMNS` に `"category": PRIMARY_CATEGORY_NAME` を追加 |
| `backend/app/repositories/assistant_repository.py` | `_SORT_COLUMNS` の `"category"` を更新日時順のフォールバックから `PRIMARY_CATEGORY_NAME` に変更 |

## 同種の漏れの確認結果

移植元で `PageableSortUtil.remapSort` を使う一覧と、`backend/app/repositories/*` の `_SORT_COLUMNS` を突き合わせた。`category` を別名に持つのは、チーム所属アシスタント（`GroupService.findGroupAssistants`）と管理者向けアシスタント一覧（`AssistantService.getAdminAssistants`）の 2 つ。後者は backend が意図して更新日時順にしていた（コメントに「多重度のため」）ため、同じ方法で揃える。

## 注意

- `Assistant` に相関させるため、`select(...).correlate(Assistant)` を明示する
