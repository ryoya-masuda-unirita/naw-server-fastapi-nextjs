## 修正前の再現手順

`server-local/app`・`alembic`・`docker-entrypoint.sh` の変更を `git stash push -u -m <tag> -- app alembic docker-entrypoint.sh` で一時的に退避し、新しいテストを実行して失敗を確認した後、SHA 指定の `git stash apply` で戻す。
