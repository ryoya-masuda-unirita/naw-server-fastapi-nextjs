# 03_詳細設計

## 実装対象ファイル

### `backend/app/services/message_service.py`

#### `_sse`

```python
def _sse(event_type: str, payload: dict) -> bytes:
    """移植元と同じ形式のSSEイベント1件を組み立てる。"""
    data = {"type": event_type, **payload}
    return f"data: {json.dumps(data, ensure_ascii=False)}\n\n".encode()
```

- 移植元の各 `Sse*Event` レコードは先頭フィールドが `type` で、`SseEmitter.event().data(json)` によりイベント名の行なしで送られる。これに合わせ、`event:` 行を出さず、JSON に `type` を含める。
- 呼び出し側（`text_delta`・`library_{kind}_delta`・`message_stop`・`error`）は引数を変えずにそのまま使える。

#### `stream_message_content` の最後のイベント

```python
yield _sse("message_content", {"data": content_response.model_dump(mode="json")})
```

- 移植元 `SseCreateMessageContentResponseEvent.of(response)`（`type="message_content"`、`data=CreateMessageContentResponse`）に合わせる。
- 送出条件（`stream_finished and content_response is not None`）・順序は変更しない。
- docstring・コメント中の「`complete`イベント」の記述を「`message_content`イベント」に更新する。

## 移植元との対応

| 移植元 | 本ポート |
|---|---|
| `sendSseTextDelta` / `SseTextDeltaEvent` | `_sse("text_delta", {"text": ...})` |
| `sendSseLibraryTitleDelta` / `sendSseLibraryContentDelta` | `_sse(f"library_{kind}_delta", {"text": ...})` |
| `sendSseMessageStop` / `SseMessageStopEvent` | `_sse("message_stop", {"inputTokens", "outputTokens"})` |
| `sendSseError` / `SseErrorEvent` | `_sse("error", {"message": ...})` |
| `sendSseFinalResponse` / `SseCreateMessageContentResponseEvent` | `_sse("message_content", {"data": ...})` |
