# 08_動作確認

## 確認環境

- **ブラウザ・実機確認は行わず、自動テストのみで代替した**（全自動モード。ローカルの Postgres / Redis / backend サーバーは他の作業と共有のため起動・変更していない）
- `backend/` で `uv run pytest`（インメモリ SQLite + fakeredis、LLM 呼び出しはモック）
- Issue #182 の修正（PR #207、リクエストの multipart 化）を含む origin/develop をマージ済みの状態で実行
- `backend/.env` はメインの作業ツリーからコピーして使用（設定系テストの前提）

## 確認手順

1. ストリーミング応答を frontend-angular と同じ規則（`data:` 行の JSON の `type` で種別を判定）で解釈する検証に、単体・結合テストを置き換えて実行した
2. 編集・再送信シナリオのテスト（`test_edit_and_resend_streams_message_content_with_edited_question`）について、サービスだけを修正前（origin/develop）に一時的に戻して実行し、修正前は失敗することを確認した
3. backend の全テストと mypy（CI と同じ `uv run mypy app tests`）を実行した
