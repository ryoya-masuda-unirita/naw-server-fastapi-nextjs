# ユーザーメッセージを編集して再送信すると、内容が更新されずAI回答がエラーになる

## 概要

チャットのユーザーメッセージを編集（鉛筆アイコン）し、内容を変更して「再送信」ボタンを押すと、メッセージ内容が編集後のテキストに更新されず、AI回答が「回答エラー」（"エラーが発生しました。しばらく経ってから再度お試しください。"）となる。

## 説明

### 再現手順

1. チャットルームでメッセージを送信し、AI回答が返るまで待つ
2. 送信したユーザーメッセージにカーソルを合わせ「編集」ボタンをクリック
3. テキストエリアの内容を別の文言に変更する
4. 「再送信」ボタンをクリック

### 期待結果

編集後の内容でメッセージが更新され、新しいAI回答が生成される（バージョン分岐として2/2等のページネーションが表示される）。

### 実際の結果

- 画面上のユーザーメッセージは編集前の元テキストのまま変化しない
- AI回答側に「回答エラー」が表示される

### 追加調査（Issue コメント）

編集用テキストエリアの内容を空にしても「再送信」ボタンが非活性にならない（空入力に対するバリデーションが機能していない）。
