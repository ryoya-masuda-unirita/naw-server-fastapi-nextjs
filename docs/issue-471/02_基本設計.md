# 02_基本設計

- `select`・`select-with-search`: 外側の div は見た目とクリックだけを受け、役割（`combobox`・`aria-expanded`・`aria-haspopup`・名前）は中のラベル部分（`select`）または入力欄（`select-with-search`）に付ける。クリアボタンは外側の div の子として、`combobox` の外に置く
- `multi-select`・`chunk-select`・`period-filter`: トリガーに `role="combobox"` と名前を足す（中にチップの削除ボタンがある `multi-select` の入れ子は今回は残す）
- 文字色: プレースホルダーを `text-text-muted`（#666、白地で 5.7:1）にする。全体の `text-text-lighter` トークンは変えない
- 新しい翻訳キー `COMMON.CLEAR`（ja「クリア」/ en「Clear」）
