# 00_チケット内容

## タイトル

#471 issue-471 共通セレクト／コンボボックスのアクセシビリティ違反を直す（axe）

## 内容

Issue #471 の本文のとおり。E2E 探索（2026-11-24-develop）で出た axe の違反のうち、共通セレクト／コンボボックス（`select`・`select-with-search`・`multi-select`・`chunk-select`・`period-filter`）の分。

- `aria-allowed-attr`: `aria-haspopup="listbox"` が役割のない div に付いている
- `button-name`: `.combobox-clear`（クリアボタン）に名前がない
- `color-contrast`: プレースホルダー（`text-text-lighter` #adadad）のコントラスト不足
- `aria-input-field-name`: ドロップダウンの listbox に名前がない
- `nested-interactive`: トリガーの中にクリアボタンが入れ子
