# 05_テスト詳細設計

## 対象テストファイル

### `backend/tests/unit/test_message_service.py`

`TestStreamMessageContent`配下に以下を追加する。

- `test_raises_404_when_message_content_not_found_for_regenerate`
  - `MessageContentRepository.find_by_id_and_tenant_id`を`None`でモックし、`messageContentId`指定のリクエストで404になることを確認。
- `test_regenerates_existing_content_and_overwrites_answer`
  - `MessageContentRepository.find_by_id_and_tenant_id`が既存`MessageContent`（`question="元の質問"`）を返すようモックし、`MessageContentRepository.update_answer`が`status`・`answer`・`context`・`file_paths`を引数に呼ばれ、`question`は変更されないことを確認。
  - `_persist_message_content`の呼び出し経路上、`MessageContentRepository.save`ではなく`update_answer`が呼ばれることをアサートする。
- `test_regenerate_preserves_question_when_error_occurs`
  - ストリーミング中に例外発生 → `ERROR`ステータスで`update_answer`が呼ばれ、`question`は元のまま保持されることを確認。
- 既存の`test_streams_text_delta_then_message_stop_and_persists_content`等は`messageId`指定のみのため変更不要（回帰確認用にそのまま維持）。

### `backend/tests/unit/test_message_schemas.py`（新規）

`MessageContentCreateRequest`のバリデーションテスト。

- `test_raises_error_when_both_message_id_and_content_id_are_none`
  - `messageId`・`messageContentId`両方省略 → `ValidationError`。
- `test_accepts_message_content_id_only`
  - `messageContentId`のみ指定 → 正常にインスタンス化できる。
- `test_accepts_message_id_only`
  - `messageId`のみ指定（既存動作） → 正常にインスタンス化できる。

### `backend/tests/integration/test_messages.py`（既存ファイルに追記）

`TestCreateMessageContent`配下に、実際に`POST /api/messages/content`をE2Eで叩くテストを追加する（既存の`owned_message_content`フィクスチャを再利用できるため、新規Repositoryテストファイルは作成せず、既存のE2E統合テストに寄せる）。

- `test_regenerates_existing_content_and_keeps_question`
  - `messageContentId`指定でSSEを完走させ、`complete`イベントの`question`が変更されず`answer`のみ上書きされていることを確認。
- `test_regenerate_returns_404_when_message_content_not_found`
  - 存在しない`messageContentId` → 404。
- `test_regenerate_returns_403_when_room_not_owned`
  - 他人のルームに属する`messageContentId`（テナント分離検証を兼ねた`other_users_message_content`フィクスチャを追加） → 403。
- `test_returns_422_when_neither_message_id_nor_content_id_given`
  - `messageId`・`messageContentId`いずれも未指定 → 422（Pydanticバリデーションエラー）。

## 実行コマンド

```bash
cd backend
pytest tests/unit/test_message_service.py tests/unit/test_message_schemas.py -v
pytest tests/integration/test_messages.py -v
pytest
```
