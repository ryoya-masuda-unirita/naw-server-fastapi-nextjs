# テンプレート一覧の並べ替え(名前順/昇順降順)がUI上のみでAPIに反映されずupdated_at降順固定になる

## 概要

管理コンソール「テンプレート」一覧の並べ替えUI（テンプレート名順/更新日時順、昇順/降順）を操作しても、実際の表示順が一切変化しない。

## 説明

- Issue 本文の想定: フロントエンドの `template-list.store.ts` が `sortField`/`sortOrder` を API に送っておらず、バックエンドの `find_page_for_admin` も `sort` 系パラメータを受け取らず `updated_at` 降順で固定されている。
- 発見経緯: Issue #166（結合テストE2Eのプレイライト自動化、19_テンプレートカテゴリ 項番11〜13）で並べ替え機能をテスト中に発見。期待値は「並べ替えで『テンプレート名順』を選択するとテンプレート名順に表示される」こと。
- 対応方針案（Issue 記載）: バックエンドでソートキー・順序を受け取り `order_by` を動的に組み立てる。フロントエンドでも `sortField`/`sortOrder` を送信する。
