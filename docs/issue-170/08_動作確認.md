# 08_動作確認

## 確認環境

- ブラウザ・実機での確認は行わず、自動テストのみで代替した（ローカルの Postgres/Redis/backend サーバーは他の作業と共有しているため起動・変更しない方針）。
- `backend/` で `uv run pytest` を実行（DB はインメモリ SQLite、Redis は fakeredis）。
- `backend/.env` はメインの作業ツリーと同じものを使用（設定まわりのテストが `.env` を前提にしているため）。

## 確認手順

1. 並べ替えの追加テストとサービス単体テストを実行する。

   ```bash
   uv run pytest -v tests/integration/test_prompt_templates.py::TestGetAdminPromptTemplatesSort tests/unit/test_prompt_template_service.py -p no:warnings
   ```

2. バックエンドのテストを全件実行し、回帰がないことを確認する。

   ```bash
   uv run pytest -q -p no:warnings
   ```
