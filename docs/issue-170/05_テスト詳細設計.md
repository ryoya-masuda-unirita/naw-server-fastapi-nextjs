# 05_テスト詳細設計

## テスト対象ファイル

- `backend/tests/integration/test_prompt_templates.py`
  - `TestGetAdminPromptTemplates` にテストを追加する。
  - 並び順を確定させるため、`updated_at` を明示してテンプレートを作成するヘルパーを使う。
- `backend/tests/unit/test_prompt_template_service.py`
  - 既存テストの `get_admin_prompt_templates` 呼び出しに `sort` 引数を追加する。
  - `sort` の分解結果がリポジトリへ渡ることのテストを追加する。

## テストケース

| No | テスト名 | 内容 |
|---|---|---|
| 1 | `test_sorts_by_name_asc` | `sort=name,asc` で名前昇順 |
| 2 | `test_sorts_by_name_desc` | `sort=name,desc` で名前降順 |
| 3 | `test_sorts_by_updated_at_asc` | `sort=updatedAt,asc` で更新日時昇順 |
| 4 | `test_default_sort_is_updated_at_desc` | `sort` 未指定で更新日時降順 |
| 5 | `test_sort_is_applied_before_paging` | `sort=name,asc&page=1&size=2` で3〜4件目 |
| 6 | `test_sort_direction_defaults_to_asc` | `sort=name` で昇順 |
| 7 | `test_unknown_sort_property_falls_back_to_updated_at` | `sort=unknown,asc` で更新日時昇順・200 |
| 8 | `test_ties_are_ordered_by_id` | 同名テンプレートが ID 昇順 |
| 9 | `test_passes_parsed_sort_to_repository`（unit） | `name,DESC` → `("name", "desc")` |

## 実行コマンド

```bash
cd backend && uv run pytest
```
