# 03_詳細設計

## 移植元調査結果サマリ

- `secuaigent/server/src/main/java/com/example/naw/api/PromptTemplateController.java`: `getAdminPromptTemplates(Pageable pageable, ..., search, team, excludeGroupId)`。ページング・並べ替えは Spring Data の `Pageable` で受ける（`page`/`size`/`sort=<property>,<asc|desc>`）。
- `secuaigent/server/src/main/java/com/example/naw/service/PromptTemplateService.java`: `getAdminPromptTemplates` が Specification と `pageable` をそのまま `promptTemplateRepository.findAll(spec, pageable)` に渡す。既定の並べ替え指定はない。
- `secuaigent/server/src/main/java/com/example/naw/domain/prompttemplate/PromptTemplate.java`: 並べ替え可能なプロパティは `name`・`updatedAt` など（エンティティのフィールド名）。
- `secuaigent/client/src/app/features/admin/management/template-list/services/template-list-api.service.ts`: `toParams` で ``sort = `${sortField},${sortOrder ?? 'desc'}` `` を作って送信する。`sortField` の値は `updatedAt` / `name`、`sortOrder` は `asc` / `desc`（`template-list-filter.component.ts` の選択肢）。
- `secuaigent/client/src/app/features/admin/management/group-list/services/group-templates-api.service.ts`: チーム詳細の「テンプレート追加」モーダルも同じ API に同じ形式で `sort` を送る。
- `frontend-angular/` の template-list は上流と同一（spec の allure 記述の差分のみ）。

## 実装対象ファイル

### `backend/app/routers/prompt_templates.py`

- 定数 `DEFAULT_ADMIN_SORT = "updatedAt,desc"` を追加する。
- `get_admin_prompt_templates` に `sort: str = Query(DEFAULT_ADMIN_SORT)` を追加し、`sort.strip() or DEFAULT_ADMIN_SORT` をサービスへ渡す（`sort=` の空文字は FastAPI では既定値にならないため。既存の `size or DEFAULT_PAGE_SIZE` と同じ扱い）。

### `backend/app/services/prompt_template_service.py`

- `get_admin_prompt_templates` の引数に `sort: str` を追加する（`exclude_group_id` の後ろ）。
- `sort.split(",")` で項目と向きに分け、それぞれ前後の空白を除く。向きが無いときは `"asc"`。向きは小文字にする（Spring Data は `Direction.fromString` で大文字・小文字を区別しない）。
- リポジトリの `find_page_for_admin` に `sort_col_name`・`sort_dir` を渡す。

### `backend/app/repositories/prompt_template_repository.py`

- `find_page_for_admin` の引数に `sort_col_name: str`・`sort_dir: str` を追加する（`admin_group_ids` の後ろ、`page` の前）。
- 並べ替え列の対応表をモジュール定数 `_ADMIN_SORT_COLUMNS = {"name": PromptTemplate.name, "updatedAt": PromptTemplate.updated_at}` として持ち、対応外は `PromptTemplate.updated_at` にする。
- `order_by(sort_col.desc() if sort_dir == "desc" else sort_col.asc(), PromptTemplate.id.asc())`。第2キーの `id` は、同じ名前・同じ更新日時のテンプレートがページ境界で揺れないようにするため。
- 一般ユーザー向けの `find_page_by_group_ids` は変更しない。

## 処理フロー

1. Router: `sort`（既定 `updatedAt,desc`）を受け取る。
2. Service: `sort` を項目・向きに分けてリポジトリへ渡す。
3. Repository: 検索・フィルタ条件で絞り込み、件数を数えたあと、並べ替え・ページングして取得する。
