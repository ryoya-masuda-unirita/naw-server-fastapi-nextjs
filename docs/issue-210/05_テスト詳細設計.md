# 05_テスト詳細設計

テストは `server-local/tests/` に置き、`cd server-local && uv run pytest` で実行する。

## 共通フィクスチャ（`tests/conftest.py`）

- `settings`: `tmp_path` 配下の SQLite ファイル・ストリーム出力先、短いポーリング間隔（tail 10ms / result 30ms / Waha! リトライ 0ms）、認証キー `test-key`
- `session_factory`: 上記 DB にテーブルを作成した `async_sessionmaker`
- `fake_waha`: `WahaClient` と同じメソッドを持つ偽クライアント。呼び出し履歴・アップロード内容を記録し、結果ステータス列・ダウンロード内容・例外を差し替えられる。`execute_with_stream_file` 時にストリームファイルへ書き込む関数を差し込める
- `fake_naw`: `NawApiClient` の偽クライアント
- `client`: 上記を注入した `create_app()` に対する `httpx.AsyncClient`（`ASGITransport(raise_app_exceptions=False)`）。既定で `X-SERVER-AUTH-KEY: test-key` を付ける
