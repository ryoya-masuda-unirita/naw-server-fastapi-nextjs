# 04_テスト設計

## テスト方針

- すべて自動テスト（pytest）で確認する。外部連携（Waha!、NAW 本体）はモック（偽クライアント、または HTTP 層のモック）に置き換える
- DB はテストごとに一時ディレクトリの SQLite ファイルを作り、テーブルを作成して使う（実運用の DB ファイルには触れない）
- 移植元のテスト（Controller / Service / StreamFileTailReader / DTO / Security）の観点を移植し、API の互換性（パス・フィールド名・ステータスコード・SSE 形式）を重点的に確認する
- コンテナでのビルド・起動・稼働確認 API の応答は動作確認（08）で確認する

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 稼働確認 | 認証キーなしで稼働確認 API を呼ぶ | 200 と固定文言 |
| 2 | 認証 | 正しい認証キー | 業務 API が応答する |
| 3 | 認証 | 認証キーなし・誤り | 401（Spring 既定形式） |
| 4 | 認証 | OPTIONS（プリフライト） | 認証なしで CORS ヘッダー付きで応答 |
| 5 | コンテキストパス | コンテキストパスを設定 | その配下で応答し、稼働確認は認証不要 |
| 6 | 入力不備 | 必須ヘッダー・パラメーター欠落 | 400（422 にならない） |
| 7 | 同期 API | Waha! 成功 | 回答・参照・添付を保存し、移植元と同じ JSON を返す |
| 8 | 同期 API | Waha! 失敗 | ERROR 状態で保存して返す。セッションは必ず終了する |
| 9 | 同期 API | 回答再生成（既存 ID 指定） | 既存レコードの回答を更新 |
| 10 | 同期 API | 対象未指定 / 既存 ID が存在しない | 400 / 404 |
| 11 | 同期 API | 追加プロンプト・履歴・添付あり | Waha! に連結した質問・履歴 JSON・添付が送られる |
| 12 | SSE（NAW 互換） | Waha! 成功、ストリームに推論途中経過 | 中継イベント → 回答 → 終了 → メッセージ内容の順で `data:` 形式で返り、DB が確定する |
| 13 | SSE（NAW 互換） | ストリームファイルが空のまま成功 | 出力ファイルから回答を確定する |
| 14 | SSE（NAW 互換） | ストリームに回答・終了イベント | 回答は出力ファイルの内容を使い、ストリーム側の回答は無視する |
| 15 | SSE（NAW 互換） | ライブラリ作成あり | スタブ作成 → ライブラリ ID 通知 → 途中経過中継 → 本文保存・タイトル更新 |
| 16 | SSE（NAW 互換） | ライブラリスタブ作成失敗 | Waha! を起動せずエラー終了 |
| 17 | SSE（NAW 互換） | Waha! ジョブ失敗 / ストリームが error 終端 | エラーとメッセージ内容（添付つき）を返し ERROR 状態で保存 |
| 18 | SSE（NAW 互換） | 結果ポーリング | 初回遅延前には結果を取りに行かない |
| 19 | SSE（NAW 互換） | textData | 移植元と同じキー構成で Waha! に送る（空ツール・未指定値は省略） |
| 20 | SSE（旧形式） | 正常 | ストリームの内容をそのまま中継し、ID ヘッダーを返す |
| 21 | SSE 準備 | 新規 / 再生成 | 仮レコードとストリームファイルを作る / 既存レコードを初期化する |
| 22 | ストリームファイル追従 | 空行区切り・1 行形式・途中までの書き込み・error 終端 | イベント単位で取り出し、終端を判定、途中分はバッファに残す |
| 23 | 一括取得・削除 | メッセージ ID 指定 | 該当レコードを添付つきで返す / 添付ごと削除 |
| 24 | ライブラリ本文 | 取得・未存在・削除 | `{"data"}` / 404 / 204 |
| 25 | 学習ファイル一覧 | 絞り込み・ページング | 条件に合うものだけを Page 形式で返す。不正なページ指定は 400 |
| 26 | 学習ファイル登録 | Waha! 成功 / BOM 付き / 空の結果 | パートつきで保存 / BOM を除去 / エラー |
| 27 | 学習ファイル更新 | ファイルなし / ファイルあり / 未存在 | 表示名・参照先のみ更新 / 削除→再登録 / 404 |
| 28 | 学習ファイル削除 | 物理 / 論理 / 未存在 / Waha! 失敗 | 削除 / DELETED / 404 / 500 |
| 29 | 学習ファイル同期 | 新規・既存・BOM・短い ID・同一ファイルの複数パート | 未登録分だけ追加し、名前・参照先を導出 |
| 30 | 追加学習 | フィードバック / ルーム / 指定不備 | 移植元どおりの名前で登録 / 400 |
| 31 | ダウンロード | 任意 | 500 |
| 32 | 外部クライアント | Waha! / NAW のリクエスト形式 | パス・クエリ・ヘッダー・本文が移植元どおり |
| 33 | 定期処理 | 古いファイルと新しいファイル | 古い `*.txt` だけ削除 |
| 34 | マイグレーション | 空の DB にマイグレーションを適用 | 全テーブル・制約が作られ、モデル定義と一致する |
