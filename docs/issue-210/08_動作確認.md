# 08_動作確認

ブラウザ・実機（Waha!・NAW 本体と接続した状態）での確認は行わず、自動テストと Docker コンテナへの curl で代替した。

## 確認環境

- macOS（Apple Silicon）上の Docker 29.4.0（Linux コンテナ `python:3.12-slim`）
- Python 3.12.13 / uv 0.11.21（自動テスト）
- Waha!・NAW 本体は用意していない（自動テストではモック、コンテナ確認では未接続）

## 確認手順

1. `cd server-local && uv run pytest`（外部連携はモック、DB は一時 SQLite）
2. `uv run ruff check .` / `uv run ruff format --check .`、`pre-commit run --all-files ruff-format` / `ruff-check`
3. `docker build -t naw-server-local:issue-210-verify .`
4. `docker compose -p sl210verify up -d --build`（`SECURITY_SERVER_AUTH_KEY=verify-key`、データはスクラッチディレクトリにバインド、公開ポート 8090）
5. curl で各 API を確認
6. `docker compose -p sl210verify down`、`docker rmi` でコンテナ・ネットワーク・イメージを削除（既存の naw-fastapi-* 等のコンテナには触れていない）
