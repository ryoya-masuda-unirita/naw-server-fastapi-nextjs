# #210 issue-210 secuaigent-server-local を Python（FastAPI）に移植し、Linux（Docker）で動かせるようにする

## 概要

移植元モノレポ `secuaigent` の `secuaigent-server-local/`（オンプレ配布用サーバー、Spring Boot 3.2.3 / Java 21 / H2 + Liquibase）を、このリポジトリのルートに新設する `server-local/` へ Python（FastAPI）で移植する。

当面の動作環境は Linux（Docker コンテナ）とする。移植元は Windows 向け配布（`.bat` スクリプト等）も想定しているが、Windows 対応は本 Issue のスコープ外とする（2026-11-12 ユーザー判断）。

## 説明

### 移植元

- `~/Documents/unirita-develop-pj/secuaigent-ref/secuaigent-server-local/`（参照専用 worktree、`origin/develop`）
- 主なエンドポイント: `/api/messages`（contents・content/stream・content/sync・sync 等）、`/api/libraries`、`/api/admin/indexes/{indexId}`（files の CRUD・additionalLeaning）、`/api/hello`
- 外部連携: Waha!（`waha.url`・`waha.authkey`）、NAW 本体（`naw.base-url`）、サーバー認証キー（`security.server-auth-key`）

### 完了条件

- `server-local/` に移植元と同等の API が FastAPI で実装されている
- Docker（Linux コンテナ）でビルド・起動でき、手順が README に書かれている
- 自動テストがある

### スコープ外

- Windows 向けの配布・起動スクリプト
- `backend/` 側の SECURE（ローカル LLM）対応（#102）

## その他

- Issue: https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/issues/210
- 全自動モードで対応する（第1承認・第2承認はユーザー確認を省略）
- 追加指示（依頼時）:
  - 移植先は `backend/` から独立したプロジェクトとし、`backend/` のコードを import しない
  - 構成・規約（uv / ruff / pytest）は `backend/` に揃える
  - DB は SQLite（SQLAlchemy/SQLModel + Alembic）を第一候補とする
  - 外部連携は環境変数で切り替え、テストではモックする
  - API のパス・リクエスト/レスポンス形式・ストリーミング形式・認証ヘッダーは移植元のまま保つ
  - 動作確認は `docker build` とコンテナ起動後の curl で行う（ポートは 8090 等、既存コンテナに触れない）
