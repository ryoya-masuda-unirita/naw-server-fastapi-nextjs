# #74 issue-74 テナント情報取得・部分更新API(管理者向け)を移植

## 概要

`TenantController` の管理者向けテナント情報取得・部分更新APIの移植。GETとPATCHはどちらも同じ `TenantDetailResponse` を返し、同じ `TenantService` のロジックを共有する密結合なAPIのため1単位にまとめる。

## 説明

### 対象エンドポイント

| メソッド | パス | 概要 |
|---|---|---|
| GET | `/api/admin/tenants` | テナント情報取得（`X-Tenant-ID`ヘッダーで対象テナントを指定） |
| PATCH | `/api/admin/tenants/{tenantId}` | テナント情報の部分更新。`tenantName` / `maxUsageBasedCreditsPerMonth` のいずれか一方または両方を、送られたキーのみ反映して更新する |

### PATCH の仕様詳細

- 送ったキーのみが反映される（キーの有無で判定。値がnullかどうかではない）
- `maxUsageBasedCreditsPerMonth` に `null` を指定すると 0 にリセットされる
- いずれのキーも送らない場合は更新せず 200 で現状を返す
- テナントが存在しない場合は 404
- 請求期間内の利用クレジットがプラン枠＋新しい利用ベース上限以上になり、上限を下げられない場合は 400

### レスポンス項目（`TenantDetailResponse`）

- `tenantId`, `tenantName`, `maxUsageBasedCreditsPerMonth`, `isDeleted`
- `resources`: `id`, `type`, `description` の配列
- `subscription`: `id`, `status`, `startDate`, `endDate`, `createdAt`, `updatedAt`, `plan`（`id`, `name`, `maxUsers`, `maxCreditsPerMonth`）
- `createdAt`, `updatedAt`
