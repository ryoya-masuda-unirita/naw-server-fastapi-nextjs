# ワークフローエディター（画面）を onprem の docker compose に入れる

## 概要

waha-emulator のワークフローエディター（画面。#522）を、`onprem/` の docker compose に入れて、`docker compose up` だけで、エミュレーターと一緒に立ち上がるようにする。

## 説明

### 背景

- #522 の画面は、今は `waha-emulator/ui/` で `npm run dev` を別に動かし、エミュレーターは `WAHA_STUDIO_DIR` を付けて起動する必要がある
- `onprem/` の compose は、server-local・waha-emulator・vector-db を 1 つで立ち上げる検証用。画面もここで立ち上がれば、ブラウザでワークフローを組み、そのサービス ID を server-local から呼ぶ、までを compose だけで通せる

Issue #524 のとおり。詳細は `01_要件定義.md`。
