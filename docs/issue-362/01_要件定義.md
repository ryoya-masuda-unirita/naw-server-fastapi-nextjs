# 01_要件定義

## 背景

パスワード再設定画面が移植元と違い、(A) 未入力のとき画面の文言ではなくブラウザ標準の吹き出しが出る、(B) 失敗時に backend のメッセージが出ず「HTTP 403」などが出る、(C) 成功のメッセージが出ない（遷移でトーストが消える）。

## 機能要件

- 送信時に全欄を検証し、誤りのある欄の下に文言を出す。誤りがあれば更新 API を呼ばない
  - 旧パスワード: 必須
  - 新パスワード: 必須・64 文字以下・半角英数字記号のみ（入力欄は全角を取り除き 64 文字で切る）
  - 再入力: 同じチェック。新パスワードと違えば（両方空は除く）「パスワードが一致しません」を、必須より優先して再入力欄に出す
- ログインID欄は移植元と同じく編集できない（disabled）。値は URL の `username`、なければログイン中のユーザーの ID
- 失敗時は backend が返した message を表示する
  - 429: 試行回数上限の文言をログインID欄の下に
  - 400: 新パスワード欄の下に
  - それ以外: ログインID欄の下に
- 成功したら「パスワードを更新しました。」のトーストを出し、ページを読み込み直さずにダッシュボードへ遷移する
- ブラウザ標準の吹き出しは出さない。エラーは触れた欄にだけ出し、入力を直せば消える

## 非機能要件

- 文言は既存の i18n キーを使う。辞書は変えない

## スコープ外

- ログイン画面（#360）、ログインキー認証（#361）
- `window.location.href` による他の経路の遷移（#293 の確認事項）
