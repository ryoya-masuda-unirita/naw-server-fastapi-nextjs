# パスワード再設定画面に移植元と同じ必須チェックとエラー・成功メッセージを出す

## 概要

パスワード再設定画面（`frontend/src/routes/auth/pw-reset.tsx`）が、(A) HTML の `required` によるブラウザ標準の吹き出しで「この項目は必須です」が出ない、(B) 失敗時に backend のメッセージではなく「HTTP 403」「HTTP 400」と出る、(C) 成功時の「パスワードを更新しました。」が出ない。移植元に揃える。

## 説明

対象の項番: 05-03・05-04・05-05〜05-09・05-17・05-19・05-20（`pw-reset.tsx`・`store/auth-store.ts`）。05-05 はログインID欄の扱い（移植元の現行は disabled）を docs の注記どおり確かめて決める。

結合テスト項目書の E2E（#316、`e2e-spec/`）で見つかった、移植元との本当の差。原因・移植元の挙動・見立ては `docs/issue-316/ng-パスワード再設定.md`。
