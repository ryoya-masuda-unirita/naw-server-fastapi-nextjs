# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 必須 | 3 つのパスワード欄が未入力で送信 | 必須エラーが 3 か所 |
| 2 | 必須 | 旧パスワードだけ未入力 | 必須エラーが 1 か所 |
| 3 | 不一致 | 新パスワードだけ未入力 | 新パスワード欄に必須、再入力欄に不一致 |
| 4 | 不一致 | 再入力だけ未入力 | 不一致のみ（必須は出ない） |
| 5 | 不一致 | 新パスワードと再入力が違う | 不一致エラー、API を呼ばない |
| 6 | 入力制限 | 全角を入力 | 取り除かれる |
| 7 | 初期表示 | ログインID欄 | 編集できない。URL → ログイン中ユーザーの ID の順で入る |
| 8 | 成功 | 更新成功 | 成功トーストが 1 つ、ダッシュボードへ遷移、ログイン済み |
| 9 | 失敗 | 403 | backend の message がログインID欄の下に出る。「HTTP 403」は出ない |
| 10 | 失敗 | 400 | backend の message が新パスワード欄の下に出る |
| 11 | 失敗 | 429 | 試行回数上限の文言 |
| 12 | 再入力 | 失敗後に入力を直す | エラーが消える。トーストは出ない |
| 13 | 標準検証 | フォーム | `noValidate` |
| 14 | E2E | 05-03・05-04・05-05〜05-09・05-17・05-19・05-20 | OK |
