# クラウド側 server の埋め込みを Bedrock（Titan）に対応させる

## 概要

クラウド側の `server/` で、質問のベクトル化（埋め込み）を、Azure OpenAI に加えて、Bedrock（Titan）でも行えるようにする。クラウドの RAG を Bedrock だけで動かすための 1 つ目（全体は #460 → #461 → #462）。

## 説明

- クラウド（学習先指定）のアシスタントは、質問を埋め込んでから、ベクトル DB を検索する。今の `server/` は、埋め込みが Azure OpenAI だけ（接続先の種別 `AZURE_OPENAI_EMBEDDING`、`AzureLlmEmbeddingClient`）
- ローカル環境のテストデータの埋め込み接続先は、架空のホスト（`example-embedding.openai.azure.com`）で、質問すると、画面に「回答エラー」が出る（backend は 400）
- #439 で、オンプレ側のアダプタには、Bedrock の Titan（`amazon.titan-embed-text-v1`、1536 次元、Bedrock Runtime の InvokeModel、Bearer の API キー）の埋め込みを足した。クラウド側は、その時点でスコープ外だった
- #444 の実機の確認で、Bedrock は `x-api-key` と `Authorization` を同時に送ると拒否し、Bearer だけなら通ると分かった
