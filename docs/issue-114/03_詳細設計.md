# 03_詳細設計

## `backend/app/core/room_access.py`

変更なし。既存の `can_view_room`・`require_viewable_room` をそのまま利用する。

## `backend/app/services/message_service.py`

- import に `can_view_room`・`require_viewable_room` を追加（`require_owned_room` は書き込み系で引き続き使うため残す）
- `get_messages_and_assistants`（453行目付近）
  - `await require_owned_room(tenant_id, current_user, room_id, session)` を `await require_viewable_room(tenant_id, current_user, room_id, session)` に置き換え
  - docstringの `Raises` を「所有者でない場合は403」→「閲覧権限がない場合は403」に更新
- `get_message_contents`（529〜553行目付近）
  - 現状 `room.user_id != current_user.id` で直接403を出しているインライン判定を、`if not await can_view_room(tenant_id, current_user, room, session):` に置き換え
  - docstringの `Raises` を更新

## `backend/app/services/room_service.py`

- import に `app.core.room_access.require_viewable_room` を追加
- `get_room`
  - `_get_owned_room_or_404` 呼び出しを `require_viewable_room` に置き換え
  - `_get_owned_room_or_404` 自体は他の書き込み系メソッド（`update_room`・`delete_room`・`pin_room`・`unpin_room`・`feedback_room`）で使用中のため削除しない
- `list_rooms`
  - `GroupUserRepository.find_belonging_group_ids(tenant_id, current_user.id, session)` でログインユーザーの所属グループID一覧を取得
  - `RoomRepository.find_page_by_login_id` の呼び出しを、新設する `RoomRepository.find_page_viewable_by_user` に置き換え、`current_user.id` と所属グループID一覧を渡す

## `backend/app/repositories/room_repository.py`

- `find_page_by_login_id`（`list_rooms`からのみ呼ばれる）を削除し、代わりに `find_page_viewable_by_user` を追加する
- 新メソッドのシグネチャ:

```python
@staticmethod
async def find_page_viewable_by_user(
    tenant_id: str,
    user_id: UUID,
    group_ids: list[str],
    page: int,
    size: int,
    name: str | None,
    session: AsyncSession,
) -> tuple[list[Room], int]:
```

- 抽出条件: `Room.tenant_id == tenant_id AND (Room.user_id == user_id OR Room.id IN (SELECT room_id FROM share_rooms WHERE tenant_id = :tenant_id AND group_id IN :group_ids))`
  - `group_ids` が空リストの場合は共有条件のサブクエリを組み立てず、所有条件のみにする（無駄な `IN ()` を発行しない）
- 固定順（`RoomPin`との `outerjoin`）・更新日時降順・ページネーションは既存の `find_page_by_login_id` と同じロジックを維持する。ただし `RoomPin.user_id` との結合条件は、既存が `login_id`からのサブクエリだったのに対し、新メソッドでは呼び出し側から渡される `user_id`（`current_user.id`）を直接使う（サブクエリを1段減らせるため簡潔になる）
- `ShareRoom`（`app.models.share`）と `sqlalchemy.or_` の import を追加
