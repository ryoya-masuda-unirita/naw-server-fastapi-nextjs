# 05_テスト詳細設計

## `backend/tests/integration/test_messages.py`

新規fixture（`test_shares.py`パターンを踏襲）:

- `share_group`: `Group` + `GroupUser`（`other_user_same_tenant` を所属メンバーとして登録）
- `shared_room`: `owned_room` とは別に、`message_owner_user` が所有する新規ルームを作成
- `shared_room_share` / `shared_room_share_room`: `shared_room` に対する `Share` + `ShareRoom`（`share_group` に共有）

追加テストケース（`TestGetMessages`・`TestGetMessageContents`配下）:

- `test_get_messages_with_shared_group_member_returns_200`: 共有先グループのメンバー（`other_user_same_tenant`）のヘッダーで `GET /api/messages?roomId=shared_room.id` を呼び、200・メッセージ一覧が返ることを確認
- `test_get_message_contents_with_shared_group_member_returns_200`: 同様に `POST /api/messages/contents` で共有ルームに属するメッセージ内容が取得できることを確認
- `test_create_message_with_shared_group_member_returns_403`（`TestCreateMessage`配下・回帰確認）: 共有先グループのメンバーが `POST /api/messages` で共有ルームにメッセージを送信しようとすると403になることを確認（書き込み系が引き続き所有者限定であることの確認）

## `backend/tests/integration/test_rooms.py`

新規fixture（`test_shares.py`パターンを踏襲）:

- `share_group`: `Group` + `GroupUser`（`another_user_same_tenant` を所属メンバーとして登録）
- `shared_room`: `room_owner_user` が所有する新規ルーム
- `shared_room_share` / `shared_room_share_room`: `shared_room` に対する `Share` + `ShareRoom`（`share_group` に共有）

既存テスト修正:

- `TestGetRoom::test_get_room_returns_404_for_other_users_room` → `test_get_room_returns_403_for_other_users_room` にリネームし、期待ステータスを403に変更

追加テストケース:

- `TestGetRoom::test_get_room_with_shared_group_member_returns_200`: 共有先グループのメンバーが `GET /api/rooms/{shared_room.id}` で200・ルーム詳細を取得できることを確認
- `TestGetRooms::test_get_rooms_includes_shared_room_for_group_member`: 共有先グループのメンバーが `GET /api/rooms` を呼ぶと、自分の所有ルームと共有ルームの両方が一覧に含まれ、`other_users_room`（未共有）は含まれないことを確認
- `TestUpdateRoom` 配下（回帰確認）: `test_update_room_with_shared_group_member_returns_403`: 共有先グループのメンバーが共有ルームを更新しようとすると403になることを確認（書き込み系が引き続き所有者限定であることの確認）
