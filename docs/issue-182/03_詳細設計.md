# 03_詳細設計

## 実装対象ファイル

### `backend/app/schemas/message.py`

#### `MessageContentHistoryTurn`

- `model_config = ConfigDict(populate_by_name=True)` を追加する（サービス層・既存テストが属性名 `role` で生成しているため、属性名での生成も許可する）。
- `role` に `validation_alias="type"` を付け、ワイヤ上は移植元 `HistoryMessageContent.type` の名前で受け取る。
- `@field_validator("role")` で小文字化し、`system` / `assistant` / `user` 以外は `ValueError` とする（移植元 `HistoryMessageContentType` の列挙値 `SYSTEM` / `ASSISTANT` / `USER` 相当）。

#### `MessageContentCreateRequest`

- `model_config = ConfigDict(populate_by_name=True)` を追加する。
- `isCreateLibrary` に `validation_alias="createLibrary"`、`responseFormat` に `validation_alias="response_format"` を付ける（移植元 `@JsonProperty` 名）。
- docstring を multipart 受け取りに合わせて更新する。

#### `parse_message_content_create_form`（新規・非同期の依存関数）

```python
async def parse_message_content_create_form(
    textData: Annotated[UploadFile | str, Form()],
    attachmentFiles: Annotated[list[UploadFile] | None, File()] = None,
    historyAttachmentFiles: Annotated[list[UploadFile] | None, File()] = None,
) -> MessageContentCreateRequest:
```

1. `textData` が `UploadFile`（クライアントが `application/json` の Blob として送った場合）なら読み出して UTF-8 デコードし、文字列ならそのまま使う。
2. `json.loads` に失敗した場合、または結果が `dict` でない場合は `RequestValidationError` を送出する（422）。
3. 添付ファイルは `{"name": filename, "type": content_type, "data": base64(bytes)}` に変換する（`AttachmentFile.data` は `Base64Bytes` のため Base64 で渡すと検証時に元のバイト列へ戻る）。Content-Type 未指定時は `application/octet-stream`。
4. `MessageContentCreateRequest.model_validate({**text_payload, "attachmentFiles": ..., "historyAttachmentFiles": ...})` で検証する。`ValidationError` は `RequestValidationError(e.errors(include_url=False))` に変換して 422 にする（依存関数内の `ValidationError` は FastAPI が自動で 422 に変換しないため）。

### `backend/app/routers/messages.py`

- `create_message_content` の `req` を `req: MessageContentCreateRequest = Depends(parse_message_content_create_form)` に変更する。

### `backend/app/schemas/attachment.py`

- `AttachmentFile` の docstring のうち「`MessageContentCreateRequest` も JSON ボディで受け取る」旨の記述を、メッセージ送信 API は移植元同様 multipart で受け取り本クラスへ変換する旨に更新する。

## 移植元との対応

| 移植元 | 本ポート |
|---|---|
| `MessageController.createMessageContent` の `@RequestPart("textData")` | `parse_message_content_create_form` の `textData` |
| `@RequestPart("attachmentFiles")` / `@RequestPart("historyAttachmentFiles")` | 同名の `File()` パラメータ |
| `CreateMessageContentRequest.createLibrary` / `response_format` | `MessageContentCreateRequest.isCreateLibrary` / `responseFormat`（validation_alias） |
| `HistoryMessageContent.type`（`SYSTEM`/`ASSISTANT`/`USER`） | `MessageContentHistoryTurn.role`（小文字へ正規化） |
| `MessageService.toFileDataList`（`getOriginalFilename`/`getContentType`/`getBytes`） | 添付ファイルの変換処理 |
