# 03_詳細設計

| ファイル | 変更 |
|---|---|
| `server/app/core/security.py` | `SECRET_KEY` の定数を削除。`create_access_token`・`decode_token` で `get_settings().secret_key` を使う |
| `server/tests/unit/conftest.py`・`server/tests/integration/conftest.py` | `security.SECRET_KEY` の import をやめ、`get_settings().secret_key` で署名する |
| `server/tests/unit/test_security.py` | 設定の鍵で署名されること・以前の直書きの鍵で署名した JWT を弾くこと・`SECRET_KEY` を変えると既存の JWT が無効になることのテストを足す |
| `server/pyproject.toml`・`server/uv.lock` | `python-jose` を削除（`pyasn1`・`rsa` も、推移的に外れる） |
| `server/.env.example` | 任意の項目をコメントで足す |
