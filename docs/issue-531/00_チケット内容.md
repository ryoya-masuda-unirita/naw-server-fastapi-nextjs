# 【高】JWT の署名鍵が SECRET_KEY を使わず、ソースに直書きされている

## 概要
`server/` の JWT の署名・検証が、設定の `SECRET_KEY` ではなく、ソースに直書きした固定の鍵（`security.py` の `"your-secret-key-change-in-production"`）を使っている。環境変数を変えても鍵は変わらず、全環境で同じ既知の鍵になる。

## 説明
Issue #531 のとおり。あわせて、使われていない `python-jose` の削除と、`.env.example` を `Settings` に合わせる。
