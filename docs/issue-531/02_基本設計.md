# 02_基本設計

- `security.py`: 署名鍵の定数を削除する。`create_access_token`・`decode_token` が、`get_settings().secret_key` を、呼び出しのたびに読む（`get_settings` はキャッシュされるため、コストは小さい）
- `SECRET_KEY` が未設定なら、`Settings` の必須項目として、起動時に失敗する（以前から。今は、実際に効く）
- 依存: `pyproject.toml` から `python-jose[cryptography]` を外し、`uv.lock` を更新する
- `.env.example`: 必須の項目（`DATABASE_URL`・`SECRET_KEY`）はそのまま。任意の項目（`FILE_STORAGE_ROOT`・`TOKENS_PER_CREDIT`・`INPUT_CREDIT_WEIGHT`・`PASSWORD_RESET_*`・`TIKA_*`・`AZURE_APP_*`）を、コメントで足す
