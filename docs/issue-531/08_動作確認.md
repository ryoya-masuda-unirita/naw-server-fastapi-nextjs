# 08_動作確認

実際に確認した内容だけを書く。

## 自動テスト（`server/`）

```
uv run python -m pytest tests/unit -q   →  772 passed
uv run python -m ruff check app tests   →  All checks passed
uv run python -m ruff format --check    →  249 files already formatted
uv run python -m mypy                   →  Success: no issues found in 249 source files
```

新しい 3 つのテスト（設定の鍵で署名される・以前の直書きの鍵の JWT を弾く・`SECRET_KEY` を変えると既存の JWT が無効になる）を含む。`uv lock` で、`python-jose`・`pyasn1`・`rsa` が外れたことを確認した。

## 確認していないこと

- 結合テスト（`tests/integration`）の手元での実行。開発用の DB（`naw-fastapi-postgres`）に影響しないよう、実行していない。CI の「結合テスト」で確かめる
- 本番（ECS）で `SECRET_KEY` が渡されていること（`Settings` で必須のため、渡されているはず。デプロイ前に確認する）
- 鍵が変わるため、デプロイ後は、発行済みのトークンが無効になり、利用者はログインし直しになる
