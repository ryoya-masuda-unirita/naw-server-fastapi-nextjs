# 02_基本設計

## 変更対象レイヤー

`backend/` 配下を新規作成する。今回は機能実装を含まないため、全レイヤーの骨格を一括で構築する。

| レイヤー | 役割 |
|---|---|
| routers | HTTP ルーティング・エンドポイント定義 |
| services | ビジネスロジック |
| repositories | DB アクセス |
| models | SQLModel テーブル定義 |
| schemas | リクエスト・レスポンス専用スキーマ |
| core | 設定・DB接続・共通ユーティリティ |

## エンドポイント概要

初期セットアップとして、動作確認用のヘルスチェックエンドポイントのみ実装する。

| メソッド | パス | 概要 |
|---|---|---|
| GET | /health | サーバーの起動確認 |

## パッケージ・依存管理

`pyproject.toml` で依存パッケージを管理する。主要な依存は以下の通り。

| パッケージ | 用途 |
|---|---|
| fastapi | Web フレームワーク |
| uvicorn | ASGI サーバー |
| sqlmodel | ORM（SQLAlchemy async ベース） |
| pydantic-settings | 環境変数管理 |
| asyncpg | PostgreSQL 非同期ドライバ |

## 環境変数管理

`.env` ファイルから設定を読み込む。`pydantic-settings` で型安全に管理する。

## Dockerfile

ローカル開発用とコンテナ起動確認用を兼ねた Dockerfile を作成する。ECS EC2 へのデプロイを前提とした構成にする。

## 影響範囲

- `backend/` 配下の新規作成のみ
- `frontend/`・`infra/` への影響なし
