# 08_動作確認

## Step 1: Docker イメージのビルド

```bash
cd backend
docker build -t naw-backend:dev .
```

## Step 2: コンテナ起動と /health 確認

```bash
docker run --rm -d -p 8001:8000 \
  -e DATABASE_URL=postgresql+asyncpg://root:root@localhost:5433/postgres \
  -e SECRET_KEY=changeme \
  --name naw-backend-dev \
  naw-backend:dev

curl http://localhost:8001/health
```

実際の出力結果:

```json
{"status":"ok"}
```

✅ ステータス 200 で `{"status":"ok"}` が返ることを確認

## 備考

- FastAPI（uvicorn）のデフォルトポートは 8000。OrbStack がホスト側 8000 を使用中のため、ホスト側は 8001 にマッピング
- docker-compose 導入後はポートマッピングをそちらで管理する
