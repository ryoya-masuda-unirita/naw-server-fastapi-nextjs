# 01_要件定義

## 背景

Spring Boot で実装された `naw-server` を FastAPI に移植するにあたり、まず `backend/` 配下にプロジェクトの骨格を構築する必要がある。この段階では機能の実装は行わず、開発を進めるための基盤を整えることを目的とする。

## 機能要件

- FastAPI アプリケーションとして起動できること
- 以下のレイヤー構造をディレクトリとして持つこと
  - routers（HTTPルーティング）
  - services（ビジネスロジック）
  - repositories（DBアクセス）
  - models（SQLModelテーブル定義）
  - schemas（リクエスト・レスポンススキーマ）
  - core（設定・DB接続・共通ユーティリティ）
- 依存パッケージを `pyproject.toml` で管理できること
- 環境変数を `.env` ファイルから読み込めること
- Docker コンテナとして起動できること
- ヘルスチェックエンドポイント（`GET /health`）が動作すること

## 非機能要件

- Python 3.12 以上を使用すること
- 非同期処理（`async/await`）を前提とした構成にすること
- ローカル開発時は `uvicorn --reload` でホットリロードが有効になること

## スコープ外

- 実際の業務機能（ユーザー管理・チャット等）の実装
- DB への接続・マイグレーション
- 認証・認可
- AWS へのデプロイ
