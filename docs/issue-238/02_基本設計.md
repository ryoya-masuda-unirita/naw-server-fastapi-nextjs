## 変更対象

- ライブラリタグ一括削除 API（管理者用）
- ライブラリ更新 API のタグ指定
- ライブラリタグ ID の正規化処理（#227 でライブラリタグ更新 API の中だけに書いていたものを共通化する）

## 画面 / API 変更概要

### ライブラリタグ一括削除 API

| 指定した ID | 変更前 | 変更後 | 移植元 |
|---|---|---|---|
| ハイフンなし 32 桁（保存形式） | 削除・204 | 削除・204（変更なし） | 400（UUID として読めない） |
| ハイフン付き UUID 標準形式 | 削除されず 204 | 削除・204 | 削除・204 |

### ライブラリ更新 API のタグ指定

| 指定したタグ ID | 変更前 | 変更後 | 移植元 |
|---|---|---|---|
| ハイフンなし 32 桁（保存形式） | 付与 | 付与（変更なし） | 400（UUID として読めない） |
| ハイフン付き UUID 標準形式・大文字 | 400（存在しないタグ扱い） | 付与（保存形式で保存） | 付与 |
| 同じタグを別の表記で重複して指定 | 400 | 1 件として付与 | 1 件として付与 |
| 形式は正しいが存在しないタグ | 400 | 400（変更なし） | 400 |
| UUID として解釈できない文字列 | 400（存在しないタグ扱い） | 400（形式不正のメッセージ） | 400（形式不正のメッセージ） |

保存形式（ハイフンなし 32 桁）は移植元では受け付けないが、このリポジトリの応答の ID はこの形式で、画面もこの形式で送るため、引き続き受け付ける。

画面の変更は無い（画面は応答のハイフンなしの ID をそのまま送るため、今も動いている）。

## 影響範囲

- ライブラリタグ一括削除 API・ライブラリ更新 API
- ライブラリタグ更新 API: 正規化処理を共通の処理に置き換えるだけで、挙動は変えない
- 一覧・作成など、他の API は変更しない

## 移植方針

### 移植元の挙動

- 一括削除: コントローラで本文の ID 一覧を 1 件ずつ UUID に変換してから削除する。変換に失敗すると不正な引数の例外になり、共通のエラー処理で 400 になる（削除の前に変換するため 1 件も削除しない）。存在しない ID は無視する
- ライブラリ更新: ライブラリの存在・所有者の確認（404・403）、共有グループの確認（400）の後、タグ ID 一覧を UUID に変換し、重複を除いてから存在を確認する。変換に失敗すると 400、存在しないタグがあると 400（`指定されたタグが存在しません`）。トランザクションのため、途中で失敗すると何も更新しない
- ライブラリ作成: タグを受け取らない

### このリポジトリの方針

- #227 の正規化（2 形式だけを受け付け、ハイフン除去・小文字化で保存形式に揃える）を共通の処理に切り出し、ライブラリタグ API とライブラリ API の両方から使う。サービス同士は呼び出せない規約のため、共通の処理として置く
- 不正な形式の扱いは移植元に合わせる

| API | 不正な形式の扱い | 根拠 |
|---|---|---|
| 一括削除 | 400・1 件も削除しない | 移植元が 400 |
| ライブラリ更新のタグ指定 | 400 | 移植元が 400 |
| ライブラリタグ更新（#227） | 404（変更なし） | #227 で決めた扱いを維持（スコープ外） |

- 不正な形式のメッセージは移植元の `UUID.fromString` に揃え、37 文字以上は `UUID string too large`、それ以外は移植元で最もよく出る `Invalid UUID string: <指定値>` にする（移植元は 16 進以外の文字などで別の文言になる場合もあるが、そこまでは合わせない。長い値を応答に含めない点は code-review の指摘で追加した）
- ライブラリ更新では、移植元と同じ順（ライブラリの存在・所有者 → 共有グループ → タグの形式 → タグの存在）で確認する
- 一括削除の、形式は正しいが存在しない ID を無視する仕様は変えない

| 案 | 内容 | 判定 |
|---|---|---|
| A | 共通の正規化処理で、形式不正は 400 にする。各サービスがそれを呼ぶ | 採用。移植元の順序・ステータスと合う |
| B | リクエスト本文の入力チェックで正規化する | 不採用。ライブラリ更新で、所有者でない・存在しない場合より先に 400 になり、移植元と確認の順序が変わる |
| C | 不正な形式は存在しない ID と同じく無視する（一括削除）／存在しないタグと同じ 400（ライブラリ更新） | 不採用。一括削除で移植元（400）と違う |
