## 移植元の根拠

- `server/src/main/java/com/example/naw/api/LibraryTagController.java` の `deleteLibraryTags`（`request.getIds().stream().map(UUID::fromString)`）
- `server/src/main/java/com/example/naw/service/LibraryTagService.java` の `deleteLibraryTags`（`findByTenantIdAndIdIn` → 空なら何もしない → `deleteAll`）
- `server/src/main/java/com/example/naw/service/LibraryService.java` の `updateLibrary` → `replaceShareGroups` → `replaceTags`（`tagIds.stream().map(UUID::fromString).distinct()`、件数不一致で `IllegalArgumentException("指定されたタグが存在しません")`）
- `server/src/main/java/com/example/naw/infrastructure/APIControllerAdvice.java` の `handleIllegalArgumentException`（400）。`UUID.fromString` の失敗も `IllegalArgumentException`（またはそのサブクラス）のため 400
- `server/src/main/java/com/example/naw/api/LibraryController.java` の `createLibrary`（`LibraryCreateRequest` は `messageId` のみでタグを受け取らない）
