# ライブラリタグの一括削除とライブラリのタグ指定でハイフン付きIDを受け付ける

## 概要

GitHub Issue #238 の内容を転記する。

ライブラリタグの ID は DB にハイフンなしの 32 桁で保存している。#227 で更新 API はハイフン付き（UUID 標準形式）を受け付けるようにしたが、次の箇所はまだ受け付けない。

- ライブラリタグの一括削除 API: ハイフン付き ID を送ると、204 を返すのに削除されない
- ライブラリの作成・更新でのタグ指定（タグ ID の一覧）

移植元は ID を `UUID` として読み取るため、どちらの形式でも動く。

## 説明

#227 で入れた正規化（ハイフンなし 32 桁・UUID 標準形式だけを受け付け、ハイフン除去・小文字化で保存形式に揃える）を、上の箇所にも適用する。ほかにタグ ID を受け取る API があれば横展開する。

不正な形式の扱い（404 / 400 / 無視）は、移植元の各 API の挙動（`UUID.fromString` 失敗時にどうなるか）を確認して決める。
