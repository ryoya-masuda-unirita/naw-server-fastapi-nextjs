# infra/ を modules/ + environments/dev の構成に再構成する（設定値は変えない）

## 概要

Issue #382（親: #380。#381 の上に積む）。フラットな `.tf` で構成している `infra/` を、移植元 `secuaigent-infra` と同じ `modules/` + `environments/dev` の構成に分ける。リソースの設定値は変えない。

## 説明

- 移植元のモジュール（network・rds・elasticache・ecr・ecs・frontend・secrets 相当）と `environments/dev` に分ける。独自要素（bastion・SQS・user-import S3・github_oidc・CloudFront Function）は、対応するモジュールまたは独立したモジュールに置く
- 新アカウントへ新規構築するので、state の移行（`moved` ブロック）は不要。同じアカウントには apply しない
- 設定値・リソース名・タグは変えない（変更は #383 以降）
