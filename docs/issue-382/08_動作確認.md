## code-review 後の追加確認

- `deploy-infra.yml` の `fmt -check` を `-recursive ../..` にした。ローカルで `terraform fmt -recursive -check -diff` が通り、YAML は読み込める
- 結合部の空行と末尾の改行を直したあと、リソースの比較（元 70 / 新 70、差分 64 行）、`validate`、`fmt` を再実行して、結果が変わらないことを確認した
- README の冒頭に、新アカウントへの新規構築が前提であること（state の key を変えたこと）を書いた
