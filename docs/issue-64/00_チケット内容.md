# TokenUsage（トークン消費量）取得APIの移植

## 概要

Spring Boot版 (naw-server) の TokenUsage（トークン消費量管理）機能をFastAPIに移植する。管理者向けのトークン消費量一覧・サマリ取得APIを実装する。

## 説明

対象エンドポイント:
- `GET /api/admin/token-usages`（トークン消費量一覧、ページング）
- `GET /api/admin/token-usages/summary`（トークン消費量サマリ）

参照（移植元バックエンド）:
- Controller: `~/Documents/naw-server/src/main/java/com/example/naw/api/TokenUsageController.java`
- Service: `~/Documents/naw-server/src/main/java/com/example/naw/service/TokenUsageService.java`
- Domain: `~/Documents/naw-server/src/main/java/com/example/naw/domain/tokenusage/`
- Request: TokenUsageListRequest / TokenUsageSummaryRequest
- Response: TokenUsageListResponse / TokenUsageItemResponse / TokenUsageSummaryResponse
- Migration: `~/Documents/naw-server/src/main/resources/liquibase/changelog/token_usages/`

対応する NAW チケット番号の記載は Issue 本文になし（`NAW-XXXX` 参照なし）。

## その他

- 本Issueは読み取り専用API。`token_usages`テーブルへのINSERT元（チャット送信・RAG・埋め込み等のトークン記録処理）は別スコープであり未実装のまま先行実装する。
- 本対応は自動化タスクとして、承認フロー省略・全自動モードで進める。動作確認はブラウザ操作の代わりに自動テスト（pytest）の実行結果で代替する。
