# 04_テスト設計

## テスト方針

- ポリシー検証処理を単体でテストし、違反の種類ごとのメッセージ・判定順序・フラグの組み合わせを網羅する
- パスワード再設定 API の結合テストで、ポリシー違反が 400 とメッセージで返り、パスワードが更新されないことを確認する
- 既存テスト全体の回帰がないことを確認する（プロフィール更新も同じ検証を共用するため、その既存テストも含む）

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 全要件を満たす | 全フラグ有効、大文字・小文字・数字・使用可能な記号を含み最小文字数以上 | 例外なし |
| 2 | 空白のみ | 空白だけのパスワード | 400「新パスワードの入力は必須です。」 |
| 3 | 最小文字数 | 最小文字数未満 | 400「新パスワードは{n}文字以上で入力してください。」 |
| 4 | 大文字 | 大文字必須で大文字なし | 400「新パスワードには大文字を含めてください。」 |
| 5 | 小文字 | 小文字必須で小文字なし | 400「新パスワードには小文字を含めてください。」 |
| 6 | 数字 | 数字必須で数字なし | 400「新パスワードには数字を含めてください。」 |
| 7 | 記号 | 記号必須で使用可能な記号なし（使用可能外の記号のみ含む場合を含む） | 400「新パスワードには次の記号のいずれかを含めてください: {記号}」 |
| 8 | 記号一覧が未設定 | 記号必須で使用可能な記号が空 | 400「新パスワードの記号要件を満たせません。」 |
| 9 | 判定順序 | 複数の要件に違反 | 移植元の順序で最初の違反メッセージ |
| 10 | 無効な要件は検証しない | 数字のみ必須で数字だけのパスワード | 例外なし |
| 11 | 16 通りの組み合わせ（受け付け） | 各組み合わせで、有効な文字種だけで作ったパスワード | 例外なし |
| 12 | 16 通りの組み合わせ（拒否） | 各組み合わせで、有効な文字種のうち 1 つを欠いたパスワード | 欠いた文字種のメッセージで 400 |
| 13 | API: ポリシー違反 | 再設定 API に数字のみの新パスワード | 400、大文字のメッセージ |
| 14 | API: 違反時は更新されない | No.13 の後に元のパスワードを旧パスワードとして再設定 | 旧パスワード照合を通る（200） |
| 15 | API: 記号違反 | 使用可能でない記号のみ含む新パスワード | 400、記号のメッセージ |
| 16 | 回帰 | backend テスト全体 | 全件成功 |
