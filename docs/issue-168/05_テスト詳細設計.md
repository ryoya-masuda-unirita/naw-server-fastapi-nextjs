# 05_テスト詳細設計

## `backend/tests/unit/test_password_policy.py`（新規、`TestVerifyPasswordStrength`）

テナントは `Tenant(id=..., name=..., pw_policy_min_length=8, 各フラグ, pw_policy_valid_symbols="!@#$%^&*")` を関数内で生成する（DB 不要）。

| No | テストメソッド | 内容 |
|---|---|---|
| 1 | `test_accepts_password_meeting_all_requirements` | `"Abcdef1!"` → 例外なし |
| 2 | `test_rejects_blank_password` | `"        "`（8 文字の空白）→ 400「新パスワードの入力は必須です。」 |
| 3 | `test_rejects_too_short_password` | `"Ab1!"` → 400「新パスワードは8文字以上で入力してください。」 |
| 4 | `test_rejects_password_without_uppercase` | `"abcdef1!"` → 大文字メッセージ |
| 5 | `test_rejects_password_without_lowercase` | `"ABCDEF1!"` → 小文字メッセージ |
| 6 | `test_rejects_password_without_digit` | `"Abcdefg!"` → 数字メッセージ |
| 7 | `test_rejects_password_without_valid_symbol` | `"Abcdef1?"`（`?` は使用可能外）→ 記号メッセージ（`!@#$%^&*` を含む） |
| 8 | `test_rejects_when_valid_symbols_empty` | `pw_policy_valid_symbols=""` → 「新パスワードの記号要件を満たせません。」 |
| 9 | `test_reports_first_violation_in_source_order` | `"12345678"` で全フラグ有効 → 大文字メッセージ（小文字・記号より先） |
| 6' | `test_rejects_non_ascii_digit_like_superscript` | `"Abcdef²!"`（上付き数字のみ）→ 数字メッセージ（Java の `isDigit` と同じく `Nd` カテゴリだけを数字とする） |
| 10 | `test_accepts_digits_only_when_only_digits_required` | 数字のみ有効で `"12345678"` → 例外なし |
| 11 | `test_accepts_password_with_enabled_char_types`（16 通り parametrize、ID は有効な文字種名を `+` でつないだもの） | 有効な文字種の代表文字（`A`/`a`/`1`/`!`）を並べ、最小文字数まで `~`（どの文字種にも使用可能な記号にも当たらない文字）で埋めたパスワード → 例外なし |
| 12 | `test_rejects_password_missing_enabled_char_type`（有効な文字種ごとに parametrize、計 32 ケース） | 有効な文字種から 1 つを除いた代表文字を `~` で埋めたパスワード → 除いた文字種のメッセージ |

## `backend/tests/integration/test_auth.py`（`TestAuthAPI` に追加）

| No | テストメソッド | 内容 |

| 13, 14 | `test_post_auth_password_reset_rejects_password_violating_policy` | `newPassword="12345678"` → 400、`detail == "新パスワードには大文字を含めてください。"`。続けて元のパスワードを旧パスワードとして有効な新パスワードで再設定 → 200（違反時に更新されていないこと） |
