# パスワード再設定時に複雑性ポリシー(大文字/小文字/数字/記号)が検証されていない

## 概要

`Tenant` モデルには `pw_policy_use_uppercase`・`pw_policy_use_lowercase`・`pw_policy_use_digits`・`pw_policy_use_symbols`・`pw_policy_valid_symbols` が存在するが、パスワード再設定時の検証関数 `verify_password_strength()`（`backend/app/core/password_policy.py`）は最小文字数（`pw_policy_min_length`）しかチェックしていない。

## 説明

これらのフィールドが実際に使われているのは `backend/app/services/user_service.py` の `_generate_initial_password`（管理者がユーザー作成時に初期パスワードをランダム生成する処理）のみで、ユーザーが送信した新パスワードの検証には一切使われていない。

### 影響

テナント管理者が「大文字必須」等のパスワードポリシーを設定しても、パスワード再設定時にそのポリシーに反するパスワード（例: 数字のみ）を設定できてしまう。

### 対応方針（Issue 記載）

移植元（Spring Boot）の該当バリデーションロジックを確認し、`verify_password_strength()` に複雑性チェックを追加する。
