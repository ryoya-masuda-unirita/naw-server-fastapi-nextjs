### 確認で分かったこと

- 既存のテストは 1 件も書き換えていない。最初に選んだベンダー ID `98` は、既存の 2 件のテストが「未知の ID」の例に使っていたため、`97` に変えた
- 失敗の文に含まれる API キーを伏せる処理は、OpenAI 系と共通で、`Bearer xxx` など決まった形のキーだけを伏せる。応答の本文にキーがそのまま入っていても伏せられないのは、既存のプロバイダと同じ
