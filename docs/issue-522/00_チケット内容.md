# waha-emulator のワークフローエディター（画面）を作る

## 概要

waha-emulator の管理用 API（#521）を使って、ノードと線でワークフローを組む画面を作る。Waha! Transformer の Designer のような、左に一覧、中央にキャンバス、右にプロパティの構成にする。

## 説明

### 背景

- #520 の第 2 弾。第 1 弾（#521）で、ワークフローの保存・管理用 API・サービス ID での実行までできた。今は curl で JSON を書かないと組めない
- 目的は、Dify のように対話的にワークフローを組み、SecuAiGent（server-local）から呼んで動作を確かめること
- 本家 Designer の画面（スクリーンショット 2 枚）: 左にジョブのツリー、右に点のグリッドのキャンバス。データと処理を矢印でつなぐ

### 要件（案）

Issue #522 のとおり。詳細は `01_要件定義.md`。
