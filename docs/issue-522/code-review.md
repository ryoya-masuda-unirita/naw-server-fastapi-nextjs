## 詳細

### 1. 検索なしで「1: RAG」を選べる（🔴 致命的）→ 対応済み

出力モードの選択肢を、検索ノードがないときは 0 と 2 だけ、あるときは 1（固定）だけにした。テスト: `PropertyPanel.test.tsx` の「選択肢に RAG（1）を出さない」「RAG（1）だけを固定で出す」。

### 2. 検索を足すと `outputType` を送り続ける（🔴 致命的）→ 対応済み

サーバーは、検索ノードがあるとき `outputType` を拒否する。画面は、検索ノードがあるとき生成AI の `outputType` を、サーバーへ送る定義に入れないようにした（`fromFlow`）。テスト: `model.test.ts`「検索ノードがあるときは、生成AI の出力モードをサーバーへ送らない」。

### 3. 「入れ直す」の状態の漏れ（🟡 注意）→ 対応済み

状態を持たず、値が伏せ字かどうかだけで表示を決める作りにした。「入れ直す」で値が空になれば入力欄になり、保存後にサーバーが伏せ字を返せば、また「保存済みの値を使います」になる。ノードをまたいだ漏れも、状態がないため起きない。

### 4. 処理中の Ctrl+S（🟡 注意）→ 対応済み

`save`・`validate` の先頭で、処理中なら何もしないようにした。再描画の前に続けて呼ばれても二重にならないよう、state とは別に ref でも持つ。テスト: `App.test.tsx`「Ctrl+S を続けて押しても、保存の要求は 1 回だけ送る」。

### 5. コメントの誤り（🔵 提案）→ 対応済み

「候補は `/admin/workflows` の下ではないため、別のルーターにする」に直した。
