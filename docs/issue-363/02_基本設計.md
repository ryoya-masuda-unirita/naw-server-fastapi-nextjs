# 02 基本設計

`frontend/src/components/shared/period-filter.tsx` の `document` の `click` リスナーの「部品の外か」の判定を、DOM の現在の状態に依存しないものに変える。

- 変更前: `!hostRef.current.contains(event.target)`
- 変更後: `!event.composedPath().includes(hostRef.current)`

`PeriodFilter` を使う画面は `chat-history-filter.tsx`・`training-data-filters.tsx`（`training-data-files-view.tsx` 経由）の 2 系統。いずれも props は変えない。
