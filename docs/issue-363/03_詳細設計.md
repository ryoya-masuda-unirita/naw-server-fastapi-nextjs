# 03 詳細設計

## 原因

カレンダーの日を押すと `setView('range')` で日のボタンを含むカレンダー画面が DOM から外れる。React は離散イベントの更新をイベントの途中で反映するため、イベントが `document` に届く時点で `event.target` は DOM から外れており、`contains` が `false`（外を押した）になって閉じていた。

## 移植元との対応

移植元（`shared/components/filter/period-filter/period-filter.component.ts` の `@HostListener('document:click')`）は Angular の変更検知がイベント処理後に走るため、`document` のリスナーの時点でも日のボタンが DOM に残り、閉じない。React 側は、判定を発火時点のイベント経路（`composedPath()`）で行うことで同じ結果にする。

## 判断

`mousedown` 判定への変更案（`ng-チャット履歴.md`）は、移植元の `click` に合わせる方針に反するため採らず、`composedPath()` にした。
