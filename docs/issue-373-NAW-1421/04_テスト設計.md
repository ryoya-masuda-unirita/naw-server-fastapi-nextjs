# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | ACTIVE | ADMIN / USER の行 | userType=ACTIVE、userName=ユーザー名 |
| 2 | SYSTEM | SYSTEM ロールの行 | userType=SYSTEM、userName=ユーザー名 |
| 3 | 削除済み | 同テナントにいない userId の行 | userType=DELETED、userName=null |
| 4 | userId なし | user_id が NULL の行 | userType=DELETED、userName=null |
| 5 | 他テナント | 他テナントのユーザーの userId の行 | DELETED（他テナントの名前を返さない） |
