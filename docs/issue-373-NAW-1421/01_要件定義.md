# 01_要件定義

## 背景

利用履歴の一覧は `userId` しか返さず、画面で利用者名を出せない。移植元では NAW-1421 で `userName` と `userType` が追加された。

## 機能要件

- 一覧の各行に `userName`（文字列または null）と `userType`（ACTIVE / SYSTEM / DELETED）を返す
- ユーザーがテナントにいて SYSTEM ロールなら SYSTEM、それ以外なら ACTIVE。`userName` はユーザー名
- `userId` が null、または同テナントにユーザーがいない行は DELETED、`userName` は null
- ユーザーの解決は、ページ内の `userId` をまとめて 1 回で引く（行ごとのクエリは発行しない）

## 非機能要件

- 他テナントのユーザー名を返さない（テナントを条件に含めて引く）
- 既存のフィールド・ページング・並び替えの挙動は変えない

## スコープ外

- サマリ API の変更
- frontend の変更
