# 02_基本設計

## 変更対象

- 利用履歴一覧のレスポンス（行の項目）
- 利用履歴一覧を組み立てるサービス

## 画面 / API 変更概要

`GET /api/admin/token-usages` の各行に `userName`・`userType` を追加する（追加のみで後方互換）。

## 影響範囲

- 一覧レスポンスのみ。サマリ API は変更なし
- 既存の一覧テストは項目追加の影響を受けない

## 移植方針

- 移植元の `resolveUsageUser` と同じ規則で利用者を決める
- ユーザーの一括取得は既存の取得処理を使う（新規のクエリは作らない）
- 種類の定義はレスポンスのスキーマに置く
