# #373 issue-373 NAW-1421 利用履歴 API の各行に userName と userType を足す

## 概要

`GET /api/admin/token-usages` の各行に `userName` と `userType` を足す。

## 説明

- `userType` は ACTIVE / SYSTEM / DELETED
- SYSTEM ロールのユーザーは SYSTEM
- `user_id` が NULL、または同テナントに存在しない行は DELETED（`userName` は null）
- 同テナントのユーザーを一括取得して解決する（移植元は `UserRepository.findByTenantIdAndIdIn`。移植先は既存の `UserRepository.find_by_ids`）

## その他

- 移植元: NAW-1421 の `TokenUsageController.toItemResponse`、`TokenUsage.resolveUsageUser`・`UsageUserType`、`TokenUsageService.listTokenUsage`、`TokenUsageItemResponse`
- frontend の利用状況タブ（NAW-1421）が依存する
