# 03_詳細設計

## `backend/app/schemas/token_usage.py`

- `UsageUserType`（`str, Enum`）: `ACTIVE` / `SYSTEM` / `DELETED`
- `TokenUsageItemResponse` に `userName: str | None`、`userType: UsageUserType` を追加
- `from_token_usage(token_usage, users_by_id)` に変更。`users_by_id: dict[UUID, User]` から利用者を決める
  - `user_id` が None、または `users_by_id` にない -> DELETED / name=None
  - `user.role == UserRole.SYSTEM` -> SYSTEM、それ以外 -> ACTIVE。name は `user.name`

## `backend/app/services/token_usage_service.py`

- `list_token_usages` で `find_page` の結果から None でない `user_id` の集合を作り、`UserRepository.find_by_ids(user_ids, tenant_id, session)` で一括取得（空集合なら `{}` が返る）
- 各行を `from_token_usage(token_usage, users_by_id)` で変換
