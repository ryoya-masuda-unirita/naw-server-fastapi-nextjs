# 05_テスト詳細設計

## `backend/tests/integration/test_token_usage.py`（新クラス `TestTokenUsageUserType`）

`token_usages.user_id` に外部キーはないため、存在しない UUID や他テナントのユーザー ID の行を直接作れる。

- `test_active_user_has_name_and_active_type`: USER ロールの行が ACTIVE / ユーザー名
- `test_system_role_user_has_system_type`: SYSTEM ロールの行が SYSTEM / ユーザー名
- `test_missing_user_is_deleted_type`: 実在しない UUID の行が DELETED / null
- `test_null_user_id_is_deleted_type`: user_id NULL の行が DELETED / null
- `test_other_tenant_user_is_deleted_type`: 他テナントのユーザー ID の行が DELETED / null
