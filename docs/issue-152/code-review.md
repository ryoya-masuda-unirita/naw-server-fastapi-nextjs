## 詳細

### 1. コメントと実際の割り当て件数の不一致（🔵 提案）→ 対応済み

`groups_assistants`へのアシスタント割り当てで、6件のアシスタントを`(s-1) % 4 + 1`で
4グループへ順繰りに割り当てているため、実際にはグループ1・2が2件ずつ、グループ3・4が
1件ずつという不均等な分布になる。コメントは「4グループに2件ずつ回す」となっており、
実態と異なっていた。

コメントを実際の割り当てに合わせて修正した。機能的な不具合ではない（デモ用データの
分布の違いであり、動作には影響しない）ため、割り当てロジック自体は変更していない。
