# seed.sqlをより実データに近い規模・構成に拡充する

## 概要

`backend/seed.sql`は現状、各Issue対応時に動作確認用の最小限データを都度追記する形で
育ってきたため、テナント数・ユーザー数・アシスタント数などが実運用と比べて非常に少ない。
dev/staging RDS（Spring Boot版）の実データの「件数・構成パターン」を参考に（実データ
そのものはコピーしない）、より実運用に近い規模・多様性を持つseedデータに拡充する。

## 説明

- 現状のseed.sqlは、テナント1件・管理者/一般ユーザー数名・アシスタント数件程度で、
  機能ごとの動作確認に必要な最小データしか無い
- 参考として確認したdev/staging RDS（Spring Boot版）のデータ規模: テナント3件・
  ユーザー61件・グループ13件・アシスタント88件・プロンプトテンプレート58件・
  ルーム87件・メッセージ98件・フィードバック10件・テナントエンドポイント10件・
  AIモデル7件 など
- このリポジトリの`backend/`はAlembicで独自にスキーマを管理しており、Spring Boot側の
  スキーマ・データをそのまま移行することはできない（#150関連の調査で確認済み）ため、
  実データの値そのものはコピーせず、規模感・構成パターンのみを参考にゼロから作成する
