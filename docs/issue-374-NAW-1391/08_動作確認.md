# 08_動作確認

## 確認環境

- ローカル（worktree）、`backend/` で `uv run pytest`
- 全自動モードのため、ブラウザ・実 Azure AI Search での確認は行っていない。動作確認は自動テストのみで代替した

## 確認手順

1. `uv run pytest tests/unit/test_vector_store.py -q`
2. `uv run pytest tests/unit -q`（回帰確認）
3. `uv run ruff check`・`ruff format`・docstring 検査（`D101,D102,D103,D105,D106,D107,D417`、numpy）
