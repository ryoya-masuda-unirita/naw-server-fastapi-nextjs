# 01_要件定義

## 背景

インデックスは学習データを初めて追加したときに作られる。学習データが 1 件もないテナントや、VDB の接続先を別の Azure AI Search に変えた直後のテナントにはインデックスがない。この状態で SAAS_RAG のチャットをすると、現状は 400 になりチャットが失敗する。移植元（NAW-1391）では、インデックスがないことを 0 件の検索結果として扱う。

## 機能要件

- RAG 検索で Azure AI Search が「インデックスが存在しない」ことを示す 404 を返したときは、エラーにせず検索結果 0 件として扱う
- 0 件のとき、チャットは RAG の文脈なしで通常どおり続行する
- 404 のうち、Azure AI Search のインデックスへの要求（要求パスが `/indexes` で始まる）のものだけを対象にする
- 質問文の埋め込みの 404（埋め込みのデプロイがない等）は設定の誤りであり、0 件にせず従来どおりエラーとして返す
- 404 以外の失敗（認証エラー・接続失敗など）は従来どおり 400 `Failed to connect to vector database` を返す

## 非機能要件

- 0 件として扱ったときは、原因が追えるようログ（info）を残す

## スコープ外

- 学習データの追加・削除側のインデックス操作（`generative-ai-adapter/embedding-adapter/` の担当）
