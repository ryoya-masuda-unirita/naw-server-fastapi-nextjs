# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | インデックス未作成 | 検索が `/indexes` への要求の 404 で失敗する | 例外にならず空リストを返す |
| 2 | 他の 404 | 検索が `/indexes` 以外への要求（埋め込み API 等）の 404 で失敗する | 400 になる |
| 3 | 404 以外の HTTP エラー | 検索が 401 などで失敗する | 400 になる |
| 4 | 要求情報なし | 404 だが response が無い | 400 になる |
| 5 | 接続失敗 | `ServiceRequestError` | 400 になる（既存） |
