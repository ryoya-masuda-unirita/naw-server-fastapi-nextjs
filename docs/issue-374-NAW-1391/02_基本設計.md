# 02_基本設計

## 変更対象

- Azure AI Search へのベクトル類似検索クライアント（`core` 配下のインフラ層）

## 画面 / API 変更概要

- 画面・API の入出力仕様の変更はない
- インデックス未作成のテナントで SAAS_RAG のチャットを送ったときの結果が、400 エラーから「RAG の文脈なしの通常応答」に変わる

## 影響範囲

- 検索クライアントを呼ぶ RAG のチャット処理。移植元と違い、このリポジトリでは質問文の埋め込みは別クライアントが行うため、検索クライアント側だけの判定で「埋め込みの 404 は 0 件にしない」が満たされる。サービス層の変更は不要

## 移植方針

- 移植元は VectorStore をラップするクラスで 404 を判定している。Python 版は検索クライアントの検索失敗時の例外処理の中で、同じ判定（404 かつ要求パスが `/indexes` 始まり）を行い、該当すれば空リストを返す
- 移植元の削除側の寛容処理は、削除をこのクライアントが持たないため対象外
