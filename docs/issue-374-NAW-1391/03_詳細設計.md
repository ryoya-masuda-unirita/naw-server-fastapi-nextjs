# 03_詳細設計

## 変更ファイル

- `backend/app/core/vector_store.py`
- `backend/tests/unit/test_vector_store.py`

## 設計

- 定数 `_HTTP_NOT_FOUND = 404`、`_SEARCH_INDEXES_PATH = "/indexes"` を追加
- `_is_index_not_found(error: HttpResponseError) -> bool` を追加。`error.status_code == 404` かつ `error.response.request.url` のパスが `/indexes` で始まる場合のみ True（response・request・url が欠ける場合は False）
- `similarity_search` で `HttpResponseError` を捕捉したとき、`_is_index_not_found` が True なら info ログを出して `[]` を返す。それ以外は従来どおり 400 に変換。`ServiceRequestError` は従来どおり 400
- docstring（Raises・概要）を更新
