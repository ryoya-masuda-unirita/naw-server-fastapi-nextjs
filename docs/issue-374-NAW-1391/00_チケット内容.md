# #374 issue-374 NAW-1391 RAG 検索でインデックス未作成のときは 400 にせず 0 件として扱う

## 概要

チャットの RAG 検索で、Azure AI Search のインデックスが未作成のときは 400 にせず 0 件として扱う。`/indexes` への要求が 404 のときだけ 0 件にし、質問文の埋め込みの 404 など他の失敗はそのまま返す。

## 説明

現状は `AzureAiSearchVectorStoreClient.similarity_search` が `HttpResponseError` をすべて 400 `Failed to connect to vector database` に変換するため、新規テナントや VDB 接続先変更直後に SAAS_RAG のチャットが失敗する。

## その他

- 根拠（移植元）: NAW-1391。`factory/IndexNotFoundTolerantVectorStore`、`VectorStoreFactory.connectVectorStore`、`MessageService`。テストは `IndexNotFoundTolerantVectorStoreTest`・`VectorStoreFactoryTest`
- 学習データ追加・削除側のインデックス操作は `generative-ai-adapter/embedding-adapter/` の担当で、この Issue の範囲外
