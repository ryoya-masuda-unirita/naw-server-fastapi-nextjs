# 04_テスト設計

## テスト方針

ファイル一覧・削除 API を結合テスト（インメモリ SQLite・一時ディレクトリのストレージ）で呼び出し、論理削除後の一覧の内容を検証する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 削除済みの除外 | 2 件アップロードし 1 件を論理削除後、`status` 未指定で一覧取得 | 削除していないファイルのみ返り、件数は 1 |
| 2 | 削除済みでの絞り込み | 論理削除後、`status=DELETED` で一覧取得 | 削除したファイルが返る（既存テスト） |
| 3 | 既存動作の維持 | 既存の一覧・絞り込み・削除テスト | すべて成功する |
