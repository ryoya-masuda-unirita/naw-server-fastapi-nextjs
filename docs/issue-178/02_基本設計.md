# 02_基本設計

## 変更対象

- ファイル一覧取得のリポジトリ層（絞り込み条件の組み立て）

## 画面 / API 変更概要

| API | 変更内容 |
|---|---|
| `GET /api/admin/indexes/{indexId}/files` | `status` 未指定時に削除済みファイルを返さない（`totalElements` からも除外） |

## 影響範囲

- `status` 未指定の一覧取得結果のみ。`status=DELETED` を指定すれば削除済みファイルを取得できる
- 削除 API（論理削除・物理削除）自体の動作は変わらない

## 移植方針

- 移植元 `FileService.searchFiles` の Specification と同じく、`status` 指定時は `status = 指定値`、未指定時は `status <> DELETED` を条件に加える
