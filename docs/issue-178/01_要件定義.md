# 01_要件定義

## 背景

学習データ詳細画面でファイルを削除（個別・一括）すると、削除 API は成功（204）するが、一覧を再取得しても削除したファイルが表示され続ける。削除は論理削除（状態を「削除済み」にするだけ）だが、一覧取得は状態の指定が無いときに削除済みを除外していない。

移植元（Spring Boot）でも同じ不具合があり、NAW-1332「学習データのファイルを削除しても、一覧から消えない」（コミット `fa766714`）で、状態の指定が無いときは削除済みを除外するよう修正されている。

## 機能要件

- ファイル一覧 API で状態（`status`）を指定しない場合、削除済み（`DELETED`）のファイルを一覧・件数から除外すること
- 状態に `DELETED` を指定した場合は、従来どおり削除済みのファイルを一覧に含めること
- 状態に `ENABLE` / `DISABLE` を指定した場合の動作は変えないこと

## 非機能要件

- DB スキーマ変更を伴わないこと
- API のリクエスト・レスポンス形式は変更しないこと

## スコープ外

- 削除済みファイルを更新 API で元に戻せないようにする制御（移植元 NAW-1375）
- フロントエンド（`frontend-angular/`・`frontend/`）の変更
