## 実装内容

```python
if status is not None:
    stmt = stmt.where(File.status == status)
else:
    stmt = stmt.where(File.status != FileStatus.DELETED)
```

- 件数（`count_stmt`）は同じ `stmt` から作るため、`totalElements` からも除外される
