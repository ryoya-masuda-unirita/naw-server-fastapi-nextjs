# 08_動作確認

## 確認環境

- macOS（ローカル）、`backend/` で `uv run`
- 自動テスト（`uv run pytest`、インメモリ SQLite + fakeredis）
- **ブラウザ・実機確認は行わず、自動テストのみで代替した**（保存処理中の DB 障害は手動では再現しにくく、モックで例外を起こすテストの方が確実なため。共有のローカル DB・サーバーにも触れない運用のため）

## 確認手順

1. 追加したテスト 8 件を実行する
2. サービス 2 ファイルを一時的に修正前（origin/develop）の内容に戻し、追加したテストがすべて失敗することを確かめる（確認後に修正を戻した）
3. CI と同じく、全件テスト・mypy・ruff を実行する
