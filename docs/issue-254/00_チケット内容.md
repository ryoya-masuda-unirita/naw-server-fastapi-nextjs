# #254 issue-254 メッセージ送信のSSEで保存処理の例外でもerrorイベントを送る

## 概要

メッセージ送信 API の SSE（#220）で、回答の保存処理（`_persist_message_content`・`_persist_library`・`_persist_token_usage`）で `ValueError` 以外の例外（DB の障害など）が起きると、error イベントを送らないまま接続が切れる（`backend/app/services/message_service.py` の `finally` は `ValueError` だけを捕まえている）。

移植元（`service/MessageService.java`）は一番外側の catch で `sendSseError` を送る。

## 説明

### 再現シナリオ

保存の途中で DB に接続できなくなると、クライアントには error も message_content も届かず、ストリームが途中で終わったように見える。

### 対応

移植元に合わせて、保存処理で起きた例外でも error イベントを送ってからストリームを閉じる。`/api/llm/chat` の SSE（`llm_chat_service.py`）にも同じ問題がないか確認する。
