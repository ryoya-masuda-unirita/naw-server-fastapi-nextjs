# 04_テスト設計

## テスト方針

保存処理を例外にするモックで、SSE のイベント列と保存処理の呼び出しを検証する（DB 不要の単体テスト）。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | メッセージ送信: 回答の保存失敗 | 回答の保存が DB 障害相当の例外 | text_delta → message_stop → error（固定文言）。トークン使用量の保存は実行される |
| 2 | メッセージ送信: トークン使用量の保存失敗 | トークン使用量の保存が例外 | text_delta → message_stop → error。message_content は送らない |
| 3 | メッセージ送信: ライブラリの保存失敗 | ライブラリ生成モードでライブラリの保存が例外 | 最後が error、message_content は送らない。トークン使用量の保存は実行される |
| 4 | メッセージ送信: 内部情報を出さない | 回答の保存が例外 | 本文に例外の文字列が含まれない |
| 5 | メッセージ送信: LLM・保存ともに失敗 | LLM 呼び出しと回答の保存が例外 | error → error（2 つ目は固定文言）。例外は伝播しない |
| 6 | メッセージ送信: 切断後の保存失敗 | 最初のイベント受信後にクライアントが切断し、回答の保存が例外 | 終了処理で例外が出ない。回答・トークン使用量の保存は実行される |
| 7 | 汎用チャット: トークン使用量の保存失敗 | トークン使用量の保存が例外 | text_delta → message_stop で正常に閉じる（error は送らない） |
| 8 | 汎用チャット: ライブラリの保存失敗 | ライブラリ生成モードでライブラリの保存が例外 | message_stop で正常に閉じる。トークン使用量の保存は実行される |
| 9 | 回帰 | 既存テスト全件 | すべて成功 |
