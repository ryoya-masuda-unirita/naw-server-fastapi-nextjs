# 01_要件定義

## 背景

移植元の最新の学習データ詳細は、絞り込みが「検索」と「期間」だけで、更新者・学習設定の絞り込みもファイル一覧の並べ替えも無い。結合テスト項目書 V1.1.0 のこれらの操作を使う項目は、現行の画面では成り立たず、通し実行で NG（または、画面が古いと OK）になる。

## 機能要件

1. 17-11・17-30・17-33・17-34 を、移植元に無い操作のため、理由つきの未実施（skip）にする
2. 使われなくなったテスト用の部品（Page Object のメソッド・定数）を削除する
3. 集計結果のドキュメントの件数と、未実施の一覧を合わせる

## 非機能要件

- 失敗を隠さない。NG を OK に見せかけない。skip の理由に、画面から消えた経緯（NAW 番号と移植 Issue）を書く
- #416 と同じ方針・同じ書き方にそろえる

## スコープ外

- 画面（`client/`）・backend の変更
- 17-11 などの操作を、移植元に合わせた別の確認方法に作り直すこと
- 通し実行
