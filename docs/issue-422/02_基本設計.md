# 02_基本設計

## 変更対象

- e2e-spec の学習データのテスト（4 項目）
- 学習データの Page Object（使われなくなった操作・定数）
- 集計結果のドキュメント

## 画面 / API 変更概要

画面・API の変更はない。

## 影響範囲

- 17_学習データの OK が 4 件減り、未実施（skip・理由あり）が 4 件増える
- 他のカテゴリには影響しない

## 移植方針

- 移植元の最新の画面を確認し、4 項目が使う操作が無いことを確かめた上で、skip にする（#416 と同じ）
- skip の理由は、更新者の絞り込み（NAW-1424・#411）、学習設定（NAW-1405・#375）、並べ替え（NAW-1427・#392）の 3 種類にする
