### 1. 17-33 を skip にすると、検索と期間の組み合わせが無くなる（🔵 提案）→ 対応しない

17-33 は項目書の「詳細：検索＋フィルター」で、フィルターは更新者（ユーザー）を指す。移植元の最新の画面にはその絞り込みが無いので、項目としては成り立たない。「検索と期間」の組み合わせは別の確認になり、項目書にある項目ではない。新しい確認を足すのは、`01_要件定義.md` でスコープ外とした。必要なら、別 Issue で扱う。

### 2. skip 理由が片方しか書かれていない（🔵 提案）→ 対応済み

17-30 は学習設定に加えて更新者の絞り込みも、17-34 は並べ替えに加えて更新者の絞り込みも使っていた。`docs/issue-316/09_集計結果.md` には両方の理由を書いていたので、テストの理由と食い違っていた。両方の理由をつなげるよう直した（`${FILTER_REMOVED_REASON}。更新者の絞り込みも同様（${USER_FILTER_REMOVED_REASON}）` など）。直したあと、`tsc`・`eslint` を通し、4 項目が `skipped` になることを確かめた。
