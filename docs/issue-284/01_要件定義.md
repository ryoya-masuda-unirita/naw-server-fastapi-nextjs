# 01_要件定義

## 背景

チャット画面は、利用者が AI アシスタントと会話するこのプロダクトの中心画面。#283 で土台（SSE・messages・rooms の store）を移したので、画面を移す。

## 機能要件

1. 新規チャット画面（`/dashboard`・`/chat/new`）
   - 開くたびに、ルームなし・メッセージなしの状態にする。ロゴと見出し（`CHAT.EMPTY.SUBTITLE`）・入力欄を出す
   - 最初のメッセージを送ると、ルームを作って `/chat/:roomId` へ移り、移動先の画面で送信する
2. チャットルーム画面（`/chat/:roomId`）
   - ルームのメッセージを読み込んで表示する（読み込み中はローディング）。ルーム名をヘッダーに出す
   - 新規チャットから移ってきたときは、読み込まずに預かった最初のメッセージを送る
   - 回答が 1 つでもあれば、右にビューワーの枠（`chat-data-panel`）を出す。幅はドラッグで変えられ、折りたためる
3. ヘッダー
   - ルーム名・名前変更・共有・評価（PC）、メニュー（モバイル。名前変更・ビューワーを開く・共有・評価）、ハンバーガー（モバイル）
   - 名前変更はダイアログ。空白だけでは保存できない。保存時は前後の空白を除く
4. メッセージ一覧・項目
   - ユーザーの質問（添付表示・編集して再送信・版の切り替え・コピー・削除）
   - アシスタントの回答（名前・思考過程・Markdown・参考資料・エラー表示・ローディング・コピー・評価・再生成・削除）
   - 解決できないアシスタント（削除済み等）の回答は、編集・再生成を禁止する。名前の読み込み中はプレースホルダー
   - 更新のたびに末尾までスクロールする
5. 入力欄
   - Enter で送信、Shift+Enter で改行。日本語変換の確定 Enter では送信しない
   - 「@」で始まる入力は送信できない（メンション選択中。メンション自体は #286）
   - 送信ごとにアシスタント・Web 検索・テンプレート・ライブラリ作成を載せる（選ぶ UI は #286・#287。値の受け口は用意する）
   - 初期アシスタントは、ルームの既定 → 一覧の既定 → 先頭の順
6. サイドバーの「新しいチャット」ダイアログ（アシスタントを選んでルームを作り、その画面へ移る）
7. 部品: `chat-alert`・`chat-error`・`chat-file-preview`・`chat-claude`・`chat-new-room-dialog`

## 非機能要件

- 見た目・文言は移植元に揃える（Angular のテンプレートのクラス・i18n キーをそのまま使う）
- 他の画面が並行して触る共通ファイルの変更は最小限（`routes/index.tsx`・`lib/constants/*`・`sidebar.tsx`・`index.css`・`public/i18n/*`・`package.json` は触らない）

## スコープ外

- アシスタント選択・テンプレート選択・メンション・アシスタント試験（#286。`/chat/assistant` も #286）
- 添付・評価ダイアログ・検索・共有（#287）、ビューワー本体・共有閲覧・ライブラリ保存（#288）、SECURE の local 送信の結合（#289）
- サイドバーのルーム一覧（#285）
