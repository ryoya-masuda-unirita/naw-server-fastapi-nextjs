## メンション

- 開く条件: `messageContent.startsWith('@') && !isMentionDismissed`。候補は `filterAssistants(parseLeadingMention(content).query, assistants)`
- 状態の同期（移植元 `syncMentionState`）: 入力が変わるたびに `isMentionDismissed=false`、選択位置を候補数に収める（「@」でなければ 0）。Esc の「閉じた」を一覧の再取得で戻さないよう、依存は入力だけにして一覧は ref から読む
- キー処理（`onTextareaKeyDown`。true を返すとその入力は `ChatInput` が処理しない）: ↑↓（端で止まる）、Esc（閉じる）、Enter / Tab（Shift なし。変換中は何もしない。候補があれば確定、なければ Enter のみ抑止）
- 確定: 本文を `rest`（「@検索語」を除いた残り）にし、アシスタントを切り替え、閉じた状態・選択位置を戻し、textarea の高さを戻してフォーカス
- 入力欄が消えるとき（ルーム移動など）に store を `reset()`

## 「＋」メニュー

- 開く: 位置は「＋」ボタンの上（`bottom = innerHeight - rect.top + 4`、`left` は幅 280 を画面内に収める、`maxHeight` は 120〜400）。開くたびにメイン画面に戻し、ウィジェットの複数パネルを閉じる
- 閉じる: メニュー外のクリック（`[data-chat-add-menu]` の外）、項目の選択
- テンプレート: 768px 未満は同じパネルの中身を一覧に切り替え（戻るボタン）。それ以上は右にサブメニュー（右にはみ出すなら「＋」メニューごと左へ寄せる）
- 項目は `StatefulItem`（`div role="menuitem"`、Enter / Space）

## 有効な機能

- 数: Web 検索・テンプレート・ライブラリ作成の有効数
- 1 つ: ピル（×で外す）。2 つ以上: 件数ボタン + パネル（位置はボタンの上、`bottom`・`right`・`maxHeight` 120〜320）。外側クリックで閉じ、2 つ未満になったら閉じる

## アシスタント選択

- 位置・幅: 幅 `min(320, innerWidth - 16)`、`left` は右端そろえで画面内に収める、`bottom = innerHeight - rect.top + 4`、`maxHeight` は 120〜320
- 開閉は `dropdownService`（開いているドロップダウンを 1 つにする）と外側クリックで閉じる

## 試験画面

- `ChatWindow` に `isChatExamList` を渡すと、`ChatMessageList` の代わりに `.chat-page-messages` 内に `ChatAssistantExam` を出し、ヘッダーのルーム名は隠す。ルームは選ばない
- 見本の文言は移植元がハードコードした日本語をそのまま移す。フッターのボタンは何もしない。「コードをコピー」は 2 秒だけ「コピーしました」にする（実際のコピーはしない。移植元と同じ）
