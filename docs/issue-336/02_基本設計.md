# 02_基本設計

## 変更対象

- デモ環境の起動定義（compose）の新設
- frontend の開発サーバーをコンテナで動かす定義の新設
- デモデータの SQL の新設
- 既存の seed の不整合の修正
- README

## 画面 / API 変更概要

画面・API の変更はない。環境整備のみ。

起動の構成（サービスと役割）:

| サービス | 役割 | ホストに公開 |
|---|---|---|
| postgres | DB | しない |
| redis | ログインセッションの保存先 | しない |
| localstack | AWS（S3・SQS）の偽物。ユーザーの一括登録で使う | しない |
| migrate | DB のテーブルを作る（一度だけ動いて終了） | しない |
| seed | ログイン用データとデモデータを入れる（一度だけ動いて終了） | しない |
| backend | FastAPI | 既定 8001 |
| frontend | React の画面（Vite の開発サーバー） | 既定 5173 |

起動の順序は `postgres` → `migrate` → `seed` → `backend`（`redis`・`localstack` の healthy も待つ）→ `frontend`。

デモデータ（`test-tenant` に追加する）:

| 画面 | データ |
|---|---|
| ユーザー | 社員 10 名（管理者 1 名を含む） |
| チーム | 営業部・開発部・管理部・全社共通（所属ユーザー・アシスタント・テンプレート付き） |
| アシスタント | 6 件（SAAS_RAG 1・SAAS_CHAT 4・SECURE 1）と 3 カテゴリ |
| テンプレート | 6 件 |
| ライブラリ | 管理者の資料 4 件とタグ 4 件 |
| 学習データ | 学習先フォルダ 2 件（クラウド・ローカル）とファイル 10 件 |
| フィードバック | 回答の評価 8 件（追加学習の設定付きを含む）とルームの満足度 |
| チャット履歴 | 社員のチャット 12 件 |
| ワークスペース | クレジットの利用履歴 13 件 |

## 影響範囲

- 既存の `docker-compose.yml`・`backend/Dockerfile.dev`・既存ローカル環境には触れない
- `backend/seed.sql`: ライブラリの INSERT を `libraries` と `library_contents` に分けるだけ。他の行は変えない。`e2e-explorer/` も同じ `seed.sql` を使うため、この修正で E2E 探索環境の seed 失敗も直る
- README: 先頭に節を足す。古くなった「React のログイン画面にテナント ID 入力欄がなくログインできない」旨の注記を、現状（入力欄がありログインできる）に合わせて削除する

## 移植方針

移植元に対応物はない（独自の環境整備）。`e2e-explorer/docker/compose.yml` の専用環境の作り（`migrate` → `seed` → `backend` → `frontend`、healthcheck、frontend を開発サーバーで動かす）を参考にし、次の点を変えた。

- 名前・ボリューム: `name: naw-demo`（コンテナ名を固定しない）。データはボリュームに残し、`down` では消えず `down -v` で消える（デモの再起動のたびに seed し直さなくてよい）
- localstack を含める（ユーザーの一括登録が動く）
- ポートは `DEMO_FRONTEND_PORT`・`DEMO_BACKEND_PORT`（既定 5173・8001）
