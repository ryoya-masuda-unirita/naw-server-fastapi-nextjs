# #336 issue-336 ブラウザで画面を見られるよう1コマンドで起動できる環境とデモデータを用意する

## 概要

ここまで移植した backend + React の画面を、手元で 1 コマンドで起動してブラウザで見られるようにする（ユーザーが画面を動かして確かめる・理解するため）。

## 説明

### 要件

- ルートの `docker-compose.yml`（postgres・redis・localstack・backend）に、frontend（Vite の開発サーバー）を足す、または別 compose で起動できるようにする。既存のローカル環境（ポート 5433・6380・8001・5173）と衝突しない場合は既定のポートのままでよい
- 起動時に alembic のマイグレーションと `backend/seed.sql`（テナント・管理者・一般ユーザー）を流す
- `http://localhost:5173` でログイン（テナント ID・ユーザー ID・パスワード）できる。ログイン情報を README に書く
- 管理画面（9 画面）に、見て分かるデータが入っている seed（ユーザー・グループ・アシスタント・テンプレート・ライブラリ・学習データ・フィードバック・チャット履歴など）を用意する。既存の `backend/seed.sql` に足すか、`seed-demo.sql` を別に用意する
- SECURE のチャットを試すために、`onprem/`（#301）をつなぐ手順も書く（クラウド側 backend に LOCAL_SERVER エンドポイントを登録する seed は `onprem/cloud-seed.sql`）
- README は短く: 起動・停止のコマンド、ログイン情報、見られる画面の一覧、困ったときの確認

### 完了条件

実際に起動し、ログインして管理画面が表示されることを Playwright 等で確かめ（スクリーンショットを 08 に貼る）、片付ける。

## その他

- 担当は `backend/`・`frontend/` の両方にまたがる環境整備（コードの機能追加ではない）
- ユーザーの指示: `docker-compose.yml` のコメントは「各サービスが何を表すかの 1 行」だけにする
