# 05_テスト詳細設計

## 確認の方法

| No | 方法 |
|---|---|
| 1 | `DEMO_FRONTEND_PORT=15173 DEMO_BACKEND_PORT=18001 docker compose -f docker-compose.demo.yml up -d --build` のあと `ps -a` で状態を見る |
| 2 | `docker compose -f docker-compose.demo.yml run --rm seed` をもう一度流し、`users` などの件数が変わらないことを `psql` で見る |
| 3 | 1 の起動に含まれる（`seed` のログ） |
| 4・5 | Playwright（`e2e-explorer/` の `node_modules`）でログインし、9 画面のスクリーンショットを撮る（`docs/issue-336/screenshots/`） |
| 6 | 既存の `naw-fastapi-*` コンテナ・既存のポートには触れず、別ポート（15173・18001）で確認する |
| 7 | `docker compose -f docker-compose.demo.yml exec -T postgres psql … < onprem/cloud-seed.sql` |
| 8 | `docker compose -f docker-compose.demo.yml down -v` のあと `docker ps -a`・`docker volume ls` で残りがないことを見る |

自動テスト（`uv run pytest` など）は、アプリケーションコードを変えていないため対象外。`seed.sql` を参照する自動テストはない。
