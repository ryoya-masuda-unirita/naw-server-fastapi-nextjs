# frontend-angular/ を削除し、dev環境のフロントのデプロイをReact（frontend/）に切り替える

## 概要

`frontend-angular/`（上流 `secuaigent/client` のコピー。React 移植完了までの backend 動作確認用）は不要になったため、リポジトリから削除する（2026-11-12 ユーザー判断）。あわせて、dev 環境（S3 + CloudFront）のフロント配信を React（`frontend/`）に切り替える。

## 説明

### 対応内容

- `frontend-angular/` をディレクトリごと削除する（`frontend-angular/e2e/` の Playwright テストを含む。git 履歴には残る）
- CI/CD: `.github/workflows/deploy.yml` のフロントジョブと `deploy-frontend-angular.yml` を、`frontend/` をビルドして同じ S3 バケット / CloudFront に配信する形に切り替える（API は相対パスで呼ぶ。#197 で Angular 側に入れた「本家の本番 API ドメインを使わない」修正と同等の考慮をする）
- `docker-compose.yml` の `frontend-angular` サービス、backend の CORS 許可オリジン等の `frontend-angular`（ポート 4201）前提の設定を整理する
- ドキュメント・スキル: `frontend-angular-sync` スキル（`.claude/`・`.codex/`）を削除し、CLAUDE.md・AGENTS.md・README・`infra/README.md`・`.claude/launch.json`・各スキル/エージェント定義から `frontend-angular` 前提の記述を外す（backend の動作確認は自動テスト、または React `frontend/` で行う）

### 関連

- frontend-angular 専用の Issue（#165・#169・#174・#180・#184）は not planned でクローズ済み

### スコープ外

- React 移植（`frontend/`）の未移植画面の実装
- React 向け E2E テストの作成
