# 05_テスト詳細設計

## 新規テスト: `frontend/src/lib/api-client.test.ts`

`API_BASE_URL` はモジュール読み込み時に決まるため、各テストで `vi.stubEnv('VITE_API_URL', ...)` → `vi.resetModules()` → `await import('./api-client')` の順で読み込み直す。送信先は MSW（`src/test/setup.ts` の `server`）の `server.use(...)` で受け、リクエスト URL を検証する。終了時に `vi.unstubAllEnvs()`。

| No | テスト名 | 内容 |
|---|---|---|
| 1 | `sends GET to same origin when base url is empty` | `VITE_API_URL=''`、`get('/api/items', { params: { page: 1 } })` → `${window.location.origin}/api/items?page=1` に届き、レスポンスが返る |
| 2 | `sends POST to same origin when base url is empty` | `VITE_API_URL=''`、`post('/auth/logout', null)` → `${window.location.origin}/auth/logout` に届く |
| 3 | `sends GET to absolute base url when configured` | `VITE_API_URL='http://localhost:8000'`、`get('/api/auth')` → `http://localhost:8000/api/auth` に届く |

テスト名は英語、意図は日本語のコメント（TypeScript のため docstring の代わりに `it` の直前コメント）で書く。
