# #93 issue-93 メッセージ送信（アシスタント応答生成・SSEストリーミング）APIの移植

## 概要

Issue #48（メッセージ送受信API（同期系）の実装）でスコープ外とした `POST /api/messages/content`（メッセージ送信によるアシスタント応答生成・SSEストリーミング）を移植する。

## 対象エンドポイント

- POST /api/messages/content

## 参照

- 移植元（バックエンド）:
  - `~/Documents/naw-server/src/main/java/com/example/naw/api/MessageController.java`（createMessageContent, L77-105）
  - `~/Documents/naw-server/src/main/java/com/example/naw/service/MessageService.java`（resolveStreamContext, buildChatContext, buildRagContext, streamAndPersist, persistLibrary 等）
- 移植先: `backend/app/routers/messages.py`, `backend/app/services/message_service.py`

## 説明

- SAAS_CHAT（通常チャット）とSAAS_RAG（ベクトル検索付き）の2分岐を持つ。SSEイベント列は `LlmController`（Issue #88, PR #91）と共通利用する部分がある。
- 実装規模が大きいため、要件定義フェーズで「まず基本チャット（RAG・添付ファイル・tools・ライブラリ生成・response_format除外）から着手し、RAG対応等は別issueに切り出す」といった段階分けの要否を検討すること。

## その他

- スコープ: バックエンド（FastAPI）のみ
- 本Issue着手時点で `feature/issue-93` ブランチには Issue #88（PR #91: LLMチャット・埋め込みAPI）がマージ済み。PR #91 は本チケット着手時点で `develop` 未マージ（詳細は `01_要件定義.md` 参照）。
