## 単体テスト（`test_message_service.py`）

- `AzureLlmChatClient.stream_chat`は`unittest.mock.AsyncMock`かつ非同期ジェネレータを返すダミー関数でモック化する。
- `AssistantRepository` / `AssistantEndpointRepository` / `AIModelRepository` / `MessageRepository` / `enforce_within_quota` はモックまたはインメモリDB（既存`conftest.py`のfixtureパターンに準拠）で用意する。
- `test_stream_message_content_returns_400_when_assistant_type_is_saas_rag`
  """SAAS_RAGアシスタント宛の場合は400を返すこと（本Issueのスコープ外である旨のバリデーション）"""
- `test_stream_message_content_returns_403_when_room_not_owned`
  """所有していないルームのメッセージIDを指定した場合は403を返すこと"""
- `test_stream_message_content_returns_429_when_quota_exceeded`
  """テナント月次クレジット上限を超過している場合は429を返し、LLM呼び出しが行われないこと"""
- `test_apply_additional_prompt_prefixes_last_user_turn`
  """additionalPromptが末尾から最後のuserロール発話にのみ前置されること（llm_chat_serviceと同一ロジックの再利用を確認）"""

## 統合テスト（`test_messages.py`）

- `test_post_messages_content_streams_text_delta_and_persists_message_content`
  """SAAS_CHATアシスタント宛にメッセージ送信すると、text_delta→message_stop→completeの順でSSEが配信され、MessageContentがstatus=OKで永続化されること"""
  - Azure OpenAI呼び出しは`AzureLlmChatClient.stream_chat`をモノキーパッチしたダミー非同期ジェネレータで代替する（`text_delta`を2回、最後に`input_tokens`/`output_tokens`を含むチャンクを返す）。
  - レスポンスボディ（SSEテキスト）を行単位でパースし、`event:`/`data:`の組を検証する。
  - DB確認: `MessageContent`が1件追加され`question`/`answer`/`status`が期待値であること、`TokenUsage`が1件追加されること、`Room.updated_at`が更新されていること。
- `test_post_messages_content_returns_404_when_message_not_found`
  """存在しないmessageIdを指定した場合は404を返すこと"""
