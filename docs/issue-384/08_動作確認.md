- **実際の `apply` と起動は、していない**（費用がかかるため、ユーザーの指示でデプロイしない）。そのため、次は未確認: Fargate のタスクが NAT 経由でイメージを取得できること、ALB のヘルスチェックが通ること、マイグレーションの一時タスクが実際に起動すること、`depends_on` による NAT の作成順序
- NAT GW・Fargate の月額は未確認。東京リージョンの単価を、公式の料金ページから確認できなかった（検索では、リージョンの特定できる単価が出なかった）。当初 README に書いた「月 4,000 円超」は、根拠のない概算だったので削除した。料金ページと Pricing Calculator、実際の請求で確認する
- `plan` で確定しない値（コンテナ定義、NAT GW の ID）は、コードの読解で確認した
