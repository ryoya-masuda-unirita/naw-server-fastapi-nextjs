# ECS を Fargate に、network を NAT GW + private サブネットに揃える

## 概要

Issue #384（親: #380。#381〜#383 はマージ済み）。コンテナの実行基盤を EC2 起動タイプから Fargate に変え、ネットワークを移植元と同じ「NAT GW + private サブネット」の構成にする。

## 説明

- ECS: EC2 起動タイプ（ASG・キャパシティプロバイダ・起動テンプレート・EC2 のロール）を廃止し、Fargate（awsvpc）にする。サービスの `health_check_grace_period` なども移植元に合わせる
- network: VPC の CIDR を `10.10.0.0/16` にし、`cidrsubnet` で public / private を 2 AZ ずつ作る。NAT GW + EIP を追加し、private のルートテーブルは NAT 経由にする。`enable_dns_hostnames` / `enable_dns_support` を有効にする
- ALB: ターゲットを `ip` タイプにする。ヘルスチェックは FastAPI の `/health` のまま（移植元の `/actuator/health` は使わない）。ECS の SG の入力は 8000 のまま
- 維持するもの: ALB の CloudFront プレフィックスリスト + 管理 CIDR による制限、HTTP のみのリスナー（HTTPS・ACM はサブドメイン関連のため持ち込まない）、bastion、`backend-migrate` タスク定義
- `deploy-backend.yml` の ECS 関連の設定を同じ PR で直す
- 固定費（NAT GW）が増えるので、PR に月額の目安を書く
