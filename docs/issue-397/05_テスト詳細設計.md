# 05_テスト詳細設計

## 実行コマンド

| No | コマンド | 場所 |
|---|---|---|
| 1 | `npm run spec:all`（2 回） | `e2e-spec/` |
| 2 | `npm test`（全体、2 回。client の package.json のコマンドを確かめてから実行する） | `client/` |
| 3 | `npm run lint` と `npm run typecheck` | `e2e-spec/` |
| 4 | client の lint・型チェック | `client/` |

## 記録するもの

- 各回の OK・NG・未実施の数と、NG の項番
- 実行にかかった時間（並列 4 と 2 の比較用。変更前の回も 1 回記録する）
- 実際のコマンド出力は `08_動作確認.md` に貼る（生成・推測はしない）
