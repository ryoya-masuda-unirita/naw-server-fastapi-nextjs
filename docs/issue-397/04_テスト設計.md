# 04_テスト設計

## テスト方針

製品コードの振る舞いは変えないので、新しいテストは足さない。変更後に既存のテスト全体を繰り返し回して、安定したことを確かめる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | e2e-spec の安定 | `npm run spec:all` を連続 2 回 | 07-16 を除き NG 0（2 回とも） |
| 2 | vitest の安定 | `npm test` の全体実行を連続 2 回 | 2 回とも全件成功 |
| 3 | 期待値を緩めていない | 変更箇所の差分を読む | アサーションの条件・期待値が変わっていない |
| 4 | lint・型 | e2e-spec の `lint`・`typecheck`、client の lint・型チェック | エラー 0 |
