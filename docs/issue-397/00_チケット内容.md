# #397 issue-397 e2e-spec の通し実行と vitest の全体実行で一部のテストが不安定になる

## 概要

e2e-spec を並列 4（`npm run spec:all`）で通し実行すると、負荷で一部のテストが落ちる。単独の再実行ではすべて OK だった。

## 説明

### 事実

- 通し実行で 11 項目が NG: 05-03〜05-06・09-15・11-15・11-38・11-68・14-63・15-06・15-08
- 症状: 要素が待ち時間内に出ない／後片付けの API が 500 または ECONNRESET
- 別件: `client` の vitest を全体で回したときに `library-list.test.tsx`「タイトル・タグ・更新日時が表示されること」が 1 回落ちた。単独では 2 回とも通った（タイミング依存の疑い。#316 の件とは別の原因かもしれない）

### 調べること

- backend が 500 を返した原因（11-38 のルーム削除、11-68 のルーム作成）。負荷によるものか、同時操作のバグか
- 並列数（`E2E_SPEC_WORKERS`）の既定を 2 に下げるか
- 該当テストの待ち時間の見直し（期待値は緩めない）
- `library-list.test.tsx` の不安定さの原因

### 受け入れ条件

通し実行を 2 回続けて、07-16 を除き NG 0。vitest の全体実行も 2 回続けて成功する。
