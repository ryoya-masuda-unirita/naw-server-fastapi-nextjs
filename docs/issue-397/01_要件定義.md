# 01_要件定義

## 背景

結合テスト項目書に沿った自動テスト（e2e-spec）と、React のユニットテスト（vitest）に、負荷で結果が変わる不安定さがある。通し実行で落ちた項目は、単独で再実行すると通る。落ちたのが本当の不具合なのか、負荷による揺れなのかを区別できないと、NG の数で移植の完成度を追えない。

## 機能要件

1. e2e-spec の通し実行を、07-16 を除き NG 0 で 2 回続けて通せる
2. vitest の全体実行を、2 回続けて成功させられる
3. 通し実行で出た backend の 500・切断の原因を特定する
   - 負荷で応答が遅れただけなのか、同時操作で起きる backend の不具合なのかを分ける
   - backend の不具合だった場合は、このチケットで直すか別チケットにするかを決める
4. 不安定さの原因を、テストの設定・待ち時間・並列数のうち何にあるかを分けて記録する

## 非機能要件

- 期待値を緩めない。待つ上限を伸ばすのは良いが、失敗を再実行や条件の緩和で OK にしない
- 並列数を下げる場合は、通し実行にかかる時間への影響を記録する

## スコープ外

- 07-16 の NG の修正（別件として残っている）
- 通し実行・全体実行以外の、個別のテストの修正
- CI への組み込み
