## code-review 後の追加確認

- ECS サービスに、実行ロールの権限ポリシーへの `depends_on` を足した（`fmt`・`validate` は OK。リソース数は変わらない）
- シード投入スクリプトに `--region` を足した。偽の `aws` で、既定（`ap-northeast-1`）、`AWS_REGION=us-east-1`、空の `DB_PASSWORD`、失敗時のメッセージ（リージョンを表示）を確認した
- README に、既存の環境に適用してはいけないこと、過去のタスク定義のリビジョンに旧い平文が残ることを明記した

## 未確認事項

- **`apply` していないため、次は未確認**: 実行ロールがシークレットを読んで、タスクの起動時に環境変数として注入されること。アプリが、注入された接続文字列で RDS に接続できること。マイグレーションの一時タスクの起動
- **RDS のパスワードの変更**: Terraform が `apply_immediately` を既定（false）のまま変更するため、既存の RDS に対しては、次のメンテナンスウィンドウまで反映されず、シークレットの値と食い違うおそれがある。新アカウントへの新規構築（RDS を最初からこのパスワードで作る）が前提で、パスワードの変更手順は、README に「確認できていないため書かない」と明記した
