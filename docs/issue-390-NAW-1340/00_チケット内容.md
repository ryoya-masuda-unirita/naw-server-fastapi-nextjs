# ローカルの学習先フォルダのファイル操作をローカル用サーバー経由にする（NAW-1340）

## 概要

ローカルの学習先フォルダ（種類が LOCAL）のファイルを、クラウドの API ではなく、フォルダに登録された接続先（ローカル用サーバー）へ画面から直接送って、一覧・追加・更新・削除・同期できるようにする。

## 説明

- GitHub Issue: #390
- 移植元チケット: NAW-1340（関連: NAW-1408 は #391）
- 移植元のコミット: ecb5759d2（本体）、d8218e389（401 の扱い・期間）、f6c09d71b（物理削除）、216b8f75a（編集から学習の ON/OFF を外す）
- 現状（調査結果）:
  - React は LOCAL でも常にクラウドの backend を呼ぶ。LOCAL かどうかの分岐は、見た目の切り替え（案内文・同期ボタン・ダウンロード非表示・ダイアログ幅）にしかない
  - backend は LOCAL のファイルの追加・更新・削除を 400 で断る。一覧は backend の DB の行を返すだけなので表示できる（デモ環境で一覧が出たのはこのため）。同期も LOCAL では画面から送られても動かない見込み
  - 接続先を返す backend の API（`/api/tenants/endpoints/local/{id}`）と、ローカル用サーバー（server-local）の受け口は既にある。frontend だけが未対応

## その他

- backend の変更は無い
- Issue 本文の「LOCAL フォルダの一覧は動かない見込み」は誤りだった。一覧は表示できる。追加・更新・削除・同期が動かない
