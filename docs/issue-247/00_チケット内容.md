# #247 issue-247 ユーザー一覧でexcludeGroupIdの所属ユーザーを除外する

## 概要

ユーザー一覧（`GET /api/admin/users`）が `excludeGroupId` を無視している（`backend/app/services/user_service.py` に「グループ機能実装時に対応する」のコメントが残っている）。

移植元は `group_users` に `NOT EXISTS` を掛けて、そのグループの所属ユーザーを除外する（`service/UserService.java`）。クライアントは、グループのメンバー追加ダイアログでこのパラメータを送る。

グループのモデル（`GroupUser`）は既にあるため、実装できる。

## 説明

移植元に合わせて、`excludeGroupId` を指定したら、そのグループの所属ユーザーを除外する。
