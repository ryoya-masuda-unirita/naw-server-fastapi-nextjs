# 08_動作確認

## 確認環境

- ローカル（macOS）、`backend/` で `uv run`（Python 3.14）
- DB はインメモリ SQLite（結合テストの fixture）。ローカルの Postgres・Redis・backend サーバーは起動していない
- **ブラウザ・実機確認は行わず、自動テストのみで代替した**

## 確認手順

1. `uv run pytest tests/integration/test_users.py -k ExcludeGroup -v` で追加したテストを実行
2. 除外条件を一時的に無効化して、追加したテストが失敗することを確認（確認後に戻した）
3. CI と同じ `uv run pytest`（全件）・`uv run mypy app tests`・`uv run ruff check`・`uv run ruff format --check` を実行

## 確認結果

### 1. 追加したテスト

```text
tests/integration/test_users.py::TestGetUsersExcludeGroup::test_excludes_members_of_group PASSED
tests/integration/test_users.py::TestGetUsersExcludeGroup::test_excludes_members_with_usage_and_credit_sort PASSED
tests/integration/test_users.py::TestGetUsersExcludeGroup::test_unknown_group_id_excludes_nobody PASSED
tests/integration/test_users.py::TestGetUsersExcludeGroup::test_other_tenant_group_id_excludes_nobody PASSED
tests/integration/test_users.py::TestGetUsersExcludeGroup::test_empty_group_id_excludes_nobody PASSED
======================= 5 passed, 31 deselected in 2.44s =======================
```

✅ 指定グループの所属ユーザーだけが除外され、件数にも反映される（利用量の付与・利用クレジット順の並べ替えと併用しても同じ）

✅ 存在しない・他テナントのグループ ID、空文字では 200 で誰も除外されない

### 2. 除外条件を無効化したときに失敗すること

`if exclude_group_id:` を一時的に `if False and exclude_group_id:` にして実行した結果（確認後に戻した）。

```text
FAILED tests/integration/test_users.py::TestGetUsersExcludeGroup::test_excludes_members_of_group
FAILED tests/integration/test_users.py::TestGetUsersExcludeGroup::test_excludes_members_with_usage_and_credit_sort
2 failed, 3 passed, 31 deselected in 2.48s
```

✅ 除外が効かない旧挙動をテストで検出できる

### 3. CI と同じチェック

```text
$ uv run pytest
1085 passed in 47.07s

$ uv run mypy app tests
Success: no issues found in 219 source files

$ uv run ruff check
All checks passed!

$ uv run ruff format --check
243 files already formatted
```

`ruff format --check` は初回に `tests/integration/test_users.py` の整形差分を検出したため、`uv run ruff format` で整形してから再実行した（整形後に `tests/integration/test_users.py` は `36 passed in 12.16s`）。
