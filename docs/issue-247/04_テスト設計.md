# 04_テスト設計

## テスト方針

ユーザー一覧 API を結合テストで呼び、除外の有無と件数を確かめる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 除外 | 除外グループ ID に、所属ユーザーのいるグループを指定 | 所属ユーザーが返らず、未所属のユーザーは返る。件数も除外後の数 |
| 2 | 除外 | 別のグループにだけ所属するユーザーがいる | そのユーザーは除外されない |
| 3 | 他の条件との併用 | 利用量の付与・利用クレジット順の並べ替えと併用 | 所属ユーザーが返らない |
| 4 | 存在しない ID | 存在しないグループ ID | 200、除外されない |
| 5 | 他テナント | 他テナントのグループ ID | 200、除外されない |
| 6 | 指定なし | 空文字 | 200、除外されない |
