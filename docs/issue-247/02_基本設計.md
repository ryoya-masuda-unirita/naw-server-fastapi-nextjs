# 02_基本設計

## 変更対象

- ユーザー一覧の取得処理（除外グループの条件を追加する）

## 画面 / API 変更概要

| API | パラメータ | 変更前 | 変更後 |
|---|---|---|---|
| ユーザー一覧 | 除外グループ ID | 受け取るが無視する | 指定グループの所属ユーザーを除外する |

レスポンスの形・ステータスは変わらない。存在しない・他テナントのグループ ID でもエラーにしない（移植元と同じ）。

## 影響範囲

- ユーザー一覧 API の利用者（グループのメンバー追加ダイアログ）
- 除外グループ ID を指定しない呼び出しの結果は変わらない

## 移植方針

- 移植元と同じく、一覧の条件に「指定グループにそのユーザーの所属行が存在しない」を加える
- 移植元はグループの存在・テナントを確かめないため、こちらでも確かめない
- 件数の取得・並べ替えの両方が同じ条件を使うようにする
