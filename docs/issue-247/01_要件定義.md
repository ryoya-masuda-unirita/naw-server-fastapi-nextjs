# 01_要件定義

## 背景

グループのメンバー追加ダイアログは、ユーザー一覧にそのグループの ID を除外条件として渡し、まだ所属していないユーザーだけを候補に出す。backend はこの条件を無視しているため、既に所属しているユーザーも候補に出てしまう。移植元はこの条件で、指定グループに所属するユーザーを一覧から除外している。

## 機能要件

1. ユーザー一覧に除外グループ ID が指定されたら、そのグループに所属するユーザーを一覧から除外する
2. 除外は件数（`totalElements`）にも反映する
3. 他の絞り込み（検索文字列・ロール）・並べ替え（利用クレジット順を含む）・利用量の付与と同時に指定できる
4. 未指定・空文字のときは除外しない
5. 存在しないグループ ID・他テナントのグループ ID が指定されたときは、移植元と同じくエラーにせず、除外も起きない（そのテナントのユーザーはどのユーザーもそのグループに所属していないため）

## 非機能要件

- 除外の判定は一覧取得と同じ 1 回のクエリ内で行い、ユーザーごとに追加のクエリを発行しない

## スコープ外

- ユーザー一覧の他の挙動の変更
- アシスタント・プロンプトテンプレート一覧の同名パラメータ（実装済み）
