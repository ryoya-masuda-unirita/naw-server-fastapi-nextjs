# 【高】Terraform の OIDC 設定が、旧リポジトリ名のまま・CI の apply と食い違っている

## 概要
GitHub Actions が AWS のロールを引き受ける条件（OIDC の信頼条件）が、改名前のリポジトリ名で作られる。また、CI の `terraform apply` が、infra 用ロール自身を削除する恐れがある。

## 説明
Issue #532 のとおり。`github_repository` の既定値が旧名（`naw-server-fastapi-nextjs`）で、CI は `TF_VAR_github_repository`・`TF_VAR_enable_github_actions_infra_role` を渡していない。`dev/main.tf` に `required_version` がない。
