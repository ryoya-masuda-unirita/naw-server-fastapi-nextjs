## ローカル（Terraform v1.15.8）

| 確認 | 結果 |
|---|---|
| `terraform fmt -check -recursive secuaigent-infra` | 差分なし |
| `environments/dev` で `terraform init -backend=false` → `terraform validate` | `The configuration is valid`（既存の非推奨の警告のみ） |
| `bootstrap` で `terraform init -backend=false` → `terraform validate` | `The configuration is valid` |

## 確認していないこと
- `terraform plan`・`apply`（AWS の資格情報が要る）。AWS 側のロールが旧名で作られているなら、次の apply で、信頼条件が新名に更新される
- GitHub の Variable `ENABLE_GITHUB_ACTIONS_INFRA_ROLE` の登録（ローカルで infra 用ロールを作っているなら、true にする。README に手順）
- `deploy-infra.yml` の実行（手動実行のワークフロー）
