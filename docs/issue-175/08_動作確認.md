# 08_動作確認

## 確認環境

- ブラウザ・実機での確認は行わず、自動テスト（pytest、インメモリ SQLite + fakeredis）のみで代替する
  - 他の作業と共有しているローカルの Postgres / Redis / backend サーバーを起動・変更しないため
- 実行ディレクトリ: `backend/`（`.env` は `.env.example` をコピーしたもの）

## 確認手順

1. 修正前のコード（`_ORDER_BY_COLUMNS` 変更を戻した状態）で追加テストを実行し、失敗することを確認
2. 修正後のコードで `uv run pytest tests/integration/test_files.py -v` を実行
3. 修正後のコードで `uv run pytest -q`（全件）を実行

## 未確認事項

- ブラウザ（`frontend-angular/`）からの並べ替え操作は未確認（自動テストのみで代替）
- 実 PostgreSQL での並べ替え順は未確認。`user_id` は UUID 型、`status` は SMALLINT 型の列値での並べ替えのため、SQLite と同じ順序になる想定
- 「更新者順」は移植元と同じくユーザー ID 順であり、ユーザー名の五十音・アルファベット順ではない（01_要件定義.md のスコープ外を参照）
