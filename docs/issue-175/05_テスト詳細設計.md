# 05_テスト詳細設計

## テスト対象ファイル

- `backend/tests/integration/test_files.py`（`TestFilesRouter.TestList`）

## テストケース

| No | テストメソッド | 準備 | 操作 | 検証 |
|---|---|---|---|---|
| 1, 2 | `test_sort_by_user_id` | ユーザー ID が確定した順になるよう固定 UUID のユーザーを 2 名作成し、各ユーザーのファイルを 1 件ずつ DB に直接登録（ID の大きいユーザーのファイルを更新日時が新しくなるようにし、既定の更新日時順とは異なる結果になるようにする） | `sort=userId,asc` と `sort=userId,desc` で一覧取得 | 返却された `userId` の並びがそれぞれ昇順・降順であること |
| 3, 4 | `test_sort_by_status` | 状態が `DISABLE` のファイルを更新日時が新しく、`ENABLE` のファイルを古くなるよう DB に直接登録 | `sort=status,asc` と `sort=status,desc` で一覧取得 | `status` の並びが `[0, 1]`・`[1, 0]` であること |
| 5 | 既存テスト | - | `uv run pytest` | 全件成功 |

- 既定の更新日時降順と結果が異なるデータにすることで、並べ替えキーが無視された場合にテストが失敗するようにする
