# 04_テスト設計

## テスト方針

ファイル一覧 API を結合テスト（インメモリ SQLite）で呼び出し、並べ替え結果の順序を検証する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 更新者順（昇順） | 異なるユーザーが登録したファイルが複数あり、`sort=userId,asc` を指定 | ユーザー ID の昇順で返る |
| 2 | 更新者順（降順） | 同上で `sort=userId,desc` を指定 | ユーザー ID の降順で返る |
| 3 | 学習設定順（昇順） | 有効・無効のファイルがあり、`sort=status,asc` を指定 | 有効 → 無効の順で返る |
| 4 | 学習設定順（降順） | 同上で `sort=status,desc` を指定 | 無効 → 有効の順で返る |
| 5 | 既存動作の維持 | 既存の一覧・絞り込みテスト | すべて成功する |
