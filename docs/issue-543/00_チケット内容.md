# 旧名・コメント・命名の取り残しを直す

## 概要

改名のあとに取り残された、実体と合わないコメントと、踏み台の AMI の保護を直す。影響が大きいもの（ボリューム名・コンテナ名の変更、ECR のライフサイクル、alembic のファイル名）は、見送る。

## 説明

コメントが、存在しないファイル（cloudfront.tf・backend.hcl の旧パス）や、移植元の Angular の仕組みを指している。踏み台の AMI が most_recent で、新しい AMI が出るたびに plan が再作成を出す。user-import モジュールのコメント記法が混在している。
