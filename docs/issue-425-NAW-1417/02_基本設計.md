## 画面 / API 変更概要

- 画面の見た目は変わらない。「追加学習」で、トーストが出る場合が増える
- API は、`GET /api/messages?roomId=` を、追加学習の直前に 1 回呼ぶ（メッセージの本文の取得も）。ほかは変えない

## 影響範囲

- 満足度タブの追加学習のみ。回答精度タブ・`useAddAdditionalLearning` は変えない
- 追加学習の前に、通信が増える（メッセージ一覧と本文）。やり取りが多いルームでは、時間がかかる（移植元と同じ）
- 学習データの本文が変わる（質問・回答が入る）。すでに登録された学習データは、変わらない

## 移植方針

- 移植元の判定（0 件・失敗・件数の不一致・`ERROR`）と、トーストを出す条件を、そのまま移す
- `selectVisibleThread` は、チャット画面の `buildVisibleThread` と、選び方（各段で最新の版）を揃える
- 例外は、握りつぶさず、理由つきで投げる
