# 01_要件定義

## 背景

満足度タブの追加学習は、ルームの情報だけを学習データにしていて、質問・回答の本文が入っていない。学習データとして意味がない。移植元は NAW-1417 で、本文を入れるようにした。

## 機能要件

1. 追加学習の前に、`GET /api/messages?roomId=` を取り、画面に表示中の版（根から各段で最新の版）だけを使うこと。編集・再生成で捨てた版を学習させない
2. 各やり取りの本文（質問・回答）を、学習データの本文（Markdown）に入れること。ローカルのアシスタントの本文は、ローカル用サーバーから取ること（既存の `fetchMessageContents`）
3. 次のどれかなら、送らずに、トーストを出すこと
   - やり取りが 0 件: `FEEDBACK.ADD_LEARNING_ROOM_EMPTY`
   - 本文を取れない（通信の失敗・件数の不一致を含む）、または `status=ERROR` がある: `FEEDBACK.ADD_LEARNING_CONTENT_MISSING`
4. 送らなかったとき、ダイアログは開いたままにすること（今の失敗時と同じ）
5. 回答精度タブの追加学習・ローカルのフォルダへの送信・成功後の一覧の読み直しは、変えないこと
6. `ja.json`・`en.json` に、2 つの文言を足すこと（移植元の文言のまま）
7. テストを足すこと

## 非機能要件

- 既存のテスト・`lint`・`type-check`・`build` が通ること
- 費用: なし

## スコープ外

- server の変更
- 回答精度タブの追加学習
