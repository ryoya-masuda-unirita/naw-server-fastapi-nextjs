# 01_要件定義

## 機能要件

- ヘッダー（`CHAT_HISTORY.TITLE`）
- 検索（チャット名。入力のたびに反映）・フィルター（ユーザー、期間: 全ての期間／今日／過去7日間／過去30日間／期間を指定）・並べ替え（更新日時順／更新者名順／チャット名順、昇順／降順）
- 1 ページ 20 件。件数表示（`1-20件 / 45件`）と上下のページ送り。条件を変えたら 1 ページ目へ
- 行: 更新日時（`yyyy/MM/dd HH:mm`）・更新者名・チャット名・説明、右端の `>` で詳細画面へ（`state` に roomName・userName・userId を渡す）
- 0 件のとき `CHAT_HISTORY.NO_DATA`。読み込み中はスピナー
- ユーザーの選択肢は、新しい順の履歴 20 件から重複を除いて推定する（移植元 `listUsers` の近似）

## 日時の絞り込み（#257 対応）

backend は ISO 8601（オフセット付き）だけを受け付け、終了は排他（「より前」）。画面の期間（暦日）を `toDateTimeRange`（#279）で「開始日の 0:00」「終了日の翌日 0:00」の UTC 日時にして `createdAtFrom`・`createdAtTo` に送る。
