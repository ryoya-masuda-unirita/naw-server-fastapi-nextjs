# 04_テスト設計

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ確認は行わない。

| 対象 | 観点 |
|---|---|
| 一覧の表示 | 名前・更新者・更新日時・件数、0 件、初期の取得条件（page 0・size 20・updatedAt desc） |
| 詳細への遷移 | `>` で `/admin/chat-history/:id` へ、`state` を渡す |
| 検索・絞り込み | name・orderBy（チャット名順 → name）・期間（ISO 8601、終了は翌日 0:00）・userId |
| ページ | ストアのページ位置が `page`（0 始まり）で送られる |
