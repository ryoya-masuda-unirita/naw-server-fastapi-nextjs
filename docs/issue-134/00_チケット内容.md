# チャット履歴 一覧画面をReactに移植する

## 概要

チャット履歴 一覧画面（`/admin/chat-history`）を Angular（`secuaigent/client` の `features/admin/management/chat-history/`）から React（`frontend/`）に移植する。Issue #134。

## 説明

- 対象: `chat-history.component`（画面）・`chat-history-filter`・`chat-history-list`・`chat-history.store`・`chat-history-api.service`
- スコープ外: 詳細画面 `/admin/chat-history/:roomId`（#291）。一覧から詳細への遷移（`state` 付き）だけ移植元どおり
- 土台は #277・#278・#279。#124・#125・#122・#136 の作り方に揃える
- 目標は移植元の完璧なクローン

## その他

- Issue 本文の移植先 `routes/app/admin/histories/` ではなく、#277 の仮ファイル `frontend/src/routes/admin/chat-history/chat-history.tsx`（export 名 `ChatHistoryPage` は維持）
- ルートは `/admin/chat-history`（Issue 本文の `/admin/histories` ではなく移植元の `ROUTES.APP.ADMIN_CHAT_HISTORY`）
