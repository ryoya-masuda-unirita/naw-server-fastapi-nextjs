# 移植元の結合テスト項目書627項目に沿ってReactの画面をE2Eで確かめる

## 概要

移植元の結合テスト項目書（ルートの `25DA61_結合テスト項目書_md/`、20 カテゴリ・627 項目。移植元 SecuAiGent V1.1.0 を人が手で確かめたもの）に沿って、React（`frontend/`）+ backend が移植元と同じに動くかを確かめる。完璧なクローンになっているかの確認に使う。

## 説明

### 進め方

- 各項目の「テスト方法」「確認内容」を Playwright の E2E テストにする（移植元の `e2e-test/` の fixture・Page Object の書き方を参考にする）。置き場所は着手時に決める（#275 の `e2e-explorer/` と専用環境を共有するか）
- 自動化できない項目（外部サービス・目視が必要なもの）は、理由を付けて一覧に残す
- 項目書の備考にある移植元の実際の挙動（例: ログイン失敗は 403 と「Authentication failed」）を正とする
- 結果を項目書と同じ形（カテゴリごとの OK・NG・未実施）で集計し、NG は原因ごとに Issue にする

### 依存

画面の移植（#122・#124・#125・#127・#128・#132〜#136・#284〜#291・#293）。移植の済んだカテゴリから順に進めてよい

### 関連

- #275（画面を巡回してバグの疑いを洗い出すハーネス）と合わせて、クローンの完成度を確かめる

## その他

- この PR（`feature/issue-316-foundation`、`Refs #316`）は **土台だけ**。Issue は閉じない
