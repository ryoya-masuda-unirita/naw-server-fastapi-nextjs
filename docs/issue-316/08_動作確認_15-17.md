## 実行中に見つけたテストの誤り（直したもの）

NG になったが、本当の差ではなくテストの書き方・環境の違いだったもの。

- 接続サーバー「クラウド(学習先指定)」のアシスタントを API で作るとき、接続先に埋め込み用のエンドポイントを渡していた（backend は「SAAS_RAG アシスタントはチャット用エンドポイントのみ使用できます」で 400）→ チャット用のエンドポイントだけにした
- 「カテゴリ」「所属するチーム」の複数選択は、選択肢を選んだあとに「決定」を押さないと反映されない（閉じるだけでは取り消し）→ 「決定」を押す
- 学習先フォルダを削除したあとの遷移は、移植元も `location.back()`（前の画面）。URL を直接開いたテストでは前の画面がダッシュボードになるため、一覧からフォルダを開く手順にした
- 学習データの並べ替えの文言は「学習データの表示名順」「更新者名順」（移植元も同じ。項目書の「表示名順」「更新者順」は略称）
- 学習設定・更新者の並べ替えは、1 ページ（10 件）に 2 種類の値が並ぶ条件（ファイル01〜09 に絞る）で確かめる。昇順で学習設定 OFF のファイル02 は 2 ページ目になる
- ログイン直後に別の画面へ移動すると、ダッシュボードへの遷移とぶつかって `net::ERR_ABORTED` になることがある → サイドバーが出てから移動する（`gotoAdminPage`）

## 代替・読み替え（NG にしていないもの）

- 15-06（API 未登録時）・15-40（カテゴリ0件）: 専用環境のテナントでは作れない状態なので、接続先・カテゴリ一覧の API の応答をブラウザ側で空にして確かめた
- 17-38〜47（プラン制限）: 専用のテナントを DB に直接作る（`src/db-quota.ts`）。プランの月間クレジット上限 1000・テナントの従量課金上限 500・今月の利用クレジットを決め、ファイルを画面から追加して、追加できるか・拒否されるかを確かめた
- 17-06〜09 以外のローカル向けの項目（5・26）は、seed のローカルフォルダ（0 件）で確かめた。データのある項目（検索・フィルター・並べ替え・ページ送りなど）は seed のクラウドフォルダで確かめた（seed のコメントは「ローカルに 11 件」だが、実際のデータはクラウドのフォルダにある）
