## [17-15] 詳細期間（指定期間）

- 項目書の期待: 期間「期間を指定」でカスタム範囲を設定すると、指定期間のデータだけが表示される
- 移植元の挙動: `training-data-filters.component` が共有部品 `<app-period-filter>` を使い、「期間を指定」→ 開始日・終了日をカレンダーから選び → 「決定」で絞り込める
- React の挙動: 「期間を指定」→ 開始日の入力欄 → カレンダーの日を押すと、**期間フィルターのパネルごと閉じる**。終了日も「決定」も押せない（テストの失敗: 開始日を選んだあと `training-data-file-period-from-input` が見つからない）
- 原因・修正の方針: [ng-チャット履歴.md](./ng-チャット履歴.md) の 16-23 と同じ（`period-filter.tsx` の `document` の `click` リスナーが、DOM から外れた `event.target` を「部品の外」と判断する）
- 確かめた手順: seed のファイル10（40 日前に更新）の日を含む期間を、カレンダーから開始日・終了日として選び、そのデータだけが出ることを期待している
