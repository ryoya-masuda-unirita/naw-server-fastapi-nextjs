# 08_動作確認

## 確認環境

- バックエンド: `uv run uvicorn app.main:app --reload --port 8001`（ローカルPostgreSQL、`alembic upgrade head` 済み、`seed.sql` 投入済み）
- フロントエンド: `frontend-angular`（`npm start`、`http://test-tenant.localhost:4201`）
- ログインユーザー: `admin` / `admin@1234`（全体管理者）、`user01` / `user01@1234`（動作確認用グループ所属の一般ユーザー）

## 確認手順・結果

### 1. 管理者向けテンプレート一覧（ブラウザ）

`admin` でログインし `/admin/templates` を表示。

✅ シードデータの2件（「丁寧な回答テンプレート」＝動作確認用グループ紐付けあり、「未紐付けテンプレート」＝グループ紐付けなし）が一覧に表示されることを確認。

### 2. テンプレートの新規作成（ブラウザ）

「テンプレートを新規作成」から名前・システムプロンプトを入力し作成。

✅ 作成したテンプレート（「ブラウザ動作確認テンプレート」）が一覧に即時反映されることを確認。

### 3. テンプレートの削除（ブラウザ）

作成したテンプレートの歯車アイコン→「テンプレートを削除」→確認ダイアログで削除を実行。

✅ 削除後、一覧からテンプレートが消え、シードデータの2件のみに戻ることを確認。

### 4. API直叩きでの一覧・作成・更新・削除・一般ユーザー一覧の確認

`curl` で以下を確認。

- `GET /api/admin/prompt-templates`（admin）: シードデータ2件が `content`/`totalElements`/`number`/`size` 形式で返る
- `POST /api/admin/prompt-templates`（グループ紐付け指定あり）→ 200、`groups` にグループIDが返る
- `PATCH /api/admin/prompt-templates/{id}`（グループ未指定）→ 200、既存の紐付けを維持したまま名前等が更新される
- `DELETE /api/admin/prompt-templates/{id}` → 204
- `GET /api/prompt-templates`（user01、動作確認用グループ所属）→ 所属グループに紐づく「丁寧な回答テンプレート」のみが返る

✅ いずれも設計通りの結果であることを確認。

### 5. チャット画面のテンプレート選択機能との疎通確認（不具合発見・修正）

`/chat` 画面を開いたところ、ブラウザコンソールに `GET /api/prompt-templates?size=0` の422エラーが発生していることを発見。

原因: チャット画面のテンプレート選択（`PromptTemplatesService`）が `size=0` で一般ユーザー向け一覧APIを呼び出す実装になっており、移植元（Spring Data `Pageable`）は `size` が1未満の場合デフォルトページサイズにフォールバックする仕様だが、今回の実装は `size` に `ge=1` の制約を設けていたため422になっていた。

対応: `size` の制約を `ge=0` に緩め、`0`が指定された場合はデフォルトページサイズ（20）にフォールバックするよう `backend/app/routers/prompt_templates.py` を修正（一般ユーザー向け・管理者向け両エンドポイント）。結合テストにも `test_size_zero_falls_back_to_default_page_size` を追加。

✅ 修正後、`/chat` 画面をリロードして再確認し、`GET /api/prompt-templates?size=0` が200 OKになることをネットワークログで確認。
