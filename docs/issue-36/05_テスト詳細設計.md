## テスト対象ファイル

### `backend/tests/integration/test_prompt_templates.py`（新規）

`test_groups.py`・`test_assistants.py` と同じ方針（`ASGITransport` + 実DB）で以下を検証する。

- `TestGetPromptTemplates`（`GET /api/prompt-templates`）
  - `test_returns_templates_for_belonging_groups`: 所属グループに紐づくテンプレートのみ返ること（04テスト設計 No.1）
  - `test_returns_empty_page_when_no_group`: 所属グループがない場合は空ページになること（No.2）
  - `test_deduplicates_when_multiple_groups_share_template`: 複数グループ経由で重複しても1件になること（No.3）
  - `test_filters_by_search_text`: 検索文字列で絞り込まれること（No.4）
  - `test_excludes_other_tenant_templates`: 他テナントのテンプレートが含まれないこと（No.5）

- `TestGetAdminPromptTemplates`（`GET /api/admin/prompt-templates`）
  - `test_tenant_admin_gets_all_templates`（No.6）
  - `test_group_admin_gets_only_managed_group_templates`（No.7）
  - `test_non_admin_user_gets_empty_page`（No.8）
  - `test_filters_by_team`（No.9）
  - `test_filters_by_exclude_group_id`（No.10）
  - `test_filters_templates_with_no_group`（No.11）

- `TestCreatePromptTemplate`（`POST /api/admin/prompt-templates`）
  - `test_create_with_groups`（No.12）
  - `test_create_ignores_nonexistent_group_id`（No.13）
  - `test_create_without_groups`（No.14）

- `TestUpdatePromptTemplate`（`PATCH /api/admin/prompt-templates/{templateId}`）
  - `test_update_without_groups_keeps_existing_groups`（No.15）
  - `test_update_replaces_groups`（No.16）
  - `test_update_nonexistent_template_returns_404`（No.17）

- `TestDeletePromptTemplate`（`DELETE /api/admin/prompt-templates/{id}`）
  - `test_delete_removes_template_and_associations`（No.18）
  - `test_delete_other_tenant_template_is_noop`（No.19）
