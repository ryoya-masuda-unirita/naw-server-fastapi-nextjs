# プロンプトテンプレート管理APIの実装

## 概要

NAW-929ほか（複数チケットにまたがる機能）の一部移植。プロンプトテンプレート（PromptTemplate）管理APIをFastAPIで実装する。

## 説明

### 背景

issue-24（チーム管理API）実装時、GroupエンティティはAssistant・PromptTemplateとM2M関連を持つが、両ドメインが未実装だったためGroup単体のCRUD・ユーザー所属管理のみをスコープとし、PromptTemplateとの紐付けは別チケットとした。

Assistant関連は issue-26（一覧取得）・issue-28（テナントエンドポイント）・issue-30（紐付け）で完了済み。今回はもう一方のGroup関連ドメインであるPromptTemplateを移植する。

移植元のPromptTemplateドメインを調査した結果、以下の構成であることが判明した。

- `prompt_templates`（本体：`id`, `tenant_id`, `name`, `description`, `system_prompt`, `updated_at`。RLS有効）
- `groups_prompt_templates`（Group⇔PromptTemplate紐付け中間テーブル。Groupは実装済みのため中間テーブルのみ新規）
- `PromptTemplateController`が持つのは一般ユーザー向け一覧取得と、管理者向けCRUD（作成・更新・削除・検索付き一覧）の5エンドポイントで、作成・更新時に`groups`（グループIDの集合）を直接受け取り紐付けを更新する

一方、`GroupController`側にも`/api/admin/groups/{groupId}/prompt-templates`（グループ視点でのテンプレート追加・削除・一覧取得）が存在するが、これはGroup側からの操作エンドポイントであり、issue-30（`assistants_endpoints`紐付け）と同様の「別チケットで対応する紐付け機能」に位置づけ、本チケットのスコープ外とする。

### やること（今回のスコープ）

移植元 `~/Documents/naw-server` の `PromptTemplateController` のうち、以下のエンドポイントをFastAPIに移植する。

- `prompt_templates`テーブル・モデルを新規作成する（`id`, `tenant_id`, `name`, `description`, `system_prompt`, `updated_at`）
- `groups_prompt_templates`中間テーブル・モデルを新規作成する（`GroupAssistant`等と同様のパターン。複合PK・テナントID同期）
- `GET /api/prompt-templates`（一般ユーザー向け：ログインユーザーが所属するGroupに紐づくテンプレート一覧、検索・ページネーション）
- `GET /api/admin/prompt-templates`（管理者向け一覧：検索・チームフィルタ・除外グループフィルタ・ページネーション。全体管理者かグループ管理者かで参照範囲が変わる）
- `POST /api/admin/prompt-templates`（作成。`groups`でグループ紐付けを同時指定）
- `PATCH /api/admin/prompt-templates/{templateId}`（更新）
- `DELETE /api/admin/prompt-templates/{id}`（削除）

### スコープ外（後続チケット）

- `GET/POST/DELETE /api/admin/groups/{groupId}/prompt-templates`（Group側からのテンプレート紐付け操作。issue-30の`assistants_endpoints`と同様の位置づけで別チケットとする）
- プロンプトテンプレートを利用したチャット時のライブラリ生成機能（NAW-1041、Room/Message API未実装のためスコープ外）
