# 04_テスト設計

## テスト方針

Vitest + React Testing Library + MSW。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 学習設定の列 | 一覧表示 | ON/OFF の表示がない |
| 2 | 行メニュー | メニューを開く | 切り替え項目がなく、編集項目はある |
| 3 | 絞り込み | 一覧表示 | 学習設定の選択がなく、取得クエリに status がない |
| 4 | 編集保存 | 表示名を変えて保存 | status を送らず、スイッチがない |
| 5 | 接頭辞 | 編集したリンクに適用 | 編集したリンクの先頭に付く |
| 6 | 接頭辞 | 押し直し・文字を変えて再適用 | 重ならない。最新の文字が使われる |
| 7 | ファイル取り消し | 選んで × | チップが消え、欄が戻り、保存でファイルが送られない |
| 8 | ファイル選び直し | 取り消したあと同じファイルを選ぶ | 再び選べる |
| 9 | フォルダ作成 | 作成成功 | 学習先フォルダのキャッシュが無効化される |
| 10 | フォルダ更新 | 更新成功 | 同上 |
| 11 | フォルダ削除 | 応答前 | 前の画面へ戻らない。応答後に戻り、無効化される |
| 12 | フォルダ削除失敗 | 500 | 戻らない |
