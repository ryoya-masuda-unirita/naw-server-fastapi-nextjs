# 03_詳細設計

## 学習設定の削除（NAW-1405）

- `frontend/src/components/features/admin/training-data/training-data-table.tsx`: 学習設定の列・行メニューの切り替え・`onToggleLearning` を削除（「学習データの設定を編集」メニューは残す）
- `training-data-filters.tsx`: 学習設定の Select と props を削除
- `training-data-files-view.tsx`: 並べ替えの `status`、`statusOptions`、`toggleLearning`、保存・追加の status を削除
- `training-data-files-helper.ts`: `mapUiStatusToApi`・`status`・`initialLearningEnabled` を削除
- `training-data-validation.ts`: `EditFileValues.status` を削除
- `frontend/src/hooks/use-training-data-detail.ts`: `useToggleTrainingFileLearning` と `FileDto.status` を削除
- `frontend/src/types/training-data.types.ts`・`frontend/src/store/training-data-store.ts`: `selectedStatus`・並べ替えの `status`・`TrainingFileUploadEntry.status` を削除
- `frontend/public/i18n/{ja,en}.json`: 移植元で削除されたキー（ALL_SETTINGS・COLUMN_LEARNING・COLUMN_LEARNING_STATUS・SORT_LEARNING_STATUS・SET_LEARNING_ON/OFF・STATUS_ON/OFF・EDIT_DATA_LEARNING_SETTING_LABEL）を `LEARNING_DATA` から削除

## リンク接頭辞（NAW-1420）

- 新規 `training-data-link-prefix.ts` の `applyLinkPrefix(rows, prefix)`。リンクが接頭辞で始まらない行だけ `prefix + reference` にする
- `training-data-files-view.tsx` の `handleApplyLinkPrefix` から呼ぶ

## ファイルの取り消し（NAW-1409・NAW-1412）

- `training-data-edit-modal.tsx`: props に `uploadFile`・`previewLoadFailed`・`fileLocked`・`onRemoveUploadFile` を追加。選んだファイルがあり、画像でプレビューが出ていないときは `FileChip`（取り消し可）を出す。プレビュー表示中の × は選んだファイルがあるときだけ出す。`fileLocked` の間は入力を無効にし、取り消しを出さない。選択欄の値を空にして同じファイルを選び直せるようにする
- `training-data-files-view.tsx`: 選ぶ前の入力を ref に保持し、取り消しで `editingFile`・プレビュー・入力欄を戻す。画像の読み込み完了時に、そのファイルがまだ選ばれているか ref で確かめる

## フォルダ操作後の取り直し（NAW-1414・NAW-1397）

- `frontend/src/hooks/use-training-data.ts`: `LEARNING_FOLDERS_QUERY_KEY`・`invalidateLearningFolders` を追加。作成の成功時に呼ぶ
- `use-training-data-detail.ts`: 更新・削除の成功時に呼ぶ
- `frontend/src/hooks/use-feedback.ts`: `useLearningFolders` のキーを定数に変更
- `frontend/src/routes/admin/training-data/training-data-detail.tsx`: 削除は `mutateAsync` の完了を待ってから `navigate(-1)`。失敗時は戻らない
