# #375 issue-375 学習データ・フィードバック周りの小さな差分を移植元に揃える（NAW-1405・1420・1409・1412・1414・1397）

## 概要

学習データ・フィードバック周りで、移植元の最近の修正に揃っていない小さな差分をまとめて直す。

## 説明

1. 学習設定（ON/OFF）の列・メニュー・絞り込み・並べ替え・編集ダイアログのスイッチ・API 送信を画面から削除する（NAW-1405）
2. 追加ダイアログの「先頭に一括追加」で、編集済みのリンクに接頭辞を付け、すでにその接頭辞で始まるリンクには付けない。入力した文字をそのたびに使う（NAW-1420）
3. 編集ダイアログで選んだファイルを × で取り消したら、保存で送らない。保存中はファイルを変えられない。プレビューを読み込めなかった画像も取り消せる（NAW-1409, NAW-1412）
4. 学習先フォルダの作成・削除・更新後に、フィードバック一覧の学習先フォルダ（`['feedback','learning-folders']`）を取り直す。フォルダ削除は完了を待ってから一覧へ戻る（NAW-1414, NAW-1397）
