# 02_基本設計

## 変更対象

- 学習データ詳細画面（ファイル一覧・フィルタ・追加ダイアログ・編集ダイアログ）
- 学習先フォルダの作成・更新・削除の後処理
- フィードバック一覧の学習先フォルダ一覧のキャッシュ

## 画面 / API 変更概要

- 一覧: 学習設定の列、メニュー項目、絞り込み、並べ替え項目を削除
- 編集ダイアログ: 学習設定スイッチ削除。選んだファイルのチップ表示・取り消し・保存中のロック・プレビュー失敗メッセージを追加
- 追加ダイアログ: ［全体に適用］の挙動修正
- API: ファイル一覧・更新・追加で status を送らない（backend の API は変更しない）

## 影響範囲

- 学習データ詳細画面のみ。フィードバック一覧は、学習先フォルダのキャッシュが無効化されたとき取り直される

## 移植方針

- Angular の computed の不具合（接頭辞が最初の値のまま）は、React では適用のたびに state の最新値を使うことで解消する
- 接頭辞付与は純関数として切り出し、単体テストで確かめる（移植元 `applyLinkPrefix` に対応）
- NgRx store の `invalidateLearningFolders` は、TanStack Query の `invalidateQueries` を呼ぶ関数にする。キーは `LEARNING_FOLDERS_QUERY_KEY` として学習データ側の hook に置き、両画面から参照する
- Angular の `FileChipComponent` は React の `FileChip` に対応させる
