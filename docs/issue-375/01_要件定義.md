# 01_要件定義

## 背景

移植元の学習データ画面は、学習設定（ON/OFF）が実際には回答に効かないため画面から削除され、あわせて追加・編集ダイアログとフォルダ操作の不具合が直された。React 版はこれらに追従していない。

## 機能要件

1. 学習データ一覧に学習設定の列、行メニューの ON/OFF 切り替え、絞り込み、並べ替え項目を出さない。編集ダイアログに学習設定のスイッチを出さない。一覧の取得・保存・追加で status を送らない
2. 追加ダイアログの［全体に適用］は、各行の参照資料のリンクの先頭に入力した文字を付ける。すでにその文字で始まるリンクには付けない。押すたびに入力欄の最新の文字を使う
3. 編集ダイアログで選んだファイルは × で取り消せる。取り消すとプレビューと選んだファイルの両方を捨て、書き換えた欄を戻す。取り消したファイルは保存で送らない。画像のプレビューを読み込み中・読み込み失敗の間も取り消せる。保存中は選んだファイルを変えられない
4. 学習先フォルダを作成・削除・更新したら、フィードバック一覧の学習先フォルダの一覧を取り直す。フォルダ削除は完了を待ってから前の画面へ戻り、失敗したら詳細にとどまる

## 非機能要件

- 既存の `training-data-*` の data-testid を壊さない
- 画面のデザインは移植元に合わせる

## スコープ外

- NAW-1424（更新者の絞り込み削除・`loginIds` 化）。backend の `loginIds` 対応（#372）が先に必要
- backend の status API の変更
