## 置き換えの規則

- 双方向バインド: `value` + `onValueChange`、`checked` + `onCheckedChange`。output は `on` + PascalCase
- ホスト要素: 部品のルート要素に移植元の host クラス + `app-<部品名>`、利用側のクラスは `className`
- `TemplateRef` の input は ReactNode か描画関数（Table の `renderActions(row)`、ContextMenu の `menu({ close })` など）
- `ViewChild` で呼んでいた操作は `ref`（ContextMenu の `open/close/toggle`）
- `document:click` の HostListener は `useEffect` で document に listener を付ける
- 開閉アニメーション（isVisible → requestAnimationFrame → isOpen、閉じるときは遅延して外す）は移植元の 2 段のまま

## Dialog の設計

- `MatDialog.open(DialogComponent, { data, width, panelClass })` を、`open` で開閉する `<Dialog>` にする。`data` の項目は props、`width`/`panelClass` は `dialogWidth`/`panelClass`
- `afterClosed()` の結果は `onClose(result)`（確認=true、キャンセル=false、×・Esc・背景=undefined）
- DOM は Material と同じ `cdk-overlay-container > cdk-overlay-backdrop + cdk-global-overlay-wrapper > cdk-overlay-pane.mat-mdc-dialog-panel > mat-mdc-dialog-container > mat-mdc-dialog-inner-container > mat-mdc-dialog-surface.mdc-dialog__surface > .app-dialog.modal-dialog`。`styles.css` の `.mat-mdc-dialog-container .mdc-dialog__surface`（角丸・余白・最大幅）や `.dialog-xl` などがそのまま効く
- MatDialog の既定（autoFocus: first-tabbable、restoreFocus、block スクロール、Esc・背景クリックで閉じる、disableClose）を再現する

## 移植元と変えた点（判断と理由）

| 部品 | 変えた点 | 理由 |
|---|---|---|
| index.css | フォントの `@import` を `main.tsx` の import に移した | Tailwind の `@import` 展開を通すと、フォント CSS 内の相対 `url()` がビルド時に解決できずフォントが読み込まれない（develop の時点で noto-sans-jp・roboto が 992 件の警告とともに未解決だった。移植した material-symbols も同じ状態になり、アイコンが文字のまま出る） |
| index.css | material-symbols は outlined だけ読み込む | mat-icon の fontSet は `material-symbols-outlined` のみ。rounded/sharp（約 8MB）は使われない |
| Checkbox・Switch | ルート要素に `role="checkbox"`/`role="switch"` と `aria-checked` を付けた | テストで操作対象を特定するため。見た目は変わらない |
| Dialog | Angular Material の Dialog を DOM とクラス名で再現 | React に Material がないため。styles.css の上書きが効くよう同じクラスにした |
| ContextMenu | `menu` に関数も渡せる（`close` を受け取る）、`ref` で開閉できる | 移植元はテンプレート変数経由で `contextMenu.close()` を呼んでいる（モバイルのドロワーは中身のクリックで閉じない） |
| Table | `TemplateRef` の列テンプレートは `render(row)` | React に TemplateRef がないため |
| Pagination | 静的クラスと状態のクラスを合成 | Angular（Ivy）は静的 `class` と `[class]` を合成するため、同じ結果にした |
| useIsMobile | UiStore を変えずにフックで同じ判定（幅 768px 未満） | ui-store は #277 の担当領域のため |
| 型 | SelectOption などは `components/shared/types.ts` に置いた | `src/types/` は #279 の担当領域のため。#279 で `types/common.ts` を作る場合は統合する |
| ConfirmService | 状態だけを移植（UI なし） | 移植元でも UI がなく、どこからも使われていない |
| FileImageChip | プレビュー URL を file ごとに 1 回作り、外すときに revoke | 移植元は描画のたびに作って解放しない（メモリリーク）。見た目は同じ |
| DropdownSelect・DateRangeSelect | 背景に `cdk-overlay-backdrop-showing` を付けた | 実際の CDK と同じクラス構成にしないと、CDK の基本スタイル（opacity: 0）で背景が見えなくなる |
| FormInput | input に id を付け、ラベルと結び付けた | 既存の auth テストがラベルで入力欄を探すため。見た目は変わらない |

その他、フォークごとの細かな判断は README の各節と PR 本文に記載した。

## 移植元どおりに残したもの（不具合に見えるが変えていない）

- ComboboxMulti のエラーアイコン名 `attention` は SVG 辞書にない（空のアイコン）
- SelectWithSearch は入力欄でスペースを押すと開閉が切り替わる（ホストの keydown で Enter・Space を処理しているため）
- PeriodFilter のフッターの `bg-bg-surface-soft` は存在しないトークン
- `COMMON.CLEAR`・DateRangeSelect の `COMMON.SPECIFY_PERIOD` ほか 5 キーは移植元の翻訳ファイルにもない（キーのまま表示される）
