# 02_基本設計

## 変更対象

- 共通部品（新規 約 45 部品、既存のボタン・入力欄を移植元の仕様に作り直し）
- グローバル CSS（移植元の CSS に置き換え）
- アプリのルート（トーストの表示先とドロップダウンの暗幕を置く。移植元の app と同じ）
- ログイン・パスワード変更画面（パスワード欄に移植元どおり表示切替ボタンを付ける）
- 依存パッケージ（移植元と同じ版のアイコンフォント `material-symbols`）
- 部品の使い方の README

## 画面 / API 変更概要

- API の変更なし
- 画面の見た目: グローバル CSS を移植元に揃えたことで、ログイン・パスワード変更画面も移植元の CSS で表示される。パスワード欄に表示切替ボタンが付く

## 影響範囲

- 既存のボタン・入力欄の呼び出し（ログイン・パスワード変更）は互換を保つ
- グローバル CSS の置き換えにより、既存の画面にも移植元のクラス定義が効く（移植元に揃う方向の変化）

## 移植方針

- Angular の部品を 1 部品ずつ React の関数コンポーネントにする。テンプレートの Tailwind クラスと DOM 構造は 1:1 で移す
- 値の双方向バインド（model / ControlValueAccessor）は「値 + 値変更通知」の制御コンポーネントに、出力イベントは on〜 の props に置き換える
- 部品ごとの SCSS（:host 付き）は部品ごとの CSS ファイルに移し、部品のルート要素のクラスでスコープする
- Angular Material / CDK に頼っている部品（ダイアログ・操作メニュー・各種オーバーレイ）は、Material と同じクラス名の DOM を組み、Material の基本スタイルも移すことで、移植元 CSS の上書きがそのまま効くようにする
- サービス（トースト・確認・ドロップダウン）はシングルトン（Zustand store / モジュール内の 1 インスタンス）にする
- 画面幅によるモバイル判定（移植元 UiStore.isMobile）は、レイアウト側の store を変えずに部品側の共通フックで同じ判定をする
- 移植元のバグや未使用の入力も、見た目・挙動に関わるものは移植元どおり残す（変える場合は 03 に理由を書く）
