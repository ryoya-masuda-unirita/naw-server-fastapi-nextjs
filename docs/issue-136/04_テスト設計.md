# 04_テスト設計

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ確認は行わない。

| 対象 | 観点 |
|---|---|
| 一覧の表示 | タイトル・タグ・更新日時・件数、初期の取得条件（page 0・size 5・updatedAt desc）、他人のライブラリには編集・削除が出ない |
| タブ | 管理者はタグ管理へ切替（`?tab=tags`）、一般ユーザーはタブなし・`tags` 指定でも contents へ戻る |
| 検索・絞り込み | title・createdBy（ログインID）・excludeCreatedBy・tagIds が API に付く |
| ページ送り | 範囲外のページになったら最終ページへ戻る |
| 編集 | 既存値が入る、保存で PUT（name・tags・groups）、失敗でトーストしてダイアログは閉じない |
| 削除 | 確認で DELETE、失敗でトースト |
| タグ管理 | 表示（説明 null は `-`）、取得条件（size 25・sort）、作成（空だと押せない・空白のみ不可）、編集（PATCH）、複数選択削除（`{ ids }`） |
| ローカル本文の削除 | 削除先の決定（SECURE・接続先・APIキー）、認証ヘッダー、失敗しても投げない |
