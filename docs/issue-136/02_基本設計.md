## 方針
- 共通 UI は #278 のものを使う（`Table`・`TableList`・`Pagination`・`SearchInput`・`Select`・`FormSortInput`・`MultiSelect`・`FormInput`・`FormTextarea`・`Dialog`・`ContextMenu`・`PageHeader`・`Skeleton`・`Button`）。新規の共通部品は作らない
- 画面は `AdminPageShell` を使わず、`PageHeader` と本文を並べる（移植元 `library-list.component.html` が `app-admin-page-shell` を使っていないため）
- 触った共通ファイルは `mocks/handlers/index.ts`（ハンドラー登録）のみ
