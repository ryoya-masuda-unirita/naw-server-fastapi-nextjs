# ライブラリ管理 一覧画面をReactに移植する

## 概要

ライブラリ管理 一覧画面（`/library`、コンテンツ一覧タブ + タグ管理タブ）を Angular（`secuaigent/client` の `features/admin/library/library-list/`）から React（`frontend/`）に移植する。Issue #136。

## 説明

- 対象: `library-list.component`（画面シェル・タブ）・`content-tab`（一覧・検索・絞り込み・並べ替え・編集設定ダイアログ・削除）・`tags-tab`（タグ一覧・作成・編集・削除・複数選択）・`library.store`・`tags.store`・`library-api.service`・`tags-api.service`
- スコープ外: ライブラリ詳細 `/library/:id`（#288）
- 土台は #277（ルート・ガード・サイドバー・i18n）・#278（共通 UI）・#279（API の型・パス・api-client・MSW）。#124（テンプレート管理）の作り方に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）

## その他

- 移植先は Issue 本文の `routes/app/library/` ではなく、#277 の仮ファイル `frontend/src/routes/library/library-list.tsx`（export 名 `AdminLibraryPage` は維持）
- Issue 本文の移植元パス `secuaigent-client/.../admin/library/library-list/` は現在の `secuaigent-ref/client/src/app/features/admin/library/library-list/`
