# 03_詳細設計

## 1. `backend/app/schemas/response_format.py`（新規）

```python
class ResponseFormatRequest(BaseModel):
    """response_format(構造化出力)指定。

    移植元(Spring Boot)の`ResponseFormatRequest`に対応するが、`json_schema`の中身は
    移植元同様に現時点では未使用（typeのみ有効）。
    """

    type: str = Field(min_length=1)

    @field_validator("type")
    @classmethod
    def _validate_type(cls, value: str) -> str:
        """typeがjson_object/json_schemaのいずれかであることを検証する。"""
        if value not in ("json_object", "json_schema"):
            raise ValueError("response_format.type は json_object または json_schema です")
        return value
```

- `schemas/llm.py`・`schemas/message.py`はいずれも`schemas/`配下からのインポートであり、「serviceが別serviceを呼ばない」規約には抵触しない（スキーマ間の共有は許容する）

    endpoint: str,

    deploy_name: str,

## 5. `backend/app/services/llm_chat_service.py`

- モジュールdocstringから「response_format」を対象外リストから削除
- `ResponseFormatRequest`を`app.schemas.llm`からインポート（`LlmChatRequest`経由で既に依存しているスキーマモジュールのため追加の依存にはならない）
- 以下のヘルパー関数を追加（`message_service.py`にも同一ロジックを複製する。既存の`_apply_additional_prompt`と同じ複製方針）：

```python
_JSON_RESPONSE_INSTRUCTION = "回答は JSON 形式で出力してください。"


def _build_llm_response_format(
    response_format: ResponseFormatRequest | None,
) -> dict | None:
    """responseFormat指定をAzure OpenAI呼び出し用のresponse_format辞書へ変換する。

    移植元同様、type(json_object/json_schema)の値によらず常にJSONモード
    (response_format={"type": "json_object"})として扱う（json_schemaの中身は
    移植元でも未実装のため踏襲しない。`01_要件定義.md`参照）。
    """
    if response_format is None:
        return None
    return {"type": "json_object"}


def _prepend_json_response_instruction(
    messages: list[ChatMessage], response_format: ResponseFormatRequest | None
) -> list[ChatMessage]:
    """responseFormat指定時、JSON出力を促すsystemメッセージを先頭に追加する。

    OpenAIのJSONモードは、メッセージ内に"json"という語を含めることが要件のため、
    移植元Java版`OpenAiLlmChatAdapter`同様の固定指示文を前置する。
    """
    if response_format is None:
        return messages
    return [ChatMessage(role="system", content=_JSON_RESPONSE_INSTRUCTION), *messages]
```

- `stream_chat`内、`chat_messages`組み立て直後に`_prepend_json_response_instruction(chat_messages, req.responseFormat)`を適用し、`response_format_param = _build_llm_response_format(req.responseFormat)`を計算、`AzureLlmChatClient.stream_chat`呼び出しに`response_format=response_format_param`を追加する
