# 01_要件定義

## 背景

新規チャットのダイアログには、「アシスタント表示名・カテゴリで検索できます」という案内文がある。ところが、入力した文字で絞り込まれるのはアシスタント名だけで、カテゴリ名を入力すると選択肢が 0 件になる。案内文と挙動が食い違っていて、結合テスト項目 07-16（タグで絞り込み）も通らない。

移植元の同じ部品も、名前だけで絞り込む作りで、食い違いは移植元にもある。

## 機能要件

1. 新規チャットのアシスタント選択で、入力した文字が、アシスタント名またはカテゴリ名に含まれる選択肢を表示する
2. 大文字・小文字は区別しない（今のアシスタント名の絞り込みと同じ）
3. カテゴリがない選択肢は、アシスタント名だけで判定する（エラーにしない）
4. 入力が空のときは、すべての選択肢を表示する（今のとおり）
5. パソコン幅とモバイル幅（ドロワー）の両方で、同じ絞り込みになる

## 非機能要件

- 既存の挙動を壊さない。アシスタント名での絞り込み、選択、クリア、キーボード操作は、今のとおり動く
- カテゴリを持たない画面（フィードバック・チャット履歴・学習データなど、同じ選択部品を使う他の画面）の絞り込みは変わらない
- 案内文の文言は変えない

## スコープ外

- 説明文（description）での絞り込み
- カテゴリの表示（バッジ）の見た目の変更
- 移植元（`secuaigent/client`）への修正。差が出ることは承知のうえで進める（移植元への修正提案は、別途共有する）
- 他の画面の絞り込み方法の見直し
