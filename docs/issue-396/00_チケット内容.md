# 新規チャットのアシスタント選択で、案内文どおりカテゴリでも絞り込めるようにする

## 概要

新規チャットのアシスタント選択は、画面の案内文では「アシスタント表示名・カテゴリで検索できます」とあるが、実際はアシスタント名でしか絞り込めない。カテゴリ名を入力すると選択肢が 0 件になる（結合テスト項目 07-16）。

## 説明

- 原因は、選択部品の絞り込みがラベル（アシスタント名）だけを見ていること
- 移植元の同じ部品も同じ作りで、移植漏れではなく、移植元にもある食い違い
- 案 A（絞り込みにカテゴリを加える。移植元とは差が出る）で進める。案 B（現状のまま、項目書と案内文を直す）は採らない
- 参照: #316、`docs/issue-316/10_Issue下書き.md`、e2e-spec の `[07-16]`
