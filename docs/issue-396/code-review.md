## 詳細

### 1. テスト名が日本語（🔵 提案）→ 対応しない

CLAUDE.md の「テスト名は英語、意図は日本語 docstring」は、pytest（`async def test_...`）の規則。client のテストは、同じファイルの既存テストも含めて、すべて日本語の名前で書かれている。新しいテストも、既存に合わせた。

03 の設計書に「英語名」と書いていたのは誤りだったので、日本語名に直し、理由を書いた。

### 2. 全体実行と e2e（🔵 提案）→ 一部対応

- 全体実行の 7 件の失敗は、どれも今回の変更と無関係な route のテストで、単独で実行すると成功する（83 件）。負荷が高い環境の不安定さ（#397）で、PR の CI（負荷のない環境）で、フロントエンドのテストが全体で通るかを確認する
- e2e の `[07-16]` は、通しの環境を起動していないので未確認のまま。`08_動作確認.md` に書いてある。画面のテスト（`chat-dialogs.test.tsx`）で、ダイアログにカテゴリ名を入力すると絞り込まれることは確認している。ダイアログが渡すデータと `SelectOption.category` の対応は、同じテストで、実際の API の形（`category` が文字列）のレスポンスを使って確認している

### 3. 型の説明（🔵 提案）→ 対応済み

`SelectOption.category` のコメントに、「画面にバッジで表示し、SelectWithSearch では入力による絞り込みの対象にもなる」と書いた。
