# 03_詳細設計

## 1. 絞り込みの変更

対象: `client/src/components/shared/select-with-search.tsx`

今の絞り込み（`filteredOptions`）は、ラベルだけを見ている。

```ts
const filteredOptions = query ? options.filter((opt) => opt.label.toLowerCase().includes(query)) : options;
```

これを、ラベルまたはカテゴリに含まれるかで判定する関数に変える。

```ts
/** 選択肢が検索語に一致するか。アシスタント名（label）またはカテゴリ（category）に含まれていればよい */
function matchesQuery<T>(option: SelectOption<T>, query: string): boolean {
  return (
    option.label.toLowerCase().includes(query) || (option.category?.toLowerCase().includes(query) ?? false)
  );
}

const filteredOptions = query ? options.filter((opt) => matchesQuery(opt, query)) : options;
```

- `query` は、今と同じ `searchQuery.toLowerCase()`（小文字化済み）
- `category` がない選択肢は、ラベルだけで判定する
- `description` は対象にしない（スコープ外）
- デスクトップとモバイル（ドロワー）は、同じ `filteredOptions` を使っているので、両方に効く
- 絞り込みの箇所に、移植元との差（移植元はラベルだけ）と理由（案内文どおりに動かすため。Issue #396）をコメントで書く

## 2. 単体テスト

対象: `client/src/components/shared/select-with-search.test.tsx`

既存のテストデータ（`FIXTURE_OPTIONS`）には、カテゴリを持つ選択肢（Grape: 果物）がある。次のテストを足す。

| テスト名（日本語） | 確認すること |
|---|---|
| カテゴリ名を入力すると、そのカテゴリの選択肢に絞り込めること | カテゴリ名の一部で絞り込まれる |
| カテゴリの大文字・小文字を区別せずに絞り込めること | 大文字・小文字を区別しない |
| カテゴリがない選択肢はラベルで絞り込めること | カテゴリがない選択肢は、ラベルだけで判定される |
| モバイル幅のドロワーでもカテゴリ名で絞り込めること | モバイル幅のドロワーでも、カテゴリで絞り込まれる |

テスト名は、同じファイルの既存テストに合わせて日本語にする（client のテストの慣例。英語名とdocstringの規則は pytest 用）。

- カテゴリが英字の選択肢は、既存のデータにないので、大文字・小文字のテスト用に、テスト内で専用の選択肢を渡す
- `SelectOption.category` の型のコメントに、「絞り込みの対象にもなる」ことを書く（表示だけのつもりで足した人が気づけるように）
