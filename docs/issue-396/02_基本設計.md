# 02_基本設計

## 変更対象

- 共有の選択部品（検索つき単一選択）の、入力による絞り込み
- その単体テスト

## 画面 / API 変更概要

| 項目 | 今 | 変更後 |
|---|---|---|
| 新規チャットのアシスタント選択で「業務効率」（カテゴリ名）と入力 | 0 件 | カテゴリが一致するアシスタントが表示される |
| アシスタント名の一部を入力 | 名前が一致するものを表示 | 変わらない |
| カテゴリを持たない選択肢 | 名前だけで判定 | 変わらない |

API・画面のレイアウト・文言は変わらない。

## 影響範囲

- 選択部品は 7 か所の画面で使われているが、選択肢にカテゴリを入れているのは新規チャットのダイアログだけ。部品の側で「名前またはカテゴリ」に変えても、ほかの画面は、カテゴリがないので今と同じ結果になる
- 将来、ほかの画面が選択肢にカテゴリを入れると、その画面でもカテゴリで絞り込まれる。カテゴリを表示している以上、検索にも効くのは自然なので、部品側で対応する（画面ごとに分けない）
- 結合テスト項目 07-16 が、通るようになる（今は項目書の期待に挙動が合わず、通らない）

## 移植方針

- 移植元の挙動（名前だけ）とは差が出る。案内文どおりに動かすことを優先する、という判断（Issue #396 の案 A）
- 修正は部品の絞り込みの 1 か所に限る。見た目・キーボード操作・モバイルのドロワーは変えない
- 部品の既存のコメントは「移植元と同じ」としているので、絞り込みの箇所に「移植元との差」と理由を書く
- 確認は、部品の単体テスト（名前・カテゴリ・カテゴリなし・大文字小文字・モバイル）と、新規チャットの画面のテストで行う。e2e の 07-16 は、通しの環境で確認できるかを試し、できなければ「未確認」と書く
