# infra/bootstrap を分離し、deploy-infra を手動実行のみにする

## 概要

Issue #381（親: #380）。Terraform の state を置く S3 バケットを、インフラ本体の構成から切り離して `infra/bootstrap/` に分ける。あわせて、develop への push で `terraform apply -auto-approve` が自動実行されないようにする。

## 説明

- tfstate 用の S3 を `infra/bootstrap/` に分離する（移植元 `bootstrap/` に合わせ、バージョニング・AES256 暗号化・public block・`prevent_destroy`。バケット名はアカウント ID を含めて一意にする）。`infra/` 自身が state バケットを管理していて、destroy で state ごと消える問題を避ける
- backend の設定は `backend.hcl` などで渡し、バケット名の直書きをやめる
- `deploy-infra.yml` が develop への push で自動 apply されないようにする（新アカウント構築が済むまでの安全策）
- 新アカウント用の `TF_VAR_*` の再登録手順を README に書く
