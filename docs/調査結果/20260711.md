# 移植進捗調査（2026-07-11）

naw-server-fastapi-nextjs の移植プロジェクトについて、移植元 Spring Boot 実装（`~/Documents/naw-server`）と移植先 FastAPI 実装（`backend/`）の突き合わせ調査を、`naw-explore` サブエージェントを使って実施した結果をまとめる。

## 1. 全体サマリー

- **Controller数: 17個 → Router数: 21ファイル**。Java側17 Controllerのエンドポイントは、粒度の違い（1 Controllerが複数FastAPI routerに分割されているケースあり）を踏まえて突き合わせた結果、**Java側の全エンドポイントがFastAPI側に対応実装済み**だった。
- GitHub Issueは**全47件クローズ済み、オープン0件**。GitHub Projects（プロジェクト番号3）もトラッキング対象17件すべて`Done`。
- つまり「Controller単位のエンドポイント移植」という観点では**ほぼ100%完了**しているが、移植元Spring Bootリポジトリの`develop`ブランチは日々更新され続けており（直近もNAW-1214等の細かいバグ修正が継続）、**機能全体（RAG検索・tools・添付ファイル・ライブラリ生成・response_format等の高度機能）は意図的に多数スコープ外としたまま**である点に注意が必要。以降ではこの「エンドポイント自体はあるが中身が段階的実装」の観点も含めて報告する。

## 6. 調査上の注意点・不確実な点

- **GitHub Projects（プロジェクト番号3）の追跡件数は17件のみ**で、Issue総数（47件）と一致していない。プロジェクトへの手動アタッチ漏れがある可能性があり、進捗管理の実態を完全には反映していない可能性がある。
- naw-server（`develop`）側は本調査時点でも直近に細かいNAW番号付きバグ修正（フォーマット統一・チーム管理者権限・表示順ソート・MCP接続修正など多数）が継続的に積まれており、**「エンドポイント単位の存在有無」を超えた挙動レベルの差分（バグ修正の反映漏れ）は今回網羅的には確認できていない**。NAW-1096・NAW-1192の2件のみサンプル的に深掘りし、両方とも未反映であることを確認したが、これ以外にも同様の未反映バグ修正が存在する可能性がある。
- `frontend`/`frontend-angular`側の対応状況は本調査のスコープ外（プロジェクト方針により、バックエンド優先開発のため）。
- `messages.py`/`llm.py`の「部分実装」判定は、エンドポイントのパス自体は存在するため機械的な「エンドポイント突き合わせ」だけでは移植済みに見えてしまう点に注意。実体としての機能網羅性は各Issueの要件定義（`01_要件定義.md`）のスコープ外節を必ず確認する必要がある。
