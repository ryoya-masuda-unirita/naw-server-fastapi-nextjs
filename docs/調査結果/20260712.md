## 候補: ユーザー一覧・グループ所属メンバー一覧の「利用クレジット順」ソート機能（`includeUsage`パラメータ）

- **対応するnaw-server側の実装箇所**
  - `src/main/java/com/example/naw/api/UserController.java`（`GET /api/users` に `includeUsage` パラメータ追加）
  - `src/main/java/com/example/naw/api/GroupController.java`（`GET /api/admin/groups/{id}/users` に同様のパラメータ追加）
  - `src/main/java/com/example/naw/service/UserService.java`（`getUsers` を `UserListItem(User, Long totalCredits)` を返すよう変更）
  - `src/main/java/com/example/naw/service/GroupService.java`（`findGroupMemberUsers` に同様の対応）
  - `src/main/java/com/example/naw/service/UserBillingUsageService.java`（新規。`sort=totalCredits` のバリデーション・請求期間内クレジット合計のサブクエリソート・一括取得）
  - `src/main/java/com/example/naw/response/UserResponse.java` / `GroupMemberUserResponse.java`（`totalCredits` フィールド追加）
  - 該当コミット: `48307475 NAW-1172 ユーザー管理の一覧で、利用クレジット順でユーザーをソートできない`
  - 関連の前提実装: `00c6f985 NAW-1125`（`CreditUsageController`/`CreditUsageService` = クレジットダッシュボード。backendには`credit_usage_service.py`/`credit_usage.py`として既に移植済み）

- **概要**
  - ユーザー管理画面・チーム管理画面のユーザー一覧に `includeUsage=true` クエリパラメータを追加すると、有効な請求期間（subscription）内の `totalCredits`（クレジット利用量）をレスポンスに付与し、`sort=totalCredits,asc|desc` でのソートを可能にする機能。
  - `includeUsage=false` で `sort=totalCredits` を指定すると400エラーを返すバリデーションも含む。
  - 請求期間の解決には既存の `BillingPeriodService` を利用している。

- **移植先の現状**: 未実装
  - `backend/app/services/user_service.py`・`app/routers/users.py`・`app/services/group_service.py`・`app/routers/groups.py` に該当ロジックなし（`credit`/`billing`でgrepして0件）
  - `UserResponse`・`GroupMemberUserResponse` 相当スキーマに `totalCredits` フィールドなし
  - 一方、クレジット利用状況ダッシュボード自体（`GET /api/credit-usage/me`・`/workspace`）は `backend/app/routers/credit_usage.py`・`app/services/credit_usage_service.py` として既に実装済みで、この請求期間解決ロジックを再利用できる可能性が高い

- **移植の規模感**: 小〜中
  - 既存エンドポイント（`GET /api/users`、`GET /api/admin/groups/{id}/users`）へのクエリパラメータ追加のみで、新規エンドポイントは不要
  - 「請求期間内のトークン使用量をユーザー単位で集計→ソート用サブクエリ/JOIN構築→ページング結果に付与」というロジックが新規追加になるため、単純なフィールド追加よりは工数がかかる。ただし`credit_usage_service.py`の請求期間解決ロジックを流用できれば規模は抑えられる

- **既存Issueとの重複**: なし（`credit`/`sort`/`ソート`で検索し、#73（クレジット利用状況ダッシュボードAPI、closed）のみヒット。ソート機能自体を扱うIssueはなし）

- **フロントエンド側の補足情報（参考、対応不要）**
  - `secuaigent-client` の `src/types/admin/user.types.ts`・`group-management.types.ts`・モックハンドラ（`admin-users.mock.ts`, `admin-groups.mock.ts`）に既に `includeUsage`/`totalCredits` の型・モックが存在し、UI側もこの機能を前提とした実装が進んでいる状態
