# 利用状況タブの利用者名を API の userName・userType で表示し、絞り込みで全ユーザーを選べるようにする（NAW-1421）

## 概要

テナント管理の「利用状況」タブで、利用履歴の利用者名を API が返す `userName`・`userType` で出し、利用者の絞り込みで全ユーザーを選べるようにする。

## 説明

- GitHub Issue: #426
- 移植元チケット: NAW-1421（server 側は #373 で移植済み。ユーザー一覧の並び順の一意性は backend で確保済み）
- 移植元の理由:
  - 利用者名を、画面が取ったユーザー一覧（`users.id` の対応表）から引いていたため、削除済みのユーザーは ID がそのまま出ていた。`user_id` が無い行は `-` だった
  - 絞り込みの選択肢のユーザーは 500 件まで（1 ページ目）で、それより後のユーザーを選べなかった
- 移植元の方針（コミット c42791aae・d6020c799・5c990ecc8・fb50ef11d）:
  - 利用者名は API の `userType` で決める。ACTIVE は `userName`、SYSTEM は「SYSTEMユーザー」、DELETED（`user_id` が無い行を含む）は「削除されたユーザー」
  - `userType` が無い・不明な応答は、ID や `-` を出さず、失敗として扱う
  - 絞り込みの選択肢は、全ユーザーを全ページ取得（1 ページ 1000 件・名前順）し、検索つきのセレクトにする

## その他

- 移植元の `tieBreakById`（`sort=name,asc&sort=id,asc`）は移植しない。こちらの backend は、並び替えの最終キーに `id` を加えるため、`sort=name,asc` だけで、ページをまたいでも順序が一意になる
- 参照: `secuaigent-ref/client` のテナント管理の利用状況タブ
