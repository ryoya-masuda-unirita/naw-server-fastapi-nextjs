# 01_要件定義

## 目的

移植元の見た目・文言・操作・ルートのパスを揃えて React に移す。

## 要件

- `/reports`: 移植元と同じスタブ（Reports の見出しと 3 枚のカード）
- `/settings`: Appearance / Notifications / Security の設定カード。動くのは Compact Sidebar（サイドバーの折りたたみ）だけ
- `/users`: モックユーザーの一覧（ページ送り・件数切り替え）、追加・編集・削除のモーダル。データはメモリ上のモックで、画面を離れても残りリロードで戻る
- `/users/new`・`/users/:id/edit`: 共用フォーム。保存は 1.5 秒待って `/admin/users` へ戻るだけのモック
- `/users/:id`: 固定のモック（John Doe）の詳細
- `/admin/groups/:id/members`: モックのメンバー表、チームの編集ダイアログ、削除の確認ダイアログ
- クレジット確認ダイアログ: `GET /api/credit-usage/me`・`/workspace`・`/api/users/profile` から個人・ワークスペースの利用量、上限警告・エラーを表示

## 範囲外

- 用語集・データソース、backend の変更（新しい API は使わない。既存の credit-usage・profile を使う）
