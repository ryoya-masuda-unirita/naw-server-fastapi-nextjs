# 02_基本設計

| 画面 | 実装 |
|---|---|
| `/reports` | `routes/reports/reports.tsx` + `reports.css` |
| `/settings` | `routes/settings/settings.tsx` + `settings.css`（`useUiStore` の `sidebarCollapsed`） |
| `/users` | `routes/users/users.tsx`、`components/features/users/user-form-modal.tsx`、`store/legacy-user-store.ts`、`lib/constants/mock-data.ts` |
| `/users/new`・`/users/:id/edit` | `routes/users/user-form.tsx` |
| `/users/:id` | `routes/users/user-detail.tsx` + `user-detail.css` |
| `/admin/groups/:id/members` | `routes/admin/groups/group-members.tsx`（共通 UI の PageHeader・Table・Select・SearchInput・Pagination・Dialog） |
| クレジット確認 | `components/layouts/usage-dialog.tsx`、`hooks/use-user-profile.ts`（既存の `use-credit-usage.ts` を使う） |

- 移植元の component SCSS は、Angular のスコープの代わりに画面のルートクラス（`.reports-page` など）配下に限定した CSS ファイルに置く
- MSW: `mocks/handlers/credit-usage.ts` に自分のクレジット利用量の既定の応答だけを足した
