# 03_詳細設計

## 移植元と変えた点・判断

1. **旧ユーザー管理のモーダルのキャンセル**: 移植元は `(cancel)` を宣言のない出力にバインドしており、キャンセルボタンが何も起こさない（移植元の不具合）。React ではモーダルを閉じる
2. **旧ユーザー管理の保存**: 移植元は保存後に `userId` を `username` へ写さないため一覧の「ユーザーID」が空になる。入力した値が出るよう `username` に写す
3. **グループメンバー画面で移していないもの**: 移植元は `PageHeader` の `tabChange` を受け取っておらず「所属アシスタント」タブに切り替わらない。追加・選択行削除・行クリック・メニュー・検索の実行もテンプレートから呼ばれない。到達できない処理は移していない
4. **グループメンバー画面のダイアログ**: 移植元は `showConfirm` を指定しないため確認ボタンがなくキャンセルしかない。同じにした。ユーザーの追加ボタンは「チームの編集」ダイアログを開く（移植元どおり）
5. **ユーザー詳細の編集リンク**: `/admin/users/:id/edit` は移植元にもルートがない。パスは移植元どおり
6. **文言**: レポート・設定・ユーザーフォーム・ユーザー詳細は移植元が英語をハードコードしているため i18n を通さない（辞書にキーがない。キーは足さない）
7. **クレジット確認ダイアログ**: MatDialog の `width: 800px / maxWidth: 90vw` を `dialogWidth` と `panelClass="max-w-[90vw]!"` で再現。移植元でコメントアウトされている日間上限・日間アラートの行は移していない
8. **ユーザー一覧のページサイズ変更**: 移植元と同じくページを 1 に戻さない（モック 7 件なので常に 1 ページ）
