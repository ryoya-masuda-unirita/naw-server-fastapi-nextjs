# #72 issue-72 UserController ユーザー一括インポートAPIの移植

## 概要

Spring Boot版のユーザー一括インポートAPIをFastAPIへ移植する。

## 説明

対象エンドポイント:

- `POST /api/admin/users/import`
- `GET /api/admin/users/import/{jobId}`

移植元はS3/SQSを使う非同期構成だが、FastAPI側には外部インフラ連携がないため、Issue本文の想定に従いアップロードCSVを同期的に処理する縮小版として実装する。

## その他

- `/naw-issue-loop` 全自動モードのため、同期縮小版のユーザー承認は省略する
- S3/SQS関連コードは移植対象外
