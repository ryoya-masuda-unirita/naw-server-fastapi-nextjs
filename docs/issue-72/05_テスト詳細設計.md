# 05_テスト詳細設計

## 統合テスト

- `test_import_users_creates_user_and_job`
  - multipart CSVをPOSTし、`jobId/status` が返ること
  - 作成ユーザーとパスワード履歴が保存されること
  - GETでジョブ詳細を取得できること
- `test_import_users_updates_existing_user_without_password_change`
  - 既存ユーザーの名前・ロールが更新されること
  - 既存パスワード履歴が増えないこと
- `test_import_users_replaces_group_memberships`
  - CSVの `groupIds` に応じて `groups_users` が作成されること
- `test_import_users_returns_failed_job_for_invalid_csv`
  - 必須カラム不足で `FAILED` ジョブが保存されること
- `test_general_user_cannot_import_users`
  - 一般ユーザーでは403になること
- `test_get_import_job_returns_404_for_other_tenant`
  - テナント境界が守られること
