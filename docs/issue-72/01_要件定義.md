# 01_要件定義

## 背景

管理者がCSVファイルでユーザーを一括登録・更新できるようにする。
移植先には外部ストレージ/キュー基盤がないため、アップロードされたCSVをAPIリクエスト内で同期的に処理する。

## 機能要件

- 管理者はCSVファイルをアップロードしてユーザーインポートジョブを作成できる
- CSVの必須カラムは `login_id`, `name`, `password`, `role` とする
- 任意カラムとして `createLoginKey`, `groupIds` を扱う
- CSVバリデーションに失敗した場合はジョブを `FAILED` とし、エラー内容を保存して返す
- 処理に成功した場合はジョブを `COMPLETED` として保存する
- 既存ユーザーは名前・ロール・ログインキーを更新し、パスワードは更新しない
- 新規ユーザーはCSVのパスワードをハッシュ化してパスワード履歴へ保存する
- `groupIds` が指定された場合、既存のグループ所属をCSV内容で洗い替える
- 管理者はジョブIDからインポートジョブ状態を取得できる

## 非機能要件

- テナント境界を越えてジョブやユーザーを参照・更新しない
- 既存の管理者認可とJWT/X-Tenant-ID検証を利用する
- 外部S3/SQS依存を追加しない
- CSVは最大100行まで処理する

## スコープ外

- S3アップロード、SQS送信、非同期リスナー、DLQ対応
- ブラウザによる手動動作確認
