# 02_基本設計

## 変更対象

- 管理者向けユーザーAPI
- ユーザーインポートジョブ永続化
- CSVバリデーション/同期インポート処理
- 統合テスト

## 画面 / API 変更概要

- `POST /api/admin/users/import` は multipart form-data の `file` を受け取り、同期的にCSVを検証・処理する
- レスポンスは `jobId` と `status` を返す
- `GET /api/admin/users/import/{jobId}` はジョブ詳細を返す

## 影響範囲

- 管理者ユーザーAPIに新規ルートが追加される
- ユーザー作成/更新、パスワード履歴、グループ所属に書き込みが発生する
- 新規テーブルが追加される

## 移植方針

- 参照実装のCSV列・バリデーション・処理単位は踏襲する
- 外部インフラがない部分は同期縮小版として置き換える
- `PENDING`/`PROCESSING` はスキップし、完了時は `COMPLETED`、エラー時は `FAILED` を保存する
