# 01_要件定義

## 背景

FastAPI バックエンドは現時点でヘルスチェックエンドポイントのみ実装されており、DB 接続基盤が存在しない。認証 API（issue-6 予定）をはじめ、以降のすべての機能実装は DB への接続とテーブル定義を前提とする。本チケットでは、移植先の DB マイグレーション基盤を整備し、認証に必要な最小限のテーブル（`tenants`・`users`）を定義する。

---

## 機能要件

### ローカル開発用 DB 環境

- プロジェクトルートに `docker-compose.yml` を追加し、PostgreSQL コンテナを定義する
- `docker compose up -d` 一発で DB が起動できること

### マイグレーション基盤

- Alembic を用いたマイグレーション管理を導入する
- 非同期 DB ドライバ（asyncpg）に対応した設定にする
- `alembic upgrade head` の実行でテーブルが作成されること

### DB 接続設定

- SQLAlchemy の非同期エンジン・セッションを設定する
- 接続情報は環境変数（`DATABASE_URL`）から取得する
- セッションは DI（依存性注入）経由でルーター層に渡す

### tenants テーブル

移植元の Liquibase changeset（全バージョン）を適用した最終状態を定義する。

| カラム | 型 | 制約 |
|---|---|---|
| id | varchar(32) | PK、NOT NULL |
| name | varchar(32) | NOT NULL |
| owner | varchar(32) | NOT NULL |
| is_deleted | boolean | NOT NULL、デフォルト false |
| created_at | timestamptz | NOT NULL、デフォルト CURRENT_TIMESTAMP |
| updated_at | timestamptz | NOT NULL、デフォルト CURRENT_TIMESTAMP |
| pw_policy_min_length | smallint | NOT NULL、デフォルト 12 |
| pw_policy_use_uppercase | boolean | NOT NULL、デフォルト true |
| pw_policy_use_lowercase | boolean | NOT NULL、デフォルト true |
| pw_policy_use_digits | boolean | NOT NULL、デフォルト true |
| pw_policy_use_symbols | boolean | NOT NULL、デフォルト true |
| pw_policy_valid_symbols | varchar(100) | NOT NULL、デフォルト `!@#$%^&*` |
| pw_validity_period_days | smallint | NOT NULL、デフォルト 90 |
| pw_histories_limit | smallint | NOT NULL、デフォルト 1、CHECK >= 1 |
| max_usage_based_credits_per_month | bigint | NOT NULL、デフォルト 0 |

- `is_deleted` カラムにインデックス（`tenants_is_deleted_idx`）

### users テーブル

移植元の Liquibase changeset（全バージョン）を適用した最終状態を定義する。

| カラム | 型 | 制約 |
|---|---|---|
| id | UUID | PK、NOT NULL、デフォルト gen_random_uuid() |
| login_id | varchar(255) | NOT NULL |
| tenant_id | varchar(32) | NOT NULL、FK → tenants.id（ON DELETE CASCADE） |
| name | varchar(255) | NOT NULL |
| password | varchar(255) | NOT NULL |
| role | varchar(32) | NOT NULL、ENUM（`USER` / `ADMIN` / `SYSTEM`） |
| login_key | varchar(32) | NULL 許容 |
| is_required_password_reset | boolean | NOT NULL、デフォルト true |
| created_at | timestamptz | NOT NULL、デフォルト CURRENT_TIMESTAMP |
| updated_at | timestamptz | NOT NULL、デフォルト CURRENT_TIMESTAMP |

- `(login_id, tenant_id)` に UNIQUE 制約

---

## 非機能要件

- マイグレーションは冪等であること（再実行しても副作用が出ないこと）
- SQLAlchemy モデルはテーブル定義の正規表現として機能し、型安全に扱えること
- 非同期 I/O に対応し、FastAPI の async/await と統合できること

---

## スコープ外

- RLS（Row Level Security）の設定
- `user_import_jobs` テーブルの定義
- `tenants`・`users` 以外のテーブル定義
- シードデータの投入
- 認証ロジック（JWT 等）の実装（issue-6 で対応）
