# DBマイグレーション基盤（Alembic）と tenants・users テーブルの定義

## 概要

FastAPI バックエンドに Alembic によるDBマイグレーション基盤を導入し、認証APIの前提となる `tenants`・`users` テーブルを定義する。

## 説明

- Alembic のセットアップ（`alembic init`、`env.py` の非同期対応）
- SQLAlchemy AsyncEngine / AsyncSession の設定
- `tenants` テーブルの定義（Spring Boot 側の全 changeset 適用後の最終状態）
  - id, name, owner, is_deleted, created_at, updated_at
  - パスワードポリシーカラム（pw_policy_min_length 等）
- `users` テーブルの定義（Spring Boot 側の全 changeset 適用後の最終状態）
  - id (UUID, surrogate PK), login_id, tenant_id, name, password, role, login_key, is_required_password_reset, created_at, updated_at
- 初期マイグレーションの実行確認（`alembic upgrade head`）

## その他

- 移植元（バックエンド）: `~/Documents/naw-server/src/main/resources/liquibase/changelog/tenants/` および `users/`
- Spring Boot 側は Liquibase を使用しているが、FastAPI 側は Alembic で対応する
- RLS（Row Level Security）は今回スコープ外とする
- `user_import_jobs` テーブルは今回スコープ外とする
