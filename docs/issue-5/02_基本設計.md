# 02_基本設計

## 変更対象レイヤー

バックエンドのみ。フロントエンド・インフラへの変更はなし。

| レイヤー | 変更内容 |
|---|---|
| プロジェクトルート | `docker-compose.yml` を追加（PostgreSQL コンテナ、ホスト側ポート 5433） |
| `core/` | DB 接続設定（エンジン・セッション）を追加 |
| `models/` | `Tenant`・`User` の SQLModel モデルを追加 |
| マイグレーション | Alembic を新規導入し、初期マイグレーションを作成 |
| 設定 | `pyproject.toml` に Alembic・asyncpg を追加 |

---

## 変更概要

### Alembic の導入

- `backend/` 直下に `alembic/` ディレクトリを作成し、非同期エンジンを使った `env.py` を設定する
- SQLModel のメタデータを `env.py` に渡し、モデル定義からマイグレーションを自動生成できるようにする
- 初回マイグレーションとして `tenants`・`users` テーブルの CREATE TABLE を記述する

### DB 接続設定

- `core/database.py` に非同期エンジン（`AsyncEngine`）と非同期セッションファクトリ（`async_sessionmaker`）を定義する
- `get_session()` を FastAPI の `Depends` で使える形で公開する
- 接続文字列は `core/config.py` の `DATABASE_URL` から取得する

### SQLModel モデル定義

新規モデルを2つ追加する。

**Tenant モデル**
- `tenants` テーブルに対応するモデル
- パスワードポリシーカラムを含む最終形で定義する

**User モデル**
- `users` テーブルに対応するモデル
- PK は UUID（`gen_random_uuid()` によるサーバーサイド生成）
- `tenant_id` で `tenants` テーブルへの外部キーを持つ

## 影響範囲

- 既存の `app/main.py`・`routers/health.py` への変更は不要
- 本チケット完了後、認証 API（issue-6）で `User`・`Tenant` モデルと `get_session()` を使用する
- 以降のすべてのテーブル定義は本チケットで整備した Alembic・SQLModel の仕組みを踏襲する
