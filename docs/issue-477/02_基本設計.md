# 02_基本設計

## 変更対象

- チーム詳細の所属ユーザー追加のダイアログ（選択部品の置き換え）
- 共通の複数選択コンボボックス（`+N` の判定、開くときの復元、`scrollChipsWhenOpen` の追加、チップ欄の右の余白）
- 翻訳（所属ユーザー追加の検索補足文。日本語・英語）
- 自動テスト（ダイアログの絞り込みと追加、共通部品の `+N`・開き直し・高さの上限）
- 共通部品の README（`scrollChipsWhenOpen` の説明）

## 画面 / API 変更概要

- 画面: 所属ユーザーの追加ダイアログで、名前を入力して候補を絞り込める。選んだユーザーが多いとき、欄がダイアログの外へはみ出さず、欄の中でスクロールする
- API の変更はない

## 影響範囲

- 共通のコンボボックスを使う画面（アシスタント、テンプレート、チャットの共有・ライブラリ保存）は、`+N` の判定・開き直しの復元・右の余白の 3 点の修正を受ける。移植元では、これらを「部品を使う全画面の不具合」として共通部品で直している
- `scrollChipsWhenOpen` は、既定で無効にし、所属ユーザー追加だけが有効にする。ほかの利用箇所には影響しない

## 移植方針

移植元の NAW-1452（2 コミット）に合わせる。Angular → React の変換は、`client/.claude/CLAUDE.md` の対応表に従う。

| 移植元（Angular） | 移植先（React） |
|---|---|
| `app-combobox-multi` に `[scrollChipsWhenOpen]` 入力を足し、`chipsScrollable = isOpen && scrollChipsWhenOpen` で高さ上限のクラスを付ける | `ComboboxMulti` に `scrollChipsWhenOpen` の props を足し、開いている間だけ高さ上限（`max-h-24`・`overflow-y-auto`）のクラスを付ける |
| `afterRenderEffect`（選択が変わるたびに末尾へスクロールし、一覧を付け直す） | 描画後の `useEffect`（選択済みの値が変わるたびに、同じ処理） |
| 開くとき `recalcChipOverflow` を呼んで、隠したチップ・入力欄・`+N` を戻す | 開くとき、同じ復元を行う |
| `+N` の判定を、毎回 1 つ目のチップの `offsetTop` と比べる | 同じ |
| チップ欄の `padding-right` を広げる | 同じ（共通の CSS） |

## 決定（第1承認、2026-11-25）

- **開くときの復元は、この Issue に含める**（推奨どおり）。実装の前に、移植先でも再現することを、テストで確かめる
- `+N` の判定の修正は、移植元と同じく共通で直す。実画面で、ほかの利用箇所のうち 1 か所（アシスタント）でも、`+N` が正しく出ることを確かめる
- 進め方は全自動
