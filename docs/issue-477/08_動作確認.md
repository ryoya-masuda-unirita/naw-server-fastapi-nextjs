# 08_動作確認

## 確認環境

- macOS、Docker（OrbStack）。ブランチ `feature/issue-477`（`develop` の a85b9ad から作成）
- 実画面は、ルートの `docker-compose.demo.yml` を、**別のプロジェクト名（`naw-demo-477`）と別のポート**（画面 15177、backend 18077）で起動して確認した（手元で稼働中の環境には触れない）。画面はこの worktree の `client/` を配信し、配信中のソースに `scrollChipsWhenOpen` が入っていることを確かめた。デモデータ（`server/seed-demo.sql`）。ログインは seed のテナント `test-tenant`、ユーザー `admin`
- **ブラウザの操作は Playwright（ヘッドレスの Chromium。`e2e-explorer` の導入済みのもの）で行った**。Claude in Chrome は、`localhost:5173` 以外のポート（15177・18077、試験用の 5174）を開けなかったため（ブラウザ拡張側の許可の制限と見ている）。確認用のスクリプトはスクラッチに置き、リポジトリには入れていない
- 確認後、デモ環境は `down -v` で削除した

## 確認手順

04・05 の番号に対応する。実画面は、チーム「営業部」の「所属ユーザー」→「ユーザーを追加」のダイアログ。まだ所属していない 17 名が候補。

## 確認結果

### 自動テスト

| 確認 | 結果 |
|---|---|
| 修正前のコードで、新しい共通部品のテストを実行 | 7 件が失敗した（`+N` が `+6`・1 つ目しか出ない、開き直しても `+4` が消えない、`scrollChipsWhenOpen` が無い）。残りは対照のテストで通った |
| 開き直しの復元だけを一時的に外して実行 | 開き直しのテストが失敗した（`expected '+4' to be null`）。React でも、移植元と同じ不具合があることを確認した |
| `npm run test` | 142 ファイル 1472 件が通った |
| `npm run lint`、`npm run type-check` | エラー・警告なし |

### 実画面（幅 1280px。デスクトップ）

| No | 確認 | 結果 |

スクリーンショット: [開いている間](./screenshots/open-many-selected.png)、[確定して閉じた状態](./screenshots/closed-plus-n.png)、[開き直して絞り込み](./screenshots/reopened-filtered.png)

### 実画面（幅 600px。モバイル）

同じ流れで確認した。開いている間は欄の高さが 96px で止まって中でスクロールし（中身 201px）、入力欄が見える。閉じるとチップ 3 件と `+14`（3 + 14 = 17）で、区切り線（左端 451）に重ならない（右端 365）。開き直すと全チップと入力欄が出て、1 件に絞り込めた。

### ほかの利用箇所への影響（共通の修正）

アシスタントの新規作成ダイアログのコンボボックス（カテゴリ、15 件を全選択）で確認した。

| 確認 | 結果 |
|---|---|
| 開いている間の高さ上限 | 付かない（`scrollChipsWhenOpen` を指定していないため。従来どおり欄が伸びる） |
| 閉じた状態の `+N` | チップ 4 件と `+11`（4 + 11 = 15）、欄は 1 行、最後の要素が区切り線に重ならない |
