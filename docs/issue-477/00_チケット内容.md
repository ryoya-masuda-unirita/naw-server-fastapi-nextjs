# #477 NAW-1452 チーム詳細の所属ユーザー追加で名前の絞り込みと欄のはみ出し防止を入れる

## 概要

チーム詳細の所属ユーザー追加を、名前で絞り込める部品に置き換え、選択数が多くても欄がはみ出さないようにする。

- 移植元: `~/Documents/unirita-develop-pj/secuaigent-ref`（origin/develop 3260e3a84）
- 対象: `client/`

## 説明

### Issue の内容

- (a) `client/src/routes/admin/groups/group-detail-users.tsx:15,279` の `MultiSelect` を `ComboboxMulti`（`client/src/components/shared/combobox-multi.tsx`）に置換。searchHint・emptyMessage・panelSize=full・testid `admin-groups-add-user-select` を移植元に合わせる
- (b) `ComboboxMulti` に `scrollChipsWhenOpen` を追加。開いている間 `max-h-24 overflow-y-auto`、末尾へ自動スクロール、一覧の位置付け直し、+N の計算を 1 つ目チップとの offsetTop 比較に変更。チップ欄の右 padding を `spacing*12` にして ▼ と重ねない

### 移植先（React）の現状

- 所属ユーザー追加のダイアログは `MultiSelect`（入力欄・絞り込みなし）を使っている
- `ComboboxMulti` は移植済みで、`searchHint`・`emptyMessage`・`panelSize`・`testidPrefix` の指定ができる。`scrollChipsWhenOpen` はない
- `+N` の判定は移植元の修正前と同じ実装（最初に測った 1 つ目のチップの位置と比べ続ける）。開くときに隠した入力欄を戻す処理もない
- `GROUPS.MEMBERS_SEARCH_HINT` の翻訳がない
- `MultiSelect` は、ライブラリの設定ダイアログでも使っているため、置き換え後も残す（移植元でも共通部品は変えていない）
