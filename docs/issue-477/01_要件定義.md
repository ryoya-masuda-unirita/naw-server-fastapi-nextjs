# 01_要件定義

## 背景

- チーム詳細の所属ユーザーの追加は、入力欄も絞り込みもない複数選択を使っていて、ユーザーが大量にいると、候補を上から探すしかない
- 移植元（NAW-1452）は、これを、絞り込み入力つきの複数選択コンボボックスに置き換えた。さらに、たくさん選ぶと欄がはみ出す不具合（担当者の報告）を、共通のコンボボックスの修正で直した
- 移植先は、置き換えも修正も入っていない

## 機能要件

### (a) 所属ユーザー追加を、絞り込める部品に置き換える

- チーム詳細の「所属ユーザーを追加」ダイアログの選択を、ユーザー名で絞り込めるコンボボックスにする
- 検索欄の補足文（ユーザー名で検索できます）と、一致なしの文言（表示するデータがありません）を、表示言語（日本語・英語）で出す。補足文の翻訳を足す
- 候補の一覧の幅は、欄の幅に合わせる
- 自動テストが探せる識別子（`admin-groups-add-user-select`）を、移植元と同じ付け方で付ける
- 絞り込んでいる間の「すべて選択」「すべて解除」は、表示中のユーザーだけに効き、表示していないユーザーの選択は残る（共通のコンボボックスの既存の動き）

### (b) たくさん選んでも欄がはみ出さないようにする

- 一覧を開いている間の選択済みの欄に、高さの上限を付け、中でスクロールさせる。選ぶたびに末尾までスクロールして、入力欄が見えるようにする。選んで欄が高くなったら、一覧を欄の下端に付け直す。**この動きは、所属ユーザー追加だけに効かせる**（ほかのコンボボックスの利用箇所は変えない。移植元と同じ）
- 閉じている欄で、1 行に入るだけのチップを出し、残りを `+N` で出す。判定を、毎回 1 つ目のチップの今の位置と比べる方式にする（共通の修正。すべての利用箇所に効く）
- 閉じている間に隠した入力欄とチップを、一覧を開くときに戻し、`+N` を消す。2 回目に開いても、名前で絞り込める（共通の修正）
- チップの欄の右側の余白を広げ、最後のチップや `+N` が、区切り線と［▼］に重ならないようにする（共通の修正）

## 非機能要件

- 共通の修正（`+N` の判定、開くときの復元、右の余白）は、ほかのコンボボックスの利用箇所（アシスタント、テンプレート、チャットの共有・ライブラリ保存）の見た目と動きを壊さない
- 既存の自動テストが変わらず通る
- 実際の画面で、たくさん選んだ状態の見た目と、2 回目に開いたときの絞り込みを確かめる

## スコープ外

- `MultiSelect` 自体の変更や削除（ライブラリの設定ダイアログでも使っている）
- ほかの画面の複数選択を、コンボボックスに置き換えること
- バックエンド（所属ユーザーの追加の API は変えない）
- E2E の Page Object（移植元の変更にあるが、このリポジトリには対応するものがない）
