# 01_要件定義

## 背景

移植元のアシスタント管理は、アシスタントとカテゴリを 2 つのタブで管理する管理画面。React 版は #277 で画面の枠（ルート・ガード・サイドバー・仮画面）ができており、中身が未移植。

## 機能要件

- 画面の上部に、アシスタント一覧とカテゴリ管理の 2 つのタブを出す（テナント管理者のみ。選んだタブは URL の `tab` で保持）
- アシスタント一覧タブ
  - 検索（入力が止まってから反映）、接続サーバー・カテゴリ・所属チームでの絞り込み、並べ替え（更新日時・表示名・履歴送信）、ページ送り、件数表示
  - 一覧の列: 表示名と説明・接続サーバー・生成 AI モデル・カテゴリ・所属チーム・履歴送信
  - 追加・編集ダイアログ（表示名・接続サーバー・接続先 API・モデル（またはサービス ID）・学習先フォルダ・カテゴリ・所属チーム・説明・履歴送信。編集はアシスタント ID とコピーボタン付き）
  - 行ごとの編集・削除、複数選択での一括削除
- カテゴリ管理タブ
  - 並べ替え（更新日時・カテゴリ名）、ページ送り、件数表示（並べ替えとページ分けは画面側）
  - 追加・編集ダイアログ（カテゴリ名・説明）、行ごとの編集・削除、複数選択での一括削除
- 入力チェックは移植元どおり（表示名 32 文字・説明 1000 文字、カテゴリ名 16 文字・説明 255 文字、必須項目、学習先指定のクラウドでは学習先フォルダが必須）
- 作成・更新・削除の成否はトーストで知らせる。削除が 409 のときは、デフォルトアシスタントのため削除できない旨を出す

## 非機能要件

- 見た目・文言（i18n のキー）は移植元に揃える。辞書にキーを足さない
- 他画面と同じく、TanStack Query の key の先頭を `assistants` にし、サイドバーの無効化と連動させる

## スコープ外

- グループ詳細のアシスタント紐付け（`group-detail/assistants`）
- 用語辞書の絞り込み・所属用語辞書の入力（移植元でコメントアウトされている）
- backend の修正
