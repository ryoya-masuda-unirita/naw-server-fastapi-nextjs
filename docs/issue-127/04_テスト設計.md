# 04_テスト設計

## テスト方針

- Vitest + React Testing Library + MSW。ガード・レイアウト込みで画面を描画する
- i18n は未初期化のため `t()` はキーを返す。キーで検証する
- MSW の既定は空の一覧・選択肢なし。テストごとに応答を上書きし、受けたリクエストを記録する

## テスト観点

- アシスタント一覧: 各列の表示（接続先の表示名を選択肢から引く）、0 件、初期の取得条件、検索、最終ページへの戻り
- タブ: 表示、カテゴリ管理への切り替え
- 作成: 何も入力しない場合の必須エラーと未送信、名前の文字数超過、接続サーバー・接続先・モデルを選んでの作成、学習先指定のフォルダ必須、失敗時のトーストとダイアログの維持
- 編集: 既存値と ID の表示、保存時の本文
- 削除: 選択しての一括削除、使用中（409）・その他の失敗のトースト
- カテゴリ: 並び順（初期・名前順）、必須エラー、文字数超過、trim しての作成、編集、行メニューからの削除
