# アシスタント管理 一覧画面をReactに移植する

## 概要

アシスタント管理 一覧画面（`/admin/assistants`、アシスタント一覧タブ／カテゴリ管理タブ）を Angular（`secuaigent/client` の `features/admin/management/assistant-list/`）から React（`frontend/`）に移植する。Issue #127。

## 説明

- 対象: `assistant-list.component`（タブの親）・`assistant-tab`（一覧・追加・編集・メニュー）・`category-tab`（一覧・追加・編集・メニュー）・2 つの store・`assistant-list-api.service`・`assistant-list.constants`
- スコープ外: `group-detail/assistants/*`（グループ単位の紐付け。別 Issue）
- 土台は #277（ルート・ガード・サイドバー・i18n）・#278（共通 UI）・#279（API の型・パス・api-client・MSW）。画面の作り方は #124（テンプレート管理）に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）

## その他

- 移植先は Issue 本文の `routes/app/admin/assistants.tsx` ではなく、#277 の仮ファイル `frontend/src/routes/admin/assistants/assistant-list.tsx`（export 名 `AdminAssistantListPage` は維持）
- backend の応答の形の差は `docs/issue-279/api-backend-diff.md` を参照（backend は直さない）
