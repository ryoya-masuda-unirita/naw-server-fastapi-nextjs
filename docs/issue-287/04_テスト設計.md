# 04_テスト設計

## テスト方針

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ・実機確認は行わない。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 添付の許可判定 | 画像・許可 MIME・許可拡張子・許可外 | 移植元の spec と同じ結果 |
| 2 | 添付（部品） | ドロップ・input 選択・許可外だけ・チップ表示と削除 | 許可されたものだけ追加される。×で外れる |
| 3 | 評価ダイアログ | 初期選択（既存評価あり／なし）・選択して送信・失敗・キャンセル・未選択で確認 | 仕様どおり |
| 4 | 共有ダイアログ | 初期選択・未選択で共有不可・共有・解除（確認→成功/失敗）・読み取り専用・リンクコピー | 仕様どおり |
| 5 | 検索 | デバウンス・結果表示・0 件・クリックで移動・ページ送り・空欄で初期化・古い応答を捨てる | 仕様どおり |
| 6 | stores | shares-store・teams-store・chat-store（添付・共有ルームの文脈・useActiveRoom のフォールバック） | 仕様どおり |
| 7 | ウィンドウ（結合） | ヘッダーの評価・共有から各ダイアログが開く、ドロップで添付チップが出る | 仕様どおり |
| 8 | util | buildShareUrl・getRoomListTotalCount | 仕様どおり |
