# 03_詳細設計

## 添付

- `isAllowedChatAttachment(file)`: 画像（`image/*`）は常に許可。MIME が許可リストにあれば許可。なければ拡張子（`docx xlsx pptx txt md csv xml html`）で判定
- `addAttachedFiles(files, controls)`: 許可されたものだけを `controls.setAttachedFiles(current => [...current, ...allowed])`。1 件も許可されなければ何もしない
- `ChatAttachmentDropzone`: `div.rounded-2xl.border-dashed...` の中に sr-only の `<input type="file" id="chat-file-upload" accept multiple>` と `<label for>`（クリップのアイコン + `CHAT.INPUT.DROP_FILES`）。選択後は `input.value = ''`
- `ChatAttachmentChips`: 1 件以上のとき `div.flex.flex-wrap.gap-3.mb-3`。画像なら `FileImageChip`、それ以外は `FileChip`
- `ChatAttachMenuItem`: ＋メニューの 1 項目。クリックで input を開き、`onSelected`（メニューを閉じる）を呼ぶ

## 評価

- `ChatRatingDialog({ roomId, existingRating, onClose })`
  - `initial = existingRating != null ? (REVERSE_RATING_MAP[existingRating] ?? null) : null`
  - `FormRadio`（5→1 の ★ ラベル、`classOption="gap-2 flex-col!"`、`inputClass="gap-2"`）
  - 確認: 選択が null なら何もしない。`submitRoomFeedback(roomId, { rating })` が成功したら閉じる。失敗は閉じずに `console.error`
  - `Dialog`: title `CHAT.RATING_DIALOG.TITLE`、`showClose=false`、キャンセル `CHAT.RATING_DIALOG.CANCEL`、確認 `CHAT.RATING_DIALOG.SUBMIT`、`confirmMinWidth="min-w-24.5"`、`confirmLoading=isSubmittingFeedback`、幅 800px

## 共有

- `ChatShareDialog({ isReadOnly, onClose })`: 表示中のルームを `useActiveRoom()` で読む
  - `selectedTeamIds`: ルーム（参照）が変わったら `room.teamIds ?? []` で入れ直す
  - 確認ボタン: `confirmDisabled = selectedTeamIds.length === 0`、`confirmLoading = isSharing`、`showConfirm = !isReadOnly`
  - 共有: `shareRoom(roomId, teamIds)`。失敗したら閉じる。成功しても閉じない
  - 共有リンクのコピー/解除: `room.shareId` があり読み取り専用でないときだけ出す。コピーは `navigator.clipboard.writeText(buildShareUrl(shareId))`
  - 解除: 確認ダイアログ（幅 800px、`confirmDanger`、`confirmIcon="link_off"`、`confirmLoading=isUnsharing`、`buttonAlign="center"`）。確認で `unshareRoom(shareId)`、成功で閉じる、失敗でも閉じる
  - `Dialog` の `panelClass="share-dialog-container dialog-overflow-visible"`
- `useChatRoomDialogs({ isReadOnly })`: `{ onShareClick, onLikeClick, dialogs }` を返す。ルームがなければ移植元と同じく roomId は空文字（評価の送信は何もしない）

## 検索

- 状態: `query`・`results`・`isSearchLoading`・`currentPage`・`totalItems`（`pageSize = 20`）
- `useDebouncedValue(query, 300)` が `''` 以外なら 1 ページ目を読み込む。`''` なら結果・件数・ページを初期化
- 読み込み: `GET /api/rooms` に `name=trim(q)`・`page=page-1`・`size=20`。`mapRoomListApiResponse(response, existingById)`（`existingById` は `allRooms`）、件数は `getRoomListTotalCount`
- 結果クリック: `chat-store.selectRoom(id)` → ダイアログを閉じる → `navigate(ROUTES.APP.CHAT_ROOM(id))`
- 日付は `YYYY/MM/DD`（`formatLocalDate`）

## 状態（stores）

- `shares-store`: `isSharing`・`isUnsharing`・`isResolvingAccess`・`shareRoom`・`unshareRoom`・`resolveShareAccess`。`shareRoom` 成功で `rooms-store.updateRoom(roomId, { shareId, teamIds })`、`unshareRoom` 成功で `{ shareId: null, teamIds: [] }`
- `teams-store`: `teams`・`isLoading`・`loadTeams`（失敗したら空）
- `chat-store`: `attachedFiles`・`addAttachment`・`removeAttachment`・`clearAttachments`（`startNewChat` で空に）、`sharedRoomContext`・`openSharedRoom(access, shareId)`・`clearSharedRoomContext`。`useActiveRoom` は一覧になければ `sharedRoomContext` を返す
