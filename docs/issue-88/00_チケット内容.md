# #88 issue-88 LLMチャット・埋め込みAPIを移植

## 概要

LLM(Azure OpenAI)呼び出し系API（チャット・埋め込み）を移植元(Spring Boot)からFastAPIへ移植する。

## 説明

対象エンドポイント:
- `POST /api/llm/chat`（SSEストリーミング応答）
- `POST /api/llm/embedding`

移植元（バックエンド）: `~/Documents/naw-server/src/main/java/com/example/naw/api/LlmController.java`
移植先の現状: `backend/app/routers/` にLLM呼び出し用ルーターが存在せず未実装。

対応内容（想定）:
- `/chat`: SSEストリーミング応答、メッセージ永続化との統合
- `/embedding`: Azure OpenAI Embeddings API呼び出し
- Azure OpenAI SDK統合

## その他

- 起票時点で「3候補中、最も実装複雑度が高い」と明記されている。
- 調査の結果、Room/Messageドメイン（`Message`/`MessageContent`/`MessageFile`/`MessageFeedback`）は移植先に既に完成済みであり、本Issueのスコープは「LLM呼び出し＋SSE配信＋トークン使用量永続化」に限定できることが判明した。
- 移植元は「基本チャット」「Web検索/MCP tools」「ライブラリ生成（createLibrary）」「response_format（レスポンス形式指定）」の4段階で機能が積まれている。一括移植は規模が大きすぎるため、本Issueでは基本チャット（テキストのみ、tools/添付ファイル/ライブラリ生成/response_formatなし）＋embeddingのみを対象とし、残りは後続Issueに切り出す（詳細は`01_要件定義.md`のスコープ外を参照）。
