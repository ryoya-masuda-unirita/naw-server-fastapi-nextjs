# 08_動作確認

## 確認環境

- ローカル（macOS）、Terraform v1.15.8。`AWS_PROFILE=oic`（ユニリタとは別の AWS アカウント、`ap-northeast-1`）で `plan` と、読み取りだけの AWS CLI を実行（backend はローカルに差し替え。AWS には何も作っていない。**`apply` は実行していない**）
- ブランチ: `feature/issue-385`（`develop` から作成。別の作業と衝突しないよう、別の worktree で作業した）
- 変更前の基準: 着手時点の `develop` の `plan`（67 リソース）

## 確認結果

| No | 確認内容 | 結果 |
|---|---|---|
| 1 | `fmt -recursive -check`、環境（dev）の `validate` | OK |
| 2 | リソースの増減 | 67 → 69（`Plan: 69 to add, 0 to change, 0 to destroy.`）。削除なし。追加は想定の 2 つだけ: `aws_db_parameter_group.main`・`aws_ecr_lifecycle_policy.backend` |
| 3 | 変わるリソース | 想定の 2 リソースだけ（`aws_db_instance.main`、`aws_elasticache_replication_group.main`）。それ以外（VPC・ECS・ALB・CloudFront・IAM・ECR リポジトリ本体・セキュリティグループなど）に差分なし |
| 4 | RDS | `engine_version=18`、`storage_encrypted=true`、`backup_retention_period=7`、`parameter_group_name=naw-fastapi-pg18` が増えた。`postgres`・`db.t4g.micro`・`gp3`・20GB・`publicly_accessible=false`・`skip_final_snapshot=true` は不変。`auto_minor_version_upgrade=true` は既定値と同じため、`plan` の差分には出ない（コードで明示） |
| 5 | パラメータグループ | 名前 `naw-fastapi-pg18`、ファミリ `postgres18`、パラメータなし |
| 6 | ElastiCache | `engine_version=7.1`、`port=6379`、`at_rest_encryption_enabled=true` が増え、`transit_encryption_enabled=false` が明示された。`automatic_failover_enabled=false` は既定値と同じ。`cache.t4g.micro`・1 ノードは不変 |
| 7 | ECR | ライフサイクルポリシー（タグなし・プッシュから 30 日・期限切れ）が付いた。リポジトリ本体は不変 |
| 8 | RDS の提供状況（`oic`・読み取りのみ） | PostgreSQL 18 系は 18.1・18.2・18.3・18.4・18.6。ファミリは `postgres18`。18.6 の `db.t4g.micro` で `gp3` と暗号化が使える |
| 9 | ElastiCache の提供状況（同） | Redis は 7.1 まで（4.0.10・5.0.6・6.0・6.2・7.0・7.1）。7.1 のファミリは `redis7` |
| 10 | 出力・接続情報 | モジュールの出力（`address`・`username`・`db_name`・`primary_endpoint_address`）は変えていない。環境の出力 10 個も不変 |
| 11 | バージョンとファミリの整合 | 作業用コピーで RDS のバージョンを `17.9` にして `plan` すると、グループ名 `naw-fastapi-pg17`、ファミリ `postgres17`、DB のパラメータグループも `pg17` になる（食い違わない。マイナー付きの指定でもメジャーが取れる） |
| 12 | 秘密の混入 | 追加行に 12 桁の数字・鍵の文字列なし |

## 未確認事項

- **`apply` していないため、次は未確認**: PostgreSQL 18 の RDS が、実際に作成できること（提供状況は確認したが、作成の成否は未確認）、暗号化・パラメータグループ付きで起動すること、Redis の暗号化付きの作成、ECR のライフサイクルポリシーの動作
- `apply` 後に決まる値と、ECS への接続情報の受け渡し（環境変数の `DATABASE_URL`・`REDIS_URL`）の実接続は、未確認
- 費用: 暗号化・パラメータグループに追加費用はない見込みだが、バックアップ保管量などの実額は未確認（単価を確認できていない）
