# 学習データファイルの「リンク時の表示名」が常に空欄になり編集が保存できない

## 概要

GitHub Issue #177 の内容を転記する。

## 説明

### 概要
学習データファイルの一覧・編集画面で「リンク時の表示名」列/フィールドが常に空欄になる。編集モーダルでは必須項目のため、表示名以外を変更していなくても保存ボタンがフォームバリデーションエラーで無反応になり、変更を保存できない。

### 原因
- バックエンド`backend/app/schemas/file.py`の`FileResponse`（11〜27行目）はファイル名を`fileName`というフィールド名で返す
- フロントエンド`frontend-angular/src/app/features/admin/management/training-data/utils/training-api-normalize.ts`の`springFileRowToTrainingDataFile()`（147行目〜）は`row.name`を参照しており、`row.fileName`を見ていないため常に空文字になる
- `training-data-detail/components/local-view/local-view.component.ts`の`initEditForm()`（344行目〜）は`name: [file?.name || '', [Validators.required, ...]]`として編集フォームの「リンク時の表示名」を必須項目として初期化するが、上記の理由で常に空文字が入り、ユーザーが手動で入力し直さない限り`onSubmitEditData()`（566行目〜）の`isEditFormValid()`チェックで弾かれ、保存処理（`store.updateFile`のAPI呼び出し）に到達しない

### 発見経緯
Issue #166（E2Eテスト自動化）の17_学習データカテゴリ実装中、「行メニューから学習データの設定を編集して保存する」のE2Eテスト作成時に発見。表示名だけを変更して保存ボタンを押してもネットワークタブにPATCHリクエストが一切発生せず、原因を追ったところ「リンク時の表示名」欄が常に空欄であることが判明した。

### 対応方針案
`springFileRowToTrainingDataFile()`で`row.fileName`を読むように修正する（`SpringFileRow`インターフェースの`name`フィールドも`fileName`に合わせて修正、またはバックエンド側のレスポンスフィールド名を`name`に統一するかは要検討）。

### 本Issueでは対応しない
Issue #166はE2Eテスト自動化基盤の整備が目的のため、本バグの修正はこのIssueのスコープ外とする。「行メニューから学習データの設定を編集」のE2Eテストケースは`test.skip`としてこのIssueへの参照コメントを残す。
