# Bedrock（Claude）の呼び出しで x-api-key を送らず Bearer だけにする

## 概要

#436 で追加した Bedrock（Claude）の呼び出しが、認証のヘッダーを 2 種類（`x-api-key` と `Authorization: Bearer`）送っており、Bedrock Mantle に拒否される。Bearer だけを送るように直す。

## 説明

- 実機（`https://bedrock-mantle.ap-northeast-1.api.aws/anthropic/v1/messages`、`anthropic.claude-haiku-4-5`）で確かめた結果
  - 2 種類を両方送ると、401 `authentication_error`（`request must not include both 'authorization' and 'x-api-key' headers`）
  - `Authorization: Bearer` だけを送ると、200 で回答が返る
- #436 の設計では、実機で確かめられないため両方を送り、「どちらか一方だけが必要な場合も、もう一方は無視される想定」としていた。この想定が誤りだった
- 現状のまま Bedrock（Claude）を使うと、回答の生成が必ず失敗する
