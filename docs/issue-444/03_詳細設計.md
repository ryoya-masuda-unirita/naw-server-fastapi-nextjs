## 変更の中身

`request_target` が返すヘッダーを、次の 3 つにする。

```python
headers = {
    "Authorization": f"Bearer {api_key}",
    "anthropic-version": ANTHROPIC_VERSION,
    "content-type": "application/json",
}
```

- URL の組み立て、本文、回答の読み取りは変えない
- `request_target` の呼び出し元は、戻り値の形（URL とヘッダーの組）が変わらないため、変更しない

## 不要コードの確認

- `x-api-key` を扱っているのは `request_target` だけ。他に孤立するコードはない（grep で確認済み。残りはテストのみ）

## 実機の確認（ユーザーが行う）

- Bearer だけで Mantle が 200 を返すことは、`curl` で確認済み。実装後に、`onprem/` の手順（Bedrock の RAG）で通しの確認を残す
