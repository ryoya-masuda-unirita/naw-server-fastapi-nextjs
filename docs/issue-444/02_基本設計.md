# 02_基本設計

## 変更対象

- 回答の生成で Bedrock（Claude）を呼ぶ部品の、認証ヘッダーの組み立て
- そのヘッダーを確かめている、core・waha-emulator のテスト
- #436 の設計書と、アダプタの README の認証に関する記述

## 画面 / API 変更概要

- 画面・外部 API の変更はない
- Bedrock Mantle へ送るリクエストから、キー用ヘッダーをなくす。Bearer・バージョン・content-type は残す

## 影響範囲

- Bedrock（Claude）を使うワークフローだけ。他のプロバイダと、#439 の埋め込みは変わらない
- 設定の項目（URL・API_KEY・MODEL_NAME）と、ワークフロー定義は変わらない
- 既存の利用者への影響はない。現状は 401 で失敗するため、動いていた使い方がない

## 移植方針

- 移植元にない Python 版だけの拡張なので、移植元との突き合わせは要らない
- 実機で確かめた結果（Bearer だけで 200、両方で 401）を、設計の根拠にする
- キー用ヘッダーを「付けない」ことを、テストで明示的に確かめる（#439 の埋め込みのテストと同じ形）
- #436 の設計書には、誤りだった想定を消さずに、実機で確かめた結果で訂正した旨を残す
