# #246 issue-246 ファイル一覧のupdatedAtToを排他にし日時の解釈を移植元に揃える

## 概要

ファイル一覧（`GET /api/admin/indexes/{indexId}/files`）の `updatedAtTo` が、その時刻ちょうどのデータを含む（`File.updated_at <= updated_at_to`）。

移植元は NAW-1334（977fffd0）で次のように変わっている。

- 終了は排他（`lessThan`）。日の区切り（0:00）を終了にしたとき、その時刻ちょうどのデータが前の日に入らないようにするため（`service/FileService.java`）
- オフセットのない日時は 400（`util/DateParseUtil.java`）

backend は境界を含み、日付だけの値やオフセットのない日時も受け付ける。

## 説明

移植元の `FileService` / `DateParseUtil` / Controller を確認し、`updatedAtFrom` / `updatedAtTo` の解釈と境界を揃える。ほかに同じ日時パラメータを使う API があれば横展開する。
