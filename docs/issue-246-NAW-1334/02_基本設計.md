# 02_基本設計

## 変更対象

- 日時パラメータを解釈する共通処理（移植元の日時解釈ユーティリティに相当）を新設する
- ファイル一覧 API の更新日時パラメータの受け取りと絞り込み条件
- 管理者向けルーム履歴一覧 API の作成日時パラメータの受け取りと絞り込み条件

## 画面 / API 変更概要

| API | パラメータ | 変更前 | 変更後 |
|---|---|---|---|
| ファイル一覧 | 更新日時の開始・終了 | 日付だけ・オフセットなしも受け付ける。終了を含む | オフセット付きの日時だけ。終了は含まない |
| 管理者向けルーム履歴一覧 | 作成日時の開始・終了 | 日付だけを受け付け、終了日の終わりまで含む | オフセット付きの日時だけ。終了は含まない |

不正な値のときは 400 と移植元と同じメッセージを返す。

## 影響範囲

- 上記 2 API の利用者（現状 React 画面からの利用はない）
- ルーム履歴一覧の日付だけの指定は受け付けなくなる（移植元と同じ）

## 移植方針

- 移植元の日時解釈ユーティリティと同じく、未指定・空文字は「指定なし」、それ以外は絶対時刻へ変換し、変換できなければパラメータ名入りのメッセージで 400 を返す
- 移植元と同じく、パラメータの解釈は Controller 相当で行い、Service 以降には日時を渡す
- 絞り込み条件は移植元 Service と同じく、開始は以上、終了は未満にする
