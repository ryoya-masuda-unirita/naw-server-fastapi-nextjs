# 01_要件定義

## 背景

移植元は NAW-1334 で、期間絞り込みの日時パラメータを「オフセット付きの ISO 8601 の日時だけを受け付け、終了はその時刻より前（排他）」に改めた。画面は利用者のタイムゾーンの 0:00 から「終了日の翌日 0:00」までを UTC の日時で送るため、終了を含むと翌日 0:00 ちょうどのデータが前の日の範囲に入ってしまう。

backend のファイル一覧は終了を含み、日付だけの値・オフセットのない日時も受け付けている。管理者向けルーム履歴一覧の作成日時の絞り込みも、移植元は同じ解釈（オフセット付き日時・終了は排他）だが、backend は日付だけを受け付けて終了日の終わりまでを含める旧仕様のままである。

## 機能要件

1. ファイル一覧の更新日時の絞り込みを、開始は「その時刻以降」、終了は「その時刻より前」で判定する
2. ファイル一覧の更新日時の開始・終了は、末尾が `Z`、または `+09:00` のようなオフセットを持つ ISO 8601 の日時だけを受け付ける
3. 日付だけの値・オフセットのない日時・日時として解釈できない値は 400 とし、メッセージは移植元と同じ「`{パラメータ名} は 2026-10-08T15:00:00Z のような ISO 8601 の日時で指定してください`」とする
4. 値が未指定・空文字（空白だけを含む）のときは絞り込まない
5. 管理者向けルーム履歴一覧の作成日時の開始・終了にも 1〜4 を同じく適用する（横展開）

## 非機能要件

- 異なるオフセットで指定された日時も、同じ時刻（絶対時刻）として比較できること
- エラー応答の形は既存の共通エラー形式（`timestamp`・`message`）に従う

## スコープ外

- 画面（frontend）の変更。React 側にはこれらのパラメータを送る画面がまだない
- 上記以外の API の日時パラメータ（移植元で同じ解釈を使うのは上記 2 API だけ）
