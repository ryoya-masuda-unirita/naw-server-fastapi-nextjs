# 05_テスト詳細設計

本チケットはCIワークフローの追加であり、新規のpytestテストコードは追加しない。動作確認は以下の手順で行う。

## ローカルでの事前確認コマンド

```bash
cd backend
mv .env /tmp/env-backup 2>/dev/null  # 既存の.envを退避
cp .env.example .env
uv sync
uv run pytest tests/unit -q
uv run pytest tests/unit tests/integration -q
rm .env
mv /tmp/env-backup .env 2>/dev/null  # 退避した.envを復元
```

## GitHub Actions上での確認

- `feature/issue-32`ブランチへのプッシュ後、GitHub ActionsのWorkflow実行一覧で`unit-tests`ジョブが成功し、`integration-tests`ジョブがスキップ（`develop`ブランチでないため）されることを確認する
- PRマージ後、`develop`ブランチへのプッシュで`unit-tests`・`integration-tests`両方が実行され成功することを確認する（`08_動作確認.md`に実行結果へのリンクを記載する）
