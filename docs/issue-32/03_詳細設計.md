## `.github/workflows/backend-tests.yml`

```yaml
name: Backend Tests

on:
  push:
    paths:
      - "backend/**"
      - ".github/workflows/backend-tests.yml"

jobs:
  unit-tests:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: backend
    steps:
      - uses: actions/checkout@v4

      - name: Install uv
        uses: astral-sh/setup-uv@v3
        with:
          enable-cache: true

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Prepare .env
        run: cp .env.example .env

      - name: Install dependencies
        run: uv sync

      - name: Run unit tests
        run: uv run pytest tests/unit -q

  integration-tests:
    if: github.ref == 'refs/heads/develop'
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: backend
    steps:
      - uses: actions/checkout@v4

      - name: Install uv
        uses: astral-sh/setup-uv@v3
        with:
          enable-cache: true

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Prepare .env
        run: cp .env.example .env

      - name: Install dependencies
        run: uv sync

      - name: Run unit and integration tests
        run: uv run pytest tests/unit tests/integration -q
```

## 実装時の確認事項

- `astral-sh/setup-uv@v3`のバージョンはPR作成前に最新の安定版タグを確認して合わせる
- `uv sync`が`backend/pyproject.toml`・`backend/uv.lock`を正しく参照できるよう、`working-directory: backend`をジョブ全体のdefaultsとして設定する
- ワークフロー自体の追加は`backend/**`の変更を伴わないため、`paths`フィルタに`.github/workflows/backend-tests.yml`自体も含めて、ワークフロー修正時にも動作確認できるようにする
