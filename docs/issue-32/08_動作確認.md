# 動作確認

## 前提条件

- `.github/workflows/backend-tests.yml`を`feature/issue-32`ブランチにプッシュし、GitHub Actions上での実行結果を確認した

---

## ローカルでの事前確認

```
$ cp .env.example .env
$ uv run pytest tests/unit -q
66 passed, 16 warnings in 8.46s

$ uv run pytest tests/unit tests/integration -q
160 passed, 165 warnings in 16.26s
```

`.env`なしでも`.env.example`をコピーするだけで単体・結合とも全件成功することを確認した。

---

## GitHub Actionsでの確認

### Step 1: feature branchへのプッシュ（1回目・失敗）

`astral-sh/setup-uv@v8`というタグが存在せず失敗（[Run #28771215046](https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/actions/runs/28771215046)）。実在する最新版`v8.3.0`に修正した。

### Step 2: feature branchへのプッシュ（2回目・成功）

修正後、[Run #28771321649](https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/actions/runs/28771321649)で以下を確認した。

| ジョブ | 結果 |
|---|---|
| `unit-tests` | ✅ success |
| `integration-tests` | ⏭️ skipped（`develop`ブランチでないため） |

想定通り、feature branchへのプッシュでは単体テストのみが実行され、結合テストはスキップされることを確認した。

### Step 3: developへのマージ後の確認（PRマージ後に実施）

PRが`develop`にマージされた後、`develop`ブランチへのプッシュで`unit-tests`・`integration-tests`両方が実行され成功することを確認する（マージ後に別途報告する）。

---

## 結論

- feature branchへのプッシュで単体テストのみが実行されることを実機確認した
- `develop`へのマージ後の結合テスト実行確認は、マージ後に追って報告する
