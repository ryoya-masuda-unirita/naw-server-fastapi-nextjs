## 発見して直したこと

- `waha-emulator/tests/conftest.py` が、`"server-local"` というスラッシュなしの文字列でパスを組み立てていた。置き換えの対象から漏れていたので手で直した。
- `git mv` で `.venv` も一緒に動いたため、`server/`・`secuaigent-server-local/` の `.venv` を作り直した。pre-commit のフックも新しい `.venv` を指すよう入れ直した（ローカルのみの作業）。

`chat-history-detail.test.tsx` が、全体を実行したときだけ失敗した（実行ごとに 32 件→1 件→2 件と変わった）。単独で実行すると 8 件すべて成功する。並行して他のテストを動かしたときの負荷による不安定さで、リネームとは無関係と判断した。
