# ディレクトリ名を移植元に合わせる

## 概要

トップレベルのディレクトリ名を、移植元（`secuaigent` モノレポ）の名前に合わせる。移植元に対応がないディレクトリはそのままにする。

## 説明

| 今 | 変更後 |
|---|---|
| `backend/` | `server/` |
| `frontend/` | `client/` |
| `infra/` | `secuaigent-infra/` |
| `server-local/` | `secuaigent-server-local/` |

`generative-ai-adapter/` は既に一致している。`waha-emulator/`・`e2e-explorer/` は移植元がないのでそのまま。

Issue: https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/issues/399

## その他

- 全モジュールに影響するため、他のブランチと競合しやすい
- `docs/issue-*` は過去の記録なので、旧パスのまま書き換えない
