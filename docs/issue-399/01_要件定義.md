# 01_要件定義

## 背景

移植先のトップレベルのディレクトリ名が、移植元と違うため、どれがどれの移植先か分かりにくい。名前を揃えて、対応関係を一目で分かるようにする。

## 機能要件

- 4つのディレクトリの名前を、移植元に合わせて変更する
- 名前の変更で、ビルド・テスト・CI・デプロイ・ローカル起動が壊れない
- 旧名を参照している箇所（CI、docker compose、Terraform、スクリプト、AI 向けドキュメント、skill）を、新しい名前に直す
- ファイルの履歴を保つ（移動として記録する）

## 非機能要件

- 変更は名前と参照の置き換えだけにする。ロジック・仕様は変えない
- 旧名がリポジトリに残らない（過去の記録 `docs/issue-*` は除く）
- 1つの PR で全部を直し、PR の途中で CI が壊れた状態を残さない

## スコープ外

- `waha-emulator/`・`e2e-explorer/`・`generative-ai-adapter/` の名前変更
- ディレクトリ内のサブディレクトリやファイル名を移植元に合わせること
- Python パッケージ名、Terraform の state・リソース名の変更
- `docs/issue-*` の書き換え
