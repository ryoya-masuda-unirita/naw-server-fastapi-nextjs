# ワークフローエディターで、実際にワークフローを組めるようにする

## 概要

ワークフローエディター（`waha-emulator/ui/`）で、実際にワークフローを組めるようにする。今は「開始 →（検索 →）生成AI → 終了」の 1 本の鎖に固定で、ノードも、足せるのは検索だけ。Dify のように、ノードを自由に足してつなぎ、その場で動かして確かめられる画面にする。

## 説明

### 背景

- #520〜#524 で、保存・実行・画面・compose への組み込みまではできたが、組める形が固定の鎖だけで、「ワークフローを組んでいる」感じにならない
- 画面で組んでも、確かめる手段が、画面の外の `curl` しかなく、使い方も分からない

### 最初に組みたいワークフロー（ユーザーが選んだもの）

1. **推敲**: 質問 → 生成AI①（下書き）→ 生成AI②（下書きを推敲）→ 回答
2. **根拠チェック付きの RAG**: 質問 → 検索 → 生成AI（根拠つきで回答）→ 生成AI（回答が、引用した文書に書いてあるかを判定）→ 合格なら回答、不合格なら「分かりません」

要件・設計は、この 2 つが動くことを軸に決める。詳細は `01_要件定義.md`。
