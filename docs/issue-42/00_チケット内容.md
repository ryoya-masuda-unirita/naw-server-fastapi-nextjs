# アシスタント管理API（管理者向け）の実装

## 概要

アシスタント（Assistant）の管理者向けCRUD APIをFastAPIで実装する。移植元 `AssistantController` のうち、一般ユーザー向け一覧取得（`GET /api/assistants`）以外の管理者向けエンドポイント一式が対象。

## 説明

### 背景

issue-24（Group管理API）〜issue-40（AssistantCategory管理API）までで、Group・PromptTemplate・TenantEndpoint・AssistantCategoryの管理APIが完了した。Assistant自体は issue-26 で一般ユーザー向け一覧取得（`GET /api/assistants`）のみ実装済みで、管理者向けの作成・更新・削除・一覧はまだ移植されていない。

`assistant.py` のコメントにあるとおり、`assistants_endpoints`（issue-30で対応済み）以外に `assistant_category_mappings`（Assistant↔AssistantCategoryのM2M）が未実装のまま残っている。AssistantCategory本体（issue-40）が完了したことで、この紐付けに着手できる状態になった。

### やること（今回のスコープ）

移植元 `~/Documents/naw-server` の `AssistantController` のうち、以下を移植する。

- `POST /api/admin/assistants`（作成）
- `PATCH /api/admin/assistants/{id}`（更新）
- `DELETE /api/admin/assistants/{id}`（削除。デフォルトアシスタントとしてルームから使用中の場合は409）
- `GET /api/admin/assistants`（管理者向け一覧。ページネーション・検索・種別/カテゴリ/グループでのフィルタ）
- `GET /api/admin/assistants/endpoints/{type}`（種別ごとのエンドポイント一覧）
- `GET /api/admin/assistants/AIModels`（AIモデル一覧。`AIModelEntity`のFastAPI移植を含む）
- `assistant_category_mappings`テーブル・モデルの新規作成とAssistant作成・更新時のカテゴリ紐付け

バリデーション内容（表示名・接続サーバー・エンドポイント・モデル・説明の長さ等）は `AssistantCreateRequest`・`AssistantUpdateRequest`・`AssistantCreateRequestValidator` を確認して移植する。

### スコープ外

- 一般ユーザー向け一覧取得（`GET /api/assistants`）: issue-26で対応済み
- `assistants_endpoints`紐付け: issue-30で対応済み
- room（チャット本体）からのアシスタント参照・削除時の影響範囲: 別チケット
