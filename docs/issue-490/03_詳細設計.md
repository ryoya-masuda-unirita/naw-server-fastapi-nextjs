## 設計上の注意

- `useTranslation` を `ContextMenu` に足す。`react-i18next` のテストの既定の振る舞い（キーがそのまま出る）に従う
- `useId` の id（例: `:r1:`）は、`htmlFor` と `id` に使える。DOM の id を前提にした CSS・テストは、探索で確認する（`id` が空だった入力欄にだけ付く）
- `menuitem` を付けると、テストの `getByRole('button', { name })` は、`getByRole('menuitem', { name })` にしないと取得できなくなる。該当するテストだけを直す
