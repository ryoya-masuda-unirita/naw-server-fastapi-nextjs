# 03_詳細設計

## 実装対象ファイル

- 実装コードの変更なし（`backend/app/models/message.py`・`backend/app/models/room.py`・Alembicマイグレーションのいずれも、既に必要なFK制約が実装済みのため変更不要）
- `backend/tests/integration/test_assistants.py`: 回帰テストを1件追加

## 追加テストの内容

`TestDeleteAssistant` クラスに以下のテストを追加する。

```python
async def test_delete_assistant_keeps_messages_and_sets_assistant_id_null(
    self, client, session, admin_headers, tenant, member_user, assistant,
):
    """アシスタント削除時、そのアシスタントを使用したメッセージは削除されず、
    assistant_idがNULLになること（NAW-1192）"""
```

### 検証手順

1. 削除対象アシスタント（`assistant` フィクスチャ）とは別の `other_assistant` を作成する
2. `other_assistant` を `default_assistant_id` に持つ `Room` を作成する（削除対象アシスタントを `rooms.default_assistant_id` の RESTRICT 制約で参照させないため）
3. その `Room` に紐づく `Message` を作成し、`assistant_id` に削除対象アシスタントのIDを設定する
4. `DELETE /api/admin/assistants/{assistant.id}` を呼び出す
5. レスポンスが `204 No Content` であることを確認する（メッセージが存在してもRESTRICTにならないこと）
6. `Message` を再取得し、`assistant_id` が `None`（DB上は `NULL`）になっていることを確認する

## 影響範囲

- 新規テストの追加のみ。既存コード・既存テストへの変更はない
