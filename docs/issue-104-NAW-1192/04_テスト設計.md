# 04_テスト設計

## テスト方針

実装コードの変更を伴わないため、既存のFK制約が仕様通り機能していることを検証する回帰テストを追加する。既存のアシスタント削除関連テスト（`TestDeleteAssistant`）に統合テストとして追加し、実際のPostgreSQLのFK制約（`ON DELETE SET NULL` / `ON DELETE RESTRICT`）を用いて検証する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | アシスタント削除時のメッセージ保持 | 削除対象アシスタントを使用するメッセージが存在し、そのメッセージが属するルームのデフォルトアシスタントは別のアシスタントである | 削除は成功（204）し、メッセージは削除されず `assistant_id` が `NULL` になる |
| 2（既存） | デフォルトアシスタント使用中の削除拒否 | 削除対象アシスタントが、あるルームの `default_assistant_id` として参照されている | 400 Bad Request で削除が拒否される |
| 3（既存） | 未参照アシスタントの削除 | どのルームからも参照されていないアシスタント | 204で削除できる |
| 4（既存） | 存在しないアシスタントの削除 | 存在しないID | 404 |
