# #104 issue-104 NAW-1192 アシスタント削除時のチャット全消去バグ修正

## 概要

NAW-1192の移植。アシスタント削除時に、そのアシスタントを使ったチャットが全消去される不具合を修正する（FK制約変更を含む）。

## 説明

naw-server側でLiquibase changelog・エンティティのFK制約を変更する修正が入っているが、FastAPI側の`models/message.py`に対応する変更が見当たらず未反映、というのが起票時点の認識だった。

- 元チケット: NAW-1192
- 移植元（バックエンド）: naw-server コミット `2027e2cbab6283f7fb95e2724645a5f102519f48`
- 移植先: `backend/app/models/message.py`（および対応するAlembicマイグレーション）
- 参照調査: `docs/調査結果/20260711.md`（4章 項目9）

## その他

着手時点の詳細調査の結果、起票時の認識と異なり、FastAPI側は既に本修正相当のFK制約（`messages.assistant_id` を `ON DELETE SET NULL`、`rooms.default_assistant_id` を `ON DELETE RESTRICT`）で実装済みであることが判明した。詳細は `01_要件定義.md` 以降に記載する。
