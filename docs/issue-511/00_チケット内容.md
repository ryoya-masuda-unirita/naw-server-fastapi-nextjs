# ルート README を、短く読みやすく書き直す

## 概要

ルート `README.md`（現在 218 行）を、最初から最後まで書き直す。最初に開く README なのに、長く、読みにくく、読む気になれない。**1 画面ちょっとで読み切れ、目的の手順へすぐ着ける**形にする。

## 説明

- 長い。画面を見る手順・アシスタントの通信経路・Waha! エミュレーター・オンプレ・E2E 探索・ローカル疎通確認が 1 つに混ざっている
- 読みにくい。段落や表が密で、内部の用語・Issue 番号・経緯の注記が多い
- 読みたくない。最初に何をすればよいかが、見ただけでは分からない
- 期待する状態: ルート README が 80 行以内。先頭の数行で「何のリポジトリか」「まず何をするか」が分かる。書いてある手順が、そのまま動く。移した内容が、移し先から読める（リンク切れなし）
