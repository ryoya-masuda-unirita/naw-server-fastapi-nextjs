## 詳細

### 1. ユーザー情報を消さない（🟡）→ 対応しない

移植元は消したあとにサブドメイン由来のテナントでセッションを取り直して元に戻る。React はその復元が成り立たないので、消さずに保つのが同じ結果になる。セッションが無効なら、続く `GET /api/auth` の失敗で `ensureInitialized` がユーザー情報を消す。未ログインで失敗した場合は、そもそもユーザー情報がない。

### 2. トーストの表示タイミング（🔵）→ 対応しない

トーストはストアに積まれ、`ToastContainer` が描画された時点で表示される（表示時間は 5 秒）。初期化は短時間で終わるため E2E（03-23）で表示を確認できている。
