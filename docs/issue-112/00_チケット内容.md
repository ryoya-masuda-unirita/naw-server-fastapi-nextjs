# #112 issue-112 Group一覧APIのassistants/assistantIds/promptTemplates実データ配線

## 概要

`GET /api/groups` のレスポンスにある `assistants`/`assistantIds`/`promptTemplates`/`promptTemplateIds` フィールドが常に空リストになっている問題を修正する。

## 説明

- issue-69/70（Group×Assistant/PromptTemplate紐付け管理API）でGroupAssistant/GroupPromptTemplateリポジトリは整備済みだが、Group一覧レスポンスへの実データ配線自体はスコープ外として残されていた。
- 移植元: `~/Documents/naw-server/src/main/java/com/example/naw/response/GroupListResponse.java`（`GroupController.getGroups`, `GET /api/groups`）が `GroupAssistant`/`GroupPromptTemplate` から実データを組み立てて返している。
- 移植先: `backend/app/schemas/group.py` の `GroupListItemResponse` はコメントで「未実装ドメインのため常に空リスト」と明記されたまま。`backend/app/services/group_service.py` の `GroupService._to_list_item`（L129-156付近）が常に空リストを返している。
- 依存先の `GroupAssistantRepository`/`GroupPromptTemplateRepository` には既にIN句一括取得メソッドがあり、N+1回避の土台は揃っている。
