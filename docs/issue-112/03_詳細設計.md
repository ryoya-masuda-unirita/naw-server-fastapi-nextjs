### `backend/app/repositories/group_assistant_repository.py`

`GroupAssistantRepository` に以下を追加する。

```python
@staticmethod
async def find_grouped_by_group_ids(
    group_ids: list[str], tenant_id: str, session: AsyncSession
) -> dict[str, list[tuple[str, str]]]:
    """グループID一覧に対して、それぞれに紐づくアシスタント (id, name) 一覧を1クエリでまとめて取得する。

    グループごとに個別クエリを発行するとN+1になるため、対象グループID一覧に対する
    (group_id, assistant_id, assistant_name) の組を1クエリで取得しPython側で集約する。

    Args:
        group_ids: 対象のグループID一覧。
        tenant_id: テナントID。
        session: 非同期DBセッション。

    Returns:
        グループIDをキーとした (アシスタントID, アシスタント名) 一覧の辞書。
    """
    if not group_ids:
        return {}
    stmt = (
        select(GroupAssistant.group_id, Assistant.id, Assistant.name)
        .join(Assistant, Assistant.id == GroupAssistant.assistant_id)
        .where(
            GroupAssistant.group_id.in_(group_ids),
            GroupAssistant.tenant_id == tenant_id,
        )
    )
    result = await session.execute(stmt)

    grouped: dict[str, list[tuple[str, str]]] = {gid: [] for gid in group_ids}
    for group_id, assistant_id, assistant_name in result.all():
        grouped[group_id].append((assistant_id, assistant_name))
    return grouped
```

### `backend/app/services/group_service.py`

`_to_list_item` のシグネチャを変更し、事前に一括取得したマップを受け取るようにする。

```python
@staticmethod
async def _to_list_item(
    group: Group,
    session: AsyncSession,
    assistant_map: dict[str, list[tuple[str, str]]],
    template_map: dict[str, list[tuple[str, str]]],
) -> GroupListItemResponse:
    """GroupをGroupListItemResponseに変換する（所属ユーザーを結合して取得する）。

    Args:
        group: 変換対象のGroup。
        session: 非同期DBセッション。
        assistant_map: グループIDをキーとした (アシスタントID, アシスタント名) 一覧の辞書
            （呼び出し側でグループID一覧を一括取得したもの）。
        template_map: グループIDをキーとした (プロンプトテンプレートID, プロンプトテンプレート名) 一覧の辞書
            （呼び出し側でグループID一覧を一括取得したもの）。

    Returns:
        グループ一覧の1件分のレスポンス。
    """
    rows = await GroupUserRepository.find_by_group(
        group.id, group.tenant_id, session
    )
    users = [user for _, user in rows]
    admins = [user for group_user, user in rows if group_user.is_admin]
    assistant_pairs = assistant_map.get(group.id, [])
    template_pairs = template_map.get(group.id, [])
    return GroupListItemResponse(
        id=group.id,
        tenantId=group.tenant_id,
        name=group.name,
        users=[str(u.id) for u in users],
        adminUserIds=[str(u.id) for u in admins],
        adminUserNames=[u.name for u in admins],
        userNames=[u.name for u in users],
        assistants=[name for _, name in assistant_pairs],
        assistantIds=[aid for aid, _ in assistant_pairs],
        promptTemplates=[name for _, name in template_pairs],
        promptTemplateIds=[tid for tid, _ in template_pairs],
        updatedAt=group.updated_at,
    )
```

呼び出し元の `get_groups`・`list_groups` で、グループ一覧取得後にグループID一覧をまとめて `GroupAssistantRepository.find_grouped_by_group_ids` / `GroupPromptTemplateRepository.find_grouped_by_group_ids` に渡し、結果のマップを `_to_list_item` に渡す。

```python
group_ids = [g.id for g in groups]
assistant_map = await GroupAssistantRepository.find_grouped_by_group_ids(
    group_ids, tenant_id, session
)
template_map = await GroupPromptTemplateRepository.find_grouped_by_group_ids(
    group_ids, tenant_id, session
)
return [
    await GroupService._to_list_item(g, session, assistant_map, template_map)
    for g in groups
]
```

## 補足

- `users`/`userNames`/`adminUserIds`/`adminUserNames`（`GroupUserRepository.find_by_group`のグループごとの呼び出し）は既存のN+1構造のままとする（本Issueのスコープ外）。
- 移植元Javaは `Set<String>` で重複排除しているが、FastAPI側の中間テーブルはグループ・アシスタント間で一意制約があるため（`GroupAssistantRepository.find_one`が単一組み合わせを前提にしている）、重複は発生しない。`list[str]` のまま順序を保持する形で問題ない。
