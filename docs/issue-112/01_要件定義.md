# 01_要件定義

## 背景

Group一覧APIのレスポンスには、グループに紐づくアシスタント・プロンプトテンプレートの情報を返すフィールド（ID一覧・名前一覧）が用意されているが、移植先では常に空リストを返しており、移植元の挙動と一致していない。

## 機能要件

- グループ一覧取得時に、各グループに紐づくアシスタントのID一覧・名前一覧を実データで返す
- グループ一覧取得時に、各グループに紐づくプロンプトテンプレートのID一覧・名前一覧を実データで返す
- 対象は一般ユーザー向け一覧（`GET /api/groups`）・管理者向けページネーション一覧（`GET /api/admin/groups`, `GET /api/admin/all-groups`）の両方（いずれも同じ`GroupListItemResponse`を使うため）
- 複数グループを一覧取得する際、グループ数に比例したクエリ発行（N+1）を発生させない

## 非機能要件

- 既存のIN句一括取得の設計方針（`find_groups_grouped_by_template_ids`等）を踏襲し、グループID一覧に対する紐付けデータを1クエリでまとめて取得しPython側で集約する

## スコープ外

- グループ所属ユーザー一覧（`users`/`userNames`/`adminUserIds`/`adminUserNames`）の取得ロジックの変更（既存のまま。本Issueのスコープ外）
- フロントエンド（`frontend/`）側の対応
