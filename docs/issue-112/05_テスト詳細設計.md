# 05_テスト詳細設計

## 対象ファイル

### `backend/tests/integration/repositories/test_group_assistant_repository.py`（既存ファイルにテストクラス追加）

- `TestFindGroupedByGroupIds`
    - `test_returns_assistant_pairs_grouped_by_group_id`: 複数グループにアシスタントが紐づいている状態でグループIDごとの(id, name)一覧が返ること
    - `test_returns_empty_list_for_group_without_assistants`: アシスタントが紐づいていないグループは空リストになること
    - `test_returns_empty_dict_for_empty_group_ids`: 空のグループID一覧を渡すと空辞書が返ること

### `backend/tests/integration/repositories/test_group_prompt_template_repository.py`（既存ファイルにテストクラス追加）

- `TestFindGroupedByGroupIds`
    - `test_returns_template_pairs_grouped_by_group_id`: 複数グループにプロンプトテンプレートが紐づいている状態でグループIDごとの(id, name)一覧が返ること
    - `test_returns_empty_list_for_group_without_templates`: テンプレートが紐づいていないグループは空リストになること

### `backend/tests/unit/routers/test_group_router.py`（既存ファイルにテストクラス・テストケース追加）

- `TestGetGroups`（既存クラスがあれば追加、なければ新設）
    - `test_returns_assistants_and_prompt_templates`: グループにアシスタント・プロンプトテンプレートが紐づいている状態でレスポンスに実データが含まれること
    - `test_returns_empty_lists_when_nothing_linked`: 何も紐づいていない場合は空リストのままであること
    - `test_multiple_groups_do_not_mix_data`: 複数グループの一覧取得で紐付けデータが混在しないこと

（実際のテストファイルパスは既存のテストコード構成に合わせて配置する。既存の同種テストが見つかった場合はそのファイルに追記する。）
