# 05_テスト詳細設計

## 対象ファイル

`backend/tests/integration/test_assistants.py`

## 変更内容

`TestDeleteAssistant` クラス内、`test_delete_assistant_returns_400_when_used_as_default_assistant_of_room` を以下に置き換える。

```python
async def test_delete_assistant_returns_409_when_used_as_default_assistant_of_room(
    self,
    client,
    session,
    admin_headers,
    tenant,
    member_user,
    assistant,
):
    """デフォルトアシスタントとして参照中のルームがある場合409になること"""
    session.add(
        Room(
            tenant_id=tenant.id,
            name="Referenced Room",
            default_assistant_id=assistant.id,
            user_id=member_user.id,
        )
    )
    await session.commit()

    async with client as c:
        response = await c.delete(
            f"/api/admin/assistants/{assistant.id}", headers=admin_headers
        )

    assert response.status_code == 409
    assert (
        response.json()["detail"]
        == "このアシスタントはルームのデフォルトアシスタントとして使用されているため削除できません。"
    )
```
