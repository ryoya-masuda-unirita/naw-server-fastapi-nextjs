# 03_詳細設計

## 実装対象ファイル

### `backend/app/services/assistant_service.py`

`delete_assistant` メソッドを以下のように修正する。

- docstringの「room（チャット本体）ドメインが未移植のため...409はここでは行わない」という記述を削除し、409を返す旨を明記する
- `IntegrityError` 捕捉時のレスポンスを `HTTP_400_BAD_REQUEST` → `HTTP_409_CONFLICT` に変更
- エラーメッセージを移植元 `AssistantInUseException.MESSAGE` に合わせて
  `"このアシスタントを使用中のルームが存在するため削除できません。"` →
  `"このアシスタントはルームのデフォルトアシスタントとして使用されているため削除できません。"` に変更
  （移植元は末尾に句点なしだが、本リポジトリの既存エラーメッセージ規約（他のHTTPExceptionのdetailは句点あり）に合わせて句点を付与する）

変更後イメージ:

```python
@staticmethod
async def delete_assistant(
    assistant_id: str, tenant_id: str, session: AsyncSession
) -> None:
    """アシスタントを削除する。

    いずれかのルームのデフォルトアシスタントとして使用中の場合、
    FK制約（`rooms.default_assistant_id` の `ON DELETE RESTRICT`）違反により
    `IntegrityError` が発生するため、これを捕捉してHTTP 409を返す。

    Args:
        assistant_id: 削除対象のアシスタントID。
        tenant_id: テナントID。
        session: 非同期DBセッション。

    Raises:
        HTTPException: 存在しない場合404を返す。
            いずれかのルームのデフォルトアシスタントとして使用中の場合409を返す。
    """
    assistant = await AssistantService._get_assistant_or_404(
        assistant_id, tenant_id, session
    )
    try:
        await AssistantRepository.delete(assistant, session)
    except IntegrityError as exc:
        await session.rollback()
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="このアシスタントはルームのデフォルトアシスタントとして使用されているため削除できません。",
        ) from exc
```
