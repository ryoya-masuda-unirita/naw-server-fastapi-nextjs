# 05_テスト詳細設計

## 実装対象ファイル

- `infra/acm.tf`（削除）
- `infra/cloudfront.tf`（`aliases`削除、`viewer_certificate`をデフォルト証明書に変更、Route53 Aレコード2件削除）
- `infra/main.tf`（`data "aws_route53_zone" "main"`削除、`us_east_1`プロバイダエイリアス削除）
- `infra/variables.tf`（`variable "domain_name"`削除）
- `infra/terraform.tfvars` / `infra/terraform.tfvars.example`（`domain_name`指定行削除）
- `infra/ecs.tf`（`CORS_ALLOWED_ORIGIN_REGEX`を空文字化、`CORS_ALLOWED_ORIGINS`をCloudFrontデフォルトドメイン参照に変更）
- `infra/README.md`（運用ドキュメント更新）

## 検証コマンド・確認内容

### `terraform fmt -check -recursive`（`infra/`直下で実行）

- 変更した`.tf`ファイルがTerraform標準フォーマットに従っていること

### `terraform validate`（`infra/`で実行）

- 構文エラー・未定義変数参照エラー（特に削除した`var.domain_name`）が出ないこと

### `terraform plan`（`infra/`で実行、AWS認証情報が必要）

- 削除対象として表示されること: `aws_acm_certificate.main`、`aws_route53_record.cert_validation`（各キー）、`aws_acm_certificate_validation.main`、`aws_route53_record.root`、`aws_route53_record.wildcard`
- 変更対象として表示されること: `aws_cloudfront_distribution.main`（`aliases`削除、証明書設定変更）、`aws_ecs_task_definition.backend`（`environment`のCORS関連値変更。ただし`lifecycle.ignore_changes = [container_definitions]`が設定されているため、実際のplan出力上は無視される可能性がある点に留意する）
- それ以外のリソース（VPC/ECS本体/RDS/ALB/S3/SQS等）に差分が出ないこと

## テストデータ

- 新規のテストデータ追加は不要
