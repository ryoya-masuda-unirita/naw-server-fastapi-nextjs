# 04_テスト設計

## テスト方針

- Vitest + React Testing Library + MSW。画面は `renderApp('/admin/tenant')`（ガード・レイアウト込み）で描画する
- i18n は未初期化のため `t()` はキーを返す。キーで検証する
- MSW の既定は `mocks/handlers/admin-tenant.ts`（テナント情報・請求期間・利用サマリー・履歴・エンドポイント）。テストごとに `server.use` で上書きする。`usage-limit` の既定は置かない（backend に無いため）

## テスト観点

- ヘッダー・タブ: テナント名、`tab` クエリの補完・不正値、タブ切替
- 利用状況: プラン名・利用量/上限・履歴の行、ドーナツの割合、請求期間の起算日を `from` にした取得、利用者の絞り込み、並べ替え、ページ送りと件数、0 件、利用制限パネルが出ないこと
- 名称変更: 現在の名前で開く・空/空白で保存不可、trim して送信・成功トースト・閉じる、失敗でトーストとダイアログ維持
- API設定: 行表示・LOCAL_SERVER 以外は無効の歯車、0 件、API キー生成（32 文字英数字）とコピー、作成（成功・失敗）、編集（API キーを作り直すまで保存不可）、削除（成功・失敗）
- 利用制限ダイアログ: 初期値、数字以外の除去と先頭 0 の除去、0 のエラー、空で保存不可、404 で失敗トーストとダイアログ維持、月間・日間の送信本文
- 純粋関数: mapper・並べ替えパラメータ・表示名・表示整形
