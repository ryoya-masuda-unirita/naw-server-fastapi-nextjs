# テナント管理画面をReactに移植する

## 概要

テナント管理画面（`/admin/tenant`。利用状況タブ・API設定タブ・ワークスペース名の変更ダイアログ）を Angular（`secuaigent/client` の `features/admin/management/tenant/`）から React（`frontend/`）に移植する。Issue #132。

## 説明

- 対象: `tenant.component`（シェル・タブ・名称変更）・`tabs/usage-tab`・`tabs/api-tab`・`components/add-api-dialog`・`components/usage-limit`・`services/tenant-api.service`（API・mapper）・`services/tenant-rename.service`・`services/tenant-usage-dialog.service`・`utils/user-display-name.util`
- 土台は #277（ルート・レイアウト）・#278（共通 UI）・#279（API パス・型・util）。作りは完成例の #124・#125・#122・#136 に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・ルートのパス・入力チェック）
- usage タブの上限更新（`PATCH /api/admin/tenants/{id}/usage-limit`）は移植元 server にも無い API（#281 で判断済み）。移植元の画面と同じ挙動（保存が失敗してトーストが出る）のまま移植する

## その他

- 移植先は Issue 本文の `routes/app/admin/tenant/` ではなく、#277 の仮ファイル `frontend/src/routes/admin/tenant/tenant.tsx`（export 名 `TenantPage` は維持）
- 部品は `frontend/src/components/features/admin/tenant/`
