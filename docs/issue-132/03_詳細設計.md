# 03_詳細設計

## 状態

- URL: `?tab=usage|api`（`useTabQueryParam`。未指定・不正値は `usage` に置換、履歴は増やさない）
- Zustand `useTenantUsageStore`: 利用履歴の `sortField`・`sortOrder`（初期 null＝作成日時の新しい順）・`page`（1 始まり）・`userFilter`。並べ替え・利用者を変えたら 1 ページ目へ戻す。画面を離れたら `reset`
- ダイアログの開閉・入力は各部品の `useState`。開いている間だけ描画し、開くたびに初期化する
- 名称変更の入力値だけは親（`TenantPage`）が持つ。移植元の `FormControl` が保存せず閉じても値を保ち、テナント名が変わるたびに上書きされるため

## 判断と理由（移植元との差・移植元どおりにした点）

1. 利用制限パネル（ワークスペース・ユーザー）: 移植元 `usage-tab.component.html` は 2 パネルをコメントアウトしており画面に出ない。ダイアログ（`UsageLimitDialog`）と更新（`useUpdateUsageLimit`）は移植し、`SHOW_USAGE_LIMIT_PANELS = false`（`tenant.constants.ts`）で非表示にした。移植元でコメントアウトが外れたら true にするだけで出る。保存は `PATCH .../usage-limit`（backend に無い・#281）で 404 になり、失敗トーストを出してダイアログを残す（移植元の本番と同じ）
2. 利用サマリーの「本日」区分: 移植元の `tokenUsageSummaryType` は常に `month` のまま変わらず使われないため、今月（請求期間）だけ移植した
3. 利用履歴の `to`: 移植元は条件が変わるたびの現在時刻。React は取得のたびに現在時刻を `queryFn` 内で作り、query key には入れない（key に入れると再描画のたびに取り直す）
4. 条件の保持: 移植元はルート提供のサービスが条件を持つため画面を開き直しても残るが、並べ替え・絞り込みの表示は初期に戻る。React は離れるときに `reset`（#124 と同じ判断）
5. ウィンドウフォーカスでの再取得は止める（#125・#136 と同じ。一覧がスピナーに替わるため）
6. エンドポイントの更新・作成・削除: 移植元どおり、テナント ID が無い・`LOCAL_SERVER` 以外のときは API を呼ばない（後者はトースト）。API の失敗はトーストを出して例外を投げ直し、ダイアログは開いたまま
7. API キー: backend は一覧・更新の応答に `apiKey` を返さない（移植元 server も `WRITE_ONLY` 相当）。編集ダイアログの `apiKey` は空で始まり、移植元どおり「生成」し直さないと保存できない
8. 日本語のハードコード: API 追加ダイアログ・上限編集ダイアログの一部（「APIの表示名」「任意」など）は移植元が i18n を使っていないため、そのまま移した
9. ダイアログの `maxWidth: '90vw'`・`showDivider`: 共通 `Dialog` に対応する prop がない（#124 と同じ）。幅は `min(800px, 90vw)`
10. 日時・数値の表示: 移植元の `DatePipe`（`yyyy/MM/dd HH:mm`・ローカル）と `DecimalPipe`（en-US）を `tenant-format.ts` で再現
11. ヘッダー: 移植元 `AdminPageShell` は `PageHeader` に `showActions=false`・`showBackButton=false` を渡す。React では呼び出し側で明示する
12. 「コピー」ボタン: 移植元は `app-button` のホストに `data-copy-btn` と `chat-message-action--copied` を付ける。`Button` はホストに属性を付けられないため、外側の `span` に付けた
13. モバイル下部固定の「APIを追加」: 移植元どおり `sp-fixed-btn`（本文の下余白は移植元も指定しない）

## backend の応答との突き合わせ（`docs/issue-279/api-backend-diff.md`）

- `GET /api/admin/tenants`: `subscription` は null あり、`plan` に `maxCreditsPerDay`・`alertPercentage`・`dailyAlertPercentage` が無い → 画面は `?.`・`?? 0`/null で吸収（日間上限・アラートは 0/空）
- `Endpoint.apiKey`: 無い → 上記 7
- `GET /api/admin/token-usages`: `size` は 100 まで、`orderBy` は `createdAt`・`totalTokens` のみ、期間は 31 日以内（請求期間は 1 か月）。画面の並べ替え項目は 2 つだけで収まる
- `GET /api/credit-usage/workspace`: 契約がないと `{}` → 起算日が無いので集計・履歴は取得しない
- `GET /api/admin/users`: `size` 最大 1000。500 件で取得（`page` を読む形の差は `normalizeAdminUsersListBody` が吸収）
