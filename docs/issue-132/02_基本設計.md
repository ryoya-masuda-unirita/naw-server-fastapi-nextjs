## API

| 操作 | API |
|---|---|
| テナント情報 | `GET /api/admin/tenants`（`tenantId`・`tenantName`・`subscription.plan`） |
| 名称変更 | `PATCH /api/admin/tenants/{tenantId}`（`{ tenantName }`） |
| 上限更新 | `PATCH /api/admin/tenants/{tenantId}/usage-limit`（backend に無い。404 で失敗トースト） |
| 請求期間 | `GET /api/credit-usage/workspace`（`periodFrom`・`nextBillingResetAt`） |
| 利用サマリー・履歴 | `GET /api/admin/token-usages/summary`・`GET /api/admin/token-usages`（`from`・`to`・`userId`・`page`・`size`・`orderBy`・`reverse`） |
| 利用者の選択肢 | `GET /api/admin/users`（`size=500`・`sort=name,asc`） |
| エンドポイント | `GET/POST /api/admin/tenants/{id}/endpoints`、`PATCH/DELETE /api/admin/tenants/{id}/endpoints/{endpointId}` |

## 移植方針

- NgRx / signal サービス → TanStack Query（`use-tenant.ts`）+ Zustand（`tenant-store.ts`）。ダイアログは `Dialog`（共通）で、開いている間だけ中身を描画する
- Angular の `MatDialog` + `ng-template` → 親が `useState` で開閉を持ち `Dialog` を描画
- 詳細な判断は `03_詳細設計.md`
