# 05_テスト詳細設計

## `backend/tests/unit/test_llm_client.py`（追加）

- `TestBuildResponsesTool`（新規テストクラス）
  - `test_web_search_tool`: `ToolConfig(name="web_search")` → `{"type": "web_search"}`
  - `test_mcp_tool_minimal_fields`: 必須項目のみの`mcp` → `server_label`/`server_url`のみを含む辞書
  - `test_mcp_tool_all_fields`: `authorization`/`headers`/`allowed_tools`/`require_approval`すべて指定 → 対応するキーがすべて含まれる
  - `test_unsupported_tool_name_raises`: 未対応のツール名 → `ValueError`
- `TestAzureLlmChatClient`に追加
  - `test_tools_none_uses_chat_completions`: `tools=None`（デフォルト）で呼ぶと`chat.completions.create`が呼ばれ`responses.create`は呼ばれないこと（既存テストの回帰確認を兼ねる）
  - `test_tools_specified_uses_responses_api`: `tools`指定で呼ぶと`responses.create`が呼ばれ、`tools`引数に変換済みツールが渡ること
  - `test_responses_api_yields_text_delta_then_usage`: `response.output_text.delta`イベント→`text_delta`、`response.completed`イベント→`input_tokens`/`output_tokens`をyieldすること（Responses APIストリームイベントは`type`属性を持つ`MagicMock`で模擬する）
  - `test_responses_api_passes_max_output_tokens_only_when_specified`: `max_tokens`未指定時は`max_output_tokens`をcreate呼び出しに含めないこと

## `backend/tests/unit/test_llm_chat_service.py`（追加）

- `test_passes_tools_to_llm_client`: `LlmChatRequest.tools`指定時、`AzureLlmChatClient.stream_chat`へ変換済み`tools`が渡ること
- `test_tools_none_by_default`: `tools`未指定時、`AzureLlmChatClient.stream_chat`へ`tools=None`が渡ること（回帰確認）

## `backend/tests/unit/test_message_service.py`（追加）

- `TestStreamMessageContent`配下に追加
  - `test_passes_tools_to_llm_client_for_saas_chat`: SAAS_CHATアシスタントで`tools`指定時、変換済み`tools`が渡ること
  - `test_passes_tools_to_llm_client_for_saas_rag`: SAAS_RAGアシスタントで`tools`指定時、変換済み`tools`が渡ること
  - `test_tools_none_by_default`: `tools`未指定時、`tools=None`が渡ること（回帰確認）
