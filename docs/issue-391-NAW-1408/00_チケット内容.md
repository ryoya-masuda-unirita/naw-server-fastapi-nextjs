# フィードバックのローカル学習先フォルダへの追加学習をローカル用サーバーへ送る（NAW-1408）

## 概要

フィードバック一覧（回答精度タブ・満足度タブ）で、ローカルの学習先フォルダを選んで追加学習するとき、クラウドではなくフォルダの接続先（ローカル用サーバー）へ送る。

## 説明

- GitHub Issue: #391（前提: #390 / NAW-1340。マージ済み）
- 移植元チケット: NAW-1408
- 移植元のコミット: c8f3dc951、443c1ec80 ほか
- 現状: `useAddAdditionalLearning` は常にクラウドの `/api/admin/indexes/{id}/additionalLearning` へ送る。backend は LOCAL のフォルダを 400 で断る
- やること（Issue 本文より）
  1. 追加学習の前に学習先フォルダを取り、LOCAL ならローカル用サーバーへ送る。フォルダの種類は持たず都度取る
  2. 回答精度・満足度の共通の振り分けを 1 か所にまとめる（移植元 `FeedbackLocalLearningService`）
  3. 対象は `feedbackId` か `roomId` のどちらか一方だけ送る
  4. ログイン中のユーザー ID が取れないときは `userId` なしで送らず失敗させる
  5. 接続先やユーザーが取れないなど HTTP 以外の失敗でもエラーを表示する
