# 03_詳細設計

## `feedback-local-learning.ts`

```ts
addIfLocalFolder(indexId: string, target: AdditionalLearningTarget, content: File): Promise<boolean>
```

1. `fetchTrainingFolder(indexId)` でフォルダを取る（キャッシュしない）
2. `folder.type !== 'LOCAL'` なら `false`
3. `useAuthStore.getState().user?.id` を `requireUserId` に通し、`viaLocalServer` の中で `addLocalAdditionalLearning` を呼ぶ
4. `true` を返す

## `addLocalAdditionalLearning`

接続先を `resolveLocalServer` で取り、`toLocalFormData` で `creationServiceName`・`feedbackId`（あれば）・`roomId`（あれば）・`userId`・`content` を作って POST。未指定の項目は `toLocalFormData` が送らない。

## `useAddAdditionalLearning`

`mutationFn` の先頭で `addIfLocalFolder` が `true` ならそこで終了。`false` ならこれまでどおりクラウドへ送る。成功時の一覧の読み直しは変更なし。

## エラー

- `ApiError`: api-client の共通トースト（ここでは何もしない）
- それ以外（接続先・ユーザーが取れない）: `viaLocalServer` が `COMMON.MESSAGES.ERROR.GENERAL` のトーストを出し、再スロー
