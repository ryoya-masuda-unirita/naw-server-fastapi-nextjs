# 04_テスト設計

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 振り分け | LOCAL・`feedbackId` | ローカル用サーバーへ `feedbackId` のみ（`roomId` なし）、`userId`・`creationServiceName`・`content` を送る。認証キーとテナント ID のヘッダー付き。クラウドへは送らない。`true` |
| 2 | 対象 | LOCAL・`roomId` | `roomId` のみ（`feedbackId` なし） |
| 3 | クラウド | LOCAL 以外 | 何も送らず `false` |
| 4 | 都度取得 | 2 回呼ぶ | フォルダ・接続先をそれぞれ 2 回取る |
| 5 | ユーザー不明 | 未ログイン | 送らず失敗、エラートースト 1 件 |
| 6 | 接続先なし | 接続先 ID なし | 送らず失敗、エラートースト 1 件 |
| 7 | API キーなし | API キーが空 | 送らず失敗、エラートースト 1 件 |
| 8 | HTTP エラー | ローカル用サーバーが 500 | `ApiError` を再スロー、追加のトーストなし |
| 9 | 既存画面 | 回答精度・満足度タブの追加学習（クラウドのフォルダ） | 既存の画面テストが通る |
