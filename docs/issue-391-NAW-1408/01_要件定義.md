# 01_要件定義

## 機能要件

- 追加学習の登録時、学習先フォルダをクラウドから取得し、種類が LOCAL ならローカル用サーバーの `POST api/admin/indexes/{id}/additionalLeaning`（綴りは移植元・server-local のまま）へ multipart で送る。クラウドの追加学習 API は呼ばない
- 送る項目: `creationServiceName`（フォルダの追加サービス名）、`feedbackId` または `roomId`（一方のみ）、`userId`、`content`（ファイル）
- LOCAL 以外のフォルダは、これまでどおりクラウドへ送る
- フォルダの種類・接続先（URL と API キー）は操作のたびに取り直す
- ユーザー ID が取れない、接続先が未登録、URL・API キーが空のときは、どこにも送らず失敗させ、エラートーストを出す
- ローカル用サーバーの HTTP エラーは、api-client の共通エラートーストに任せる（二重に出さない）
- 成功したら、これまでどおり該当タブの一覧を読み直す

## 制約

- サブドメインでのテナント識別は持ち込まない（ローカル用サーバーへは既存の仕組みで `X-Tenant-ID` を付ける）
- 画面（見た目）は変えない
- backend の変更はない
