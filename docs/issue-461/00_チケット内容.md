# クラウド側 server のベクトルの保存・検索を pgvector に対応させる

## 概要

クラウド側の `server/` で、ベクトルの保存・検索・削除を、Azure AI Search 以外（pgvector）でも行えるようにする。ローカルの docker compose に pgvector を立てる。クラウドの RAG を Bedrock だけで動かすための 2 つ目（#460 → #461 → #462）。

## 説明

- 今の `server/` のベクトルの検索は、Azure AI Search だけ（`AzureAiSearchVectorStoreClient.similarity_search`）。移植元（Java）も Azure AI Search 専用
- ローカルの compose には、Azure AI Search もベクトル DB もない。テストデータのベクトル DB の接続先は、架空のホスト（`vdb.example.com`）
- オンプレ側（`onprem/`）では、pgvector が動いていて、アダプタが `(id, fileid, filepath, content, embedding)` の表に保存し、`embedding <=> クエリ` の近い順で検索する
