## `PgVectorStoreClient`

- 接続: `endpoint` を `urllib.parse` で、ユーザー・ホスト・ポート・DB 名に分け、`asyncpg.connect(host=, port=, user=, password=api_key, database=, timeout=)`。接続は、操作ごとに開いて閉じる
- `similarity_search(endpoint, api_key, tenant_id, query_vector, top_k)`:
  `SELECT fileid, content FROM {表} ORDER BY embedding <=> $1::vector LIMIT $2`（`$1` はベクトルのリテラル `[0.1,...]`）。表がなければ（`UndefinedTableError`）0 件。結果は `VectorSearchResult(content, file_unique_id=fileid)`
- `ensure_table`: `CREATE EXTENSION IF NOT EXISTS vector`、`CREATE TABLE IF NOT EXISTS {表} (...)`、`CREATE INDEX IF NOT EXISTS ... USING hnsw (embedding vector_cosine_ops)`
- `add_rows`: `INSERT ... ON CONFLICT (id) DO UPDATE`（`executemany`）。次元数が 1536 でない行は、保存前に拒否
- `delete_by_file_id`: `DELETE FROM {表} WHERE fileid = $1`。削除した行数を返す
- 失敗（接続・SQL）は `HTTPException(400, "Failed to connect to vector database")`。ログには、パスワードを含めない（例外の種類だけ）

## 表名

```python
def table_name_for_tenant(tenant_id: str) -> str:
    slug = re.sub(r"[^a-z0-9_]", "_", tenant_id.lower())[:40] or "tenant"
    digest = hashlib.sha1(tenant_id.encode()).hexdigest()[:8]
    return f"docs_{slug}_{digest}"
```

- 表名は、この関数が作った、英小文字・数字・`_` だけの識別子で、SQL に `"..."` で埋め込む（値はパラメータ）

## compose

```yaml
  vector-db:
    image: pgvector/pgvector:pg17
    container_name: naw-fastapi-vector-db
    environment: {POSTGRES_DB: vector, POSTGRES_USER: vector, POSTGRES_PASSWORD: vector}
    ports: ["5434:5432"]
    volumes: [naw_fastapi_vectordata:/var/lib/postgresql/data]
    healthcheck: pg_isready
```

- backend からは、`postgresql://vector@vector-db:5432/vector`（パスワード `vector`）
