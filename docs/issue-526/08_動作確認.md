## 再現（修正前の原因）

ボードの項目は、201 件（`--limit 1000` で数えた件数）。#526 の項目を、上限を変えて探した。

```
limit 200 : ''
limit 1000: 'PVTI_lAHODGxZQ84Bb8MszhL0Lw4'
```

`--limit 200` では見つからず、`--limit 1000` では見つかった。#524 では、Actions の「Reviewへ移動」が、`Project item for issue #524 was not found.` で失敗した（`gh run view --log-failed` で確認）。
