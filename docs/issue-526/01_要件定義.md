# 01_要件定義

## 背景

ボードの項目は、完了したものも残るため、増え続ける。上限が小さいと、新しい Issue から順に、同期の対象から外れる。

## 機能要件

- ボードの項目を取得する 3 か所（`project_status_sync.sh` の 2 か所、`next_todo_issue.sh` の 1 か所）の上限を、項目数より十分大きい 1 つの定数にする
- 上限を超えて古い値のままだと再発するため、定数に理由をコメントで残す
- 200 件を超えた Issue の項目が、見つかる

## 非機能要件

- 動作・引数・出力は変えない（上限だけ）

## スコープ外

- ボードのアーカイブ、`gh issue list --limit 200`
