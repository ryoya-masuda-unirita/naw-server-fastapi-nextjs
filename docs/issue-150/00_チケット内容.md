# ローカル開発環境をルートのdocker-composeで一括起動できるようにする

## 概要

ローカル開発環境を、モノレポルートの`docker-compose.yml`で一括起動できるようにする。
現状はPostgreSQL・Redisのみdocker-compose管理されており、backend（FastAPI）と
frontend-angular（動作確認用フロントエンド）は個別にホストで直接起動する運用になっている。

## 説明

- 現状: `docker compose up`でPostgreSQL・Redisのみ起動。
  - backendは`uvicorn app.main:app --reload`をホストで直接実行
  - frontend-angularは`npm start`（`ng serve --configuration local`）をホストで直接実行
- 課題: 起動手順が複数箇所に分かれており、環境構築の手間が大きい
- ルートの`docker-compose.yml`に`backend`サービスと`frontend-angular`サービスを追加し、
  両方ともホットリロード対応で起動できるようにする
- `postgres`・`redis`サービスは現状維持
