### 7. 有効期限切れトークン（401）

**手順**: JWT を手動生成し、有効期限を過去に設定

```python
# Python で有効期限切れ JWT を生成
import jwt
from datetime import datetime, timedelta

payload = {
    "sub": "admin",
    "tenantId": "test-tenant",
    "exp": datetime.utcnow() - timedelta(hours=1),
    "iat": datetime.utcnow(),
}
token = jwt.encode(payload, "your-secret-key", algorithm="HS512")
print(token)
```
