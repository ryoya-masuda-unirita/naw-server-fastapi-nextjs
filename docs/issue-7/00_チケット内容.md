# JWT認証基盤の実装（ログインAPI・ミドルウェア）

## 概要

認証基盤（JWT ログイン API・認証ミドルウェア）を FastAPI に実装する。
認証がないと他のすべての API が動かせないため、最優先の Issue。

## 説明ややること等

### DBマイグレーション

- `password_histories` テーブルを追加（Alembic）
  - naw-server では `users.password` ではなく `password_histories` でパスワードを管理している
  - 現在の `users.password` カラムの扱いをこの Issue で決定・対応する

### API

| メソッド | パス | 概要 |
|---|---|---|
| POST | `/auth/login` | login_id / password / tenant_id でログイン → JWT 返却 |
| GET | `/api/auth` | JWT から現在のユーザー情報を返す |
| POST | `/auth/logout` | ログアウト |
| POST | `/auth/password/reset` | パスワードリセット |

### ミドルウェア

- JWT 検証 `Depends`（`python-jose` はインストール済み）
- リクエストからテナント ID を解決して DI に注入
