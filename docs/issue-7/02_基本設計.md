# 02 基本設計

## 変更対象レイヤー

| レイヤー | 変更内容 |
|---|---|
| DB（Alembic） | `users.password` カラム削除 / `password_histories` テーブル追加 |
| モデル | `User` モデルから `password` フィールド削除 / `PasswordHistory` モデル新設 |
| スキーマ | `LoginRequest`・`LoginResponse`・`PasswordResetRequest` を新設 |
| サービス | パスワード検証・JWT 生成・パスワードポリシーチェックのロジック |
| ルーター | `/auth/*`・`/api/auth` エンドポイント |
| コア | JWT ユーティリティ・認証 Depends（ミドルウェア相当） |

## DB 変更概要

### Alembic マイグレーション（002）

- `users.password` カラムを DROP
- `password_histories` テーブルを CREATE
  - `id`: UUID PK（`gen_random_uuid()`）
  - `tenant_id`: VARCHAR(32)、FK → `tenants.id`
  - `user_id`: UUID、FK → `users.id`（CASCADE DELETE）
  - `password`: VARCHAR(255)
  - `created_at`: TIMESTAMPTZ（`now()`）
  - `expired_at`: TIMESTAMPTZ（NULL 許容）
  - インデックス: `user_id`
- seed.sql の admin ユーザーを `password_histories` 方式に更新

## API 変更概要

### POST /auth/login

- リクエストヘッダー: `X-Tenant-ID`
- リクエストボディ: `{ "username": "...", "password": "..." }`
- 200 成功（通常ログイン）:
  ```json
  { "id": "admin", "name": "管理者", "role": "ADMIN", "token": "...", "groups": [], "loginStatus": "SUCCESS" }
  ```
- 200 成功（パスワードリセット必要）:
  ```json
  { "id": "admin", "name": "管理者", "role": "ADMIN", "loginStatus": "REQUIRES_PASSWORD_RESET", "reason": "INITIAL" }
  ```
- 401: 認証失敗

### GET /api/auth

- リクエストヘッダー: `Authorization: Bearer <token>`、`X-Tenant-ID`
- 200: 現在のユーザー情報と新しいトークンを返す
- 401: 未認証

### POST /auth/logout

- 200: `"Logout successful."`（処理なし）

### POST /auth/password/reset

- リクエストヘッダー: `X-Tenant-ID`
- リクエストボディ: `{ "loginId": "...", "oldPassword": "...", "newPassword": "..." }`
- 200: ログインと同じレスポンス形式（新 JWT 付き）
- 403: 旧パスワード不一致 / ユーザー不存在
- 400: パスワードポリシー違反 / 過去パスワードと重複
