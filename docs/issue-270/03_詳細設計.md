# 03 詳細設計

| 経路 | 根拠 |
|---|---|
| server が server-local の URL・API キーを返す | 移植元 `server` の `GetMessagesViewModel.java` |
| SECURE の質問を server に送ると 400 | 移植元 `server` の `MessageService.java` |
| ブラウザが server-local に直接送る | 移植元 `client` の `message-content-endpoint.resolver.ts`・`messages.service.ts`（`prepareSecureStreamContext`） |
| server-local → Waha! | `server-local/app/clients/waha_client.py` |
| アダプタ → server（`/auth/login-key`・`/api/llm/chat`） | 移植元 `generative-ai-adapter` の `SecuAiGentAuthClient.java`・`SecuAiGentTransport.java` |
| server-local → server（ライブラリ） | 移植元 `secuaigent-server-local` の `NawApiClient.java` |
| server から server-local への HTTP 通信がない | 移植元 `server` に `LOCAL_SERVER` の URL へ通信するコードがない（`ServiceRunService` は呼び出し元なし） |
