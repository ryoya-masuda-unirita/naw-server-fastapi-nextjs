## 詳細

### 2・3. 追加・削除の途中失敗 → 対応済み
`useAddTrainingFiles`・`useDeleteTrainingFiles` の一覧の読み直しを `onSuccess` から `onSettled` に変えた。移植元は成功時だけ読み直すが、複数件を扱う操作で一部だけ成功した状態を画面に残すと重複登録や 404 につながるため、正常系の挙動を変えずに塞いだ。

### 5. 楽観的更新の競合 → 対応済み
学習設定の切替・一覧上の名前変更は、書き換える前に取得中の一覧のリクエストを取り消す。取り消された取得は、書き換え後の画面を保ったまま終わる。

### 7. ダウンロード → 対応済み
リンクを `body` に追加してクリックし、URL の失効は 1 秒後にした。

### 1・4・6・8・9・10 → 対応しない
いずれも移植元（Angular）の `training-data.store.ts`・`training-api.service.ts`・`training-data-detail.component.ts` が同じ手順・同じ判定で同じ症状を持つ。クローンを保つため変えず、後続 Issue の候補として申し送る（特に 4 の削除後のページ補正、10 の削除後の遷移）。
