# 05_テスト詳細設計

## 画面テスト `routes/admin/training-data/training-data-detail.test.tsx`

- `renderApp('/admin/training-data/i1')` でガード・レイアウト込みで描画し、テナント管理者でログインした状態にする
- MSW は `server.use` で、詳細・ファイル一覧・ファイルの追加／更新／削除・フォルダの更新／削除・同期・接続先候補・グループを差し替え、受けたリクエスト（クエリ・本文）を記録して検証する
- 応答の形は backend（`FileResponse`・`IndexResponse`）の実際の形に合わせる（`fileName`・`displayName` null あり・`tenantEndpoints[]`）
- テスト環境では i18n が初期化されないため、文言はキーで確かめる（例: `LEARNING_DATA.STATUS_ON`）
- jsdom の `File` は undici の `formData()` で読めないため、アップロードの本文は読まず、クエリだけ検証する
- 同期は実時間で 3 秒待つ（テストのタイムアウトを延ばす）
