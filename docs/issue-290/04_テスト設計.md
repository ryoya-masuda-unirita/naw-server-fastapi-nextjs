# 04_テスト設計

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ確認は行わない。

| 対象 | 観点 |
|---|---|
| 表示 | 見出し（フォルダ名・取得前／失敗時の既定）、ファイルの行（表示名の代替・更新者名の解決・ON/OFF・件数）、初期の取得条件（page 0・size 10・updatedAt desc）、クラウド／ローカルでの表示の違い、戻るリンク、詳細取得失敗でデータなし |
| 検索・絞り込み | 検索語が表示名・ファイル名の両方で送られる、学習設定の絞り込みが ENABLE |
| 学習設定 | OFF にすると先に画面が変わり PATCH が `status=DISABLE`、失敗で元に戻る |
| 削除 | 行のメニューから確認して削除、キャンセルで削除しない、複数選択をまとめて削除し選択が解除される |
| 名前の変更 | 選択した行を一覧上で編集して保存（変えたものだけ送る） |
| 追加 | ファイル選択で拡張子を除いた名前が入る、リンクの先頭文字の一括適用、`displayName`・`reference`・`splitLength`・`name` が送られる、表示名が空なら完了不可、ファイル未選択で完了不可 |
| 設定の編集 | 保存で PATCH（`status` を送り、チャンク分割が同じなら `splitLength` を送らない）、リンク名が未設定なら必須エラー、ファイルを選ぶと multipart で送る、スマートフォンの追加 |
| 同期 | 3 秒後に POST され、ファイル一覧が読み直される |
| フォルダの編集 | ローカル: 現在の値・接続先・接続サーバー変更不可、全グループと接続先を付けて PATCH。クラウド: サービス ID なし、登録済みの接続先で PATCH。名前が空なら保存不可 |
| フォルダの削除 | 確認後に DELETE し `navigate(-1)` |
| 変換・helper | `splitLength` の変換と範囲、ファイル一覧のクエリ（検索・自分・ON/OFF・更新者名順・ページ）、更新者名の解決、ファイル行の変換 |
