# 01_要件定義

## 目的

学習先フォルダ 1 件の詳細（そのフォルダに登録された学習データ＝ファイルの一覧と、ファイル・フォルダの管理）を、移植元と同じ見た目・文言・操作・入力チェックで React に移す。

## 機能要件

| 区分 | 内容 |
|---|---|
| ヘッダー | モバイルのサイドバー切替、一覧へ戻るリンク、フォルダ名（取得前は「学習データの詳細」）、編集メニュー（フォルダの設定を編集／フォルダを削除） |
| 表示の切替 | フォルダの接続サーバーがローカルなら案内と一括同期、クラウドならダウンロード。それ以外は共通 |
| ファイル一覧 | 検索（表示名・ファイル名）、更新者・期間・学習設定の絞り込み、並べ替え（更新日時・表示名・更新者・学習設定）、ページ送り（10 件）、行の選択（全選択・行クリック） |
| 操作バー | 未選択=一括同期（ローカルのみ）と追加、選択中=解除・削除・名前を変更、名前変更中=解除・名前を変更（保存） |
| 追加 | PC は複数ファイルを選んで表示名・リンク名・チャンク分割を行ごとに入力、リンクの先頭文字の一括適用。スマートフォンは 1 件ずつ（編集ダイアログを共用） |
| 設定の編集 | 行のメニューから表示名・リンク名・チャンク分割・学習設定・ファイルの差し替え |
| 一覧上の名前変更 | 選択した行の表示名・リンク名をその場で編集して保存（先に画面を更新し、失敗したら戻す） |
| 学習設定の切替 | 行のメニューから ON/OFF（先に画面を更新し、失敗したら戻す） |
| 削除 | 行・選択分の削除を確認ダイアログで行う |
| ダウンロード | クラウドのみ。行のボタンとメニュー |
| 同期 | ローカルのみ。3 秒待ってから同期し、フォルダとファイル一覧を読み直す（その間は画面全体が読み込み表示） |
| フォルダの編集 | 名前・説明・（ローカルのみ）接続先とサービス ID。接続サーバーは変更不可。全グループを紐づけて更新 |
| フォルダの削除 | 確認後に削除し、前の画面へ戻る |
| 入力チェック | 表示名・リンク名は必須かつ 255 文字以内、チャンク分割は必須。フォルダ名は必須かつ 255 文字以内、説明は 1000 文字以内、ローカルの接続先は必須 |

## 非機能・方針

- 移植元のコードを正とし、判断は 03 に書く。ユーザーには聞かない
- スコープ外: 一覧（#135 で対応済み）、backend の修正
