# 学習データ詳細画面をReactに移植する

## 概要

学習データ詳細画面（`/admin/training-data/:id`、ファイル一覧・アップロード・同期・追加・編集・削除）を Angular（`secuaigent/client` の `features/admin/management/training-data/training-data-detail/`）から React（`frontend/`）に移植する。Issue #290。

## 説明

- 対象: `training-data-detail.component`（ヘッダー、学習先フォルダの編集・削除）、`local-view`・`cloud-view`、`view-shared` の action-bar・filters・table・add-modal・edit-modal、`TrainingDataStore` の詳細・ファイル系、`TrainingApiService` の詳細・ファイル・同期・ダウンロード、`training-data-files.helper`・`training-data-chunk-size.helper`・`training-api-normalize`（ファイル分）
- 依存: #135（一覧）
- 土台は #277・#278・#279。#135 の作り方に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）。意図的な差分はテナント識別にサブドメインを使わないことだけ

## その他

- 移植先は #277 の仮ファイル `frontend/src/routes/admin/training-data/training-data-detail.tsx`（export 名 `TrainingDataDetailPage` は維持）
- backend の応答の形の差は `docs/issue-279/api-backend-diff.md` を見て画面側で吸収する（backend は直さない）
