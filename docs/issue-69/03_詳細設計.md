# 03_詳細設計

## 実装対象ファイル

### スキーマ

- `backend/app/schemas/prompt_template.py`
  - `PromptTemplateResponse` に `addedAt: datetime | None = None` を追加（グループ所属テンプレート一覧取得時のみ設定、既存の他エンドポイントには影響なし）
- `backend/app/schemas/group.py`
  - `GroupPromptTemplatesAddRequest(BaseModel)` を追加（`templateIds: list[str]`）

### リポジトリ

- `backend/app/repositories/prompt_template_repository.py`
  - `find_by_ids_and_tenant_id(ids, tenant_id, session) -> list[PromptTemplate]` を追加（存在確認の一括取得。`GroupRepository.find_by_tenant_id_and_ids` と同様のパターン）
- `backend/app/repositories/group_prompt_template_repository.py`
  - `find_one(group_id, tenant_id, template_id, session) -> GroupPromptTemplate | None` を追加
  - `find_page_by_group(group_id, tenant_id, search, sort_col_name, sort_dir, page, size, session) -> tuple[list[tuple[GroupPromptTemplate, PromptTemplate]], int]` を追加（`GroupUserRepository.find_page_by_group` と同様、`PromptTemplate` をJOIN）
  - `add(group_id, tenant_id, template_id, session) -> None` を追加
  - `remove(group_prompt_template, session) -> None` を追加

### サービス

- `backend/app/services/group_service.py`
  - `add_group_prompt_templates(group_id, tenant_id, template_ids, current_user, session) -> None`
  - `remove_group_prompt_template(group_id, tenant_id, template_id, current_user, session) -> None`
  - `list_group_prompt_templates(group_id, tenant_id, current_user, search, sort, page, size, session) -> PagedPromptTemplateResponse`
  - いずれも既存の `add_group_users`/`remove_group_user`/`list_group_users` と同じ構造（`_get_group_or_404` → `_assert_can_manage_group` → 本処理）
  - `list_group_prompt_templates` は `GroupPromptTemplateRepository.find_groups_grouped_by_template_ids`（既存メソッド）を使って `groups`（グループ名集合）をN+1なしで組み立てる

### ルーター

- `backend/app/routers/groups.py`
  - `GET /{group_id}/prompt-templates`（`search`, `page`, `size`, `sort`（デフォルト `"addedAt,desc"`）クエリパラメータ）
  - `POST /{group_id}/prompt-templates`（`GroupPromptTemplatesAddRequest`、204）
  - `DELETE /{group_id}/prompt-templates/{template_id}`（204）

### モデル

- 新規モデル追加なし。`app/models/prompt_template.py` の既存 `GroupPromptTemplate` をそのまま利用する

## テスト対象ファイル

- `backend/tests/integration/test_groups.py` に `TestGroupPromptTemplates` クラスを追加
