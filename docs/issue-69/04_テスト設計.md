# 04_テスト設計

## テスト方針

既存の `TestGroupUsers`（integration）と同じ方針で、DBに実際に接続する統合テストとして `TestGroupPromptTemplates` を追加する。ルーターテスト（`ASGITransport`経由）で、権限・存在確認・冪等性・検索・レスポンス形式を検証する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 一覧取得 | グループにテンプレートが紐付いている | `content`/`totalElements`/`number`/`size` 形式で返り、`addedAt` が含まれる |
| 2 | 一覧取得（検索） | `search` パラメータで名前を指定 | 一致するテンプレートのみ返る |
| 3 | 追加 | 未紐付けのテンプレートIDを指定 | 204で追加される |
| 4 | 追加（冪等） | 既に紐付いているテンプレートIDを指定 | 204でエラーにならない |
| 5 | 追加（空リスト） | `templateIds` が空 | 400 |
| 6 | 追加（存在しないID） | 存在しないテンプレートIDを指定 | 404 |
| 7 | 削除 | 紐付いているテンプレートIDを指定 | 204で削除される |
| 8 | 削除（冪等） | 紐付いていないテンプレートIDを指定 | 204でエラーにならない |
| 9 | 削除（存在しないID） | 存在しないテンプレートIDを指定 | 404 |
| 10 | 権限（グループ管理者） | 自分が管理するグループに対して追加 | 204 |
| 11 | 権限（無関係ユーザー） | 管理権限のないグループに対して追加 | 403 |
