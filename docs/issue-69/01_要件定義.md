# 01_要件定義

## 背景

グループに対してユーザー・アシスタントの紐付け管理APIは既に移植済みだが、プロンプトテンプレートの紐付け管理APIは未移植のため、管理画面からグループ単位でプロンプトテンプレートを追加・削除・一覧できない状態になっている。

## 機能要件

- テナント管理者、またはグループ内管理者は、グループに対して1件以上のプロンプトテンプレートを一括追加できる
- テナント管理者、またはグループ内管理者は、グループから指定した1件のプロンプトテンプレートを除外できる
- テナント管理者、またはグループ内管理者は、グループに紐づくプロンプトテンプレート一覧を、名称・説明の部分一致検索およびページネーション付きで取得できる
- 一覧取得時、各テンプレートには紐付け日時（`addedAt`）を含める
- いずれの操作も、対象グループが存在しない場合は404、対象グループを管理する権限がない場合は403を返す
- 追加対象のテンプレートIDが1件も指定されない場合は400を返す
- 追加・削除の対象テンプレートが存在しない場合は404を返す
- 既に紐付いているテンプレートの追加はスキップ（冪等）、既に非紐付けのテンプレートの削除は何もしない（冪等）

## 非機能要件

- 一覧取得時、テンプレート件数に対してN+1クエリを発生させない
- 既存のグループ×ユーザー紐付けAPI（`add_group_users`/`remove_group_user`/`list_group_users`）と同じレイヤー構成・実装パターンに従う

## スコープ外

- グループ×アシスタント紐付け管理（別Issueで対応）
- フロントエンド（React）側の対応
