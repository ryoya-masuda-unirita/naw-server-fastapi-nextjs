# 05_テスト詳細設計

`04_テスト設計.md`の各Noに対応する具体的な確認コマンド・手順。

## No.1 `terraform init`/`validate`

```bash
cd infra
terraform init
terraform validate
```

期待結果: `Terraform has been successfully initialized!` / `Success! The configuration is valid.`

## No.2 `terraform plan`（初回）

```bash
terraform plan -out=tfplan
```

期待結果: `Plan: N to add, 0 to change, 0 to destroy.`（Nは想定リソース数と一致）

## No.3 `terraform apply`

```bash
terraform apply tfplan
```

期待結果: エラーなく完了し、`terraform output`でALB DNS名・CloudFrontドメイン名等が取得できる

## No.4 Issue #158の動作確認相当

`docs/issue-158/05_テスト詳細設計.md`のNo.1〜9のコマンドを、Terraformで作成したリソースのエンドポイント（`terraform output`から取得した値）に置き換えて実施する。

## No.5 `terraform plan`（差分ゼロ確認）

```bash
terraform plan
```

期待結果: `No changes. Your infrastructure matches the configuration.`

## No.6 `terraform destroy`

```bash
terraform destroy
```

期待結果: `Destroy complete! Resources: N destroyed.`（Nはapply時と一致）

## No.7 削除後の残存確認

```bash
aws resourcegroupstaggingapi get-resources --tag-filters Key=Project,Values=issue-160 --profile naw-fastapi-issue158
```

期待結果: `ResourceTagMappingList: []`

## No.8 ACM証明書の手動DNS検証

```bash
terraform output acm_validation_record
```

出力されたName/ValueをムームーDNSの「カスタム設定」に登録し、コンソールまたは以下で証明書ステータスを確認する。

```bash
aws acm describe-certificate --certificate-arn "$(terraform output -raw acm_certificate_arn)" --region us-east-1 --profile naw-fastapi-issue158
```

期待結果: `Status: ISSUED`
