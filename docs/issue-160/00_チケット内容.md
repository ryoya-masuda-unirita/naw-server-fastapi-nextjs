# Terraformで Issue #158 のAWS環境をコード化する（Terraform学習）

## 概要

Issue #158でAWSマネジメントコンソール（一部CLI）から手動構築したAWS環境を、Terraformでコード化する。ユーザーはTerraform初心者のため、本チケットは実務対応と同時にTerraform学習を兼ねる。

## 説明

- 対象: Issue #158で構築した全リソース（VPC/SG/ECR/S3/CloudFront/RDS/ElastiCache/踏み台EC2/ECS/ALB/ACM証明書/ECS用IAMロール）をTerraform化する
- スコープ外: ムームードメインのDNS設定（対応する公式Terraformプロバイダなし）、Dockerイメージビルド・ECR push、Alembicマイグレーション・seed投入、作業用IAMユーザー自体、CI/CD、本番環境
- 進め方はハイブリッド形式: リソースブロックごとに、AIがヒントを示しつつユーザー自身が`.tf`を書く場面と、AIが直接実装する場面を都度相談しながら進める
- `terraform apply`で実際にAWSリソースを立ち上げて動作確認し、`terraform destroy`で全削除する（Issue #158の手動削除との比較がポイント）

## その他

- Issue #158の成果物（`docs/issue-158/構築済みリソース一覧.md`・`architecture.md`・`03_詳細設計.md`・`09_AWSコスト.md`）を設計・実装の参照元とする
- 本チケットはIssue #158の内容をコード化するだけで、新しい機能・構成の追加は行わない（ベストプラクティス構成への発展は別チケット）
