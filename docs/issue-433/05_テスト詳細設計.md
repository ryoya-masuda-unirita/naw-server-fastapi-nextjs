# 05_テスト詳細設計

ファイル: `server/tests/integration/test_migration_issue433.py`（新規。`test_migration_issue307.py` と同じ作り）

- SQLite のインメモリに、移行前の `message_contents`（`message_id` の索引なし）を作り、`upgrade()`・`downgrade()` をそのまま実行する
- 索引は、`sa.inspect(connection).get_indexes` で、名前と列を確かめる
- モデルの索引は、`MessageContent.__table__.indexes` で確かめる
- 性能（実行計画）は PostgreSQL でしか確かめられないため、自動テストにはせず、`08_動作確認.md` に記録する
