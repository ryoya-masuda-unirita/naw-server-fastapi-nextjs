# チャットルーム共有リンクAPIの実装

## 概要

チャットルームの共有リンク機能（発行・アクセス解決・削除）を実装する。
移植元（naw-server, Spring Boot）の `ShareController` / `ShareService` に対応する。

## 説明

### 対象エンドポイント

- `POST /api/shares` — 共有リンクの作成・更新（upsert）。ルーム所有者のみ、対象グループ（`teamIds`）を指定して発行
- `GET /api/shares/{shareId}/access` — 共有リンク経由のアクセス解決（roomId・roomName・isReadOnly・teamIdsを返す）
- `DELETE /api/shares/{shareId}` — 共有リンクの削除（発行者本人のみ）

### 新規テーブル

- `shares`（共有リンク本体。`room_id`に1:1）
- `share_rooms`（共有リンクと共有先グループの中間テーブル）

### スコープ

このissueで、ルームへのグループ経由アクセス制御（共有リンクを持つグループメンバーはルームを閲覧できる、読み取り専用判定を行う等）を初めて実装する。
#45（チャットルーム管理API）・#48（メッセージ送受信API）は所有者のみアクセス可能という簡略化した権限モデルだったが、本issueの実装後、必要であれば既存APIへのグループアクセス反映（一覧・閲覧系での共有ルーム表示等）を別issueとして検討する。
