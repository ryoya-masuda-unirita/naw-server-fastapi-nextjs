## 前提フィクスチャ（想定）

- `shares_tenant` / `other_tenant`：テスト用テナント
- `room_owner_user` / `group_member_user` / `unrelated_user`：ルーム所有者／共有先グループ所属ユーザー／無関係ユーザー
- `share_assistant`：メッセージ関連テストと同様のアシスタント
- `owned_room`：`room_owner_user`が所有するルーム
- `target_group` / `other_group`：共有先グループ／未指定のグループ（存在チェックの正常系比較用）
- `group_member_user`を`target_group`に所属させる`GroupUser`レコード
- `owned_share`：`owned_room`に対する既存の共有リンク（更新系テストの前提データ）
