# 01_要件定義

## 背景

- #446 で、メッセージの作成と回答の生成が、ユーザーの所属グループに割り当てられたアシスタントでしかできなくなった（アシスタント一覧と同じ条件）。
- 09 のライブラリの組み合わせテストは、テストが作った新しいユーザーでライブラリを作る。そのユーザーは、テスト専用のグループにしか入っておらず、使えるアシスタントがないため、ライブラリの作成が 403 になる。
- 結果として、通し実行のたびに 09-26・09-30 が NG になる。

## 機能要件

- 09-26・09-30 のデータ準備で、新しいユーザーが基本のアシスタントを使えるようにする。
- テストが検証する内容（検索・フィルター・並べ替えの結果）は変えない。

## 非機能要件

- テストが作ったユーザーは、後片付けで消え、seed のグループに残らない。
- 通し実行で、09 のほかの項目に影響しない。

## スコープ外

- アプリ（server・client）の変更。#446 の挙動は意図したもの。
- 09 以外のテストの見直し（ほかに同じ原因で落ちるテストは、現状の通し実行では見つかっていない）。
