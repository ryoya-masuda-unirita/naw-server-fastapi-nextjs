# 02_基本設計

## 変更対象

09 のライブラリの組み合わせテストのデータ準備だけ。

## 画面 / API 変更概要

- 画面・API の変更はない。
- テストのデータ準備で、新しく作ったユーザーを、基本のアシスタントが割り当てられている seed のグループ（「動作確認用グループ」）にも追加する。専用グループへの追加は今のまま（ライブラリの共有先として使うため）。
- ユーザーを後片付けで削除すると、所属も消える（DB の外部キーが連動して削除）。

## 影響範囲

- 09 の組み合わせテストの準備だけ。ほかのテスト・アプリ本体には影響しない。
- テスト中だけ、seed のグループに 1 ユーザーが増える。
