# #465 issue-465 e2e-spec の 09-26・09-30 が、基本のアシスタントを使えないユーザーでライブラリを作って 403 になる

## 概要

e2e-spec の 09-26・09-30 が、通し実行のたびに 403 `Access Denied` で NG になる。#446（所属チームで使えないアシスタントでのメッセージ作成を拒否する）で、テストのデータ準備が通らなくなった。

## 事実

- 最新の `develop`（`712ae75`）で通し実行（並列 2）を 2 回続けて、2 回とも NG は 09-26・09-30 の 2 件だけ（`ライブラリ元のメッセージ作成に失敗しました: 403 {"message":"Access Denied"}`）。07-16・11-68・17 番台は NG にならなかった
- `tests/09-library.spec.ts` の「検索・フィルター・並べ替えの組み合わせ」の `beforeAll` で、`createUser` した `other` ユーザーが `createLibrary`（`POST /api/messages` に基本のアシスタント）を呼ぶ
- #446 以降、メッセージ作成は、ユーザーの所属グループにそのアシスタントが割り当てられていないと 403
- `other` は、テストが作った専用グループにだけ所属し、そのグループは基本のアシスタントに割り当てられていない（seed の「動作確認用グループ」が割り当てている）

## 対応

- `beforeAll` で `other` を seed の「動作確認用グループ」にも入れ、基本のアシスタントを使えるようにする
- 09-26・09-30 が通ること、09 の全体が通ることを確かめる
