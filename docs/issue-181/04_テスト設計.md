# 04_テスト設計

## テスト方針

API 経由の自動テスト（結合テスト）で確認する。ローカルの DB・サーバーは共有環境のため使わない。追加したテストが修正前のコードで失敗することも確かめる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 表示名順の昇降 | 大文字小文字が混ざった表示名の所属ユーザー 3 名で、表示名順の昇順・降順を取得する | 昇順と降順で先頭行が入れ替わり、大文字小文字を区別しない順に並ぶ |
| 2 | 同名ユーザーの昇降反転 | 同じ表示名の所属ユーザー 3 名で、表示名順の昇順・降順を取得する | 降順の並びが昇順の完全な逆順になる |
| 3 | 同時刻の追加日時の昇降反転 | 追加日時が同じ所属ユーザー 4 名で、追加日時順の昇順・降順を取得する | 降順の並びが昇順の完全な逆順になる |
| 4 | 権限順の昇降 | チーム管理者 1 名と一般 3 名で、権限順の昇順・降順を取得する | 昇順は管理者が末尾、降順は管理者が先頭で、並びが完全に反転する |
| 5 | 方向の大文字小文字 | 表示名順を大文字の降順指定で取得する | 降順で並ぶ |
| 6 | 既存挙動の回帰 | バックエンドの全テストを実行する | すべて成功する |
