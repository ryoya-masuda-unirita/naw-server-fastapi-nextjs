# #181 チーム詳細の所属ユーザー一覧、ユーザー表示名順の並べ替えで昇順・降順が反映されない

## 概要

チーム詳細画面（`/admin/groups/:id/users`）の所属ユーザー一覧で、並べ替えを「ユーザー表示名順」にした状態で昇順・降順を切り替えても、表示順（先頭行）が変わらない。

## 説明

### 再現手順

1. 所属ユーザーが複数いるチームの詳細画面を開く
2. 「所属ユーザー」タブで並べ替えを「ユーザー表示名順」に設定する
3. 昇順→降順と切り替える

### 期待される挙動

昇順・降順で一覧の先頭行が入れ替わる。

### 実際の挙動

昇順・降順どちらでも同じユーザーが先頭に表示される。
