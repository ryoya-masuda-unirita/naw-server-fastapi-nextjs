# 03_詳細設計

## 実装対象

### `backend/app/schemas/group.py`

- `GroupAssistantsAddRequest` を追加する
- `assistantIds: list[str]` を持たせる

### `backend/app/schemas/assistant.py`

- `AssistantGetResponse` に `addedAt: datetime | None = None` を追加する
- 既存のアシスタント一覧では未設定のまま返す

### `backend/app/repositories/group_assistant_repository.py`

以下を追加する。

- `find_one(group_id, tenant_id, assistant_id, session)`
- `add(group_id, tenant_id, assistant_id, session)`
- `remove(group_assistant, session)`
- `find_page_by_group(group_id, tenant_id, assistant_type, category_id, search, sort_col_name, sort_dir, page, size, session)`

`find_page_by_group` は `GroupAssistant` と `Assistant` をJOINし、必要に応じてカテゴリマッピング存在条件を組み立てる。検索文字列は既存 `escape_like_pattern` を使い、`%` 等をリテラルとして扱う。

### `backend/app/services/group_service.py`

以下を追加する。

- `add_group_assistants(...)`
- `remove_group_assistant(...)`
- `list_group_assistants(...)`

`list_group_assistants` は、取得した `(GroupAssistant, Assistant)` から `AssistantService._build_responses` でレスポンスを組み立て、同じ順序で `addedAt` を設定する。

### `backend/app/routers/groups.py`

以下を追加する。

- `GET /api/admin/groups/{group_id}/assistants`
- `POST /api/admin/groups/{group_id}/assistants`
- `DELETE /api/admin/groups/{group_id}/assistants/{assistant_id}`

クエリパラメータ:

- `type`
- `categoryId`
- `search`
- `page`
- `size`
- `sort`

### `backend/tests/integration/test_groups.py`

グループ×アシスタントの追加・削除・一覧・検索・権限を検証する統合テストを追加する。

## 参照実装との差分

- Spring Boot の `GroupService.findGroupAssistants` は `AssistantService.buildGetResponse` を1件ずつ呼ぶ。FastAPI 版では N+1 を避けるため、既存の一括レスポンス構築処理を使う。
- Spring Boot のカテゴリソートは主カテゴリ名サブクエリを使う。既存 FastAPI の管理者アシスタント一覧ではカテゴリソートを更新日時にフォールバックしているため、本Issueでも同じ方針に合わせる。
