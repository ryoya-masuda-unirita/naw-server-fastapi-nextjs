# 01_要件定義

## 背景

Spring Boot 版では、管理者またはグループ管理者がグループに紐づくアシスタントを管理できる。FastAPI 版には中間テーブルモデルは存在するが、グループ起点の追加・削除・一覧取得APIが未実装である。

## 機能要件

- グループに複数のアシスタントを一括追加できること
- 追加対象が空の場合は不正リクエストとして扱うこと
- 追加対象に存在しないアシスタントが含まれる場合はエラーにすること
- 既に紐付け済みのアシスタントを追加してもエラーにしないこと
- グループから指定アシスタントを削除できること
- 削除対象アシスタントが存在しない場合はエラーにすること
- 既に非紐付けのアシスタントを削除してもエラーにしないこと
- グループ所属アシスタント一覧をページング形式で取得できること
- 一覧取得では `type`、`categoryId`、`search` による絞り込みを扱うこと
- 一覧レスポンスは Spring Boot の `Page` 互換形式にすること
- 一覧レスポンスの各アシスタントに、グループ紐付け日時相当の `addedAt` を含めること
- テナント管理者、または対象グループのグループ管理者のみ操作できること

## 非機能要件

- N+1 クエリを避け、一覧レスポンスに必要な関連情報はまとめて取得すること
- 既存の FastAPI / SQLAlchemy async / SQLModel の実装パターンに合わせること
- Spring Boot のレスポンス形状・フィルタ仕様との互換性を優先すること

## スコープ外

- フロントエンド画面の改修
- ブラウザによる手動動作確認
- アシスタント作成・更新APIそのものの仕様変更
- グループ一覧レスポンスに含まれる `assistants` / `assistantIds` の実値対応
