# 04_テスト設計

## テスト方針

収集エラーの解消が主目的のため、まず対象テストファイルの `--collect-only` で収集通過を確認し、その後に対象テスト実行と全体 `pytest` を実行して、別要因の失敗有無を切り分ける。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | import 整合性 | 認証 API テストファイルを `--collect-only` で確認する | `ModuleNotFoundError` が発生せず 8 件収集できる |
| 2 | 対象テスト実行 | 認証 API インテグレーションテストを実行する | 8 件のテストが完了する |
| 3 | 回帰影響 | バックエンド全体の pytest を実行する | 少なくとも今回の import 起因の収集失敗が再発しない |
