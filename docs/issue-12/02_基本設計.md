# 02_基本設計

## 変更対象

- バックエンドの認証 API インテグレーションテスト

## 画面 / API 変更概要

- 画面変更なし
- API 変更なし
- テストコード上の依存モジュール参照先のみ修正

## 影響範囲

- 認証 API のインテグレーションテスト収集
- テスト時の DB セッション依存性オーバーライド
- ディレクトリ指定なしでの `pytest` 実行時の収集可否

## 移植方針

- 既存の DB セッション取得元に参照先を統一する
- 他のテストファイルと同じ import パターンへ合わせる
- 実装コードは変更せず、テスト側の不整合のみを解消する
