# 08_動作確認

## 確認環境

- macOS
- Python 3.14.6
- `uv run pytest`

## 確認手順

```bash
cd backend
uv run pytest --collect-only tests/integration/test_auth.py
uv run pytest tests/integration/test_auth.py
uv run pytest
```

## 確認結果

- `uv run pytest --collect-only tests/integration/test_auth.py`
  - 8 件のテストが収集され、`app.database` 起因の `ModuleNotFoundError` は再現しなかった
- `uv run pytest tests/integration/test_auth.py`
  - import 収集は通過した
  - ただし実行段階で `AsyncClient(app=...)` の `TypeError` と、`valid_jwt_token` / `expired_jwt_token` / `invalid_jwt_token` fixture 不足により失敗した
- `uv run pytest`
  - 今回の issue で対象だった import 収集エラーは解消していた
  - 一方で `test_auth.py` の実行失敗と、`tests/integration/test_models.py` の既存失敗は別途残存していた

## 未確認事項

- `test_auth.py` を現行の `httpx` / fixture 構成に合わせて完走させる修正は未対応
- `tests/integration/test_models.py` の失敗原因調査と修正は本 issue のスコープ外
