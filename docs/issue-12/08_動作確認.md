# 08_動作確認

## 確認環境

- macOS
- Python 3.14.6
- `uv run pytest`

## 確認手順

```bash
cd backend
uv run pytest --collect-only tests/integration/test_auth.py
uv run pytest tests/integration/test_auth.py
uv run pytest
```

- `uv run pytest --collect-only tests/integration/test_auth.py`
  - 8 件のテストが収集され、`app.database` 起因の `ModuleNotFoundError` は再現しなかった
- `uv run pytest tests/integration/test_auth.py`
  - 8 件のテストが完了することを確認した
- `uv run pytest`
  - 今回の issue で対象だった import 収集エラーは解消していた
  - `tests/integration/test_auth.py` は 8 件すべて成功した
  - 一方で `tests/integration/test_models.py` の既存失敗は別途残存していた
