# 03_詳細設計

## 変更対象ファイル

- `backend/tests/integration/test_auth.py`

## 変更内容

### `backend/tests/integration/test_auth.py`

- `from app.database import get_session` を `from app.core.database import get_session` に修正する
- `override_get_session` fixture が `backend/tests/integration/conftest.py` で上書きしている依存性キーと一致する状態にそろえる

## 影響範囲メモ

- `backend/tests/integration/conftest.py` は既に `app.core.database.get_session` を参照している
- `backend/app/routers/auth.py` も `app.core.database.get_session` を使用している
- そのため今回の修正は、テスト収集時の参照不整合解消に限定される
