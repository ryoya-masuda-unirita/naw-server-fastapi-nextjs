# 01_要件定義

## 背景

認証 API のインテグレーションテストを含む `pytest` 実行時に、テスト収集段階で import エラーが発生している。これにより対象テストだけでなく、ディレクトリ指定なしのテスト実行全体が中断される。

## 機能要件

- 認証 API のインテグレーションテストがテスト収集を通過できること
- 誤った import 先を、実在する DB セッション取得モジュールへ修正すること
- 既存の認証 API テストケース自体の意味や期待結果は変更しないこと

## 非機能要件

- 修正範囲は最小限に留めること
- 既存テスト実行フローとの整合性を保つこと
- 他のテストファイルと同じ依存性参照ルールに合わせること

## スコープ外

- 認証 API の仕様変更
- テストケースの追加や期待値変更
- DB セッション管理実装の構造変更
