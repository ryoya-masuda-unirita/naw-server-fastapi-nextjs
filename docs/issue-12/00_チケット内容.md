# #12 issue-12 tests/integration/test_auth.py のインポートエラーを修正

## 概要

`backend/tests/integration/test_auth.py` が存在しない `app.database` を import しており、`pytest` 実行時のテスト収集が失敗する問題を修正する。

## 説明

- `test_auth.py` の `get_session` import 先が `app.database` になっている
- 実際の定義場所は `app.core.database`
- 他のテストやルーターでは `app.core.database` を参照しており、本ファイルだけが不整合になっている
- この不整合により、テスト本体に到達する前の import 段階で `ModuleNotFoundError` が発生する

## その他

- 発見経緯: `pytest` をディレクトリ指定なしで実行した際に収集エラーとして発覚
- 修正対象は import 文のみを想定し、挙動変更は行わない
