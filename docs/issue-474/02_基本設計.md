# 02_基本設計

- アシスタント選択ボタン: 選択中の名前、なければ `CHAT.INPUT.SELECT_ASSISTANT`
- ユーザーメニュー: `aria-label` を `user-menu <ユーザー名>` にする
- `/users`: 件数 select に `USERS.ITEMS_PER_PAGE`、パスワード表示ボタンに `COMMON.SHOW_PASSWORD`・`COMMON.HIDE_PASSWORD`、保存ボタンを `bg-cyan-700`
- `FormSortInput`: 役割をラベル部分に移してクリアボタンを入れ子にしない。クリアに `COMMON.CLEAR`。プレースホルダーを `text-text-muted`
- `FormTextarea`: ラベルがなければプレースホルダーを名前にする
