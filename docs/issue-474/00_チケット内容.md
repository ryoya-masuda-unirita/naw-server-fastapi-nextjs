# 00_チケット内容

## タイトル

#474 issue-474 個別画面のアクセシビリティ違反を直す（axe）

## 内容

Issue #474 の本文のとおり。部品に絞れない axe 違反のまとめ。今回は、原因をコードで特定できたものを直す。

- `button-name`: アシスタント選択（`.dl-trigger`）、パスワード表示ボタン（`/users`）、並び替え入力のクリアボタン
- `label-content-name-mismatch`: ユーザーメニュー（`.w-56`）
- `select-name`: `/users` の件数 select
- `label`: 名前のないテキストエリア
- `nested-interactive`: 並び替え入力（`aria-haspopup="menu"`）
- `color-contrast`: 保存ボタン（`bg-cyan-600`）、並び替え入力のプレースホルダー
