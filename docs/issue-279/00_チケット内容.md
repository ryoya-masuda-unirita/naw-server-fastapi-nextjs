## 概要

React の画面移植の土台。

## 説明

### 対象（移植元）

- `core/constants/api-paths.config.ts`（全 API のパス）、`src/types/`（API の型、PagedResponse）
- `core/services/api-client.ts`・`core/interceptors/error.interceptor.ts`（配列クエリ・FormData・blob・エラー処理・401/403 の扱い）
- `core/utils`・`shared/utils`（api-datetime・display-date・validation・form-errors・scroll-to-error・debounce・tab-query-param）
- `core/initializers/login-key.initializer.ts`（`/auth/login-key`）
- `core/services/credit-usage.service.ts`・`token-usage.service.ts`
- MSW のハンドラーの置き方を決める

### 方針

- 目標は移植元（Angular `~/Documents/unirita-develop-pj/secuaigent-ref/client`）の完璧なクローン。見た目・文言（i18n）・操作・ルートのパス・入力チェックまで揃える。意図的な差分はテナント識別にサブドメインを使わないことだけ（ルート CLAUDE.md 参照）
- 移植先は `frontend/`（React、Vite + React Router）。規約は `frontend/.claude/CLAUDE.md`
