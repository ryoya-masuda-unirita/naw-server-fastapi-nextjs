# 04_テスト設計

## テスト方針

Vitest + React Testing Library で確認する。通信は MSW で応答を差し替える。既存のテスト（URL 組み立て・テナントID・ログイン・パスワードリセット）がすべて通ることも確認する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | メソッド | PUT・PATCH で本文を送る | 指定のメソッドで JSON の本文が届く |
| 2 | メソッド | DELETE で本文を送る | 本文が届く |
| 3 | テナント | テナントIDを保存して DELETE | テナントIDのヘッダーが付く |
| 4 | クエリ | 配列・値なし・false を含むクエリ | 配列は同じキーを繰り返し、値なしは送らず、false は送る |
| 5 | 本文 | フォームデータを送る | multipart で届き、内容を読める |
| 6 | 本文 | 本文なしで POST | JSON の Content-Type も本文も付かない |
| 7 | 応答 | テキスト指定 | 文字列で返る |
| 8 | 応答 | ファイル指定 | バイナリで返る |
| 9 | 応答 | 本文なし（204） | 空の値で返る |
| 10 | エラー | 404 と本文 | 状態コード・本文・メソッド・パスを持つエラーになり、文言は従来どおり |
| 11 | エラー | 共通メッセージ抑止を指定して 400 | 登録した処理に抑止の指定が渡る |
| 12 | エラー | 通信自体の失敗 | 状態コード 0 のエラーになり、登録した処理が呼ばれる |
| 13 | 外部 URL | ローカルサーバの絶対 URL で 401 | ベース URL が付かず、セッションを破棄しない扱いになる |
| 14 | SSE | フォームデータと Accept を指定 | 応答をそのまま読め、ヘッダーが届く |
| 15 | SSE | 401 | エラーになるが、共通のエラー処理は呼ばれない |
| 16 | エラー文言 | 403・404・500 以上・その他 | 対応する共通メッセージのキーになる |
| 17 | 共通メッセージ | 通常のエラー・抑止指定・ログイン失敗・回数制限・パスワードリセットの 401 | 移植元と同じ条件で出す／出さない |
| 18 | セッション破棄 | 通常 API の 401・403・セッション確認やログイン系の 401・抑止指定 | 通常 API の 401 だけ破棄する |
| 19 | エラー処理の組み立て | 401 | 翻訳した文言で通知し、ログイン画面へ戻す処理を呼ぶ。通知先が未指定でも失敗しない |
| 20 | 画面での 401 | 画面表示中に通常 API が 401 | ログイン画面へ移り、ユーザー・テナントIDが消える |
| 21 | 画面での 401 | セッション確認が 401 | 画面は移らず、テナントIDも残る |
| 22 | ログインキー | URL にキーがない | 何もしない |
| 23 | ログインキー | キーとテナントIDと他のクエリ | テナントIDを保存してログインし、認証のクエリだけ消す |
| 24 | ログインキー | ログイン失敗 | エラーを通知し、URL からキーを消す |
| 25 | ログインキー | 2回続けて呼ばれる | ログインは1回だけ |
| 26 | 認証ストア | 正しい・誤ったログインキー | 正しければログイン済み、誤りなら未ログインでテナントIDも消える |
| 27 | 認証ストア | セッション破棄 | ユーザー・管理者フラグ・テナントIDが消える |
| 28 | 利用量 | クレジット利用量 | 求めるまで取得せず、求めると自分とワークスペースを取得する |
| 29 | 利用量 | トークン利用量 | 本日・今月を UTC の期間で取得し、再描画で取り直さない |
| 30 | タブ | 有効・不正・未指定のタブ、タブ切替 | 有効ならそのタブ、不正なら既定タブに直し、切替でページ位置を消す |
| 31 | デバウンス | 指定時間内に値が続けて変わる | 最後の値だけが指定時間後に反映される |
| 32 | 日付 | API 用日時・期間・UTC 表示・ローカル表示・不正値 | 移植元と同じ形式。不正値は空 |
| 33 | 入力チェック | 必須・任意・文字数・形式・メール・パスワードの文字種 | 移植元と同じ判定と文言 |
| 34 | フォームエラー | 未操作・複数エラー・エラーなし | 操作済みのときだけ最初に解決できた文言を返す |
| 35 | スクロール | ダイアログ内の複数項目 | 指定順で最初の不正な項目までスクロールする |
| 36 | 型の変換関数 | 移植元の型のテスト | 移植元と同じ結果 |
