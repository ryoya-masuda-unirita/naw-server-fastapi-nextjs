# 01_要件定義

## 背景

画面ごとの移植を複数のエージェントが並行して進める。各画面が API のパス・型・通信処理を個別に作ると、同じ定義の重複や食い違い、共通ファイルでの衝突が起きる。移植元では、パス定数・API の型・API クライアント・エラー処理・共通の util が画面の外にまとまっている。これを先に React へ移し、各画面は自分のファイルを足すだけで済むようにする。

## 機能要件

1. API パスの定数
   - 移植元の API パス定数の全項目を、同じキー名で使えること
   - 移植元で画面ごとに持っていた API パス定数（テンプレート一覧・アシスタント一覧・学習データ・ユーザー一覧）のパスも、共通の定数から使えること
2. API の型
   - 移植元の API の型（ページング応答、共通の型、チャット・管理画面の型）を、同じファイル構成で使えること
   - 型に付いている変換関数（メッセージの変換など）も同じ振る舞いで使えること
3. API クライアント
   - GET・POST・PUT・PATCH・DELETE を送れること。DELETE は本文（一括削除の ID など）も送れること
   - どのメソッドでも任意のヘッダーとクエリを渡せること
   - クエリの配列は同じキーを繰り返して送り、値のない項目は送らないこと
   - 本文がファイル送信用のフォームデータなら、そのまま multipart で送ること
   - 応答を JSON・テキスト・ファイル（バイナリ）で受け取れること。本文のない応答でも失敗しないこと
   - SSE のように応答をそのまま読み進める用途に使えること
   - 認証 API の呼び分け（dev 環境で `/backend` を付ける）と、テナントIDのヘッダー付与を今までどおり行うこと
   - ローカルサーバのような外部の URL にも送れること
4. エラー処理（移植元のエラー処理と同じ判定）
   - エラー時に、状態コードに応じた共通のエラーメッセージ（権限なし・見つからない・サーバーエラー・その他）を出せること
   - 画面が個別にエラーを表示する場合は、共通のエラーメッセージを出さないよう指定できること
   - ログイン失敗（401・403）と、ログイン・パスワードリセットでの回数制限（429）では、共通のエラーメッセージを出さないこと
   - 401 のとき、セッションを破棄してログイン画面へ戻すこと。ただしセッション確認・ログイン系の API、ローカルサーバへの通信では破棄しないこと
5. ログインキーでのログイン
   - URL のクエリにログインキーがあれば、画面の表示より前にログインキーでログインすること。テナントIDもクエリで受け取れること
   - ログイン後、URL からログインキーとテナントIDを消すこと（他のクエリは残す）
   - 失敗したときにエラーを通知できること
6. 利用量の取得
   - 自分とワークスペースのクレジット利用量を、求められたときに並行して取得できること
   - 本日分・今月分のトークン利用量を、UTC の期間で取得できること
7. 共通の util
   - API 用の日時（UTC・ミリ秒なし）、請求期間（UTC）・画面表示（ローカル）用の日付フォーマット
   - 入力チェック（必須・文字数・形式・メールアドレス）とその文言、フォーム項目のエラー文言の解決
   - 最初の入力エラー項目へのスクロール
   - 入力の遅延反映（デバウンス）
   - タブの選択状態を URL のクエリで保持すること（不正値は既定タブに直す・タブ切替でページ位置を消す）
8. テスト用のモック（MSW）
   - 機能ごとにハンドラーを置く場所と、ベース URL に関係なく一致させる書き方を決め、規約に書くこと
9. backend との差分
   - 移植した型と backend の実際の応答の違いを一覧にして残すこと

## 非機能要件

- 既存の画面（ログイン・パスワードリセット・ダッシュボード）とテストの振る舞いを変えないこと
- 並行して進む #277（レイアウト・ルート・i18n）・#278（共通 UI）の担当領域を変更しないこと
- lint・型チェック・テスト・ビルドがすべて通ること

## スコープ外

- backend の修正（差分は一覧に残すだけ）
- 画面の移植、トースト部品の移植（#278）、翻訳ファイルへのキー追加（#277）
- 開発サーバーでの MSW によるモック起動
- チャット専用の SSE パーサ（チャット画面の移植で扱う）
- 移植元の自動生成型（Spring Boot の OpenAPI 由来）
- UI 専用の型（レイアウト・タブ）と、移植元のモックでしか使われていない型
