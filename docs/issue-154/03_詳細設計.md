# 03_詳細設計

## 変更対象ファイル一覧

### 変更

| ファイル | 変更内容 |
|---|---|
| `backend/app/routers/users.py` | `size` の `le=100` → `le=1000`（30行目） |
| `backend/app/routers/assistants.py` | `size` の `le=100` → `le=1000`（80行目） |
| `backend/app/routers/prompt_templates.py` | `size` の `le=100` → `le=1000`（29・51行目の2箇所） |
| `backend/app/routers/indexes.py` | `size` の `le=100` → `le=1000`（24行目） |
| `backend/tests/integration/test_users.py` | `size=1000` が 200 になることを検証するテストを追加（回帰防止） |

## 詳細

### 各ルーターの変更

```python
# 変更前
size: int = Query(20, ge=1, le=100)
# 変更後
size: int = Query(20, ge=1, le=1000)
```

- `prompt_templates.py` は `ge=0` のまま（既存仕様を維持し、`le` のみ変更）
- `Query` の第1引数（デフォルト値）・`ge` は変更しない

### 上限値の根拠

- frontend-angular が送る最大値は `size=1000`。これを満たす最小限の緩和として `1000` を採用
- 移植元(Spring Boot)のデフォルト上限（2000）以内であり、極端に大きな値は許容しない

## 移植元との対応整理

移植元にはページサイズ上限の明示定義が無いため対応表なし（デフォルト2000に対し、本移植では
明示的に1000上限とする）。
