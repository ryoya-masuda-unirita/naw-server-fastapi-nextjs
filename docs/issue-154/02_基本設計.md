# 02_基本設計

## 変更対象

- 管理系一覧API（`routers/users.py`・`routers/assistants.py`・
  `routers/prompt_templates.py`・`routers/indexes.py`）の `size` クエリパラメータの上限値

## 画面 / API変更概要

- APIのパス・レスポンス形式・その他のパラメータは変更しない
- `size` の許容上限を `100` から `1000` に緩和するのみ

## 影響範囲

- 上記4ルーターの一覧エンドポイント
- frontend-angular の管理画面（ユーザー一覧・アシスタント一覧・テンプレート一覧・
  グループ編集の選択肢取得・インデックス一覧など）が正常に表示されるようになる

## 移植方針

- 移植元(Spring Boot)にページサイズ上限の明示設定が無い（デフォルト2000）ことを踏まえ、
  frontend が実際に送る最大値（1000）を満たす最小限の緩和として上限を `1000` にする
- 無制限にはせず、移植元デフォルト（2000）以内に収めることで、極端に大きな `size` による
  負荷リスクを避ける
