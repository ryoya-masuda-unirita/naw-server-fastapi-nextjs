## 確認の途中で分かったこと

- 途中失敗のテストで、`expire_all()` のあとに期限切れのオブジェクトの属性を読むと `MissingGreenlet` になる。先に ID とパスを取り出す形にした（テストの書き方の問題。実装の問題ではない）

- **PostgreSQL では実行していない**（SQLite のテスト）
