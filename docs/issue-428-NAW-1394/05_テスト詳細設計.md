# 05_テスト詳細設計

ファイル: `server/tests/integration/test_indexes.py`（`TestIndexRouter.TestDelete` に追加）

- `RecordingFileStorage(LocalFileStorage)`: `deleted_urls`（削除の呼び出しの記録）と `fail_urls`（失敗させる URL）を持つ
- フィクスチャ `recording_storage`: `get_file_storage` を差し替える
- ヘルパー `_add_file`: ストレージに実体を置き、行を作る。`_stored_path`: 実体のパスを返す
- `expire_all()` のあとは、期限切れのオブジェクトの属性を読めない（`MissingGreenlet`）ので、先に ID とパスを取り出しておく

| `test_delete_index_skips_logically_deleted_files` | 2 |
| `test_delete_index_keeps_index_when_storage_fails` | 3 |
| `test_delete_index_retry_after_failure_removes_rest` | 4 |
| `test_delete_local_index_does_not_touch_storage` | 5 |
| `test_delete_by_group_admin_out_of_scope_keeps_files` | 6 |
