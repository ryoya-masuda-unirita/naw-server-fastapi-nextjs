# NAW-1443 所属チームで使えないアシスタントでのメッセージ作成・回答生成を拒否する

## 概要

NAW-1443 の移植（server）。所属チームで利用できないアシスタントを指定しても、メッセージの作成と回答の生成ができてしまう。403 で拒否する。

## 説明

- アシスタントの一覧 API は、ログインユーザーの所属チームに割り当てられたアシスタントだけを返す
- 一方、メッセージの作成と回答の生成は、アシスタントがテナントに存在するかしか見ていない。そのため、画面に前のユーザーのアシスタントの選択が残っているなどで、チームで使えないアシスタントが指定されても、そのまま回答が生成される（権限の回避）
- 移植元は、一覧と同じ判定で「利用できるか」を調べ、利用できなければ 403 を返すようにした（ba7e0bbbd・b18e17112）。テナントに存在しないアシスタントは、従来どおりのエラーのまま

## その他

- 元チケット: NAW-1443
- GitHub Issue: #446
- 移植元の同じチケットの client 側の変更（認証成功時のクエリキャッシュの破棄）は、移植先の React では通常ログインがフルリロードのため再現せず、対象外とする
- 既存の差分（今回は直さない）: 存在しないアシスタントのときの応答が、移植元は 404、移植先は 400
