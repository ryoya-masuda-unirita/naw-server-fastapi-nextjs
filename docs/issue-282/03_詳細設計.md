# 03_詳細設計

## 変更ファイル

### `backend/app/schemas/library.py`

- `LibraryContentResponse(BaseModel)` を追加。項目は `data: str`

### `backend/app/services/library_service.py`

- `get_library` の閲覧判定を `_require_readable_library(tenant_id, current_user, library_id, session) -> Library` に切り出す（移植元 `LibraryService#requireReadableLibrary` に相当）
  - ルームを閲覧できればライブラリを返す。そうでなければ `LibraryRepository.is_visible_to_user` で判定し、見えなければ 404 `Library not found`
- `get_library` は `_require_readable_library` の結果から `LibraryGetResponse` を作る（挙動は変えない）
- `get_library_content(tenant_id, current_user, library_id, session) -> LibraryContentResponse` を追加
  - `_require_readable_library` で判定し、`library.content` が `None` なら 404 `Library content not found`
  - 空文字は本文として返す（移植元は `library_contents` に行があれば内容にかかわらず返す）

### `backend/app/routers/libraries.py`

- `@library_router.get("/{library_id}/content", response_model=LibraryContentResponse)` を追加。依存は `get_library` と同じ（`get_verified_tenant_id`・`get_current_user`・`get_session`）
- パスは 2 階層なので、`/{library_id}`（1 階層）や `/api/libraries/tags`（別ルーター）とは衝突しない

移植元の根拠:

- `server/src/main/java/com/example/naw/api/LibraryController.java`: `@GetMapping("/api/libraries/{libraryId}/content")`、`ResponseEntity.ok(Map.of("data", content.getContent()))`
- `server/src/main/java/com/example/naw/service/LibraryService.java`: `getLibraryContent` は `requireReadableLibrary` のあと `EntityNotFoundException("Library content not found")`
- `server/src/main/resources/liquibase/changelog/library_contents/changeset-001-split-library-content.xml`: 本文の別テーブル化（backend は未移植のため列から読む）
- client `features/chat/services/library-content-api.service.ts`: `GET /libraries/{id}/content` の応答の `data` だけを使う

## 移植しない API の調査結果

| API | 調べた場所 | 結果 |
|---|---|---|
| `PUT /api/rooms/pin` | `RoomController` の `@*Mapping`、全ブランチの `git log -S` | 無い。`POST`・`DELETE /api/rooms/{roomId}/pin` だけ |
| `PUT /api/rooms/reorder` | 同上、`RoomEntity`・`RoomRepository` | 無い。並び順の列も無い（一覧は `OrderByPinnedThenUpdatedAtDesc`） |
| client の `bulkUpdateRoomPins` | `client/src` 全体 | `layouts/admin-layout/components/chat-sort-dialog` から呼ばれる |
| client の `saveRoomOrder` | `client/src` 全体 | 定義のみ。呼び出し元が無い |
