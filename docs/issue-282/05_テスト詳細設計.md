# 05_テスト詳細設計

## 単体テスト `backend/tests/unit/test_library_service.py`（新規）

リポジトリと `can_view_room` をモックして `LibraryService.get_library_content` を確かめる。

| No | クラス | テスト名 | 内容 |
|---|---|---|---|
| 1 | `TestGetLibraryContent` | `test_returns_content_when_room_viewable` | ルームを閲覧できれば本文を返し、見えるかの判定は呼ばない |
| 2 | `TestGetLibraryContent` | `test_returns_content_when_library_visible` | ルームは閲覧できないがライブラリが見えれば本文を返す |
| 3 | `TestGetLibraryContent` | `test_raises_404_when_not_readable` | どちらも満たさなければ 404 `Library not found` |
| 4 | `TestGetLibraryContent` | `test_raises_404_when_content_is_none` | 本文が `None` なら 404 `Library content not found` |
| 5 | `TestGetLibraryContent` | `test_returns_empty_string_content` | 本文が空文字なら空文字を返す |
| 6 | `TestGetLibraryContent` | `test_raises_404_when_library_id_is_not_uuid` | UUID でない id は検索せずに 404 `Library not found` |

## 結合テスト `backend/tests/integration/test_libraries.py`

`TestGetLibraryContent` を追加する（既存の fixture を使う）。

| No | テスト名 | 内容 |
|---|---|---|
| 7 | `test_get_content_as_room_owner` | 200、`{"data": library.content}` だけを返す |
| 8 | `test_get_content_shared_via_library_group` | 共有先グループの所属ユーザーは 200 |
| 9 | `test_get_content_without_access_returns_404` | 無関係のユーザーは 404 `Library not found` |
| 10 | `test_get_content_not_found_returns_404` | 存在しない id は 404 `Library not found` |
| 11 | `test_get_content_invalid_id_returns_404` | UUID でない id は 404 `Library not found` |
| 12 | `test_get_content_without_content_returns_404` | 本文が NULL なら 404 `Library content not found` |
| 13 | `test_get_content_without_auth_returns_401` | 認証なしは 401 |
