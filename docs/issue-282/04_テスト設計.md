# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 本文取得 | ルームの所有者が本文のあるライブラリを取得する | 200、`data` が本文 |
| 2 | 共有先グループ | ルームは見えないがライブラリの共有先グループに所属するユーザーが取得する | 200 |
| 3 | 閲覧できない | どちらの条件も満たさないユーザーが取得する | 404 `Library not found` |
| 4 | 存在しない | 存在しない id・UUID でない id | 404 `Library not found` |
| 5 | 本文が無い | 本文が NULL のライブラリを取得する | 404 `Library content not found` |
| 6 | 本文が空文字 | 本文が空文字のライブラリを取得する | 200、`data` が空文字 |
| 7 | 未認証 | 認証なしで取得する | 401 |
| 8 | 業務処理 | ルームを閲覧できない・ライブラリも見えない場合 | 本文を読まずに 404 |
| 9 | 既存の挙動 | ライブラリの取得の既存テスト | すべて通る |
