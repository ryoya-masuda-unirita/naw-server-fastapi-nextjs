# 08_動作確認

## 確認環境

- ブラウザ・実機確認は行わず、自動テストのみで代替した（ローカルの Postgres・backend サーバーは他の作業と共有のため起動しない）
- `backend/` で `uv run pytest`（インメモリ SQLite + fakeredis）、`uv run mypy app tests`、`uv run ruff check`、`uv run ruff format --check`

## 確認手順

1. ライブラリ本文取得の単体テスト・結合テストと、閲覧判定を共通化したライブラリ取得の既存テストを詳細表示で実行する
2. 全件のテスト・mypy・ruff を実行する
