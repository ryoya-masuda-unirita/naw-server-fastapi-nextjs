# 02_基本設計

## 変更対象

- ファイル一覧の絞り込み領域（更新者の選択肢）
- ファイル一覧の画面（ユーザー一覧の取得と、更新者の欄の組み立て）
- ファイル一覧の表（更新者の欄の表示）
- 一覧の条件と、API の呼び出し条件
- ファイル 1 件の型と、backend の応答の変換
- 表示文言

## 画面 / API 変更概要

- 画面: 更新者の選択肢を外す。更新者の欄は 3 種類の表示にする（名前・削除されたユーザー・Unknown）
- API: 変更しない。更新者の条件（`userId`）を送らなくなる。クラウドは応答の更新者名をそのまま使う。ローカルは #390 の「表示ページのログイン ID でのユーザー検索」を使う

## 影響範囲

- ファイル一覧の更新者の欄。これまで名前を引けないとユーザーの ID が出ていた箇所が、「削除されたユーザー」「Unknown」になる
- テナントの全ユーザー取得を、この画面からなくす
- 更新者の絞り込みを使っていた画面テスト

## 移植方針

- 移植元の最終形に合わせる（絞り込みの削除、更新者の 3 種の表示、クラウドは API の更新者名）
- ローカルのユーザー検索は、#390 で移植済みのまま使う（移植元の e8550e5be の最終形）
- 並べ替えの項目としての「更新者名順」は、#392 で暫定対応として残した条件のまま変えない
