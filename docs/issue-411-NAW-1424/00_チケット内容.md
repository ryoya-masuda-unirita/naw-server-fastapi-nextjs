# 学習データの更新者の絞り込みを削除する（NAW-1424・画面側）

## 概要

学習データ詳細のファイル一覧から、更新者の絞り込み（「全てのユーザー」）を削除し、更新者の欄を、名前を引けないときも利用者の ID を出さない表示に直す。

## 説明

- GitHub Issue: #411
- 移植元チケット: NAW-1424（backend の `loginIds` は #372、ローカルの更新者名のログイン ID での解決は #390 で移植済み）
- 移植元の理由:
  - ローカル用サーバーは更新者の絞り込みを受け取らず、選んでも一覧が変わらない
  - 更新者の選択肢のために、テナントの全ユーザー（最大 1000 件）を取っており、ユーザー数に比例して表示が遅くなる
  - ローカルのファイルの更新者はログイン ID で、ユーザーの ID（UUID）で名前を引いていたため、ローカルのファイルはすべてログイン ID のまま表示されていた
- 移植元の更新者の欄: 名前を引けたら名前、引けなければ「削除されたユーザー」、更新者の ID が無ければ「Unknown」を出す（開発メンバの決定）。ユーザーの ID は出さない
- 参照コミット: d6434dcb7, 3f5a01dbe, e8550e5be（`secuaigent-ref`）
