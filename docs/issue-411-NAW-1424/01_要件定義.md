# 01_要件定義

## 背景

学習データ詳細には更新者の絞り込みがあるが、ローカルのフォルダでは効かず、選択肢のためにテナントの全ユーザーを取っている。クラウドの API は更新者の名前を返すため、全ユーザーを取らなくても名前を出せる。ローカルの更新者名は #390 で、表示ページのログイン ID だけで引く形にした。

## 機能要件

- ファイル一覧の絞り込み領域から、更新者の絞り込みを表示しない（検索・期間は残す）
- 一覧の取得で、更新者の条件を送らない
- 更新者の欄は、次のとおり出し分ける
  - 更新者の名前を引けた: その名前
  - 更新者の ID はあるが名前を引けない（削除されたユーザーなど）: 「削除されたユーザー」
  - 更新者の ID が無い: 「Unknown」
  - どの場合も、ユーザーの ID やログイン ID は出さない
- クラウドのフォルダは、API が返す更新者名を使い、テナントの全ユーザーを取らない
- ローカルのフォルダは、表示ページのログイン ID だけで名前を引く（#390 のまま）

## 非機能要件

- 全ユーザーの取得（最大 1000 件）をやめ、ユーザー数に比例して表示が遅くならない
- 使われなくなる選択肢・取得処理・条件・文言・テストを削除する（不要コードの削除）

## スコープ外

- 並べ替えの再実装、ファイル一覧 API の更新者名の仕様変更（backend の変更は無い）
- フィードバックの追加学習（#391）
