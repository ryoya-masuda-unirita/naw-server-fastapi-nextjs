## code-review 後の追加確認

- S3 のバケット名にアカウント ID を含めた。`plan` で、`naw-fastapi-frontend-<アカウント ID>`・`naw-fastapi-user-import-jobs-<アカウント ID>` になることを確認した（72 リソースのまま）。上の No.3 の「差分 0」は、この変更の前の比較結果で、バケット名（とそれを参照する出力・環境変数）だけが意図して変わった
- プロジェクト名の形式を `^[a-z0-9][a-z0-9-]{1,28}[a-z0-9]$` にそろえた。`-abc`・`abc-`・`ab` は弾かれ、`naw-fastapi`・`a-b` は通る。Terraform の `validation` も `plan` で実際に効くことを確認した（`-bad-` を渡すと `Invalid value for variable` で失敗）
- 実のアカウント ID を、`docs/issue-382/08_動作確認.md` と `docs/issue-383/08_動作確認.md` から削除した。追加行・変更行に 12 桁の数字がないことを再確認した
