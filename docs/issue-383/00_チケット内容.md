# infra/ のアカウント ID・プロジェクト名などを変数化し、default_tags を入れ、infra/route53/ を削除する

## 概要

Issue #383（親: #380。#381・#382 はマージ済み）。`infra/` に直書きされた、環境・アカウントに依存する値を変数化し、`Project` タグを provider の `default_tags` にまとめ、不要になった `infra/route53/` を削除する。

## 説明

- `project_name` の既定値 `naw-fastapi-issue160`、tfstate バケット名、GitHub ロールの trust のリポジトリ名などの直書きを変数化する
- aws provider に `default_tags` を入れ、各リソースの手書き `Project` タグを整理する
- `infra/route53/`（別 state。#195 の残骸）と、`deploy.yml` の `!infra/route53/**` を削除する
- `deploy-backend.yml` などに直書きされたクラスタ名・サービス名を、変数・出力から渡す形にする
