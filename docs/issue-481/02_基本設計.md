# 02_基本設計

- `ExternalServiceError` の子 `WahaHttpStatusError`（`http_status` を持つ）を新設し、Waha! の成功以外の応答で投げる
- `waha_session` が `WahaSession`（`id`・`output_verified`・`end_unconfirmed`）を返し、出力確認後の 5xx の終了失敗を `end_unconfirmed` にする
- `_run_waha_create_job(kind=NORMAL|STRICT)`: NORMAL はセッション内で TSV を検証し、確認済みにする
- `create_file` は `FileRegistrationResult(body, session_end_unconfirmed)` を返し、ルーターがヘッダーを付ける
