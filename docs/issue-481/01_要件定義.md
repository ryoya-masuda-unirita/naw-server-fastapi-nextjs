# 01_要件定義

## 要件

- 通常ファイル登録（`POST /indexes/{id}/files`）の TSV に、CRLF 以外の改行（単独の CR・LF）があれば失敗にし、保存しない（セッション終了の失敗が重なっても保存しない）
- 出力を確認した（ファイル ID・パート ID が正しい）あとのセッション終了の 5xx は、登録を DB に反映し、応答ヘッダー `X-Waha-Session-End-Status: unconfirmed` と警告ログで伝える。ブラウザから読めるよう CORS で公開する
- 差し替え・追加学習は、これまでどおり、セッション終了の失敗も失敗にする
- 4xx のセッション終了の失敗は、通常登録でも失敗にする

## 対象外

- この Issue に書かれていないこと
