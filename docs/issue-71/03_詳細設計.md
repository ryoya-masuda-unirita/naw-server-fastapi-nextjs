# 03_詳細設計

## 実装対象

### `backend/app/schemas/room.py`

- `AdminRoomHistoryItemResponse`
- `AdminRoomHistoryDetailResponse`
- `PagedAdminRoomHistoryResponse`

### `backend/app/repositories/room_repository.py`

- `find_admin_histories(...)`

`Room` と `User` をJOINし、テナント・ユーザー・作成日・評価・名前・可視アシスタントIDで絞り込む。

### `backend/app/services/room_service.py`

- `list_admin_histories(...)`
- `get_admin_history(...)`

日付文字列は `yyyy-MM-dd` として扱い、不正なら400にする。

### `backend/app/routers/rooms.py`

- `admin_router = APIRouter(prefix="/api/admin", tags=["admin-rooms"])`
- `GET /histories`
- `GET /histories/{room_id}`

### `backend/app/main.py`

- `rooms.admin_router` を登録する

### `backend/tests/integration/test_rooms.py`

管理者向け履歴APIの一覧・詳細・権限・フィルタ・ソートを検証する。
