# 02_基本設計

## 変更対象

- ルームAPI
- ルームサービス
- ルームリポジトリ
- ルームレスポンススキーマ
- ルームAPI統合テスト

## 画面 / API 変更概要

| メソッド | パス | レスポンス |
|---|---|---|
| GET | `/api/admin/histories` | `content` / `totalElements` / `number` / `size` |
| GET | `/api/admin/histories/{room_id}` | ルーム履歴1件 |

## 影響範囲

- `rooms.py` に管理者向け router を追加し、`main.py` に登録する
- `RoomRepository` に管理者履歴一覧取得を追加する
- `RoomService` に管理者履歴一覧/詳細取得を追加する
- 既存の一般ユーザー向け `/api/rooms` の挙動は変更しない

## 移植方針

- 認可は既存の `require_admin_or_group_admin` を使う
- ADMIN/SYSTEM はテナント内ルームを対象にする
- グループ管理者は `GroupUserRepository.find_admin_group_ids_for_user` と `GroupAssistantRepository.find_assistant_ids_by_group_ids` で可視アシスタントを解決し、該当アシスタントを使うルームに絞る
- `createdAtTo` は参照実装同様に当日末尾まで含める
- `indexIds` は現 FastAPI のファイルモデルが Room 直結ではないため、空配列として返す
