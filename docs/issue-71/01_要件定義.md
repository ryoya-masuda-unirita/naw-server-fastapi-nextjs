# 01_要件定義

## 背景

FastAPI 版には一般ユーザー向けルームAPIはあるが、管理者・グループ管理者向けのルーム履歴一覧/詳細APIが未実装である。

## 機能要件

- `/api/admin/histories` でテナント内のルーム履歴をページング取得できること
- `userId`、`createdAtFrom`、`createdAtTo`、`roomRate`、`name` で絞り込めること
- `roomRate=unRated` は未評価ルームを返すこと
- `orderBy` と `reverse` によるソートを扱うこと
- 一覧レスポンスに `id`、`name`、`defaultAssistantId`、`userId`、`userName`、`indexIds`、`createdAt`、`updatedAt`、`shareUrl`、`rating` を含めること
- `/api/admin/histories/{roomId}` でテナント内のルーム履歴1件を取得できること
- ADMIN/SYSTEM またはグループ管理者のみアクセスできること
- グループ管理者は、自分が管理するグループに紐づくアシスタントを利用したルームのみに絞られること

## 非機能要件

- 既存の FastAPI / SQLAlchemy async / SQLModel の実装パターンに合わせること
- 一覧取得ではユーザー名をJOINで取得し、N+1を避けること
- Spring Boot の `Page` 互換形式を維持すること

## スコープ外

- ファイルドメイン未移植部分の完全再現
- ブラウザによる手動操作確認
