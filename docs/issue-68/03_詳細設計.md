# 03_詳細設計

## 実装対象ファイル

### `backend/app/schemas/auth.py`

- `LoginKeyRequest` を追加する

```python
class LoginKeyRequest(BaseModel):
    """ログインキー認証リクエスト"""

    loginKey: str
```

### `backend/app/repositories/user_repository.py`

- `find_by_login_key(login_key: str, tenant_id: str, session: AsyncSession) -> User | None` を追加する
- `login_key` と `tenant_id` の両方を `where` 条件に含める（テナント分離をクエリレベルで担保する）

### `backend/app/services/auth_service.py`

- `login_with_login_key(login_key: str, tenant_id: str, session: AsyncSession) -> AuthResponse` を追加する
- 処理内容:
  1. `UserRepository.find_by_login_key(login_key, tenant_id, session)` でユーザー検索
  2. 見つからない場合は `HTTPException(401, "Invalid login key")`
  3. `create_access_token(user.login_id, tenant_id)` でトークン生成
  4. `AuthResponse(id=user.login_id, name=user.name, role=user.role.value, token=token, groups=[], loginStatus="SUCCESS")` を返す

### `backend/app/routers/auth.py`

- `POST /auth/login-key` を追加する
- 既存の `/auth/login` と同様、`x_tenant_id: str = Header(..., alias="X-Tenant-ID")` を必須ヘッダーとして受け取る
- 成功時は `set_access_token_cookie` でCookieを設定する（既存 `/auth/login` と同じパターン）

```python
@router.post("/login-key", response_model=AuthResponse)
async def login_with_login_key(
    request: LoginKeyRequest,
    response: Response,
    x_tenant_id: str = Header(..., alias="X-Tenant-ID"),
    session: AsyncSession = Depends(get_session),
) -> AuthResponse:
    """ログインキーによるログイン"""
    auth_response = await AuthService.login_with_login_key(
        request.loginKey, x_tenant_id, session
    )
    if auth_response.token:
        set_access_token_cookie(response, auth_response.token)
    return auth_response
```
