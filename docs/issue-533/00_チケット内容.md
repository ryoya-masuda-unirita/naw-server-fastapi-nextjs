# 【高】seed_via_bastion.sh が存在しない backend/ を指している

## 概要
`secuaigent-infra/scripts/seed_via_bastion.sh` が、改名前のディレクトリ（`backend/`）を指していて、マイグレーションも seed の投入も失敗する。踏み台のローカルのポート（5433）が、開発用 DB と重なる。

## 説明
Issue #533 のとおり。`BACKEND_DIR="${REPO_ROOT}/backend"`（`backend/` は `server/` に改名済み）、`LOCAL_PORT=5433`（ルートの compose の PostgreSQL と同じ）。

- 発見: 2026-11-26 の全体調査。重要度は高（手順が動かない）
