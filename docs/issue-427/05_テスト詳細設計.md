# 05_テスト詳細設計

ファイル: `server/tests/integration/test_paging_tie_breaker.py`（新規）

- 定数: `TIE_COUNT = 5`、`PAGE_SIZE = 2`
- `pytest.mark.parametrize` で、挿入順（ID 昇順・逆順）と、並べ替えの向き（昇順・降順）を組み合わせる
- ヘルパー: `_collect`（最後までめくって ID を集める）、`_assert_each_row_once_in_id_order`（重複なし・ID 昇順の確認）、`_tenant`・`_user`・`_assistant`・`_room`（データ作成）
- ID は、文字列 ID は `{接頭辞}-{連番}`（1 桁なので文字列の昇順と連番が一致）、UUID は先頭を英字（`0xA << 124`）にした連番。数字だけの 16 進文字列だと、SQLite が数値として保存し直して壊れるため
- 既存テストの修正: `test_feedback.py` の `test_returns_feedback_message_with_assistant_name_and_content` は、同じ更新日時の行の先頭（`[0]`）に頼っていた。順番が ID（ランダム）で決まるようになり、不安定になったため、内容（質問の文字列）で対象の行を探す形にした
