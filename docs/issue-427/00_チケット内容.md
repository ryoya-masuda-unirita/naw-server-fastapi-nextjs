# NAW-1442 ページング一覧の並び順の最後に一意キーを足す

## 概要

Issue #427（NAW-1442 の移植、`server/` 側）。ページング一覧で、並べ替えキーが同じ値の行が、ページの境界で重複したり漏れたりしないよう、並び順の最後に一意キー（`id` など）を足す。

## 説明

PostgreSQL は、並べ替えキーが同じ行の順番を保証しない。一意なキーで最後まで並べないと、同じ値の行がページの境界をまたいだとき、ページを送るたびに順番が変わり、同じ行が 2 回出たり、出なかったりする（移植元で確認された不具合）。
