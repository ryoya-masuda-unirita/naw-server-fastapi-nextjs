# 03_詳細設計

対象は `server/app/repositories/`。各一覧の `ORDER BY` の**最後**に、一意キーの昇順を足す。並べ替えの列・向きは変えない。

| # | ファイル | 関数 | 変更 |
|---|---|---|---|
| 1 | `library_repository.py` | `find_page` | `.order_by(order)` → `.order_by(order, Library.id.asc())` |
| 2 | `token_usage_repository.py` | `find_page` | `.order_by(order_clause)` → `.order_by(order_clause, TokenUsage.id.asc())` |
| 3 | `message_feedback_repository.py` | `find_feedback_messages` | 並べ替えの列のあとに `MessageFeedback.id.asc()` |
| 4 | `message_feedback_repository.py` | `find_feedback_users` | 並べ替えの列のあとに、集計 CTE の `stats.c.user_id.asc()` |
| 5 | `room_repository.py` | `find_feedback_rooms` | 並べ替えの列のあとに `Room.id.asc()` |
| 6 | `room_repository.py` | `find_admin_histories` | 並べ替えの列のあとに `Room.id.asc()` |
| 7 | `library_tag_repository.py` | `find_page` | `.order_by(LibraryTag.name.asc())` → `, LibraryTag.id.asc()` を足す |
| 8 | `room_repository.py` | `find_page_viewable_by_user` | `.order_by(pinned_order.asc(), Room.updated_at.desc())` のあとに `Room.id.asc()`（Issue にはない。移植元 `RoomService` の 2 か所に合わせた） |

- 一意キーは、向きにかかわらず**昇順**（移植元と同じ）。共通部品 `build_order_by` の既定（先頭と同じ向き）は使わない
- `library_tag_repository.py` の、全件取得（`find_by_tenant_id_order_by_name`）は、ページングではなく、名前もテナント内で一意なので、変えない
- 使われなくなるコードは出ない
