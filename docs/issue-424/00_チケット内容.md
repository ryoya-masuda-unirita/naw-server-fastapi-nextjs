# NAW-1417 ルームのメッセージ一覧をメッセージ内容の作成日時の昇順で返す

## 概要

Issue #424（NAW-1417 の移植、`server/` 側）。ルームのメッセージ一覧（`GET /api/messages?roomId=…`）を、メッセージ内容（`message_contents`）の作成日時の昇順で返す。

## 説明

- `server/app/repositories/message_repository.py` の `find_by_tenant_id_and_room_id_with_feedback` に `order_by` がなく、並び順が不定。編集・再生成で、同じ親から分かれた版のうち「最新の版」を選ぶ処理（`client/` の満足度タブの追加学習 #425 など）の結果が、不定になる
- 内容がないメッセージは末尾、同順位は `messages.id` の昇順
- 並び順を確かめるテストを足す

## その他

- 移植元: `secuaigent-ref/server` の `MessageRepository`（コミット 3d84528a7。NAW-1417 FB1-02）。移植元の説明: 「`messages` テーブルには作成日時がないので、メッセージの内容の作成日時で並べる。内容がまだないメッセージは末尾」
- 後続: #425（`client/`、満足度タブの追加学習でルームのやり取りを学習データにする）の前提
- 並び順の一意キーの足し方は、#427（NAW-1442）と揃える（共通部品 `build_order_by(tie_breaker=...)`）
- ブランチは `git` で直接作成した（GitHub の GraphQL API のレート制限のため、`gh issue develop` が使えなかった）。Issue への紐づけと、プロジェクトボードの更新は、制限の回復後にやり直す
- 費用がかかるため、デプロイはしない（ユーザーの指示）。この変更は、AWS・インフラに触れない
