## 確認の途中で分かったこと

- `.env` なしで、全体のテストを実行すると、`test_auth.py` の 1 件が失敗した（`Settings` が `DATABASE_URL`・`SECRET_KEY` を必須とするため）。**この変更とは無関係の、環境の違い**（この worktree には、Git 管理外の `.env` がなかった）。CI と同じく `.env` を用意して、全体が成功することを確認した
