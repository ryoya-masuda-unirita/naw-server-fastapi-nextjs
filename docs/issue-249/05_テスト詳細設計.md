# 05_テスト詳細設計

Bedrock・Azure OpenAI の実呼び出しは行わず、`AzureLlmChatClient.stream_chat` / `BedrockLlmChatClient.stream_chat`
（クライアント単体のテストでは `anthropic.AsyncAnthropic`）をモックする。

## `backend/tests/unit/test_llm_client.py`

| No | クラス / テスト | 内容（docstring） |
|---|---|---|
| 1 | `TestCapMaxTokens.test_caps_to_model_max_tokens` | 指定値がモデルの上限を超える場合、モデルの上限に切り詰めること |
| 2 | `TestCapMaxTokens.test_keeps_requested_when_within_limit` | 指定値がモデルの上限以下の場合、指定値のままであること |
| 3 | `TestCapMaxTokens.test_returns_none_when_not_requested` | 指定がない場合はNoneを返すこと |
| 4 | `TestBedrockLlmChatClient.test_validate_request_raises_when_tools_specified` | toolsを指定するとvalidate_requestがValueErrorを送出すること |
| 5 | `TestBedrockLlmChatClient.test_validate_request_accepts_no_tools` | toolsが未指定・空の場合はvalidate_requestが例外を送出しないこと |
| 6 | `TestBedrockLlmChatClient.test_passes_max_tokens_to_messages_stream` | 渡したmax_tokensがそのままMessages APIへ渡されること（旧 `test_falls_back_max_tokens_when_none` を置き換え） |
| - | 削除: `test_raises_value_error_when_max_tokens_and_fallback_both_none` | `max_tokens_fallback` 削除により不要 |

## `backend/tests/unit/test_llm_chat_service.py`

| No | テスト | 内容 |
|---|---|---|
| 7 | `TestStreamChatBedrockDispatch.test_dispatches_to_bedrock_client_for_bedrock_model`（更新） | maxTokens 未指定時、Bedrock にモデルの上限（4096）が渡ること |
| 8 | `TestStreamChatBedrockDispatch.test_caps_max_tokens_for_azure`（parametrize: 10000→4096, 100→100, 未指定→None） | Azure の呼び出しで maxTokens がモデル上限で切り詰められ、未指定なら None のままであること |
| 9 | `TestStreamChatBedrockDispatch.test_caps_max_tokens_for_bedrock` | Bedrock の呼び出しで maxTokens がモデル上限で切り詰められること |
| 10 | `TestStreamChatBedrockDispatch.test_raises_400_when_tools_specified_for_bedrock` | Bedrock で tools 指定時 400、クライアントを呼ばないこと |
| 10-2 | `TestStreamChatBedrockDispatch.test_message_not_found_takes_precedence_over_bedrock_tools_error` | Bedrock で tools を指定しても、messageId が存在しなければ 404 を優先すること（code-review #3） |
