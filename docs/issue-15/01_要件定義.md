# 要件定義

## 背景

- バックエンド（FastAPI）の認証・ユーザー API が実装済み
- フロントエンド（React）は設定ファイルのみで、実装コードがゼロ
- 参照リポジトリ（Angular）の認証実装をベースに、React へ移植する

## 機能要件

### 1. 認証状態管理

- Zustand による認証ストア
  - ユーザー情報（id, name, role, groups）
  - セッション確認（初期化時に GET /api/auth を実行）
  - sessionStorage への永続化（USER, TENANT_ID）
  - 計算値：isAuthenticated, isAdmin, userName

- TanStack Query による認証 API hooks
  - login / logout / getSession 操作
  - エラーハンドリング（429: レート制限、401/403: 認証失敗）

### 2. API クライアント

- fetch ラッパー（api-client.ts）
  - X-Tenant-ID ヘッダー付与（sessionStorage から読み込み）
  - credentials: 'include' でクッキー送信
  - ベース URL = `${import.meta.env.VITE_API_URL}/api`

### 3. 認証ガード（ルーティング）

- ProtectedRoute ガード
  - 認証済みユーザーのみアクセス可能
  - 未認証ならログイン画面へ

- PublicRoute ガード
  - 未認証ユーザーのみアクセス可能
  - 認証済みならダッシュボードへ

- getSession で セッション確認→キャッシング

### 4. 認証画面

#### ログイン画面
- username / password フォーム（バリデーション付き）
- エラーハンドリング表示
- 多言語サポート（react-i18next）
- ログイン結果：
  - SUCCESS → ダッシュボードへ
  - REQUIRES_PASSWORD_RESET → パスワードリセット画面へ遷移

#### パスワードリセット画面
- username / oldPassword / newPassword / confirmPassword フォーム
- パスワードリセット理由表示（INITIAL / EXPIRED）
- バリデーション：
  - minLength（environment.minPasswordLength）
  - newPassword と confirmPassword の相違確認
- ナビゲーション state から username / oldPassword / reason を自動填入
- 成功時 → ダッシュボードへ

### 5. レイアウト

- AuthLayout
  - ログイン・パスワードリセット用の シンプルレイアウト
  - 中央配置フォーム、ロゴ、リンク等

## 非機能要件

- **ブラウザストレージ**: sessionStorage のみ（ページ閉じたら自動削除）
- **i18n**: react-i18next で 日本語・英語対応
- **テスト**: Vitest + React Testing Library
- **型安全性**: TypeScript strict mode
- **スタイリング**: Tailwind CSS
- **バリデーション**: クライアント側バリデーション（フォーム）

## スコープ外

- OAuth / OIDC（Google / Microsoft ログイン）
- 多要素認証
- 正常系以外のネットワークエラーハンドリング（5xx など）
- アクセスログ出力

## 依存関係

- バックエンド API
  - POST /api/auth/login → LoginResponse
  - POST /api/auth/password/reset → AuthSessionResponse
  - GET /api/auth → BackendAuthResponse
  - POST /api/auth/logout
