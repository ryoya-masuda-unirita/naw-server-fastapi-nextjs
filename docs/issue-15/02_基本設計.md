# 基本設計

## 変更対象レイヤー

- **フロントエンド**（React / TypeScript）
  - src/lib/ — API クライアント、定数、ユーティリティ
  - src/types/ — 型定義
  - src/store/ — Zustand ストア
  - src/hooks/ — カスタムフック
  - src/routes/ — ページコンポーネント、ルート定義
  - src/components/ — 再利用可能なコンポーネント

## 画面 / API 変更概要

### フロント側の画面フロー

```
初期化
  ↓
[getSession で セッション確認]
  ↓
  ├─ 認証済み → /dashboard
  │
  └─ 未認証
      ↓
      [ログイン画面]
        ↓
        ├─ ログイン成功（SUCCESS）
        │   ↓
        │   /dashboard
        │
        ├─ パスワード変更必須（REQUIRES_PASSWORD_RESET）
        │   ↓
        │   [パスワードリセット画面]
        │       ↓
        │       /dashboard
        │
        └─ ログイン失敗（401/403 or ネットワークエラー）
            ↓
            [エラー表示]
```

### バックエンド API エンドポイント（既存）

| メソッド | パス | 説明 | リクエスト | レスポンス |
|---|---|---|---|---|
| POST | /api/auth/login | ログイン | LoginRequest | LoginResponse |
| POST | /api/auth/password/reset | パスワードリセット | ResetPasswordRequest | AuthSessionResponse |
| GET | /api/auth | セッション確認 | なし | BackendAuthResponse |
| POST | /api/auth/logout | ログアウト | なし | 200 OK |

### HTTP ヘッダー

すべてのリクエストに以下を付与：

```
X-Tenant-ID: {sessionStorage の TENANT_ID}
Cookie: {バックエンドが設定したセッションクッキー}
```

（fetch の credentials: 'include' で自動送信）

## コンポーネント設計

### API クライアント (`src/lib/api-client.ts`)

```
api-client
├── baseURL = VITE_API_URL + /api
├── headers
│   └── X-Tenant-ID: resolveTenantId()
├── credentials: 'include'
└── methods: get / post / put / delete
```

### Zustand ストア (`src/store/auth-store.ts`)

```
AuthStore
├── user: Signal<User | null>
├── isAuthenticated: Computed<boolean>
├── isAdmin: Computed<boolean>
├── userName: Computed<string>
│
├── ensureInitialized()        セッション確認・初期化
├── login(credentials)          ログイン処理
├── logout()                    ログアウト処理
└── [private]
    ├── initializeSession()
    ├── handleAuthSuccess()
    ├── saveToStorage()
    └── clearStorage()
```

### TanStack Query Hooks (`src/hooks/use-auth.ts`)

```
useAuth()
├── useLoginMutation()     POST /api/auth/login
├── useLogoutMutation()    POST /api/auth/logout
├── useSessionQuery()      GET /api/auth
└── useResetPasswordMutation()  POST /api/auth/password/reset
```

### ルーティング (`src/routes/index.tsx`)

```
ProtectedRoute
├── 条件: authStore.isAuthenticated() === true
└── 未認証時: ナビゲート to /auth/login

PublicRoute (AuthPage)
├── 条件: authStore.isAuthenticated() === false
└── 認証済み時: ナビゲート to /dashboard
```

## 影響範囲

### フロント

- 新規ファイル多数（上記ディレクトリ構造参照）
- main.tsx で ルート初期化・App Initializer セットアップ

### バック

- 変更なし（既存 API を使用するだけ）

## 技術スタック決定理由

| 技術 | 理由 |
|---|---|
| Zustand | 軽量、セットアップ簡単、signal の composition に最適 |
| TanStack Query | React Query として実績多、キャッシング・同期が自動 |
| React Router v7 | loader による認証ガード実装が自然 |
| react-i18next | Angular 実装と同じ、実績多 |
| Tailwind CSS | 指定スタック、セットアップ済み |
| MSW | ローカル開発・テスト時のモックサーバー |

## 状態フロー（Zustand + TanStack Query）

```
App Init
  ↓
ensureInitialized()
  ├─ getSession (TanStack Query)
  │   ├─ キャッシュあり → 即座に返す
  │   └─ キャッシュなし → API 呼び出し
  │       ↓
  │       GET /api/auth
  │           ↓
  │           ├─ 200 → user = response
  │           └─ 401 → user = null
  │
  └─ sessionStorage 復元
      ↓
      ルート評価
        ↓
        ├─ /dashboard → 表示
        └─ /auth/login → 表示
```
