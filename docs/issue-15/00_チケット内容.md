# フロントエンド基盤構築と認証画面の実装

## 概要

Angular 実装（`~/Documents/secuaigent-client`）を参照しながら、React フロントエンドの初期セットアップと認証機能を実装する。

## 説明

現在 `frontend/` 配下には設定ファイルのみ存在し、実装コードがゼロの状態。バックエンドの auth/users API が実装済みのため、それらと接続できる最小限の UI 基盤を構築する。

### 実装範囲

#### 1. プロジェクト初期セットアップ

- Vite + React 19 + TypeScript + Tailwind CSS の初期化
- React Router v7 のセットアップ
- TanStack Query のセットアップ
- Zustand のセットアップ
- react-i18next のセットアップ
- MSW（Mock Service Worker）のセットアップ
- Vitest + React Testing Library のセットアップ

#### 2. コアインフラ

- `src/lib/api-client.ts` — fetch ラッパー（X-Tenant-ID ヘッダー付与、withCredentials）
- `src/lib/constants/routes.ts` — ルート定数
- `src/lib/constants/api-paths.ts` — API パス定数
- `src/types/auth.ts` — 認証関連型定義

#### 3. 認証状態管理

- `src/store/auth-store.ts` — Zustand による認証ストア（ユーザー情報・セッション管理）
- `src/hooks/use-auth.ts` — TanStack Query による認証 API hooks（login / logout / session）

#### 4. 認証画面

- `src/routes/auth/login.tsx` — ログイン画面
- `src/routes/auth/pw-reset.tsx` — パスワードリセット画面
- `src/components/layouts/auth-layout.tsx` — 認証ページ用レイアウト

#### 5. ルーティング

- `src/routes/index.tsx` — ルート定義（認証済みルート・未認証ルートの分岐）
- React Router v7 の loader を使った認証ガード

#### 6. テスト

- `src/hooks/use-auth.test.ts` — 認証 hooks の単体テスト
- `src/routes/auth/login.test.tsx` — ログイン画面のコンポーネントテスト
