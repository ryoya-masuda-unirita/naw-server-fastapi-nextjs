# LibraryTag CRUD APIの移植

## 概要

Spring Boot版 (naw-server) の LibraryTag 機能をFastAPIに移植する。ライブラリタグの一覧取得・作成・更新・一括削除を行うCRUD API一式。

## 説明

- 対象エンドポイント
  - `GET /api/libraries/tags`（一般ユーザー向け一覧）
  - `GET /api/admin/library-tags`（管理者向けページング一覧、search対応）
  - `POST /api/admin/library-tags`（作成）
  - `PATCH /api/admin/library-tags/{id}`（更新）
  - `DELETE /api/admin/library-tags`（一括削除、body指定）
- 移植元
  - Controller: `~/Documents/naw-server/src/main/java/com/example/naw/api/LibraryTagController.java`
  - Service: `~/Documents/naw-server/src/main/java/com/example/naw/service/LibraryTagService.java`
  - Domain: `~/Documents/naw-server/src/main/java/com/example/naw/domain/library/LibraryTagEntity.java`
  - Request: `LibraryTagCreateRequest.java` / `LibraryTagUpdateRequest.java` / `LibraryTagDeleteRequest.java`
  - Response: `~/Documents/naw-server/src/main/java/com/example/naw/response/LibraryTagResponse.java`

## その他

naw-autopilot による自動選定。Libraryドメイン本体（library_tag_mappings）とは独立したテーブル・サービスのCRUDで依存が少ないため選定。今回はLibraryTag単体のみを対象とし、Library本体・LibraryTagMappingは対象外。
