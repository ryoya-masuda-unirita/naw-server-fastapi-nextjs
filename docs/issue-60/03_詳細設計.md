## モデル設計（`app/models/library_tag.py`）

```python
class LibraryTag(SQLModel, table=True):
    __tablename__ = "library_tags"
    __table_args__ = (
        sa.UniqueConstraint("tenant_id", "name", name="uq_library_tags_tenant_id_name"),
    )

    id: str = Field(max_length=32, primary_key=True, default_factory=lambda: uuid.uuid4().hex)
    tenant_id: str = Field(sa_column=sa.Column(sa.String(32), sa.ForeignKey("tenants.id", ondelete="CASCADE"), nullable=False))
    name: str = Field(max_length=255)
    description: str | None = Field(default=None, sa_column=sa.Column(sa.Text, nullable=True))
    created_at: datetime = Field(sa_column=sa.Column(sa.DateTime(timezone=True), nullable=False, server_default=sa.func.now()))
    updated_at: datetime = Field(sa_column=sa.Column(sa.DateTime(timezone=True), nullable=False, server_default=sa.func.now(), onupdate=sa.func.now()))
```

移植元の `updated_user_id` はLibraryTagEntityに存在しないため実装しない（assistant_categoriesとの差分）。

## スキーマ設計（`app/schemas/library_tag.py`）

```python
class _LibraryTagRequestBase(BaseModel):
    name: str | None = Field(default=None, max_length=255)
    description: str | None = Field(default=None)

class LibraryTagCreateRequest(BaseModel):
    name: str = Field(max_length=255)
    description: str | None = Field(default=None)

    @field_validator("name")
    @classmethod
    def _validate_name_not_blank(cls, value: str) -> str:
        if not value.strip():
            raise ValueError("タグ名は必須です")
        return value

class LibraryTagUpdateRequest(_LibraryTagRequestBase):
    """name/descriptionともに未指定(None)の場合は現状維持する"""

class LibraryTagDeleteRequest(BaseModel):
    ids: list[str] = Field(min_length=1)

class LibraryTagResponse(BaseModel):
    id: str
    tenantId: str
    name: str
    description: str | None
    createdAt: datetime
    updatedAt: datetime

class LibraryTagListResponse(BaseModel):
    tags: list[LibraryTagResponse]

class LibraryTagPageResponse(BaseModel):
    content: list[LibraryTagResponse]
    totalElements: int
    number: int
    size: int
```

- 作成時の`name`は必須（移植元 `@NotBlank`）。更新時は移植元同様、空白のみ・null は「未指定」として現状維持する（Javaの `StringUtils.isNotBlank` 相当をAPI側で明示的に判定する）。

## リポジトリ設計（`app/repositories/library_tag_repository.py`）

- `find_by_tenant_id_order_by_name(tenant_id, session)` — 名前順全件取得
- `find_page(tenant_id, search, page, size, session)` — ページング・検索（`ilike`、`%`/`_`/`\`エスケープ）
- `find_by_id_and_tenant_id(id, tenant_id, session)`
- `find_by_tenant_id_and_ids(tenant_id, ids, session)` — 削除対象の一括取得
- `create(tag, session)` / `update(tag, session)`
- `delete_many(tags, session)` — 一括DELETE（1文で実行）

## サービス設計（`app/services/library_tag_service.py`）

- `get_all_library_tags(tenant_id, session) -> list[LibraryTagResponse]`
- `get_library_tags_page(tenant_id, search, page, size, session) -> LibraryTagPageResponse`
- `create_library_tag(tenant_id, req, session) -> LibraryTagResponse`
- `update_library_tag(id, tenant_id, req, session) -> LibraryTagResponse`（404: 存在しない場合）
- `delete_library_tags(tenant_id, ids, session) -> None`（存在しないIDは無視）

## ルーター設計（`app/routers/library_tags.py`）

- `library_tag_router = APIRouter(prefix="/api/libraries/tags", tags=["library-tags"])`
  - `GET ""` → `get_current_user` 依存、`get_all_library_tags`
- `admin_library_tag_router = APIRouter(prefix="/api/admin/library-tags", tags=["admin-library-tags"])`
  - `GET ""`（page/size/searchクエリ） → `require_admin`
  - `POST ""` → `require_admin`
  - `PATCH "/{id}"` → `require_admin`
  - `DELETE ""`（bodyでids指定） → `require_admin`
