# 01_要件定義

## 背景

Spring Boot版に存在するライブラリタグ機能をFastAPI版に移植し、テナント内でライブラリに付与するタグを管理できるようにする。

## 機能要件

- テナント内のライブラリタグを名前順に全件取得できる（一般ユーザー向け）
- テナント管理者はライブラリタグをページング・検索付きで一覧取得できる
- テナント管理者はライブラリタグを新規作成できる
- テナント管理者は既存のライブラリタグの名前・説明を更新できる（未指定項目は変更しない）
- テナント管理者はライブラリタグを複数件まとめて削除できる（存在しないIDは無視する）
- 上記いずれの操作もテナント分離が保たれること（他テナントのデータを操作・参照できない）
- 一般ユーザー向け一覧取得は管理者権限を要求しない
- 管理者向け操作（一覧・作成・更新・削除）は管理者権限を要求する

## 非機能要件

- テナント間のデータ分離をDBレベル（RLS）で担保する
- 既存の `assistant_categories` 実装と同様のレイヤー構成（router/service/repository/model）に従う

## スコープ外

- `Library`（ライブラリ本体）エンティティの実装
- `LibraryTagMapping`（ライブラリとタグの紐付け）の実装
- フロントエンド（React / Angular）側の対応
