# 08_動作確認

## 確認環境

- ローカルPostgreSQL（docker-compose、`naw-fastapi-postgres`）
- `alembic upgrade head` 実行済み（`014_add_library_tags` 適用確認）
- `uvicorn app.main:app --port 8099`（ローカル動作確認用に既存プロセスと衝突しない別ポートを使用）
- 認証: `seed.sql` の `admin` / `test-tenant`（`POST /auth/login` でトークン取得）

## 確認手順

1. `docker compose ps` でDBのUp/healthyを確認
2. `alembic upgrade head` を実行
3. `uvicorn` を起動
4. `POST /auth/login`（`X-Tenant-ID: test-tenant`）でアクセストークンを取得
5. 取得したトークンで各エンドポイントを `curl` で呼び出し

## 確認結果

| No | 内容 | 結果 |
|---|---|---|
| 1 | `GET /api/libraries/tags`（作成前） | `{"tags":[]}`（200） |
| 2 | `POST /api/admin/library-tags`（作成） | 200、id・name・description・createdAt・updatedAtを含むレスポンス |
| 3 | `GET /api/libraries/tags`（作成後） | 作成したタグが返る（200） |
| 4 | `GET /api/admin/library-tags?page=0&size=20` | `content`/`totalElements`/`number`/`size` 形式で1件返る（200） |
| 5 | `PATCH /api/admin/library-tags/{id}`（description のみ指定） | `name`は変更されず`description`のみ更新される（200） |
| 6 | `POST /api/admin/library-tags`（同名で再作成） | 400 |
| 7 | `DELETE /api/admin/library-tags`（該当IDを指定） | 204 |
| 8 | `GET /api/libraries/tags`（削除後） | `{"tags":[]}`（200） |

いずれも期待通りの結果となった。
