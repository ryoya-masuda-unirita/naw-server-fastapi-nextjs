## 変更ファイル

### `backend/app/services/user_service.py`

- `_SORTABLE_COLUMNS["role"]` を `User.role` から `sqlalchemy.cast(User.role, String)` に変更する
  - PostgreSQL のネイティブ enum `userrole`（宣言順 `USER, ADMIN, SYSTEM`）を文字列にして、移植元の varchar と同じ `ADMIN < SYSTEM < USER` の順にする
  - `typing.cast` と名前が衝突するため `from sqlalchemy import cast as sa_cast` で import する
- `get_users` のソート方向の解釈
  - `sort_dir` 文字列の比較をやめ、`is_desc = len(sort_parts) > 1 and sort_parts[1].strip().lower() == "desc"` にする
- `get_users` の ORDER BY 組み立て
  - 既存の主キー（`totalCredits` の場合はクレジット合計＋`User.name asc`）の後に、`User.id` を `is_desc` に合わせた方向で追加する
