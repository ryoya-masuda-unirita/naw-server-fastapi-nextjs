# #172 ユーザー管理一覧の並べ替えUIがAPIに反映されず表示順が変化しない

## 概要

管理コンソール「ユーザー管理」一覧の並べ替えUI（更新日時順/表示名順/権限順/利用クレジット順、昇順/降順）を操作しても、実際の表示順が変化しない。

## 説明

Issue 本文（起票時点の記載）より:

- 原因: `user_repository.py` の一覧取得系クエリに `order_by` が実装されておらず、DB のデフォルト順で返却される。ソートキー・順序を受け取るパラメータも存在しない
- 発見経緯: Issue #166（結合テスト E2E の Playwright 自動化、13_ユーザー管理 項番10「並べ替え」）で発見
- 対応方針案: 一覧取得メソッドにソートキー・順序パラメータを追加し、`order_by` を動的に組み立てる

## その他

- 関連: Issue #170（テンプレート一覧の並べ替え不具合）、Issue #181（チーム所属ユーザー一覧の並べ替え不具合）
- 調査の結果、起票時点の原因記載は現行コードと一致しない（`01_要件定義.md` 背景を参照）
