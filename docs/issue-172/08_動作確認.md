# 08_動作確認

## 確認環境

- ブラウザ・実機での確認は行わず、自動テストだけで代わりに確認した（ローカルの PostgreSQL/Redis/backend サーバーは他の作業と共有しているため起動・変更していない）
- テスト DB: インメモリ SQLite、Redis: fakeredis（`backend/tests` 標準構成）
- `backend/.env` はメインの作業ツリーからコピーしたものを使用（gitignore 対象）

## 確認手順

```bash
cd backend
uv run pytest tests/integration/test_users.py tests/unit/test_user_service.py -v -p no:warnings -k "TestGetUsersSearchAndSort or TestResolveSortColumn"
uv run pytest -q -p no:warnings
uv run ruff check app tests
uv run ruff format --check app tests
uv run mypy app
```

### 修正前の再現確認

修正前のコード（origin/develop）で一時テストを実行し、更新日時が同値のユーザー群では `sort=updatedAt,asc` と `sort=updatedAt,desc` の結果が完全に同じ並びになることを確認した（一時テストは確認後に削除）。

```
USERS updatedAt,asc 200 ['Admin', 'bob', 'Alice', 'carol', 'ページ送り確認用ユーザー02', 'ページ送り確認用ユーザー01', 'E2E']
USERS updatedAt,desc 200 ['Admin', 'bob', 'Alice', 'carol', 'ページ送り確認用ユーザー02', 'ページ送り確認用ユーザー01', 'E2E']
```
