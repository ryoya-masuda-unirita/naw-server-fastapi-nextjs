# 01_要件定義

## 背景

React 版フロントエンドは、ログイン・パスワードリセット・空のサイドバー・仮のダッシュボードしかない。これから 9〜15 件の画面移植を並列で進めるため、全画面が共通で使うルート・権限ガード・サイドバー・翻訳辞書を先に揃え、各画面の担当が共通ファイルを触らずに自分の画面だけを書けるようにする。

## 機能要件

### ルート

1. 移植元の全画面のパスを、移植元と同じ文字列で定義する（認証・ダッシュボード・管理コンソール配下・ライブラリ・チャット・共有チャット・フィードバックプレビュー・旧ユーザー管理・レポート・設定）
2. 未移植の画面は「未移植」と、画面名・担当 Issue 番号が分かる仮の画面を表示する。各画面の担当は、その仮の画面のファイルを書き換えるだけで画面を差し替えられる
3. パスワードリセットのパスを移植元と同じ「/auth/password/reset」にする（旧パス「/auth/pw-reset」は廃止）
4. 移植元のリダイレクトを揃える
   - 「/」「/auth」はそれぞれダッシュボード（未ログインならログイン）・ログイン画面へ
   - 「/chat」はダッシュボードへ（移植元は「/admin/chat/new」へリダイレクトし、該当ルートがないため最終的にダッシュボードになる）
   - グループ詳細（「/admin/groups/:id」）は「users」タブへ
   - 該当しないパスは、ログイン済みならダッシュボード、未ログインならログイン画面へ
5. ブラウザのタブのタイトルは移植元と同じく常に「SecuAiGent」にする
6. 用語集・データソースの画面とルートは作らない（移植元で非表示にした機能のため）

### 権限ガード

移植元のガードと同じ条件・同じ遷移先にする。

| ガード | 通す条件 | 通さないときの遷移先 |
|---|---|---|
| 認証 | ログイン済み | ログイン画面 |
| 未認証（ログイン画面用） | 未ログイン | ダッシュボード |
| 管理者（旧ユーザー管理・レポート・設定） | テナント管理者 | 未ログインはログイン画面。ログイン済みの非管理者は遷移しない（画面を出さない） |
| 管理コンソール（「/admin」配下全体） | テナント管理者またはグループ管理者 | 未ログインはログイン画面、それ以外は新規チャット |
| テナント管理者（ユーザー・テナント・チャット履歴・アシスタント・テンプレート・フィードバック・学習データ） | テナント管理者 | グループ管理者はグループ一覧、それ以外は新規チャット |
| グループアクセス（グループ詳細・旧グループメンバー） | テナント管理者、または URL のグループの管理者 | グループ一覧 |

認証状態には、移植元の AuthStore と同じく「グループ管理者か」「グループ管理者だけか（テナント管理者ではない）」「管理コンソールに入れるか」「管理しているグループの ID 一覧」を持たせる。セッション確認 API がグループ情報を返さない場合は、保存済みのグループ情報を引き継ぐ（移植元と同じ）。

### レイアウト・サイドバー

移植元の管理レイアウト（サイドバー＋メイン領域）と同じ見た目・挙動にする。

1. ロゴ（ダッシュボードへのリンク）・折りたたみボタン・モバイル時のオーバーレイと閉じるボタン・メイン領域の左余白（展開時 64・折りたたみ時 13）
2. サイドバーのモードは URL で決まる
   - 管理モード: 管理コンソールの画面（ユーザー・グループ・テナント・アシスタント・チャット履歴・学習データ・フィードバック・テンプレート）。管理メニューを表示する。テナント管理者は全メニュー（管理コンソール: ワークスペース設定・ユーザー管理・チーム管理、サービス設定: アシスタント・チャット履歴・学習データ・フィードバック・テンプレート）、グループ管理者だけのユーザーは「チーム管理」だけ。グループ管理者だけのユーザーがグループ以外の管理画面を開いた場合はグループ一覧へ移す
   - 戻るモード: ライブラリ詳細・共有チャット履歴・フィードバックプレビュー。「戻る」ボタンだけを表示し、押すとブラウザ履歴を 1 つ戻る。ユーザーメニューも隠す
   - 通常モード: それ以外。「新しいチャット」「チャットを検索」ボタン、「データ活用」セクション（ライブラリ）、「外部サービス」セクション（Ranabase。押すと外部サイトを新しいタブで開く）。セクションは見出しのクリックで開閉できる
3. ユーザーメニュー: パスワード設定（パスワードリセット画面へ）、クレジット確認、管理画面への切り替え（管理コンソールに入れるユーザーだけに表示。管理モード中は「チャットに切り替え」、グループ管理者だけのユーザーには「チーム管理に切り替え」と表示）、ログアウト（確認後にログアウト）
4. 管理画面への切り替え: テナント管理者はワークスペース設定、グループ管理者はグループ一覧へ。チャットへの切り替えは新規チャットへ
5. 画面遷移のたびにモバイルのサイドバーを閉じる。ダッシュボード・新規チャットへの遷移時はアシスタントとテンプレートのキャッシュを無効化する（移植元と同じ）

### 管理画面の共通枠

管理画面の各画面が使う共通の枠（ヘッダー領域＋メイン領域）を用意する。ヘッダーの中身（ページヘッダー部品）は共通 UI の Issue（#278）で作るため、枠はヘッダー部分を差し込める形にする。

### 翻訳辞書

移植元の日本語・英語の辞書を丸ごと移植する。React 独自のテナント ID 入力欄の文言（2 キー）だけ追加で残す。

### 規約

フロントエンドの規約ファイルを実際の技術スタック（Vite + React Router）に合わせて直し、ディレクトリ規約と「画面を足すときの手順」を書く。

## 非機能要件

- lint・型チェック・単体テスト・ビルドがすべて通ること
- 未移植の画面は遅延読み込みにし、後から重い画面（チャットの描画ライブラリ等）が入っても初期表示が重くならないようにする

## スコープ外

- サイドバーのチャットルーム一覧（ピン留め・リネーム・削除・並び替え）: #285
- 新しいチャットダイアログ・チャット検索モーダル・クレジット確認ダイアログの中身: 各チャット・共通 UI の Issue。サイドバーからは開くところまで（中身は仮）
- ページヘッダー・ダイアログ・確認ダイアログ等の共通 UI、移植元の共通スタイルの一括移行: #278。ログアウト確認は #278 の確認ダイアログができるまで既存のブラウザ標準の確認を使う
- API の型・パス定数: #279
- 各画面の中身
