### 権限ガード

Angular のガード関数を、子要素を包む React コンポーネント（条件を満たさなければ遷移先へリダイレクト）に置き換える。React 版はアプリ起動時にセッション確認を待ってから描画するため、ガードは同期的に認証ストアを読むだけでよい。

移植元の管理者ガードは、ログイン済みの非管理者に対してナビゲーション自体を取り消す（直接 URL を開いた場合は何も表示されない）。React Router には取り消しがないため、何も描画しない形で揃える。

### サイドバーのモード

移植元は UI ストアにモードを持ち、遷移のたびに URL から設定している。モードは URL だけで決まり（他の画面からは参照されない）、React では URL からその場で導出する。ストアにモードを持たないため、再読み込み時も同じ結果になる。

### 新しいチャット・チャット検索・クレジット確認

サイドバーのボタンからは、それぞれのダイアログ部品を開閉するところまでを作る。ダイアログ部品は担当 Issue 用の仮ファイルとして用意し、担当はそのファイルだけを書き換える（サイドバーを触らなくて済む）。

## 影響範囲

- パスワードリセットのパス変更: ログイン（パスワードリセット必須時の遷移）とユーザーメニューの遷移先が新しいパスになる
- 既存の仮のダッシュボード画面は、新規チャットの仮の画面に置き換わる
- 既存の「モバイル用の浮きボタン」（移植元にない React 独自のもの）を削除する。移植元ではページヘッダーのボタンでサイドバーを開くため、#278 のページヘッダーで同じ操作ができるようになる
- 翻訳辞書の値が移植元の最新に変わる（ログイン・パスワードリセット画面の文言も移植元に揃う）

## 移植方針

`frontend/.claude/CLAUDE.md` の Angular → React 対応表に沿う。

| 移植元 | 移植先 |
|---|---|
| ルート定数（routes.config） | 同じ名前・同じ値の定数。使われていない定数（チャットの医療・在庫・採用・SecuAiGent、学習データ（旧名）、チャット履歴（管理外）、CHAT_PATHS、USER セグメント）と、用語集・データソースは持たない |
| loadComponent による遅延読み込み | React.lazy＋Suspense（フォールバックは何も出さない。移植元も読み込み中は何も出さない） |
| canActivate / canMatch のガード関数 | 子要素を包むガードコンポーネント |
| AuthStore の computed | Zustand ストアのユーザー設定時に派生値を計算して持つ |
| UiStore のサイドバーモード | URL から導出する関数 |
| LayoutConfig（ADMIN_LAYOUT_CONFIG） | 同じ形の設定定数。移植元で使われていない USER_LAYOUT_CONFIG・pageTitleKey・hideHeader・言語切り替えは持たない |
| mat-icon（Material Symbols Outlined） | 同じフォント（移植元と同じ版）を読み込み、同じアイコン名で描画する部品 |
| app-svg-icon | 同じパスデータを持つ SVG アイコン部品（全アイコンを移植し、共通 UI・各画面が足さなくて済むようにする） |
| ng-content による枠 | children と、ヘッダーを差し込む props |
| FixedTitleStrategy | HTML のタイトルを固定（ルートごとのタイトルは使われないため持たない） |

移植元の「グループ管理者だけ、かつグループ管理者でない」場合にアクセス権剥奪を通知する処理は、条件が常に偽で実行されないため移植しない。
