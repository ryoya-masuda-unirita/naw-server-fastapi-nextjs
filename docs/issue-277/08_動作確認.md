## 確認環境

- macOS（ローカル）、`frontend/` で `npm ci` 済み
- 移植元: `~/Documents/unirita-develop-pj/secuaigent-ref/client`（棚卸し時点 0f29c3da）

## 確認手順

1. `npm run lint`
2. `npm run type-check`
3. `npx vitest --run`（JSON レポーターでファイルごとの件数も取得）
4. `npm run build`
5. 移植元と移植先の i18n 辞書をフラットなキーに展開して比較（キーの有無と訳の一致）
6. ビルド成果物に Material Symbols のフォントと、サイドバーで使うカスタムクラスが出力されているかを確認
