# 02_基本設計
- `concurrency`: 実行中のデプロイは止めず、待っている間に積まれたものは、最新だけが残る（最新のコミットが、それまでの変更も含む）
- 権限: 呼び出し側のジョブに `permissions: id-token: write, contents: read` を書く（呼び出される workflow は、すでに同じ権限を宣言している）
- `infra-checks.yml`: `terraform` ジョブと `cloudfront-functions` ジョブ。`hashicorp/setup-terraform` で、`deploy-infra.yml` と同じ 1.15.8
- `e2e-checks.yml`: `e2e-spec`・`e2e-explorer` の matrix（lint・型検査）と、`e2e-explorer` の `tests/config.test.ts`（ブラウザを使わない）
- どちらも、自分自身の変更（workflow ファイル）でも動き、PR の段階で確かめられる
