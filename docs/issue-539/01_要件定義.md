# 01_要件定義
- `deploy.yml` に `concurrency`（group `deploy`、`cancel-in-progress: false`）を足し、デプロイが並走しない
- `deploy.yml` の権限を、全体は `contents: read` にし、`id-token: write` は、AWS のロールを引き受けるジョブ（infra・backend・frontend）だけに渡す
- PR 用に、infra（`terraform fmt`・`validate`（dev・bootstrap）、CloudFront Functions のテスト）と、e2e 系（e2e-spec・e2e-explorer の lint・型検査、e2e-explorer のブラウザを使わない単体テスト）の workflow を足す。AWS の資格情報・ブラウザ・compose は使わない
- `generative-ai-adapter-tests.yml` のコメントに、server-local の変更でも流れる理由を書く
- スコープ外: e2e の通し実行（ブラウザと compose が要る）、`terraform plan`
