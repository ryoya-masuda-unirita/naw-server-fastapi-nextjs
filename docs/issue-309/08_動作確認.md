# 08_動作確認

## 確認環境

- macOS、`backend/` で `uv run`（Python 3.14 の venv）
- DB はテスト用のインメモリ SQLite、Redis は fakeredis（ローカルの Postgres・Redis・backend サーバーは使わない）
- **ブラウザ・実機での確認は行わず、自動テストのみで代替した**（React のユーザー管理・フィードバック画面などは未移植）

## 確認手順

1. `uv run ruff check`・`uv run ruff format --check`・`uv run mypy app tests` を実行する
2. 変更・追加した Python ファイルを `ruff check --select D101,D102,D103,D105,D106,D107,D417 --config 'lint.pydocstyle.convention="numpy"'` で確かめる
3. `uv run pytest` を全件実行する（単体・結合とも）
4. `uv run alembic heads` で head が 1 つであることを確かめる

## 確認結果
