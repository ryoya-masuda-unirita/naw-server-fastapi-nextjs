# 05_テスト詳細設計

## 新規: `backend/tests/unit/test_errors.py`

最小の FastAPI アプリに `register_exception_handlers` を登録し、`httpx.AsyncClient`（`ASGITransport`）で呼ぶ。

| テスト | 04 No | 内容 |
|---|---|---|
| `test_http_exception_returns_message_body` | 1, 11 | `HTTPException(409, detail="使用中です")` → 409、本文のキーが `{"timestamp", "message"}` だけ、`message == "使用中です"`、`timestamp` が実行前後の UNIX 秒の範囲内の整数 |
| `test_http_exception_keeps_headers` | 2 | `headers={"X-Test": "1"}` が応答に付く |
| `test_http_exception_without_body_status` | 3 | 304 は本文なし |
| `test_unknown_path_returns_404_message` | 4 | 未定義パス → 404、`message == "Not Found"` |
| `test_method_not_allowed_returns_405_message` | 5 | GET のみのパスに POST → 405、`message == "Method Not Allowed"`、`Allow` ヘッダーあり |
| `test_missing_body_field_returns_400` | 6 | 必須項目なし → 400、`message == "Field required"` |
| `test_returns_only_first_validation_error` | 7 | 2 項目ともエラー → `message` が 1 件目のメッセージのみ |
| `test_value_error_message_has_no_prefix` | 8 | `field_validator` で `ValueError("名前は必須です")` → `message == "名前は必須です"` |
| `test_invalid_query_returns_400` | 9 | 整数のクエリに文字列 → 400 |
| `test_invalid_json_body_returns_400` | 9 | JSON として読めないボディ → 400 |
| `test_validation_error_message_falls_back_when_empty` | 10 | `validation_error_message([])` → 「リクエストが不正です」 |
