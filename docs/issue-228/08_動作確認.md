# 08_動作確認

## 確認環境

- **ブラウザ・実機確認は行わず、自動テストのみで代替する**（pytest、インメモリ SQLite + fakeredis）
  - 他の作業と共有しているローカルの Postgres / Redis / backend サーバーを起動・変更しないため
- 実行ディレクトリ: `backend/`（`.env` はメイン作業ツリーの `backend/.env` をコピーしたもの）
- ベース: `origin/develop`（`51065ef`）を取り込み済み（`git merge origin/develop` → Already up to date）
- 結合テストは PR の CI では実行されない（develop への push 時のみ）ため、手元で全件実行した

## 確認手順

1. 変更前（`origin/develop`）で `uv run pytest tests/unit tests/integration -q` を実行し、ベースラインを確認
2. 変更後に `uv run pytest tests/unit tests/integration -q`（全件）を実行
3. 新規の例外ハンドラのテスト `uv run pytest tests/unit/test_errors.py -v` を実行
4. 書き換えた結合テスト 16 ファイルだけを実行
5. 書き換えたテストが新しい挙動を確かめていることの確認として、`app/main.py` の `register_exception_handlers(app)` を一時的にコメントアウトして全件を実行し、失敗することを確認（確認後に元に戻した）
6. `uv run mypy app tests`・`uv run ruff check .`・`uv run ruff format --check .` を実行
