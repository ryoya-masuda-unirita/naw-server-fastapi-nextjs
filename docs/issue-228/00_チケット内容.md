# #228 issue-228 エラー応答の形式とバリデーションエラーのステータスコードを移植元に揃える（{message}・400）

## 概要

backend（FastAPI）のエラー応答の本文とステータスコードを、移植元 Spring Boot の `APIControllerAdvice` / `ErrorResponse` に揃える。

## 説明

移植元 Spring Boot は `APIControllerAdvice` で、エラーを `{"message": "..."}`（`ErrorResponse`）で返し、入力チェックのエラー（`MethodArgumentNotValidException`・`ConstraintViolationException`・`IllegalArgumentException`）は 400 で返す。backend（FastAPI）は `{"detail": ...}` で、入力チェックのエラーは 422 を返している。全 API のエラー応答を移植元に揃える（2026-11-12 ユーザー判断「完全に揃える」）。#171 で入れたテンプレート名の32文字超チェックも 422 から 400 になる。server-local/（#210）は移植時に揃え済みなので参考にする。既存テストの 422 / detail の確認はまとめて書き換える。#224〜#227 のマージ後に着手する。
