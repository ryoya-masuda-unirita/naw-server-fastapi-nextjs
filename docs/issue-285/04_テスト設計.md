# 04_テスト設計

## テスト方針

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ・実機確認は行わない。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 一覧の表示 | マウント時の読み込み・並び・リンク先・ルーム名を翻訳しない・ピンのアイコン・折りたたみ | 仕様どおり |
| 2 | 追加読み込み | 末尾から遠い／近いスクロール | 近いときだけ次のページ |
| 3 | 操作メニュー | 開く・背面で閉じる・遷移しない・固定中の文言 | 仕様どおり |
| 4 | ピン留め | 固定・解除の API と一覧の反映 | 仕様どおり |
| 5 | 名前変更 | 保存（空白除去）・空白のみ不可・キャンセル | 仕様どおり |
| 6 | 削除 | 確定・表示中のルームの削除で新規チャットへ・キャンセル | 仕様どおり |
| 7 | メニュー部品 | 各項目の通知・閉じているとき・位置（下／上／下限）・背面 | 仕様どおり |
| 8 | まとめて削除 | 表示・選択して削除・キャンセル・ページ送り | 仕様どおり |
| 9 | 並び替え | 表示・切り替えて保存・戻すと送らない・API 失敗で開いたまま・キャンセル | 仕様どおり |
