# 03_詳細設計

## sidebar.tsx

- `useRoomsStore` の `allRooms`・`isAllRoomsLoading`・`isRenamingRoom` を購読。マウント時に `getAllRooms()`（失敗はログ）
- `chatSection`（useMemo）: `{ labelKey: 'SIDEBAR.CHAT', collapsed: false, items: allRooms.map(room => ({ labelKey: room.name, route: config.chatRoomRoute(room.id), hasPin: room.isPinned, hasMenu: true, roomId: room.id })) }`。`allSectionGroups = [...sectionGroups, chatSection]`
- 高さ: `items.length * 36 + (読み込み中のチャットなら 36)`。チャットは折りたたみ時 `0px`
- スクロール: 末尾まで 80px 以内で `loadNextRoomsPage()`（`isAllRoomsLoading`・`allRoomsHasMore` は store が見る）。折りたたみ中は読まない
- 操作メニューの状態 `{ isOpen, roomId, topPx(= rect.bottom + 4), triggerTopPx(= rect.top), isPinned }`。ボタンのクリックは `preventDefault`・`stopPropagation`（リンク遷移させない）
- 名前変更: `renameRoomId` → `ChatRenameDialog`（title `SIDEBAR.RENAME_CHAT`・`SIDEBAR.SAVE`・`SIDEBAR.CANCEL`）。成功で閉じる
- 削除: `deleteRoomId` → 確認 `Dialog`。確定で `deleteRoom` → `handleDeletedRooms([id])` → 閉じる
- `handleDeletedRooms`: 表示中のパス（クエリ・末尾スラッシュを除く）が削除したルームのパスと一致したら `startNewChat()` + `navigate(chatNewRoute)`
- `openDialog` に `'chat-delete'`・`'chat-sort'` を追加。`ChatContextMenu`・`ChatRoomMenu` は戻るモード以外で aside の中に描画（移植元と同じ位置）

## 部品

- `useFloatingMenu(isOpen)`: `isDesktop`（幅 >= 768）・`viewportHeight`・`visible`・アニメーションのクラス。モバイルは閉じても `animationend` まで残る
- `ChatRoomMenu`: 見積もり高さ 168px。`topPx + 168 <= viewportHeight - 8` なら下、そうでなければ `triggerTopPx - 168 - 4`、下限 8px。`ChatContextMenu`: 見積もり 80px、`chatMenuTopPx - 28 - 80 - 8`
- `SidebarRouteButton`: ピン（`push_pin`・`text-primary!`）、`IconButton`（`dropdown-trigger hidden group-hover:flex …`、aria-label「操作メニュー」）、バッジ。折りたたみ時は出さない
- `ChatDeleteDialog`: 10 件ずつの表（日付・名前・最終メッセージ）。選択が 0 件の間は削除ボタン無効。確定の確認 → `deleteRooms(ids)` → `onClose(ids)`
- `ChatSortDialog`: 固定（`isPinned=true`, size 1000）と、固定していない（10 件ずつ）。未保存の変更 `pending` を重ねて表示。もとに戻した変更は送らない。保存は `bulkUpdateRoomPins(payload)` → `onClose(payload)`、失敗は開いたまま
