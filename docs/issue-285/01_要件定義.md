# 01_要件定義

## 背景

サイドバーの下半分は、利用者のチャット（ルーム）の一覧。#277 でサイドバーの枠を、#283 でルームの store（`useRoomsStore`）を移したので、一覧の画面を移す。

## 機能要件

1. チャットのセクション（`SIDEBAR.CHAT`）
   - サイドバーを開いた時点で一覧の 1 ページ目（20 件）を読み込み、静的なセクション（データ活用・外部サービス）の下に並べる。見出しは開閉できない
   - 各行は `/chat/:roomId` へのリンク。表示中のルームは強調する。ルーム名は 1 行で省略表示
   - ピン留めのルームにはピンのアイコン。行にマウスを乗せると「操作メニュー」ボタンが出る
   - 一覧の末尾まで 80px 以内までスクロールしたら次の 20 件を読み込む。読み込み中は行の下に回転アイコン
   - サイドバーを折りたたむとチャットのセクションは高さ 0
2. 操作メニュー（ルームごと）: 名前を変更・上部に固定／固定を解除・チャットを削除
   - デスクトップは行の下（収まらなければ上）に出る。モバイルは下からのシート
   - 名前の変更: ダイアログ。空白だけでは保存できない。保存時は前後の空白を除く。保存中はボタンがローディング
   - 固定・解除: API を呼び、一覧のピンと並び（固定は先頭側）を更新する
   - 削除: 確認ダイアログ（`SIDEBAR.DELETE_DIALOG.*`）。確定で削除し一覧から消す。表示中のルームなら新規チャットへ移る
3. 「選択して削除」メニュー・まとめて削除ダイアログ・並び替え（ピン一括変更）ダイアログ
   - 部品と配線を移植する（移植元でもこれらを開くボタンは存在しない）
4. `AdminChatRoomPage` の一覧読み込み（#284 の暫定）を削除する

## 非機能要件

- 見た目・文言は移植元のテンプレートのクラス・i18n キーをそのまま使う
- 共通ファイルの変更は最小限（`sidebar.tsx`・`room-list-mapper.ts`・`chat-rename-dialog.tsx`・`features/chat/README.md`）

## スコープ外

- チャット検索モーダル（#287）、`SidebarButton`（移植元で route が `#` の項目用。React の設定にその項目がない）
