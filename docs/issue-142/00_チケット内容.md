# backend CIにmypyチェックを追加する

## 概要

backend の GitHub Actions に mypy チェックを追加し、型チェックを CI で継続的に確認できるようにする。

## 説明

Ruff と pytest は既に CI（`.github/workflows/backend-tests.yml`）で実行されているが、mypy は CI に組み込まれていない。導入済みの mypy 設定と対象範囲が安定したら、CI に追加して型の回帰を早期検出できる状態にする。

対応内容（想定）:

- `.github/workflows/backend-tests.yml` に mypy ジョブまたはステップを追加する
- 実行コマンドは段階導入済みの対象範囲に合わせる
- CI ログ上で mypy の失敗原因が分かりやすい構成にする
- README / docs / AGENTS 等、必要に応じてローカル実行コマンドを更新する

受け入れ条件:

- PR 上で mypy チェックが実行される
- 既存の Ruff / 単体テスト CI と干渉しない
- CI の mypy 対象範囲が docs と一致している

スコープ外:

- backend 全体 strict mode の強制
- 未対応範囲の型エラー一括修正
