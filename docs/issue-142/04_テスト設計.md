# 04_テスト設計

## テスト方針

本Issueは CI ワークフローへの mypy 組み込みが中心のため、以下の観点で確認する。

- ローカルで `uv run mypy app tests` を実行し、対象範囲・エラー件数が想定通り（0件）であること
- 追加した `mypy` ジョブを含め、既存の `unit-tests`・`lint` ジョブに影響がないこと（既存テストの非回帰）
- PR 作成後、実際に GitHub Actions 上で `mypy` ジョブが実行され、成功すること

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | ローカルでのmypy実行 | `uv run mypy app tests` を実行する | `Success: no issues found in 195 source files` |
| 2 | 既存テストの非回帰 | `uv run pytest tests/unit -q` を実行する | 全件成功する（Issue #141 完了時点と同数） |
| 3 | Ruffの非回帰 | `uv run ruff check app tests`・`uv run ruff format --check .` を実行する | 全て成功する |
| 4 | CIでのmypyジョブ実行 | PR を作成し、GitHub Actions の実行結果を確認する | `mypy` ジョブが実行され成功する |
| 5 | 既存CIジョブとの独立性 | 同じPRで `unit-tests`・`lint` ジョブの結果を確認する | 既存ジョブも従来通り成功し、mypyジョブの追加によって失敗・スキップが発生しない |
