# 01_要件定義

## 背景

企業向けAIチャット管理SaaSでは、テナントごとにプラン（月間クレジット上限）と契約（サブスクリプション）が紐づき、AIモデル利用（トークン消費）に応じてクレジットが消費される。ユーザー本人およびテナント管理者が、現在の請求期間内のクレジット利用状況を把握できるダッシュボードAPIが必要。移植元（Spring Boot）には実装済みだが、FastAPI移植先にはまだ存在しない。前提となるプラン・サブスクリプションドメインもFastAPI側に未移植のため、本Issueで併せて移植する。

## 機能要件

- ログイン中のユーザーが、自分自身の請求期間内クレジット利用状況（合計クレジット・期間開始/終了・次回リセット日時）を取得できる
- ログイン中のユーザーが、所属テナント全体の請求期間内クレジット利用状況（合計クレジット・クレジット上限・期間開始/終了・次回リセット日時）を取得できる
- テナントに有効なサブスクリプション（ステータスがアクティブかつ契約終了日を過ぎていない）が存在しない場合、両APIとも空のレスポンスを返す
- 請求期間は契約開始日の暦日を基準とした月次サイクルで算出する。契約開始日が29〜31日の場合、該当日が存在しない月は月末に丸める
- クレジット上限（creditLimit）は、契約プランの月間クレジット上限とテナント固有の従量課金上限の合計で算出する
- いずれのAPIも `X-Tenant-ID` ヘッダーによるテナント特定と、ログイン認証を必須とする

## 非機能要件

- 読み取り専用のAPIであり、副作用（DB更新）を持たない
- 既存の `token_usages` 集計ロジックを流用し、新規の集計ロジックを増やさない
- サブスクリプション・プランのテーブルはマルチテナントの行レベルセキュリティ方針に従う（プランは全テナント共有マスタのためRLS対象外、サブスクリプションはテナント単位のためRLS対象）

## スコープ外

- プラン・サブスクリプションの作成/更新/解約などの管理系API（本Issueは参照系のみ）
- フロントエンド（React/Angular）側の対応
- クレジット利用履歴の詳細一覧表示（本Issueは合計値のみ）
