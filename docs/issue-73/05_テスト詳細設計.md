# 05_テスト詳細設計

## `backend/tests/unit/test_billing_cycle.py`（新規）

- `test_reset_instant_when_contract_start_is_first_day_of_month`: 契約開始日1日、当月内の日付で計算すると当月1日始まり・次回リセットは翌月1日になること
- `test_reset_instant_rounds_down_to_month_end_when_base_day_not_in_month`: 契約開始日31日、対象月が30日までしかない月で計算すると月末に丸められること
- `test_reset_instant_returns_none_when_today_before_contract_start`: 契約開始日より前の日付で計算すると`None`が返ること
- `test_reset_instant_for_29th_base_day_in_february`: 契約開始日29日、2月（28日まで）で計算すると期間終了が2月末に丸められること
- `test_next_reset_instant_after_current_period`: `next_billing_reset_instant_utc`が現在の請求期間の次の境界日を返すこと

## `backend/tests/integration/test_credit_usage.py`（新規）

`TestCreditUsageRouter`配下に以下を配置。DBに`plans`・`subscriptions`のテストデータを直接INSERTして検証する。

- `TestGetMyCreditUsage`
  - `test_get_my_credit_usage_with_active_subscription`: 有効サブスクリプションと自分の利用実績がある場合、totalCredits等が正しく返ること
  - `test_get_my_credit_usage_without_active_subscription`: 有効サブスクリプションがない場合、空の`{}`が返ること
  - `test_get_my_credit_usage_without_tenant_header`: `X-Tenant-ID`未指定でエラーになること
  - `test_get_my_credit_usage_without_authentication`: 未認証で401になること
- `TestGetWorkspaceCreditUsage`
  - `test_get_workspace_credit_usage_with_active_subscription`: 有効サブスクリプションがある場合、テナント全体のtotalCreditsとcreditLimitが正しく返ること
  - `test_get_workspace_credit_usage_credit_limit_is_sum_of_plan_and_tenant`: creditLimitがPlan.maxCreditsPerMonthとTenant.maxUsageBasedCreditsPerMonthの合算になること
  - `test_get_workspace_credit_usage_credit_limit_omitted_when_plan_limit_is_null`: Plan.maxCreditsPerMonthがNULLの場合、creditLimitがレスポンスに含まれないこと
  - `test_get_workspace_credit_usage_without_active_subscription`: 有効サブスクリプションがない場合、空の`{}`が返ること
  - `test_get_workspace_credit_usage_expired_subscription_is_treated_as_inactive`: end_dateが過去のサブスクリプションは有効として扱われず空レスポンスになること
