# #73 issue-73 クレジット利用状況ダッシュボードAPIを移植

## 概要

`CreditUsageController` の移植。ログインユーザー本人およびテナント全体の、請求期間内クレジット利用状況を返す読み取り専用APIをFastAPIで実装する。

## 説明

- GET `/api/credit-usage/me` : ログインユーザー本人の請求期間内 totalCredits を取得。有効 subscription がない場合は空レスポンス
- GET `/api/credit-usage/workspace` : テナント全体の請求期間内 totalCredits と creditLimit を取得。有効 subscription がない場合は空レスポンス
- いずれも `X-Tenant-ID` ヘッダーが必要
- レスポンス: `MyCreditUsageResponse`(totalCredits, periodFrom, periodTo, nextBillingResetAt), `WorkspaceCreditUsageResponse`(totalCredits, creditLimit, periodFrom, periodTo, nextBillingResetAt)
- creditLimit は Plan.maxCreditsPerMonth + Tenant.maxUsageBasedCreditsPerMonth で算出

前提となる新規移植（未着手、本Issueで併せて移植）:
- Plan ドメイン（domain/plan/）
- Subscription ドメイン（domain/subscription/）
- UserBillingUsageService（有効請求期間の解決・クレジット集計ロジック）
- SubscriptionBillingCycle（次回請求リセット日時算出ロジック）
