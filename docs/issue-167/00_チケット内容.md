# パスワード再設定APIがフィールド名不一致で常に422エラーになる

## 概要

パスワード再設定機能が現在完全に動作しない。frontend が送信するリクエストボディのフィールド名と、backend が期待するフィールド名が一致していないため。

## 説明

- frontend: `frontend-angular/src/app/features/auth/types/auth.types.ts` の `ResetPasswordRequest.username`
- backend: `backend/app/schemas/auth.py` の `PasswordResetRequest.loginId`

frontend は `{ username, oldPassword, newPassword }` を送信するが、backend は `loginId` を要求するため、常に以下のレスポンスになる。

```
422 {"detail":[{"type":"missing","loc":["body","loginId"],"msg":"Field required",...}]}
```

### 影響

パスワード再設定に関する全てのシナリオが機能しない。

- 正常な更新（成功パス）
- 旧パスワード誤り（本来403想定）
- 存在しないログインID（本来403想定）
- 新旧パスワード同一（本来400想定）

いずれも本来の分岐に到達する前に422で弾かれる。

### 対応方針（Issue 記載）

移植元（Spring Boot）の `PasswordResetRequest` のフィールド名を確認し、`username` / `loginId` のどちらに統一するかを判断した上で、frontend・backend いずれかを修正する。
