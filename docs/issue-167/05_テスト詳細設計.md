# 05_テスト詳細設計

## `backend/tests/integration/test_auth.py`（`TestAuthAPI` に追加）

| No | テストメソッド | 内容 |
|---|---|---|
| 1 | `test_post_auth_password_reset_with_username_key` | `json={"username": ..., "oldPassword": 正しい値, "newPassword": "NewPassword123!"}` → 200、`loginStatus == "SUCCESS"`、`token` あり |
| 2 | `test_post_auth_password_reset_with_username_key_and_invalid_old_password` | `username` + 誤った旧パスワード → 403 |
| 3 | `test_post_auth_password_reset_success`（既存） | `loginId` キー → 200 |
| 4 | `test_post_auth_password_reset_without_login_id` | `oldPassword` / `newPassword` のみ → 422 |

フィクスチャは既存の `client`・`test_tenant`・`test_user_with_password` を使う。
