# 08_動作確認

**ブラウザ・実機での確認は行わず、自動テスト（pytest）のみで代替した。** ローカルの Postgres / Redis / backend サーバーは他の作業と共有しているため起動・変更していない。テストはインメモリ SQLite と fakeredis で実行した。

## 確認環境

- ブランチ: `feature/issue-167`（`origin/develop` から作成）
- `backend/` で `uv run pytest`（Python 3.14 の venv、インメモリ SQLite + fakeredis）
- 環境変数はメイン作業ツリーの `backend/.env` を worktree にコピーして実行（gitignore 対象のためコミットされない）。`backend/.env.example` の値でも同じ 786 passed だった

1. 修正前の症状を再現する: スキーマ（`backend/app/schemas/auth.py`）だけを `origin/develop` の状態に一時的に戻し、追加した `username` キーのテスト 2 件を実行する
2. 修正後のスキーマに戻し、対象テスト（スキーマ単体テスト + 認証 API 結合テスト）を実行する
