# 05_テスト詳細設計

## テスト対象ファイル

- `backend/tests/integration/test_prompt_templates.py`
  - テンプレート名の上限専用のテストクラス `TestPromptTemplateNameMaxLength` を新設する（既存の作成・更新クラスは機能確認用のため分ける）。
  - 上限値はテスト側でも `NAME_MAX_LENGTH` を参照し、境界値（上限ちょうど・上限+1）を作る。

## テストケース

| No | テスト名 | 内容 |
|---|---|---|
| 1 | `test_create_accepts_name_at_max_length` | `"a" * 32` で作成すると 200、レスポンスの `name` が一致 |
| 2 | `test_create_rejects_name_over_max_length` | `"a" * 33` で作成すると 422、`detail[0].loc` が `["body", "name"]`、テナント内のテンプレート件数が0のまま |
| 3 | `test_create_counts_multibyte_characters_as_one` | `"あ" * 32` で作成すると 200 |
| 4 | `test_create_rejects_multibyte_name_over_max_length` | `"あ" * 33` で作成すると 422 |
| 5 | `test_update_accepts_name_at_max_length` | `"a" * 32` で更新すると 200、レスポンスの `name` が一致 |
| 6 | `test_update_rejects_name_over_max_length` | `"a" * 33` で更新すると 422、DB 上の名前が元の `Template A` のまま |

## 実行コマンド

```bash
cd backend && uv run pytest
```
