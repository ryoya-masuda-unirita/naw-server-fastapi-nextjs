# テンプレート名のフロントエンド文字数上限(100)とDBカラム上限(32)が不一致で長い名前だと作成に失敗する

## 概要

テンプレート作成フォームのバリデーションはテンプレート名を100文字まで許可しているが、DBカラムの上限は32文字のため、33〜100文字の名前で作成を試みると保存時にエラーになる。

## 説明

- フロントエンド: `frontend-angular/src/app/features/admin/management/template-list/components/template-form/template-form.component.ts` の `Validators.maxLength(100)`（Issue 記載。実際の定義箇所は `template-list.component.ts` のフォーム定義）
- バックエンド: `backend/app/models/prompt_template.py` の `name: str = Field(max_length=32)`
- 発見経緯: Issue #166（結合テストE2Eのプレイライト自動化、19_テンプレートカテゴリ 項番28「名前最大長」）で、100文字ちょうどのテンプレート名で作成すると「テンプレートの作成に失敗しました」のトーストが出て作成できなかった。
- 対応方針案（Issue 記載）: フロントエンドの `Validators.maxLength` を32に合わせる、または DB カラム・バックエンド schema の上限を100に拡張する（移植元 Spring Boot の制約を確認して判断する）。

## その他

- GitHub Issue: #171
- 発見元: #166
- 調査の結果、バックエンドだけでは不一致を解消できないため一度 BLOCKED とし、Issue にコメントで選択肢を提示した。ユーザーが案 C（バックエンドのリクエスト検証に32文字上限を追加し、33文字以上を 422 で返す）に決定した。`frontend-angular/` はリポジトリから削除する方針となったため、フロント側の対応は行わない。
