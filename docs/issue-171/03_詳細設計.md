# 03_詳細設計

## 移植元調査結果サマリ

- `secuaigent/server/src/main/resources/liquibase/changelog/prompt_templates/changeset-001-init-table.xml`: `name varchar(32) NOT NULL`。`changeset-002`〜`004`（外部キー・RLS・`updated_at` 追加）でカラム長の変更はない。
- `secuaigent/server/src/main/java/com/example/naw/domain/prompttemplate/PromptTemplate.java`: `@NotNull @Column(name = "name", length = 32, nullable = false)`。`@Size` はない。
- `secuaigent/server/src/main/java/com/example/naw/request/PromptTemplateCreateRequest.java`: 検証アノテーションなし。作成（POST）と更新（PATCH）で共用。
- `secuaigent/server/src/main/java/com/example/naw/infrastructure/APIControllerAdvice.java`: DB 制約違反（`DataIntegrityViolationException`）のハンドラがなく、500 になる。
- `secuaigent/client/.../template-list/template-list.component.ts`: `name: ['', [Validators.required, Validators.maxLength(100)]]`。

## 実装対象ファイル

### `backend/app/models/prompt_template.py`

- モジュール定数 `NAME_MAX_LENGTH = 32` を追加する（コメントで「移植元 DB カラム `varchar(32)` に合わせる」理由を書く）。
- `PromptTemplate.name` を `Field(max_length=NAME_MAX_LENGTH)` にする（値は32のまま。DB スキーマは変わらない）。

### `backend/app/schemas/prompt_template.py`

- `from pydantic import BaseModel, Field` にする。
- `from app.models.prompt_template import NAME_MAX_LENGTH` を追加する。
- `PromptTemplateCreateRequest.name` を `str = Field(max_length=NAME_MAX_LENGTH)` にする。作成・更新の両方で使われるため、両方に効く。

ルーター・サービスは変更しない。Pydantic の検証エラーは FastAPI 標準の 422 になる（`app/main.py` に独自の `RequestValidationError` ハンドラはない）。

## 処理フロー

1. FastAPI がリクエストボディを `PromptTemplateCreateRequest` に変換する。
2. `name` が32文字を超えると Pydantic の検証エラーになり、ルーター関数が呼ばれる前に 422 を返す。DB には触れない。
3. 32文字以下なら従来どおり作成・更新する。
