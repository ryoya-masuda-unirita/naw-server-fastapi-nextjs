# 04_テスト設計

## テスト方針

テンプレート作成・更新 API を実際に呼び出す結合テスト（インメモリ SQLite）で、上限の境界値を確認する。SQLite は文字列の長さを制限しないため、33文字が 422 になれば、DB ではなくリクエスト検証で拒否していることが確かめられる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 作成・上限ちょうど | 32文字の名前で作成 | 200 で作成される |
| 2 | 作成・上限超え | 33文字の名前で作成 | 422 が返り、テンプレートは作成されない |
| 3 | 作成・マルチバイト | 日本語32文字の名前で作成 | 200 で作成される（文字単位で数える） |
| 4 | 作成・マルチバイト上限超え | 日本語33文字の名前で作成 | 422 が返る |
| 5 | 更新・上限ちょうど | 32文字の名前で更新 | 200 で更新される |
| 6 | 更新・上限超え | 33文字の名前で更新 | 422 が返り、既存テンプレートの名前は変わらない |
| 7 | 既存機能の回帰 | 既存テスト一式 | すべて成功する |
