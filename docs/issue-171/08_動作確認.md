# 08_動作確認

## 確認環境

- ブラウザ・実機での確認は行わず、自動テストのみで代替した（ローカルの Postgres/Redis/backend サーバーは他の作業と共有しているため起動・変更しない方針。`frontend-angular/` は削除方針のため画面での確認対象外）。
- `backend/` で `uv run pytest` を実行（DB はインメモリ SQLite、Redis は fakeredis）。
- `backend/.env` はメインの作業ツリーと同じものを使用（設定まわりのテストが `.env` を前提にしているため）。

## 確認手順

1. テンプレート名の上限テストを実行する。

   ```bash
   uv run pytest -v -p no:warnings tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength
   ```

2. テストが修正を検出できることを確認するため、リクエストスキーマ（`backend/app/schemas/prompt_template.py`）だけを origin/develop の内容に一時的に戻して 1. を実行し、その後元に戻す。SQLite は文字列長を制限しないため、修正前は33文字でも作成・更新できてしまう。

3. バックエンドのテストを全件実行し、回帰がないことを確認する。

   ```bash
   uv run pytest -q -p no:warnings
   ```

## 確認結果

### 1. テンプレート名の上限テスト

```text
tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_create_accepts_name_at_max_length PASSED
tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_create_rejects_name_over_max_length PASSED
tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_create_counts_multibyte_characters_as_one PASSED
tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_create_rejects_multibyte_name_over_max_length PASSED
tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_update_accepts_name_at_max_length PASSED
tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_update_rejects_name_over_max_length PASSED
============================== 6 passed in 0.30s ===============================
```

✅ 作成・更新とも、32文字ちょうどは受け付け、33文字は 422 で拒否される。拒否したときはテンプレートが作成・更新されない。日本語も1文字として数える。

### 2. 修正前のスキーマでの実行（テストが修正を検出できること）

```text
FAILED tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_create_rejects_name_over_max_length
FAILED tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_create_rejects_multibyte_name_over_max_length
FAILED tests/integration/test_prompt_templates.py::TestPromptTemplateNameMaxLength::test_update_rejects_name_over_max_length
3 failed, 3 passed in 0.39s
```

✅ 修正前は上限超えの3件が失敗する。DB ではなくリクエスト検証で拒否していることを確かめられた。

### 3. 全件（修正後）

```text
785 passed in 35.94s
```

✅ 既存テストに回帰はない。

## 未確認事項

- PostgreSQL 上での確認は行っていない。修正後は33文字以上が DB に届く前に 422 で返るため、PostgreSQL でも同じ結果になる想定。
- 画面（作成・編集フォーム）での確認は行っていない。画面は100文字まで入力でき、33文字以上で保存するとエラーになる点は変わらない（500 が 422 になる）。
