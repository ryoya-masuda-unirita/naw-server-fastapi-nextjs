# メッセージ送受信API（同期系）の実装

## 概要

チャットメッセージ関連APIのうち、同期系エンドポイントを実装する。
移植元（naw-server, Spring Boot）の `MessageController` から、LLM連携・SSEストリーミングを伴う
`POST /api/messages/content`（`createMessageContent`）を除いたエンドポイント群を対象とする。

## 説明

### 対象エンドポイント

- `POST /api/messages` — メッセージ（ルーム内スレッド）作成
- `GET /api/messages` — メッセージ一覧取得（roomId指定）
- `POST /api/messages/contents` — メッセージ内容一覧取得
- `DELETE /api/messages/{messageId}` — メッセージ削除
- `DELETE /api/messages/content/{messageContentId}` — メッセージ内容削除
- `POST /api/messages/{messageId}/feedback` — メッセージフィードバック作成

### スコープ外

- `POST /api/messages/content`（SSEストリーミングによるLLMチャット応答生成）は別issueで対応する
