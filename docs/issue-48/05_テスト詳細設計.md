## 前提フィクスチャ（想定）

- `messages_tenant` / `other_tenant`：テスト用テナント
- `message_owner_user` / `other_user_same_tenant`：同一テナント内の所有者／別ユーザー
- `message_assistant`：`SAAS_CHAT` タイプのアシスタント
- `owned_room` / `other_users_room`：所有者の異なるルーム
- `owned_message` / `owned_message_content` / `owned_message_feedback`：既存メッセージ・内容・フィードバック（更新系テストの前提データ）
