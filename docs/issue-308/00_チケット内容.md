# #308 issue-308 アシスタントカテゴリ更新の挙動を移植元に揃える

## 概要

#281 の申し送り。カテゴリ更新が移植元と 2 点違う。

## 説明

- `description` を省略すると空に上書きされる。移植元は空白でない値だけを反映する
- 同じ名前のカテゴリがあると独自の 400 を返す。移植元にはこの事前チェックがない（DB の制約・移植元の実際の応答を確認して揃える）

## その他

- 申し送り元: `docs/issue-281/code-review.md` の指摘 1・2
- 目標は移植元の完璧なクローン。backend の挙動は移植元 Spring Boot の API 仕様に合わせる
