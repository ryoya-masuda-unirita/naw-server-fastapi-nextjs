# 03_詳細設計

## 移植元調査結果

- `server/src/main/java/com/example/naw/service/AssistantCategoryService.java`
  - `updateAssistantCategory`: `StringUtils.isNotBlank(name)`・`StringUtils.isNotBlank(description)` のときだけ上書き。同名の事前チェックなし
  - `createAssistantCategory`: 同名の事前チェックなし
- `server/src/main/java/com/example/naw/request/AssistantCategoryUpdateRequest.java`: `name` は `@NotBlank @Size(max=16)`、`description` は `@Size(max=255)` のみ（省略可）
- `server/src/main/resources/liquibase/changelog/assistant_categories/changeset-001-init-table.xml`: `uq_assistant_categories_tenant_id_name`（`tenant_id, name`）
- `server/src/main/java/com/example/naw/infrastructure/APIControllerAdvice.java`: `DataIntegrityViolationException` のハンドラなし → Spring Boot 既定の 500
- `server/src/main/java/com/example/naw/config/SecurityConfig.java`: `anyRequest().permitAll()` のため `/error` に到達でき、既定の 500 がそのまま返る
- `client/src/app/features/admin/management/assistant-list/components/category-tab/category-tab.component.ts`: 作成・更新の失敗は状態コードに関係なく `toast.error(...)` の固定文言

## 実装対象ファイル

### `backend/app/services/assistant_category_service.py`

- `create_assistant_category`: `AssistantCategoryRepository.exists_by_tenant_id_and_name` による事前チェックと 400 を削除する。保存時の `IntegrityError` を捕捉して `session.rollback()` し、`HTTPException(500, detail="Internal Server Error")` を送出する（`AssistantService.delete_assistant` の 409 と同じ形）
- 500 の例外は `_constraint_violation_error()` で作り、文言は定数 `_CONSTRAINT_VIOLATION_MESSAGE`（移植元 Spring Boot 既定の `error` と同じ `Internal Server Error`）にする
- `update_assistant_category`:
  - 同名の事前チェックと 400 を削除し、作成と同じく `IntegrityError` を 500 に変換する
  - `req.description and req.description.strip()` のときだけ `category.description` に代入する（移植元 `StringUtils.isNotBlank`。`AssistantService` の同じ判定と同じ書き方）
  - 名前は入力チェック（空白だけは 400）を通っているため、そのまま代入する
- docstring の無い `_to_response` に docstring を付ける

### `backend/app/repositories/assistant_category_repository.py`

- 呼び出し元が無くなる `exists_by_tenant_id_and_name` を削除する（他から使われていないことを grep で確認済み。ライブラリタグは別リポジトリの同名メソッド）
- 使われなくなる `exists` の import を削除する

### 移植元の判定と Python の対応

`StringUtils.isNotBlank(s)` は「null でなく、空白文字以外を 1 文字以上含む」。Python では `s is not None and s.strip() != ""` に当たる。

## 処理フロー（更新）

1. ID とテナント ID でカテゴリを探し、無ければ 404（従来どおり）
2. 名前を上書きする
3. 説明が空白でなければ上書きする
4. 更新者を上書きして保存する。同名の別カテゴリがあれば保存時に `IntegrityError` が起き、ロールバックして 500（`{"timestamp", "message": "Internal Server Error"}`）を返す
