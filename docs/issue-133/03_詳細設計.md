# 03_詳細設計

## API（backend の実応答との差と画面での吸収）

`docs/issue-279/api-backend-diff.md` と `backend/app/routers/feedback.py`・`schemas/feedback.py`・`routers/indexes.py` を確認した。

| API | 形 | 移植元との差と対応 |
|---|---|---|
| `GET /api/admin/feedbackMessage` | `{ feedbacks: { content, totalElements, number, size, totalPages, numberOfElements }, assistantIdToServerMap }` | 型（`GetMessageFeedbackViewModel`）は Spring `Page` の全項目を必須にしているが、画面は `content`・`totalPages`・`totalElements`・`number`・`size`・`numberOfElements` だけ読む。差なし |
| `GET /api/admin/feedbackRoom` | `{ feedbacks: Page }`。`room` は `RoomInfoResponse`（`id`・`name`・`defaultAssistantId`・`defaultAssistantName`・`rating`） | 画面が読む `room.name`・`room.defaultAssistantName` はある。`indexId` は行にある。差なし |
| 同上の `folderId`・並べ替え | backend は `folderId` を**受けない**（無視される）。`sortField` は `updatedAt`・`chat`・`name`・`level` のみで、`add`・`folder` は 400 | 移植元 Spring は `folderId` を受ける。移植元の画面は並べ替えに `add`・`folder` も出し、そのまま送る。クローンのため変えない。backend の不足として申し送り（満足度タブの学習先フォルダの絞り込みが効かない／追加学習順・学習先フォルダ名順の並べ替えは 400 でエラートーストと「データがありません」） |
| `GET /api/admin/feedbackUser` | `{ feedbacks: Page }`。行は `user`・`isResponded`（`responded` も）・`feedbackMessageCount`・`feedbackRoomCount`・`updatedAt` | 差なし |
| `GET /api/admin/assistants`（絞り込みの選択肢） | `PagedAssistantResponse`（`content`） | 移植元どおりページ指定なしで取る。backend の既定は 20 件のため、アシスタントが 21 件以上ある環境では選択肢が欠ける（移植元 Spring も同じ既定の見込み） |
| `GET /api/admin/indexes`（学習先フォルダ） | `PagedIndexResponse`（`content`） | 移植元どおり配列・`{ content }` の両方を読む。同じくページ指定なし（既定 20 件） |
| `POST /api/admin/indexes/{id}/additionalLearning` | multipart（`feedbackId` または `roomId`、`content`）、204 | 差なし。`feedbackId`・`roomId` のどちらか必須は backend のサービス層で検査される |
| `GET /api/admin/users`（回答数タブの表示名） | `useAdminUsers` が `normalizeAdminUsersListBody` で正規化した `data[].displayName` | #125 の hook をそのまま使う。backend の行は `displayName` を持たないが、正規化で `name` から作る |

### 画面での扱い

- 日時: 移植元の `date: 'yyyy/MM/dd HH:mm'`（ローカルタイムゾーン）。値がなければ `-`（`formatUpdatedAt`。共通の `display-date.ts` は日付のみのため、機能内に置いた）
- `school` アイコン: 移植元は `<app-svg-icon name="school">` だが、移植元の svg-icon に `school` の登録がなく、空の 20px の枠が出ている。React の `SvgIcon` は未登録の名前を型で受けないため、同じ大きさの空の枠を置いて見た目を揃えた
- 追加学習ファイルの本文: 移植元の日本語の文言を変えない（学習データとして保存されるため、画面の言語に従わない）
- `staleTime`: 移植元は QueryClient 全体で 5 分。React の QueryClient は既定（0）のため、アシスタント・フォルダの選択肢の query にだけ 5 分を付けた。一覧は移植元の回答精度タブが `refetchOnMount: 'always'` なので、毎回読み直す形に揃う
- query key は `['feedback', 'accuracy' | 'satisfaction' | 'users', params]`。選択肢は `['feedback', 'assistant-options' | 'learning-folders']` とし、移植元の `['admin', 'assistants', 'all']` は他の画面の key と衝突しうるため使わない
- 追加学習の成功後は、移植元どおり、そのタブの一覧（`['feedback', 'accuracy']` または `['feedback', 'satisfaction']`）だけを無効化する
- `FormSortInput` の項目名は i18n キーで渡す（移植元は翻訳済みの文言を渡しているが、同じ表示になる）
- 並べ替え順の変更: 回答精度タブは null も反映し、満足度・回答数タブは null を無視する（移植元どおり）
- 回答数タブの読み込み表示は、移植元どおり `usersQuery.isFetching || adminUsersQuery.isFetching`。ユーザー管理 API は現在のページ番号を `pageIndex` にして取る（移植元どおり。表示名の上書きにしか使わない）
