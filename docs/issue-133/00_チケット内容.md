# フィードバック管理画面をReactに移植する

## 概要

フィードバック管理画面（`/admin/feedback`、回答精度評価・チャット満足度・回答数一覧の 3 タブ）を Angular（`secuaigent-ref/client/src/app/features/admin/management/feedback-list/`）から React（`frontend/`）に移植する。Issue #133。

## 説明

- 対象: `feedback-list.component`（画面シェル・タブ）・`accuracy-tab`・`satisfaction-tab`・`count-tab`・`folder-modal`、サービス（`feedback-message-api`・`feedback-room-api`・`feedback-user-api`・`feedback-list-options`）、util（`additional-learning-content`・`assistant-name.util`）、定数（`feedback.constant`）
- 土台は #277（ルート・ガード・サイドバー・i18n）・#278（共通 UI）・#279（API の型・パス・api-client・MSW）。#124・#125・#122・#136 の作り方に揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・ルートのパス・入力チェック）

## その他

- 移植先は Issue 本文の `routes/app/admin/feedback/` ではなく、#277 の仮ファイル `frontend/src/routes/admin/feedback/feedback-list.tsx`（export 名 `AdminFeedbackListPage` は維持）。部品は `frontend/src/components/features/admin/feedback/`
- 移植元の画面に echarts のグラフはない（3 タブとも表と絞り込みだけ）。指示にあった #283 の echarts の仕組みは使わない
- Issue 本文の移植元パス `~/Documents/secuaigent-client/...` は現在の `secuaigent-ref/client/src/app/features/admin/management/feedback-list/`
