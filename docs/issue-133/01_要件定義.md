# 01_要件定義

## 機能要件

### 画面全体
- ヘッダー（`SIDEBAR.FEEDBACK`）と 3 タブ（回答精度評価・チャット満足度・回答数一覧）。タブは `?tab=accuracy|satisfaction|count` で保持する（未指定・不正値は accuracy）
- ガードは `/admin/*` の `RequireAdminConsole`（#277 で定義済み）

### 3 タブ共通
- 説明文、フィルター、並べ替え（項目と昇順/降順）、1 ページ 5 件、件数表示（`1-5件 / 12件`）と上下のページ送り
- フィルター・並べ替えを変えたら 1 ページ目へ戻す。タブを切り替えるとフィルターは初期値に戻る（移植元はタブごとにコンポーネントを作り直す）
- 初期の並べ替えは更新日時の降順。読み込み中はスピナー、0 件は `FEEDBACK.NO_DATA`

### 回答精度評価タブ
- フィルター: アシスタント（検索付き）・精度（全て／不正確／正確）・学習先フォルダ（検索付き）
- 並べ替え: 更新日時・アシスタント表示名・精度・追加学習・学習先フォルダ
- 行: アシスタント表示名（なければ「不明なアシスタント」）・精度・質問と回答の概要（HTML タグ・Markdown の記号を除いて 1 行）・更新日時・追加学習 ON/OFF・学習先フォルダ名
- 行のメニュー「学習先フォルダを指定」→ フォルダ選択ダイアログ。学習先は行の学習先フォルダが初期値。未選択では「追加学習」を押せない。登録は `feedbackId` と本文の markdown ファイルを送る。成功したらダイアログを閉じて一覧を読み直す。失敗したら開いたまま（エラートーストは共通のもの）

### チャット満足度タブ
- フィルター: アシスタント・満足度（★1〜★5）・学習先フォルダ
- 並べ替え: 更新日時・チャット名・アシスタント表示名・満足度・追加学習・学習先フォルダ
- 行: チャット名・満足度（★ または未評価）・アシスタント・更新者名・更新日時・追加学習・学習先フォルダ。メニューとダイアログは精度タブと同じ。登録は `roomId` と本文のファイルを送る

### 回答数一覧タブ
- フィルター: 回答状況（全て／回答済み／未回答）・満足度
- 並べ替え: 更新日時・ユーザー表示名・精度評価数・★1〜★5 の件数
- 行: ユーザー表示名・更新日時・精度評価数・満足度 1〜5 の回答数。行に操作メニューはない
- ユーザー表示名は、ユーザー管理 API（`GET /api/admin/users`、現在のページ番号・5 件・更新日時の降順）の `displayName` で上書きする（移植元どおり）

## 入力チェック
- 入力欄はなく、チェックはなし（フォルダ未選択のときだけ「追加学習」を無効にする）

## 非機能
- 文言は i18n 辞書（移植元のクローン）を使い、キーを足さない
- API の形は backend の実際の応答に合わせる（03 を参照）
