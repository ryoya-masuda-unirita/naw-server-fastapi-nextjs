# 04_テスト設計

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ確認は行わない。

| 対象 | 観点 |
|---|---|
| タブ | 未指定は accuracy（URL も `?tab=accuracy` に直る）、タブで切り替わり URL が変わる |
| 回答精度タブ | 一覧の表示（概要の整形・精度・日時・ON/OFF・学習先フォルダ名・件数）、アシスタント名なしは不明、0 件、初期の取得条件、精度・アシスタントの絞り込み、並べ替え |
| 追加学習 | フォルダ選択ダイアログ（初期値・未選択は押せない）、`feedbackId` と本文ファイルの送信、成功で閉じて一覧を読み直す、失敗で開いたまま |
| チャット満足度タブ | 一覧の表示（★・アシスタント・更新者）、初期の取得条件、満足度の絞り込み、`roomId` と本文ファイルの送信 |
| 回答数一覧タブ | 一覧の表示（回答数の並び、表示名をユーザー管理の値で上書き）、初期の取得条件、回答状況・満足度の絞り込み |
| 整形・変換 util | アシスタント名の解決、フィルター値の正規化、満足度の変換、概要の整形、日時、件数の範囲、追加学習ファイルの本文 |
