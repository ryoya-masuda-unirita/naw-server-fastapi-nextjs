# 02_基本設計

## 構成

| 層 | ファイル | 移植元 |
|---|---|---|
| ページ | `routes/admin/feedback/feedback-list.tsx`（`AdminFeedbackListPage`） | `feedback-list.component` |
| タブ | `components/features/admin/feedback/accuracy-tab.tsx`・`satisfaction-tab.tsx`・`count-tab.tsx` | 各 `*-tab.component` |
| ダイアログ | `components/features/admin/feedback/folder-modal.tsx` | `folder-modal.component` + `DialogComponent` |

| MSW | `mocks/handlers/admin-feedback.ts` | — |

## 状態の持ち方

- 一覧のデータは TanStack Query（`use-feedback.ts`）
- フィルター・並べ替え・ページ番号は、各タブの `useState`。移植元もタブコンポーネントの signal で、タブを切り替えると破棄される。Zustand の store にすると、タブを離れたときのリセットを別に書く必要があり、共有する相手もいないため使わない（#124 などは一覧画面とダイアログで状態を共有するため store を使っている）
- タブは既存の `useTabQueryParam`（`?tab=`）

## 共通部品の使い方

`AdminPageShell`・`PageHeader`（タブ付き）・`Select`・`SelectWithSearch`・`FormSortInput`・`Pagination`・`TableList`・`ContextMenu`・`Dialog`・`CircularLoading`（すべて #278）。共通部品・共通ファイルは変更していない。
