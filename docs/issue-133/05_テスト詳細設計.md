# 05_テスト詳細設計

- `frontend/src/routes/admin/feedback/feedback-list.test.tsx`: `renderApp('/admin/feedback?tab=...')` で実際のルート・ガード・レイアウト込みで描画。MSW で 04 の各 API を差し替え、受けたクエリを記録して検証する。テストでは i18n 未初期化のため `t()` はキーを返す
- `frontend/src/components/features/admin/feedback/feedback-format.test.ts`: 整形・変換・追加学習ファイルの本文
- 追加学習の本文は、jsdom の `Blob` が `fetch` に渡すと空になるため、サーバー側では読まず、`FormData.prototype.append` を監視して `feedbackId`・`roomId`・ファイル名を確かめる（`messages-store.test.ts` と同じ理由）
- 絞り込みの選択は、`Select` は表示中のプレースホルダーをクリックして `option` を選び、`SelectWithSearch`・`FormSortInput` は `testidPrefix`（`feedback-assistant`・`feedback-sort`）で操作する
- 既定の MSW ハンドラー（`mocks/handlers/admin-feedback.ts`）は 3 つの一覧 API の空の応答。他機能の API（`/api/admin/assistants`・`/api/admin/indexes`・`/api/admin/users`）の既定は入れず、テストの中で `server.use` で差し替える
