# waha-emulator のサービス ID の接尾辞で保存先（インデックス）を自動で切り替える

## 概要

waha-emulator で、サービス ID の接尾辞（サフィックス）から、学習・検索の保存先（インデックス）を自動で決められるようにする。学習先フォルダを新規作成するたびに、設定ファイルへ手で書き足さなくても、フォルダごとに検索の対象を分けられるようにする。

## 説明

- 画面では学習先フォルダをいくつでも作れるが、オンプレ検証環境は、学習・取得・削除・質問のサービス ID を 1 組しか持たず、全フォルダが同じ保存先（ベクトル DB の `docs`）に入る
- 保存先は、サービス ID の設定だけで決まる。移植元でも、server-local は Waha! へフォルダの ID を渡さず、フォルダごとの保存先は Waha! 側のジョブ設定で作る前提（操作マニュアル: 「Waha! Transformer のジョブ設定・サービス ID の入力が必要」）
- 実機の確認で、フォルダごとに分けるには、サービス ID と保存先を設定へ手で足す必要があると分かった。複数のフォルダを使う検証に向かない
- 移植元の設計（サービス ID の先が保存先を決める）は変えず、本物の Waha! の代わりをするエミュレーターが、ジョブを先に作る手間を減らす
