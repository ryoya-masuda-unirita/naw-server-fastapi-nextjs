# テンプレート管理 一覧画面をReactに移植する

## 概要

テンプレート管理 一覧画面（`/admin/templates`）を Angular（`secuaigent/client` の `features/admin/management/template-list/`）から React（`frontend/`）に移植する。Issue #124。

## 説明

- 対象: `template-list.component`（メイン）・`template-form`（追加・編集フォーム）・`template-list-filter`（検索・チーム絞り込み・並べ替え）・`template-list-items`（一覧テーブル）・`template-list.store`・`template-list-api.service`・`groups-api.service`
- スコープ外: `group-detail/templates/`（グループ詳細のテンプレートタブ。別 Issue）
- 土台は #277（ルート・ガード・サイドバー・i18n）・#278（共通 UI）・#279（API の型・パス・api-client・MSW）
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）

## その他

- 移植先は Issue 本文の `routes/app/admin/templates.tsx` ではなく、#277 の仮ファイル `frontend/src/routes/admin/templates/template-list.tsx`（export 名 `AdminTemplateListPage` は維持）
