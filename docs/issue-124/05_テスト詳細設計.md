# 05_テスト詳細設計

`frontend/src/routes/admin/templates/template-list.test.tsx` に、04 の観点を 1 観点 1 テストで実装する（10 件）。

- フィクスチャ: `FIXTURE_TEMPLATES`（2 件。1 件目はチーム「営業」「開発」、2 件目は説明なし・チームなし）、`FIXTURE_GROUPS`（g1〜g3）
