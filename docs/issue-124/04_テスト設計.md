# 04_テスト設計

## テスト方針

- Vitest + React Testing Library + MSW。ガード・レイアウト込みで `renderApp('/admin/templates')` を描画する
- i18n は未初期化のため `t()` はキーを返す。キーで検証する
- MSW の既定（`mocks/handlers/admin-templates.ts`）は空の一覧とグループなし。テストごとに `server.use` で上書きする

## テスト観点

- 一覧: 名前・説明・所属チーム・更新日時・件数表示、0 件、初期の取得パラメータ（`page=0`・`size=10`・`sort=updatedAt,desc`）
- 検索: 入力で `search` を付けて再取得
- 作成: 入力前は確認ボタンが無効／trim して送信／100 文字超でエラー表示・無効／失敗時はトーストを出してダイアログを残す
- 編集: 既存値が入り、チーム変更なしならグループ API を呼ばない
- 削除: 選択して一括削除／行メニューから単体削除
