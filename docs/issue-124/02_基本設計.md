# 02_基本設計

## 変更対象

- `frontend/src/routes/admin/templates/template-list.tsx`（仮ファイルを本物に置換）
- `frontend/src/components/features/admin/templates/`（`template-list-filter.tsx`・`template-list-items.tsx`・`template-form-dialog.tsx`）
- `frontend/src/hooks/use-template-list.ts`（一覧・グループ選択肢・作成・更新・削除）
- `frontend/src/store/template-list-store.ts`（Zustand。フィルター・選択状態）
- `frontend/src/mocks/handlers/admin-templates.ts`（MSW。`handlers/index.ts` に登録）

## 画面 / API 変更概要

| 操作 | API |
|---|---|
| 一覧 | `GET /api/admin/prompt-templates`（`page`（0始まり）・`size`・`team`・`search`・`sort=field,order`） |
| グループ選択肢 | `GET /api/admin/groups?size=1000`（`{ data }`） |
| 作成・更新 | `POST` / `PATCH /api/admin/prompt-templates[/{id}]`（本文に `groups` は含めない） |
| グループ紐付け | `POST /api/admin/groups/{id}/prompt-templates`（`{ templateIds }`）・`DELETE .../prompt-templates/{templateId}` |
| 削除 | `DELETE /api/admin/prompt-templates/{id}`（選択分を並列） |

## 影響範囲

- 触った共通ファイル: `src/mocks/handlers/index.ts`（ハンドラー登録のみ）。ほかの共通ファイル（`routes/index.tsx`・`lib/constants/*`・`sidebar.tsx`・`index.css`・`public/i18n/*`・`package.json`）は触っていない

## 移植方針

- NgRx signalStore → UI 状態は Zustand、API 呼び出しは TanStack Query
- MatDialog＋`ng-template` → `Dialog`（共通）。追加・編集は `TemplateFormDialog` を開いている間だけ描画し、開くたびにフォーム状態を初期化（移植元の `form.reset`）
- Angular の `FormGroup` → コンポーネントの `useState`。検証は Angular の `Validators.required`・`maxLength` と同じ判定、エラー文言は `resolveControlError`
- 詳細な判断は `03_詳細設計.md`
