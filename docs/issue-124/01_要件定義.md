# 01_要件定義

## 背景

テンプレート管理画面は管理コンソールの一画面。テナント管理者・グループ管理者がプロンプトテンプレートを一覧・作成・編集・削除し、所属チーム（グループ）との紐付けを管理する。

## 機能要件

- 一覧表示（名前・説明・システムプロンプト・所属チーム・更新日時）。PC は表、モバイルはラベル付きの縦並び
- 検索（`search`）、所属チームの絞り込み（全て／所属チームなし／各グループ）、並べ替え（更新日時順・テンプレート名順、昇順・降順）
- ページ送り（上: 前後のみ＋件数表示、下: 前後とページ番号。1ページ10件）
- 行チェックボックス・全選択による複数選択。選択中は「選択を解除」「削除」、未選択時は「テンプレートを新規作成」
- 追加・編集ダイアログ（名前: 必須・100文字以内、システムプロンプト: 必須・4000文字以内、説明: 任意・500文字以内、所属チーム: 複数選択）
- 追加時は作成後に選んだグループへ紐付け。編集時は更新後にグループの差分（解除→追加）を反映
- 削除は確認ダイアログ付き。行メニューからの単体削除と、選択分の一括削除
- 成功・失敗はトースト（`TEMPLATES.*_SUCCESS` / `*_FAILED`）

## 非機能要件

- 文言は既存の i18n 辞書のキーのみ（キーは足さない）
- 共通 UI（#278）・API パス/型（#279）を使い、共通ファイルの変更は最小限

## スコープ外

- グループ詳細のテンプレートタブ
- backend の修正（応答の形の差は画面側で吸収、または docs に記載）
