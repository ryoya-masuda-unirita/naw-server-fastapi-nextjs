# 08_動作確認

## 前提

- Docker コンテナ: `naw-fastapi-postgres`
- API サーバー: `uv run uvicorn app.main:app --host 127.0.0.1 --port 8002`
- シード投入: `docker exec -i naw-fastapi-postgres psql -U root -d postgres < backend/seed.sql`

## Step 1: 管理者ログイン

実行コマンド:

```bash
curl -s -X POST http://127.0.0.1:8002/auth/login \
  -H 'Content-Type: application/json' \
  -H 'X-Tenant-ID: test-tenant' \
  -d '{"username":"admin","password":"admin@1234"}'
```

確認結果:

- `loginStatus: "SUCCESS"` でログイン成功
- `role: "ADMIN"` のトークンを取得

## Step 2: `GET /api/admin/feedbackMessage` 一覧取得

実行コマンド:

```bash
curl -s 'http://127.0.0.1:8002/api/admin/feedbackMessage?page=0&size=20&sortField=updatedAt&sortOrder=desc' \
  -H 'Authorization: Bearer <admin-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

確認結果:

- `feedbacks.totalElements` は `4`
- `content` 内で `assistantName` が返却されることを確認
- `message.content.question` / `answer` が存在するデータと `null` のデータが混在して返ることを確認
- `assistantIdToServerMap` に `10000000000040008000000000000002 -> {url, authKey}` が含まれることを確認

## Step 3: `folderId` 絞り込み

実行コマンド:

```bash
curl -s 'http://127.0.0.1:8002/api/admin/feedbackMessage?folderId=folder-responded' \
  -H 'Authorization: Bearer <admin-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

確認結果:

- `feedbacks.totalElements` は `1`
- `indexId: "folder-responded"` のデータのみ返却されることを確認
- このケースでは `assistantIdToServerMap` は空オブジェクト `{}`

## Step 4: `assistantId` 絞り込み

実行コマンド:

```bash
curl -s 'http://127.0.0.1:8002/api/admin/feedbackMessage?assistantId=10000000000040008000000000000002' \
  -H 'Authorization: Bearer <admin-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

確認結果:

- `feedbacks.totalElements` は `1`
- `assistantName: "ローカル連携アシスタント"` のデータのみ返却されることを確認
- `assistantIdToServerMap` に対象 assistant の `url` / `authKey` が返ることを確認

## Step 5: 一般ユーザー権限でのアクセス拒否

実行コマンド:

```bash
curl -s -o /tmp/issue54-user01-feedbackMessage.json -w '%{http_code}' \
  'http://127.0.0.1:8002/api/admin/feedbackMessage' \
  -H 'Authorization: Bearer <user01-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

確認結果:

- HTTP ステータス `403`
- レスポンスボディは `{"detail":"Access Denied"}`
