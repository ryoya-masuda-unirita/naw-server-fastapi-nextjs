# 01_要件定義

## 背景

移植元（naw-server, Spring Boot）には、管理者がメッセージ単位のフィードバック内容を一覧で確認できるAPIが存在する。
このリポジトリでは #48 で `message_feedbacks`、#52 でフィードバックユーザー一覧を実装済みのため、次の最小粒度としてフィードバックメッセージ一覧取得APIを追加する。

## 機能要件

- テナント内のメッセージフィードバックをページング付きで一覧取得できる
- 各一覧項目に以下を含める
  - フィードバックID
  - テナントID
  - ユーザーID
  - メッセージID
  - メッセージ情報（`assistantId`, `assistantName`, `content.question`, `content.answer`）
  - 評価（`GOOD` / `BAD`）
  - `indexId`
  - 作成日時・更新日時
- `assistantId` で絞り込める
- `rating`（`GOOD` / `BAD`）で絞り込める
- `folderId` で絞り込める
- 指定項目でソートできる
  - `updatedAt`
  - `name`
  - `accuracy`
  - `add`
  - `folder`
- ローカルサーバー接続情報（移植元の `assistantIdToServerMap` 相当）を返せる

## 非機能要件

- 管理者（テナント管理者またはグループ管理者）のみアクセスできる
- 既存の `/api/admin/**` と同じ認可・エラーハンドリング方針に合わせる
- 本リポジトリ既存の一覧APIと同様、0始まりページングを採用する

## スコープ外

- `GET /api/admin/feedbackRoom` の実装
- `feedbackUser` の追加改修
- 移植元で行っている、`message_feedbacks.index_id` が `null` の場合に関連 `File` から `indexId` を導出する処理
  - FastAPI 側では `File` ドメインが未移植であり、`message_files` にも `indexId` を保持していないため、本issueでは `message_feedbacks.index_id` をそのまま返す
