# フィードバックメッセージ取得APIの実装

## 概要

管理者向けに、メッセージフィードバック一覧を取得する `GET /api/admin/feedbackMessage` を実装する。
移植元（naw-server, Spring Boot）の `FeedbackController.getFeedbackMessages` / `FeedbackService.getFeedbackMessages` に対応する。

## 説明

### 対象エンドポイント

- `GET /api/admin/feedbackMessage` — フィードバックメッセージ一覧取得
  - クエリパラメータ: `page`, `size`, `assistantId`, `rating`, `folderId`, `sortField`, `sortOrder`
  - 想定レスポンス: フィードバック本体情報、メッセージの質問・回答、`assistantId` / `assistantName`、`indexId`、およびローカルサーバー接続情報

### スコープ

新規テーブルは不要（既存の `message_feedbacks` / `messages` / `message_contents` / `assistants` / `tenant_endpoints` を使用）。
`FeedbackController` の他エンドポイントである `feedbackRoom` は、本issueでは対象外とする。
