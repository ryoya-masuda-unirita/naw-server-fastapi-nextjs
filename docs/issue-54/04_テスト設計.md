# 04_テスト設計

## テスト方針

- ルーターのエンドポイントを実際に叩く integration test で、正常系・絞り込み・ソート・権限・補助情報の返却を確認する
- 既存の `test_feedback.py` と同じく、インメモリSQLite + `AsyncClient` 構成に合わせる
- `assistantIdToServerMap` と `assistantName` は移植元の直近修正で重要になっているため、明示的に確認する

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 基本取得 | フィードバック1件、対応する message / content / assistant が存在する | `feedbacks.content[0]` に `message.assistantId`, `message.assistantName`, `question`, `answer`, `rating` が入る |
| 2 | assistantIdToServerMap | 対象 assistant に `LOCAL_SERVER` endpoint がある | `assistantIdToServerMap` に assistant ID をキーとした `url` / `authKey` が入る |
| 3 | content欠損 | `message_contents` が存在しない message に対する feedback | `message.content.question` / `answer` は `null` で返る |
| 4 | assistantId絞り込み | `assistantId` 指定 | 指定 assistant の feedback のみ返る |
| 5 | rating絞り込み | `rating=GOOD` | `GOOD` の feedback のみ返る |
| 6 | folderId絞り込み | `folderId` 指定 | `message_feedbacks.index_id` が一致する feedback のみ返る |
| 7 | ソート | `sortField=accuracy&sortOrder=asc` | rating 順で並ぶ |
| 8 | ページング | `page=0&size=1` | 1件のみ返り、`totalElements` は全件数を示す |
| 9 | 権限 | 一般ユーザーでアクセス | 403 エラー |
| 10 | 権限 | グループ管理者でアクセス | 200 で取得できる |
