# 08_動作確認

**ブラウザ・実機での確認は行わず、自動テストのみで代替した。** 実際の Waha! は使わず、実際の `WahaClient` に `httpx.MockTransport` で Waha! の応答（503 など）を返して、httpx の例外が起きる実際の経路を通した。Dockerfile・entrypoint は変更していないため、Docker のビルド確認は行っていない。

## 確認環境

- ブランチ: `feature/issue-252`（`origin/develop` から作成）
- `server-local/`（Python 3.12、uv、pytest + pytest-asyncio、SQLite + aiosqlite、httpx の MockTransport）

## 確認手順

```bash
cd server-local
uv sync
uv run pytest tests/test_waha_client.py tests/test_waha_authkey_exposure.py -v
uv run pytest -q
uv run ruff check . && uv run ruff format --check .
uv run --with mypy mypy app tests   # server-local は mypy を依存に持たないため一時的に入れて実行
```

修正前の再現は、`server-local/app` の変更だけを `git stash push -m <tag> -- app` で一時的に退避して新しいテストを実行し、確認後に SHA 指定の `git stash apply` で戻した。
