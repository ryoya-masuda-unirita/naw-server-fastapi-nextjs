## `server-local/tests/test_waha_authkey_exposure.py`（新規）

### 仕組み

- `waha_failing_at(suffix)`: パスが `suffix` で終わるリクエストだけ 503、`/startsession` は `waha-session-1`、ほかは `OK` を返すハンドラー
- `waha_handler` フィクスチャ: ハンドラーを差し替える入れ物（既定はセッション開始で 503）
- `real_waha_client` フィクスチャ: 実際の `WahaClient`（`httpx.MockTransport`、authkey は設定の `waha-key`）と偽の NAW クライアントで `create_app()` し、ASGI 経由の `httpx.AsyncClient` を返す
- ログは `caplog.at_level(logging.DEBUG)` で取得する

### 修正前の再現手順

`server-local/app` の変更だけを一時的に退避（`git stash push -m <tag> -- app`）し、上記 2 ファイルのテストを実行して失敗を確認した後、SHA 指定で `git stash apply` して戻す。
