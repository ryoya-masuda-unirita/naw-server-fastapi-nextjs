## `waha_client.py`

### 定数

| 定数 | 値 | 説明 |
|---|---|---|
| `NO_BODY_TEXT` | `[no body]` | 本文なしのとき |
| `NEWLINE_PATTERN` / `NEWLINE_REPLACEMENT` | `[\n\r]` / `<EOL>` | LogFormatUtils の改行置換 |
| `CONTROL_CHARACTER_PATTERN` / `CONTROL_CHARACTER_REPLACEMENT` | C0・DEL・C1 制御文字 / `?` | LogFormatUtils の `\p{Cc}` 置換 |

### 関数

- `status_error_message(response: httpx.Response) -> str`: `f"{status_code} {reason_phrase}: "` + `[no body]` または `"本文"`（改行→`<EOL>`、制御文字→`?`）
- `io_error_message(method, url, error: httpx.RequestError) -> str`: `httpx.URL(url).copy_with(query=None)` でクエリを除き、`I/O error on {method} request for "{url}": {error}`。`str(error)` が空なら例外の型名（例: `ReadError`）を使う
- `WahaClient._send(method, path, **kwargs) -> httpx.Response`:
  - `self._http.request(method, url, **kwargs)` を呼ぶ
  - `httpx.RequestError` → `raise ExternalServiceError(io_error_message(...)) from e`（通信エラーのメッセージは URL を含まないため、原因を追えるよう連鎖を残す。code-review 対応）
  - `response.is_success` でなければ `raise ExternalServiceError(status_error_message(response))`（except の外なので連鎖はない）
- `_get_text()` と `upload_file()` は `_send()` を使う（`raise_for_status()` は URL 付きの `HTTPStatusError` を作るため使わない）
- 2xx 以外をエラーにする判定は修正前（`raise_for_status()`）と同じ。3xx の扱いは変えない

`ExternalServiceError` は既存の `AppError` のサブクラス（500）。例外ハンドラーは `exc.message` をログと応答の `message` に入れる。同期・SSE のサービスは `str(e)` を回答に入れるが、`AppError` の `str()` はメッセージそのもの。

## `errors.py`

`_handle_http_error`（`httpx.HTTPError` → 500 + `str(exc)`）を削除し、使われなくなる `import httpx` も削除する。万一 httpx の例外が届いた場合は、汎用の例外ハンドラーが Spring 既定の形（`message` なし）の 500 を返す。

## `main.py`

`HTTPX_LOG_LEVEL = logging.WARNING` を定義し、`logging.basicConfig()` の直後に `logging.getLogger("httpx").setLevel(HTTPX_LOG_LEVEL)` を実行する。
