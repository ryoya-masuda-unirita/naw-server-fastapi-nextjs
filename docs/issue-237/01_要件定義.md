# 01_要件定義

## 背景

チーム（グループ）の所属ユーザー一覧 API は、`role` パラメータでチーム内の権限（チーム管理者 / 一般）を絞り込める。

移植元と移植先で、`role` の値の解釈が次のように違う。

| `role` の値 | 移植元 | 移植先（現状） |
|---|---|---|
| 指定なし | 絞り込みなし | 絞り込みなし |
| 空文字・空白のみ | 絞り込みなし | 絞り込みなし |
| `ADMIN` | チーム管理者のみ | チーム管理者のみ |
| `USER` | 一般のみ | 一般のみ |
| `admin`・`Admin` など（大文字小文字違い） | チーム管理者のみ | **絞り込みなし（全件）** |
| `user`・`User` など | 一般のみ | **絞り込みなし（全件）** |
| 未知の値（`SYSTEM`・`foo` など） | **0 件** | **絞り込みなし（全件）** |
| 前後に空白が付いた値（` ADMIN` など） | 0 件（空白を取り除かずに比較するため未知の値になる） | 絞り込みなし（全件） |

## 機能要件

1. `role` を大文字小文字を区別せずに解釈し、`ADMIN` ならチーム管理者のみ、`USER` なら一般のみを返すこと
2. `role` が未知の値（前後に空白が付いた値を含む）なら、0 件を返すこと（エラーにはしない。総件数も 0）
3. `role` が指定なし・空文字・空白のみなら、従来どおり絞り込まないこと
4. 検索・並べ替え・ページング・利用量の付与など、ほかの挙動は変えないこと

## 非機能要件

- データベースの変更（マイグレーション）は行わない
- 未知の値でもエラー応答にしない（移植元と同じく 200 で空の一覧）

## スコープ外

- 検索文字列（`searchText`）の対象の差分。移植元はユーザー名だけを検索し、移植先はユーザー名とログインIDを検索する。本 Issue の指摘対象外のため扱わない
- ユーザー一覧（チーム以外）の `role` 絞り込み
- 並べ替えの挙動
