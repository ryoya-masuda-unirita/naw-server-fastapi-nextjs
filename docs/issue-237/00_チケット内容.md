# #237 issue-237 チーム所属ユーザー一覧のrole絞り込みを移植元に揃える

## 概要

チーム（グループ）の所属ユーザー一覧の `role` 絞り込みが、移植元と挙動が違う。

- 移植元: 大文字小文字を区別しない。未知の値を指定すると 0 件を返す
- backend: 移植元と違う挙動（#225 で扱わなかった差分）

## 説明

### 対応

移植元の Controller / Service / Repository を確認し、絞り込みの挙動を移植元に揃える。
