# 04_テスト設計

## テスト方針

チーム所属ユーザー一覧 API を、チーム管理者 1 名・一般 2 名が所属するチームに対して呼び出し、`role` の値ごとに返る所属ユーザーと総件数を確かめる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 大文字の指定 | `role=ADMIN` | チーム管理者 1 名だけ、総件数 1 |
| 2 | 大文字の指定 | `role=USER` | 一般 2 名だけ、総件数 2 |
| 3 | 大文字小文字の違い | `role=admin`・`Admin` | チーム管理者 1 名だけ |
| 4 | 大文字小文字の違い | `role=user`・`User` | 一般 2 名だけ |
| 5 | 未知の値 | `role=SYSTEM`・`foo` | 200 で 0 件、総件数 0 |
| 6 | 前後に空白が付いた値 | `role= ADMIN` | 200 で 0 件（移植元と同じく空白を取り除かない） |
| 7 | 指定なし | `role` を付けない | 全 3 名 |
| 8 | 空・空白のみ | `role=`・`role=   ` | 全 3 名 |
| 9 | 回帰 | 既存の全テスト | すべて成功する |
