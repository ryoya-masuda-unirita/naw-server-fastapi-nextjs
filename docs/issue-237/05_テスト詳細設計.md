# 05_テスト詳細設計

## `backend/tests/integration/test_groups.py`

クラス `TestGroupUsersRoleFilter` を追加する。既存のフィクスチャ `group_with_admin_member`（`member_user` をチーム管理者として所属）に、既存のヘルパー `_add_members` で一般 2 名（`u1`・`u2`）を足す。リクエストはテナント管理者（`admin_headers`）で `GET /api/admin/groups/{groupId}/users` を呼ぶ。

| テスト | パラメータ | 期待 |
|---|---|---|
| `test_admin_returns_group_admins_only`（`ADMIN`・`admin`・`Admin` でパラメータ化） | `role` | `content` が `member_user` 1 件・`groupAdmin` が true、`totalElements` が 1（No.1・3） |
| `test_user_returns_non_admins_only`（`USER`・`user`・`User`） | `role` | `content` の名前が `u1`・`u2`・全員 `groupAdmin` が false、`totalElements` が 2（No.2・4） |
| `test_unknown_role_returns_empty`（`SYSTEM`・`foo`・` ADMIN`・`ADMIN `） | `role` | 200、`content` が空、`totalElements` が 0（No.5・6） |
| `test_blank_role_returns_all`（`""`・`"   "`） | `role` | `totalElements` が 3（No.8） |
| `test_no_role_returns_all` | なし | `totalElements` が 3（No.7） |
