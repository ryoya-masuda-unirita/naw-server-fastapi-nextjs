# 03_詳細設計

## 移植元の根拠（`secuaigent-ref/server`）

- `api/GroupController.getGroupUsers`: `@RequestParam(required = false) String role` を受け、そのまま `GroupService.findGroupMemberUsers` に渡す
- `service/GroupService.findGroupMemberUsers`: `Specification.allOf(forGroup, excludeSystemUsers, matchesSearchText, matchesGroupRole(role))` で絞り込み、`findAll(spec, pageable)` する（件数も同じ条件）
- `domain/group/GroupUserSpecification.matchesGroupRole`:

  ```java
  if (role == null || role.isBlank()) {
    return null;
  }
  return switch (role.toUpperCase()) {
    case "ADMIN" -> (root, query, cb) -> cb.isTrue(root.get("groupAdmin"));
    case "USER" -> (root, query, cb) -> cb.isFalse(root.get("groupAdmin"));
    default -> (root, query, cb) -> cb.disjunction();
  };
  ```

  `cb.disjunction()` は常に偽の条件（`1 = 0` 相当）なので、未知の値では 0 件になる。`toUpperCase()` の前に `trim()` はしない

## 移植先の現状

`backend/app/repositories/group_user_repository.py` の `GroupUserRepository.find_page_by_group`:

```python
if role == "ADMIN":
    stmt = stmt.where(GroupUser.is_admin.is_(True))
elif role == "USER":
    stmt = stmt.where(GroupUser.is_admin.is_(False))
```

完全一致のみで、それ以外の値は条件を付けない。router（`routers/groups.py`）・service（`services/group_service.py`）は値をそのまま渡すだけ。

## 変更内容

### `backend/app/repositories/group_user_repository.py`

- ロールからチーム管理者フラグへの対応表 `_IS_ADMIN_BY_GROUP_ROLE: dict[str, bool] = {"ADMIN": True, "USER": False}` を追加
- 絞り込みを次のようにする

  ```python
  # 移植元 GroupUserSpecification.matchesGroupRole と同じく、空白のみは条件なし、
  # 大文字小文字を区別せずに判定し、未知の値は 0 件にする（前後の空白は取り除かない）
  if role is not None and role.strip():
      is_admin = _IS_ADMIN_BY_GROUP_ROLE.get(role.upper())
      if is_admin is None:
          return [], 0
      stmt = stmt.where(GroupUser.is_admin.is_(is_admin))
  ```

- docstring の `role` の説明を更新する
- `services/group_service.py` の `list_group_users` の docstring の `role` の説明も合わせる

未知の値のとき、移植元は常に偽の条件（`cb.disjunction()`）を付けて一覧・件数を問い合わせるが、結果は必ず空（一覧が空・総件数 0）なので、DB に問い合わせずに `([], 0)` を返す（code-review 指摘 3・4 で変更。当初は `where(false())` を付けていた）。

### 補足

- Java の `isBlank()` は `Character.isWhitespace` の文字だけを空白とみなし、Python の `str.strip()` はノーブレークスペースなども取り除く。画面から送られる値では差が出ないため、`strip()` で判定する
- Java の `toUpperCase()` と Python の `str.upper()` は、`ADMIN`・`USER` に変換されうる入力（`ı` などの特殊な文字を含む）について同じ結果になる
