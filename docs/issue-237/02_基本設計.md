# 02_基本設計

## 変更対象

- チーム所属ユーザー一覧の取得処理のうち、`role` による絞り込みの条件の組み立て

## 画面 / API 変更概要

- API のパラメータ・レスポンスの形式は変えない
- `role` の値の解釈だけを移植元に揃える（大文字小文字を区別しない、未知の値は 0 件）

## 影響範囲

- チーム所属ユーザー一覧 API で、`role` に大文字の `ADMIN`・`USER` 以外の値を指定したときの結果
- フロントエンドが大文字の `ADMIN`・`USER` または空を送る場合の結果は変わらない

## 移植方針

- 移植元の絞り込み（指定なし・空白のみは条件なし、大文字に変換して `ADMIN`・`USER` を判定、それ以外は常に偽の条件）を、そのままデータベースの条件として再現する
- 未知の値のときは、一覧を空・総件数を 0 にして返す（移植元は「常に偽」の条件で問い合わせて 0 件にする。結果は必ず空なので、移植先はデータベースに問い合わせずに返す）
- 値の前後の空白は取り除かない（移植元も取り除かずに大文字にして比較している）
