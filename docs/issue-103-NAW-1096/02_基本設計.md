# 02_基本設計

## 変更対象

- 管理画面ユーザー一覧取得サービス（`UserService.get_users`相当）

## 画面 / API 変更概要

`GET /api/admin/users` のレスポンスから、SYSTEMロールのユーザーが常に除外されるようになる。
リクエストパラメータ（`role`等）の型・形式は変更しない。

## 影響範囲

- 管理画面ユーザー一覧画面（フロントエンド）に表示されるユーザー件数・一覧内容が変わる
  （SYSTEMロールユーザーが非表示になる）
- 既存のUSER・ADMINロールのユーザー表示には影響しない

## 移植方針

移植元 naw-server では `UserSpecifications.visibleToAdmin()`（`Specification`）を既存の
検索条件に `.and()` で合成する形で実装されている。

FastAPI側では `Specification` パターンに対応するものが SQLAlchemy の `where()` の動的組み立てで
あるため、`UserService.get_users` 内で組み立てている `select(User).where(...)` の条件に
`User.role != UserRole.SYSTEM` を無条件で追加する形で移植する。専用クラスに切り出すほどの
再利用性はないため、既存の `stmt = select(User).where(...)` に条件を1行追加するシンプルな形とする。
