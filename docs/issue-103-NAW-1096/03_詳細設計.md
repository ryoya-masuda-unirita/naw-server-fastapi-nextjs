# 03_詳細設計

## 実装対象ファイル

- `backend/app/services/user_service.py`

## 変更内容

`UserService.get_users` の冒頭のクエリ組み立てに、SYSTEMロール除外条件を無条件で追加する。

```python
stmt = select(User).where(
    User.tenant_id == tenant_id,
    User.role != UserRole.SYSTEM,
)
```

- `role`引数によるフィルタ（`if role: stmt = stmt.where(User.role == UserRole(role))`）は
  従来通り以降で適用する。`role="SYSTEM"`が指定された場合、
  `User.role != UserRole.SYSTEM` と `User.role == UserRole.SYSTEM` が両方ANDされ、
  結果的に0件になる（naw-server側の挙動と同一）
- 既存の `search_text` によるLIKE検索・ソート・ページネーションのロジックは変更しない

## 対象外ファイル

- `app/repositories/user_repository.py`: 一覧取得用のメソッドを持たず（`find_by_*`系のみ）、
  今回のクエリはService層に直接書かれているため変更不要
