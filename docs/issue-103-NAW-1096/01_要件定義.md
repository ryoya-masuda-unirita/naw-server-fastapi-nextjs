# 01_要件定義

## 背景

管理画面のユーザー一覧APIは、テナント内の全ユーザーを対象にページネーション取得している。
naw-server（Spring Boot）側では2026年6月にSYSTEMロール（Waha等の内部連携用ユーザー）を
管理画面のユーザー一覧から除外する修正が行われたが、FastAPI移植側にはこのフィルタが
反映されておらず、管理者がSYSTEMロールのユーザーを一覧上で目にしてしまう状態になっている。

## 機能要件

- 管理画面ユーザー一覧APIは、SYSTEMロールのユーザーを常に除外して返す
- ロールフィルタ（`role`クエリパラメータ）にSYSTEMが明示的に指定された場合も、SYSTEM除外条件は
  外さない（結果として該当ユーザーは0件になる。移植元 naw-server の挙動に合わせる）
- SYSTEM以外のロール（USER・ADMIN）でのフィルタ・検索・ソート・ページネーションは従来通り動作する
- 件数（`totalElements`・`totalPages`）もSYSTEM除外後の値で計算する

## 非機能要件

- 既存のユーザー一覧取得のパフォーマンス特性（1クエリでのCOUNT・1クエリでの一覧取得）を変えない

## スコープ外

- グループメンバー一覧（`GroupService`相当）からのSYSTEMロール除外は対象外とする
  （Issue本文のスコープが「管理画面ユーザー一覧」に限定されているため）
- SYSTEMロールユーザー自体の作成・認証等の挙動変更は対象外
