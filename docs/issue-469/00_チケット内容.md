# 学習データのファイルの取り出しを、Apache Tika（コンテナの中で起動）に対応させる

## 概要

クラウド側 `server/` の学習データ登録（#462）で、PDF・Word・Excel・PowerPoint・旧形式・CSV などのテキストを、移植元と同じ Apache Tika 3.1.0 で取り出せるようにする。移植元は Tika をサーバー本体の中で動かしている。Python では、Tika のサーバー（jar）を、サーバーのコンテナの中に入れ、同じコンテナの中で子プロセスとして起動して `localhost` で呼ぶ。デプロイの単位は、移植元と同じ 1 つのまま。

## 説明

- #462 の取り出しは、テキスト系の形式だけで、PDF・Office は 400（未対応）。移植元の `TikaService` は、Tika 3.1.0 で形式を判定して取り出す
- アーキテクチャは、移植元に合わせたい。Tika を別のサービス（サイドカー）にしない
