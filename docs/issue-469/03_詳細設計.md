## `TikaClient`

- `extract_text(filename, content_type, data)`: `_ensure_server` で、URL を得る → `PUT {url}/tika`（`Accept: text/plain`、`Content-Type`（なければ octet-stream）、`Content-Disposition: attachment; filename*=UTF-8''…`、本文はファイルの中身）。200 は本文を返す。415 は未対応のメッセージ、422 とその他の 4xx・5xx、通信エラーは取り出せなかったメッセージで、400
- `_ensure_server`: `TIKA_URL` があれば、その URL（子プロセスは起動しない）。なければ `TIKA_SERVER_JAR` で、`asyncio.Lock` の中で、子プロセスがなければ（または終了していれば）起動する。どちらもなければ 400
- `_start`: `java -Xmx{heap} -jar {jar} --host 127.0.0.1 --port {port}`（`stdin`・`stdout`・`stderr` は捨てる）。`GET /version` が 200 を返すまで、0.5 秒間隔で待つ（`TIKA_START_TIMEOUT_SECONDS`、既定 60 秒）。起動できない（`OSError`）・時間切れ・途中で終了した場合は、止めて 400
- `shutdown`: 子プロセスに `terminate`、5 秒待って終了しなければ `kill`
- メッセージ・ログには、jar のパス、ファイルの中身、Tika の応答の本文を出さない

## イメージ

```dockerfile
ARG TIKA_VERSION=3.1.0
ARG TIKA_SHA512=<固定したチェックサム>
RUN apt-get update && apt-get install -y --no-install-recommends default-jre-headless curl ca-certificates \
 && curl -fsSL -o /opt/tika-server.jar https://archive.apache.org/dist/tika/${TIKA_VERSION}/tika-server-standard-${TIKA_VERSION}.jar \
 && echo "${TIKA_SHA512}  /opt/tika-server.jar" | sha512sum -c - \
 && apt-get purge -y curl && apt-get autoremove -y && rm -rf /var/lib/apt/lists/*
ENV TIKA_SERVER_JAR=/opt/tika-server.jar
```

- チェックサムは、公式の `.sha512` と一致することを確かめて、固定する
