# IndexController（インデックス管理）基本CRUD APIの移植

## 概要

`~/Documents/naw-server`（Spring Boot）の `IndexController` にある基本CRUD5エンドポイントをFastAPI(`backend/`)へ移植する。インデックス（RAG検索対象の情報源）を管理するための一覧・詳細・作成・更新・削除APIを実装する。

## 説明

対象エンドポイント:

| メソッド | パス | 概要 |
|---|---|---|
| GET | `/api/admin/indexes` | インデックス一覧取得（グループ・検索フィルタ、ページング） |
| GET | `/api/admin/indexes/{id}` | インデックス詳細取得 |
| POST | `/api/admin/indexes` | インデックス作成 |
| PATCH | `/api/admin/indexes/{id}` | インデックス更新 |
| DELETE | `/api/admin/indexes/{id}` | インデックス削除 |

参照実装:

- Controller: `~/Documents/naw-server/src/main/java/com/example/naw/api/IndexController.java`
- Service: `~/Documents/naw-server/src/main/java/com/example/naw/service/IndexService.java`
- Domain: `~/Documents/naw-server/src/main/java/com/example/naw/domain/index/Index.java`, `IndexRepository.java`
- Request: `IndexCreateRequest`
- Response: `SingleIndexResponse`
- Validator: `~/Documents/naw-server/src/main/java/com/example/naw/validator/IndexRequestValidator.java`
- Migration: `~/Documents/naw-server/src/main/resources/liquibase/changelog/{indexes,indexes_endpoints,indexes_groups}/`
