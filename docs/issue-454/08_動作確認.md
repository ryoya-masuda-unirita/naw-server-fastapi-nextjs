# 08_動作確認

## 確認環境

- macOS、`feature/issue-454`
- テストは `generative-ai-adapter/`・`waha-emulator/` の `uv run pytest`（外部通信はモック）
- 実機: オンプレ（`onprem/` の docker compose）。waha-emulator を再ビルドし、Bedrock の設定（回答は Mantle、埋め込みは Runtime の Titan）、実際のベクトル DB（pgvector）で確認

## 確認手順

1. 先にテストを足し、実装なしでは読み込みの段階で失敗することを確かめる
2. 実装し、テスト・ruff・mypy を実行する
3. 読み取りの前処理を使わない状態に戻して、RAG のテストが失敗することを確かめ、元に戻す
4. オンプレの実機で、学習済みの文書について質問する

## 確認結果

### テスト

- 実装前: `json_payload` が未定義のため、テストファイルの読み込みで失敗した
- 前処理を使わない状態に戻すと、フェンス付きの回答と検証を扱う 2 件が失敗し、他は通った（`2 failed, 43 passed`）。戻すと 45 passed
- 実装後: `generative-ai-adapter` 1445 passed, 3 skipped（追加 14 件）、`waha-emulator` 173 passed。ruff（format・check）と、`generative-ai-core`・`generative-ai-adapter`・`retrieval-adapter`・`embedding-adapter` の mypy が問題なし

### オンプレの実機

`bedrock-rag`（保存先 `docs`。学習済みは `情報セキュリティ方針.txt`）に、server-local 経由で質問した。

| 質問 | 結果 |
|---|---|
| パスワードは何文字以上にする必要がありますか？ | 「パスワードは12文字以上にする必要があります。」、参照元 `情報セキュリティ方針/情報セキュリティ方針.txt` |
| 情報の誤送信に気づいたらどうすればいいですか？ | 「30分以内に情報システム部へ報告する必要があります。」、参照元あり |
| 経費精算の申請期限はいつまでですか？（`docs` にない内容） | 定型文「提供された情報からは答えが分かりませんでした。」（文書にない内容を作り話で答えない） |

- ログで、`rag-answer` のあとに `rag-validation` が呼ばれ、`answerPresent=True`、`referenceIds=[1]` になることを確認した（修正前は検証の呼び出しがなく、`rag answer rejected` になっていた）

### 確認の過程での訂正

- 最初の質問で、`bedrock-rag-hr`（#452 のひな形）を使ったところ、検索なしの一般的な回答が返った。この `feature/issue-454` は `develop` から切っており、#452（ひな形）がまだ入っていないため、未登録のサービス ID として普通のチャットで動いたことが原因で、#454 の不具合ではない。以降は、明示的に登録してある `bedrock-rag` で確認した
