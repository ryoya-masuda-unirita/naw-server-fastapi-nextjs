## 詳細

### 1. 無関係の画像のコミット（🔴 致命的）→ 一部対応済み

コミット時に `git add generative-ai-adapter` で、ユーザーの未追跡のスクリーンショットまで含めてしまった私の誤り。#452 では気づいて外したが、今回は見落とした。`git rm --cached` でリポジトリの管理から外した（ファイル自体は、ユーザーの手元に残してある）。ただし、すでに push 済みのコミットの履歴には残っている。画面の画像であり、履歴から消すには、ブランチの履歴の書き換えと強制 push が要るため、ユーザーの判断を待つ。

### 2. 説明文の中の括弧（🟡 注意）→ 対応済み

指摘どおり、`設定は {name} の形式です。` のような説明文のあとに JSON があると、最初の `{` から最後の `}` までの切り出しが読めなかった。各 `{` から `json.JSONDecoder().raw_decode` で読める最初の JSON オブジェクトを探す形に直した。テスト（`test_braces_in_surrounding_text_are_skipped`）を足した。

### 3. 読めないときの戻り値（🔵 提案）→ 対応済み

読めないときは、元の文字列をそのまま返すようにし、docstring と一致させた。フェンス付きの読めない文字列のテストも足した。
