# 04_テスト設計

## テスト方針

- 判定役・巡回役・調査済みの一覧・レポート・設定は、専用環境を使わない単体テストで確かめる。画面は、小さなテスト用サイト（ブラウザの通信を横取りして HTML と API の応答を返す）で作る
- 専用環境での巡回（今の frontend を対象）は、動作確認（08）で実際に 1 コマンドで流し、レポートが出ることを確かめる
- lint・型チェックも通す

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 判定: 500 | ボタンを押すと API が 500 を返す | 「HTTP 5xx」の疑いが 1 件、重大度「高」、場所に API のメソッドとパス |
| 2 | 判定: 想定外の 4xx | API が 404 を返す | 「HTTP 4xx」の疑いとして 5xx と区別される |
| 3 | 判定: 想定内の 4xx | 設定で想定内とした 4xx | 疑いにならない |
| 4 | 判定: コンソールのエラー | ボタンで `console.error` | 「コンソールのエラー」の疑い |
| 5 | 判定: 未処理の例外 | ボタンで例外を投げる | 「未処理の例外」の疑い、重大度「高」 |
| 6 | 判定: Promise の reject | ボタンで reject を放置 | 「未処理の reject」の疑い |
| 7 | 判定: はみ出し | 画面幅より広い要素がある | 「横スクロール」と「はみ出し」の疑い |
| 8 | 判定: はみ出しなし | 普通の画面 | 表示崩れの疑いなし |
| 9 | 判定: 真っ白 | ボタンで本文を消す | 「真っ白」の疑い |
| 10 | 判定: 何も起きない | 何もしないボタン | 「何も起きない」の疑い |
| 11 | 判定: 入力チェックで止まる | 必須の欄が空のまま送信 | 「何も起きない」にならない |
| 12 | 判定: 遅い | API が しきい値を超えて応答する | 「遅い応答」の疑い |
| 13 | 判定: アクセシビリティ | ラベルのない画像・入力欄 | 「アクセシビリティ」の疑い |
| 14 | 判定: 戻れない | 操作できる要素のない画面に遷移 | 「戻れない」の疑い |
| 15 | 巡回: 再帰 | リンクでつながる複数の画面 | 深さの上限までの画面をすべてたどり、各疑いが見つかる |
| 16 | 巡回: 同じ状態 | 同じ画面へのリンクが複数ある | 状態は 1 回だけ数える |
| 17 | 巡回: 上限 | 深さ・操作回数の上限を小さくする | 上限を超えない |
| 18 | 巡回: 再現性 | 同じ種で 2 回 / 違う種 | 同じ種なら操作の順番が同じ。違う種なら順番が変わる |
| 19 | 巡回: 異常値の送信 | maxlength のある入力欄のフォーム | 空・最大・最大+1・記号・絵文字・負の数・長い文字列などが送信される |
| 20 | 巡回: 再現手順 | 疑いが見つかる | 起点からの操作の列・スクリーンショット・trace がある |
| 21 | 巡回: 担当外 | 範囲外の画面へのリンク | その先は掘らず、担当外として記録される |
| 22 | 巡回: ログイン | ログイン画面を通す権限 | ログイン画面に入力してログインし、以後の新しいタブでもログインしたまま |
| 23 | 巡回: 外部リンク・除外 | 別オリジンのリンク・除外指定の要素 | 操作しない |
| 24 | 一覧の共有 | 同じ一覧を使う 2 つの担当範囲が同じ共通領域を持つ | 共通領域の操作は片方だけが行う |
| 25 | 一覧の排他 | 同じキーを同時に 20 回取り合う | 取れるのは 1 回だけ |
| 26 | レポート: まとめ | 2 つの担当範囲で同じ指紋の疑い | 1 件にまとまり、発生回数・担当範囲・権限が併記される |
| 27 | レポート: 出力 | まとめを書き出す | JSON・Markdown・HTML が出て、HTML の文字はエスケープされる |
| 28 | 設定: 担当範囲 | 既定の設定 | まとまり × 権限の担当範囲が展開され、ID が重ならない |
| 29 | 設定: 単独実行 | `--shard` に存在する ID / しない ID | 指定だけが選ばれる / エラー |
| 30 | 設定: 安全策 | 対象がローカル以外 | 明示の引数がなければエラー |
| 31 | 設定: テナント | 担当範囲の ID が長い | テナント ID が 32 文字以内に収まる |
| 32 | 入力値 | 種類ごとの値 | 最大は maxlength ちょうど、最大+1 は 1 文字多い。数値欄は数値として入る値 |
| 33 | 専用テナントの SQL | 担当範囲の一覧 | テナント・ユーザー・パスワード履歴を写す SQL ができ、何度流しても重複しない |
