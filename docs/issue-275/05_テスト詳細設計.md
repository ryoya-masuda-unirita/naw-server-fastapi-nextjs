# 05_テスト詳細設計

テストランナーは Playwright Test（`e2e-explorer/playwright.config.ts`、`tests/*.test.ts`）。テスト用サイトは `tests/fixtures/test-site.ts` が `context.route('http://127.0.0.1:65530/**')` で HTML と API の応答を返す（実際のサーバーは立てない。ホストがローカルなので安全策にも掛からない）。

## tests/fixtures/test-site.ts

| パス | 内容 |
|---|---|
| `/` | 各画面へのリンク、共通領域 `<aside>`（「サイド」ボタン）、外部リンク、除外指定のボタン、`/` 自身へのリンク |
| `/server-error` | 「読み込む」ボタン → `GET /api/boom`（500） |
| `/not-found-api` | 「探す」ボタン → `GET /api/missing`（404） |
| `/console` | 「ログ」→ `console.error`、「投げる」→ 例外、「拒否」→ 未処理の reject |
| `/overflow` | 幅 3000px の要素 |
| `/form` | `maxlength=10` の文字欄と数値欄を持つフォーム → `POST /api/echo`（受け取った本文を記録） |
| `/required` | 必須の欄だけのフォーム（送信しても何も通信しない） |
| `/noop` | 何もしないボタン |
| `/blank` | 本文を消すボタン |
| `/slow` | `GET /api/slow`（しきい値より遅い） |
| `/a11y` | ラベルのない入力欄 |
| `/dead-end` | 操作できる要素がない文字だけの画面 |
| `/login`・`/home` | ログインの確認用。ログインで sessionStorage にテナント ID を入れ、`/home` は sessionStorage がなければ `/login` に飛ばす。`/home` のボタンは `X-Tenant-ID` がないと 401 になる API を呼ぶ |
| `/normal`・`/dead-end-start` | はみ出しのない普通の画面・行き止まりへの入口 |
| `/placeholder` | 「未移植: …」の目印・幅の広い要素・何もしないボタン |
| `/focus-style` | フォーカスで見た目が変わる欄と、空白なら何もしない送信 |
| `/break-form` | 入力で 500 の API を呼んでフォームを消す |
| `/polling` | 100ms ごとに API を呼び続ける画面 |
| `/home` のログアウト | Cookie を消してログイン画面へ（次のタブはログインし直しが要る） |
