## 詳細

### 1. 操作の失敗で疑いを捨てていた（🔴 致命的）→ 対応済み

入力で呼ばれた API が 500 を返してフォームが消える、のように「失敗の原因そのものが重大な疑い」のときに、レポートには再生失敗しか残らなかった。操作に失敗しても、通信が落ち着くのを待って判定役を閉じ、それまでの疑いを再現手順付きで記録するようにした。テスト用サイトに「入力で 500 を呼んでフォームを消す」画面を足し、`keeps findings that happened before an action failed` で確かめた。

### 2. 再ログインの上限で担当範囲が止まる（🔴 致命的）→ 対応済み

ログアウトの操作のたびに再ログインが要るため、合計の回数に上限を付けると、ログアウトを押せる状態が多い担当範囲（共通の領域の一覧を使わない `--no-shared-registry` のときなど）が途中で止まっていた。上限は「ログインし直しても起点がログイン画面のまま」が続いた回数（3 回）だけに付け、起点を開けたら数え直すようにした。`logs in again after a logout action and keeps crawling` で確かめた。

### 3. 流し直しで共通の領域を飛ばす（🟡 注意）→ 対応済み

担当範囲の開始時に、その担当範囲が前に取ったキーを手放す（`releaseOwner`）ようにした。同じ担当範囲の中での重複を防ぐ働きは変わらない。`releases keys so that a rerun of the same shard explores them again` で確かめた。

### 4. 落ち着かない画面ですべてが「遅い操作」になる（🟡 注意）→ 対応済み

`waitForSettle` が「落ち着いたか」を返すようにし、上限まで待っても落ち着かなかった操作は遅さを判定しない（API ごとの応答時間の判定は残る）ようにした。`does not report every action as slow on a polling page` で確かめた。

### 5. フォームの送信で古い番号を使っていた（🟡 注意）→ 対応済み

列挙のたびに要素の番号が振り直されるため、番号は同じ列挙の中でだけ使うようにした。欄は 1 回の列挙でまとめて探し、送信の前にもう一度列挙して、その列挙の中でフォーム（署名と順番）と送信ボタンを探す。

### 6. 古いロックを壊すときの競合（🟡 注意）→ 対応済み

ロックを「持ち主の印（token）を入れたディレクトリを一時名で作り、ロックの名前へ付け替える」方式にした。古いロックはまず自分だけの名前に付け替えてから古さを確かめて消し、新しいロックだったら元に戻す。ロックを外すときは自分の印のロックだけを消す。`removes a stale lock`・`waits for a fresh lock instead of breaking it` で確かめた。ごく短い間に 3 者が重なる場合の競合は残るが、古いロックはプロセスが落ちたときにしかできないため許容する。

### 7. 共通の領域を取ったまま失敗する（🔵 提案）→ 対応済み

操作に失敗した（再生できなかった・操作できなかった）共通の領域のキーは手放し、他の担当範囲が調べられるようにした。

### 8. 準備の失敗で他のワーカーが止まる（🟡 注意）→ 対応済み

出力先・コンテキストの作成も担当範囲の `try` の中に入れ、その担当範囲のエラーとして記録するようにした。並列実行の側でも担当範囲ごとに例外を受け止め、他のワーカーは続ける（結果を残せなかった担当範囲はコマンドの最後にエラーとして出す）。

### 9. フォームの送信の列挙の無駄（🔵 提案）→ 対応済み

5 の対応で、欄の数によらず列挙は 2 回（入力の前・送信の前）になった。

### 10. 握り潰し・マジックナンバー・重複（🟡 注意）→ 対応済み

- タブ・コンテキストを閉じる、trace の記録を始める・保存するなどの後片付けの失敗は、`warnOnFailure` で警告としてログに残すようにした（巡回は止めない）。trace を保存できなかったときは、その trace を指している疑いから trace のパスを外す
- 判定役に残した `.catch` は、遷移の途中で評価できないときの扱い（変化あり・真っ白の判定をしない）で、理由をコメントに書いた
- `auth.ts` の待ち時間・回数、`crawler.ts` の既定の画面幅を定数にした
- 例外を 1 行にする処理を `errorMessage`（`src/errors.ts`）にまとめ、要素の列挙を `enumeratePage`（`oracle.ts`）にまとめて巡回役と判定役で共有した
