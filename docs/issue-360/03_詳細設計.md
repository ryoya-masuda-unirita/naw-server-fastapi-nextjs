# 03_詳細設計

## 実装対象ファイル

| ファイル | 内容 |
|---|---|
| `frontend/src/lib/utils/auth-validation.ts`（新規） | `validateRequiredField`・`validateUsername`・`validatePasswordField`。エラー文言（翻訳済み）か空文字を返す |
| `frontend/src/routes/auth/login.tsx` | 欄ごとの touched 状態と、現在の入力値から計算したエラーを `FormInput` の `error` に渡す。`<form noValidate>`。`required` 属性を外す。パスワード欄に `maxLength={PASSWORD_MAX_LENGTH}`・`asciiOnly` |

## 処理

1. 送信時に `touched` を全欄 true にし、`fieldErrors` に 1 つでもあれば `return`（認証 API を呼ばない）
2. blur した欄は `touched` を true にする
3. エラーは毎回の描画で入力値から計算するので、入力を直せば消える

## 参照

移植元 `client/src/app/features/auth/pages/login/login.component.ts`、`shared/utils/form-errors.ts`、`features/auth/validations/password.validation.ts`
