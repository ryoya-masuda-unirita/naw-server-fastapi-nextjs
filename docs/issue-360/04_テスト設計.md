# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 必須 | ユーザーID・パスワード未入力で送信 | 必須エラーが 2 か所に出て、認証 API を呼ばない |
| 2 | 必須 | ユーザーIDだけ／パスワードだけ未入力 | 必須エラーが 1 か所 |
| 3 | 必須 | テナントID未入力 | 必須エラーが出る |
| 4 | 文字数 | ユーザーID 2 文字 | 最小文字数エラー、認証 API を呼ばない |
| 5 | 文字数 | ユーザーID 51 文字 | 最大文字数エラー |
| 6 | 入力制限 | パスワード欄に全角・70 文字 | 全角は取り除かれ、64 文字で切られる |
| 7 | 再入力 | エラー表示後に入力を直す | エラーが消える |
| 8 | 標準検証 | フォーム | `noValidate` が付く |
| 9 | 共通関数 | 必須・3〜50・64・半角 | 境界値で期待どおり |
| 10 | E2E | 03-03・03-04・03-05・03-17 | OK |
