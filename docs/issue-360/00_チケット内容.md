# ログイン画面に移植元と同じ入力チェック（必須・文字数・半角英数字記号）を入れる

## 概要

ログイン画面（`frontend/src/routes/auth/login.tsx`）に入力チェックがない。移植元は `Validators.required`・ユーザーID 3〜50 文字・パスワード必須・最大 64 文字・半角英数字記号のみで、「この項目は必須です」「3文字以上で入力してください」などを欄の下に出し、認証 API を呼ばない。

## 説明

対象の項番: 03-03・03-04・03-05・03-17（同じフォームの他のチェックも揃える）。

結合テスト項目書の E2E（#316、`e2e-spec/`）で見つかった、移植元との本当の差。原因・移植元の挙動・見立ては `docs/issue-316/ng-ログイン.md` の「原因 A」。
