# 07_gitコミット

## コミット分割案

本チケットはAWSリソースの手動構築・削除が主体で、コード変更を伴わない。コミット対象は`docs/issue-158/`配下のドキュメントのみ。

| # | コミット内容 | 対象ファイル |
|---|---|---|
| 1 | `00_チケット内容.md` を作成 | `docs/issue-158/00_チケット内容.md` |
| 2 | `01_要件定義.md`〜`05_テスト詳細設計.md` を作成 | `docs/issue-158/01_要件定義.md`〜`05_テスト詳細設計.md` |
| 3 | 動作確認結果を`08_動作確認.md`に記録し、`06_タスクリスト.md`を更新 | `docs/issue-158/06_タスクリスト.md`・`08_動作確認.md` |

## 各コミットメッセージ案

```
#158 issue-158 docs/issue-158 のドキュメント一式を作成
    - AWS環境（dev）手動構築・手動デプロイ・全リソース削除の要件・設計・テスト方針を記録
```

```
#158 issue-158 AWS環境の構築・動作確認・全リソース削除を実施
    - 08_動作確認.md に構築〜検証〜削除の結果を記録
    - 06_タスクリスト.md の該当項目をチェック済みに更新
```

コード変更が発生した場合（例: 環境変数追加等の軽微な修正）は、別コミットとして追加する。
