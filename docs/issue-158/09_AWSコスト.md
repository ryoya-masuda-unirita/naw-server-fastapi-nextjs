# 09_AWSコスト

今回のIssue #158で構築する全リソースを**削除せず放置した場合**の概算コスト。

- リージョン: `ap-northeast-1`（東京）、オンデマンド料金
- 為替: $1 = 155円で換算（変動する）
- 単価は2026年時点のAWS公表料金からの概算。実際の請求額はAWS Pricing Calculator / Cost Explorerで確認すること
- 前提: ECSホスト・踏み台・RDS・ElastiCache・ALBがすべて起動しっぱなしの状態
- トラフィックはほぼ0（放置）として、データ転送料金・ALBのLCU従量課金・CloudFront/S3のリクエスト課金は「ほぼ$0」として除外

## ポイント

- **一番高いのはALB（時間課金）とRDS/ElastiCacheのインスタンス時間**。この3つで放置コストの約8割を占める
- ストレージ（EBS・RDSストレージ）は起動・停止に関係なく月額固定でかかる。ただし金額としては小さい
- S3・CloudFront・ECRは放置してもほぼ無料（数MB〜数百MBのため）
- **本チケットの方針どおり、動作確認後に全削除すれば、これらの課金はすべて止まる**。数時間の検証で削除すれば実際の課金は数十円〜200円程度で収まる（`02_基本設計.md`のリソース一覧・費用概算参照）

## 注意: 「停止」では止まらない費用

- RDS・EC2を「停止」しても、EBS/RDSストレージ料金は発生し続ける（インスタンス時間課金だけが止まる）
- ElastiCache・ALBには「停止」の概念自体がなく、削除しない限り時間課金が続く
- 完全に$0にするには**全リソースの削除**が必要（`03_詳細設計.md`フェーズ5参照）
