## RDS初期化（実施済み）

| 項目 | 内容 |
|---|---|
| 接続方法 | 踏み台へのSSHトンネル（`ssh -i ~/.ssh/naw-fastapi-issue158-bastion-key.pem -L 5433:<RDSエンドポイント>:5432 ec2-user@57.180.55.138 -N`） |

| ローカル前提 | `psql`は`brew install libpq`で導入（`/opt/homebrew/opt/libpq/bin`をPATHに追加） |
