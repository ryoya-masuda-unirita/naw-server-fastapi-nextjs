# 08_動作確認

## 確認環境

- **ブラウザ・実機確認は行わず、自動テストのみで代替する**（pytest、インメモリ SQLite + fakeredis）
  - 他の作業と共有しているローカルの Postgres / Redis / backend サーバーを起動・変更しないため
- 実行ディレクトリ: `backend/`（`.env` はメイン作業ツリーの `backend/.env` をコピーしたもの）
- ベース: `origin/develop`（`88838f7`）

## 確認手順

1. 修正前のコード（テストだけ追加した状態）で `uv run pytest tests/integration/test_library_tags.py -q` を実行し、追加したテストが失敗することを確認
2. 修正後のコードで `uv run pytest tests/integration/test_library_tags.py -v` を実行
3. 修正後のコードで `uv run pytest -q`（全件）・`uv run mypy app tests`・`uv run ruff check .`・`uv run ruff format --check .` を実行
