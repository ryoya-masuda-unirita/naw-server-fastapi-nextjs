## 実装内容

### `LibraryTagService._get_tag_or_404`

```python
try:
    normalized_id = uuid.UUID(tag_id).hex
except ValueError:
    raise HTTPException(status_code=404, detail="Library tag not found") from None
tag = await LibraryTagRepository.find_by_id_and_tenant_id(normalized_id, tenant_id, session)
```

- `uuid.UUID` はハイフン付き・ハイフンなし・大文字・`{...}`・`urn:uuid:` 形式を受け付け、`.hex` は常にハイフンなし 32 桁の小文字を返す。保存値は `uuid4().hex`（小文字）で作っているため一致する
- 不正な形式は、存在しない ID と同じ 404・`Library tag not found` を返す（変更前の応答と同じ。ライブラリ API の `_parse_library_id` と同じ扱い）
- 呼び出し元は `update_library_tag` だけ

### `LibraryTagService.update_library_tag`

- `exists_by_tenant_id_and_name(..., exclude_id=tag_id)` を `exclude_id=tag.id` に変える。パスの値（ハイフン付き）のままだと保存値と一致せず、自分自身を重複とみなしてしまうため
