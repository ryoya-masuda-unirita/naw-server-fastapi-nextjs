# 05_テスト詳細設計

## `backend/tests/integration/test_library_tags.py` の `TestUpdateLibraryTag`

ハイフン付きの ID は `str(uuid.UUID(tag.id))` で作る。

| No | テスト名 | 確認内容 |
|---|---|---|
| 1 | `test_update_with_hyphenated_id` | ハイフン付き ID で PATCH → 200、`name`・`description` が更新され、`id` が `tag.id`（ハイフンなし） |
| 2 | `test_update_with_uppercase_hyphenated_id` | ハイフン付き大文字の ID で PATCH → 200、`id` が `tag.id` |
| 3 | `test_update_with_hyphenated_id_keeping_same_name` | ハイフン付き ID で今と同じ `name` を指定して PATCH → 200 |
| 4 | `test_update_with_hyphenated_id_and_duplicate_name_returns_400` | ハイフン付き ID で `second_tag.name` を指定 → 400 |
| 5 | 既存 `test_update_not_found_returns_404` | `nonexistent`（不正な形式）→ 404。変更なしで通ることを確認 |
| 6 | `test_update_other_tenant_tag_with_hyphenated_id_returns_404` | 他テナントのタグをハイフン付きで指定 → 404 |

## 実行コマンド

```bash
cd backend
uv run pytest tests/integration/test_library_tags.py -v
uv run pytest -q
uv run mypy app tests
uv run ruff check . && uv run ruff format --check .
```
