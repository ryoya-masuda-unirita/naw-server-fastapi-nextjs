# ライブラリタグの更新APIがハイフン付きのタグIDを受け付けない

## 概要

GitHub Issue #227 の内容を転記する。

## 説明

#173 の調査で判明。タグ ID は DB にハイフンなし 32 桁の hex で保存されているが、更新 API はハイフン付き（UUID 標準形式）の ID を受け付けない。移植元の挙動を確認し、一覧の絞り込み（#173 で両形式を受け付けるよう修正済み）と同様に両形式を受け付けるようにする。

## その他

- Issue: https://github.com/ryoya-masuda-unirita/naw-server-fastapi-nextjs/issues/227
- 関連: #173（PR #203、マージ済み。ライブラリ一覧のタグ絞り込みでハイフン付き・なしの両方を受け付ける）
- エラー応答の形式（`detail` / `message`）やバリデーションエラーのステータスコードは別途検討中のため、本 Issue では新たに決めず、既存の API と同じ形にする
