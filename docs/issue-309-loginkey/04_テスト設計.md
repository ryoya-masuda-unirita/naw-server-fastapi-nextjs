# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 一覧・プロフィールの応答 | キーありのユーザー | `hasLoginKey` が true、キーの値が出ない |
| 2 | 一覧・プロフィールの応答 | キーなしのユーザー | `hasLoginKey` が false |
| 3 | プロフィールの null 項目 | 通常のプロフィール取得 | `totalCredits` が出ない |
| 4 | ユーザー作成 | キーを指定して作成 | 指定したキーが `loginKey` に入り、`hasLoginKey` が true、`totalCredits` が無い、`Cache-Control: no-store` |
| 5 | ユーザー作成 | キーを指定せずに作成 | `loginKey` が null、`hasLoginKey` が false |
| 6 | ユーザー更新 | キーありのユーザーをキー指定なしで更新 | `loginKey` が null（保存済みのキーを返さない）、`hasLoginKey` が true、`Cache-Control: no-store` |
| 7 | ユーザー更新 | キーを指定して更新 | 指定したキーが保存され `loginKey` で返る |
| 8 | グループのメンバー一覧 | キーありのメンバー | キーの値も `loginKey`・`hasLoginKey` の項目も出ない |
| 9 | 回帰 | 全件 | 既存のテストがすべて通る |
