# 08_動作確認

## 確認環境

- macOS、`backend/` で `uv run`（Python 3.14 の venv）
- DB はテスト用のインメモリ SQLite、Redis は fakeredis（ローカルの Postgres・Redis・backend サーバーは使わない）
- **ブラウザ・実機での確認は行わず、自動テストのみで代替した**

## 確認手順

1. 追加したテストを `-v` で実行する
2. `uv run ruff check`・`uv run ruff format --check`・`uv run mypy app tests` を実行する
3. `uv run pytest` を全件実行する（単体・結合とも）
4. 変更・追加した docstring を `uv run ruff check --select D101,D102,D103,D105,D106,D107,D417 --config 'lint.pydocstyle.convention="numpy"'` で確かめる
