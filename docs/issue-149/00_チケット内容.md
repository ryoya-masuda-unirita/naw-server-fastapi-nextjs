# AWS Bedrock（Claude）をチャット用エンドポイントとして追加対応

## 概要

`tenant_endpoints`（AIプロバイダ接続設定）に、AWS Bedrock経由でのClaude呼び出しを
追加する。認証方式は AWS の「Bedrock API keys」（Bearerトークン方式、Preview機能）を
採用する。

## 説明

- 現状の`tenant_endpoints`は`endpoint`（URL）＋`api_key`（Bearer/APIキー1本）という
  構成で、Azure OpenAI・OpenAI・Gemini・Claude directのような「単純なAPIキー1本で
  呼べるREST API」を前提にしている
- AWS Bedrockには2つの認証方式があり、従来のSigV4署名方式（`boto3`ベース、アクセスキー・
  シークレットキー・リージョンでリクエスト署名）は現行スキーマと相性が悪いが、
  「Bedrock API keys」（Bearerトークンをヘッダーに乗せるだけの方式）であれば
  現行スキーマのまま対応できる
- 移植元（Spring Boot / naw-server）にBedrock関連の実装・言及は無く、完全に新規機能
- `EndpointType`（`tenant_endpoints.type`）に`BEDROCK_CHAT`を追加し、Bedrock Runtime API
  を呼び出すLLMクライアントを既存の`AzureLlmChatClient`と並ぶ形で実装する想定
