# 05_テスト詳細設計

テストの命名規則: テスト名は英語、意図は日本語の docstring。

## 新規テストファイル

| ファイル | 内容 |
|---|---|
| `waha-emulator/tests/test_studio_graph.py` | 定義の検証・コンパイル（`parse_graph`・`compile_graph`） |
| `waha-emulator/tests/test_studio_store.py` | `GraphStore`（保存・読み込み・削除・壊れたファイル・置き換え） |
| `waha-emulator/tests/test_studio_service.py` | `StudioService`（作成・更新・削除・重複・伏せ字・起動時の読み込み・レジストリへの反映） |
| `waha-emulator/tests/test_studio_admin_api.py` | 管理用 API（ステータス・応答・未設定時の 404） |
| `waha-emulator/tests/test_studio_workflow.py` | 保存したワークフローを execute で動かす結合（echo・検索の差し替え・失敗時のノード名・優先順位） |

## 既存テスト

- `tests/test_registry.py` に、動的な登録（優先・解除・解除後に元へ戻る）を足す
- `tests/test_config.py` に、`WAHA_STUDIO_DIR` の既定（未設定）と、空文字列を未設定とみなすことを足す
