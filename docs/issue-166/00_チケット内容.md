# 残り19カテゴリの結合テストをPlaywright E2Eで自動化する

## 概要

Issue #163で構築したPlaywright E2E基盤を使い、`25DA61_結合テスト項目書_md/`の残り19カテゴリ（`04_ログアウト.md`〜`22_Waha!生成AI検索.md`、計約604項目）を順次E2E自動化する。

## 説明

### 背景

Issue #163はE2E基盤構築が目的で、`03_ログイン.md`のみ試験実装した。残り19カテゴリは規模が大きいため後続Issueに送られていた。

### 対象カテゴリ

`04_ログアウト`(10)・`05_パスワード再設定`(38)・`06_レイアウト`(29)・`07_チャット送信`(55)・`08_チャット検索`(15)・`09_ライブラリ`(41)・`10_チャットルーム`(16)・`11_チャット詳細`(77)・`12_ワークスペース設定`(16)・`13_ユーザー管理`(24)・`14_チーム管理`(71)・`15_アシスタント`(48)・`16_チャット履歴`(25)・`17_学習データ`(47)・`18_フィードバック管理`(52)・`19_テンプレート`(29)・`20〜22_Waha!生成AI`(11)

### 進め方

- カテゴリ単位で`frontend-angular/e2e/`にspecファイルを追加
- 各カテゴリごとに自動化可能な項目を仕分けてから実装（Issue #163と同じ方針）
- 実装中に見つかったアプリ側の不具合はスコープ外とし、`test.skip`＋追跡Issue化
- 規模が大きいため、カテゴリ単位で段階的に進める
