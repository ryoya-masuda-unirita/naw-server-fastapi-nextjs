# 03_詳細設計

`02_基本設計.md`のディレクトリ構成・テストデータ方針・ドキュメント運用方針を参照。

カテゴリ共通の実装パターンは以下の通り（Issue #163の`login.spec.ts`/`auth.fixture.ts`を踏襲）。

```ts
import { test, expect } from './fixtures/auth.fixture';

test.describe('カテゴリ名', () => {
  test('...であること', async ({ authenticatedPage: page }) => {
    await page.goto('/対象パス');
    // ...
  });
});
```

カテゴリごとの自動化対象・除外項目・実装したテストケースの一覧は、各カテゴリ実装時に`06_タスクリスト.md`の該当セクションへ追記する。
