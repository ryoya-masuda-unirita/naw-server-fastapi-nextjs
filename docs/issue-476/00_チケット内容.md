# NAW-1449 フィードバック一覧の並べ替えから追加学習順・学習先フォルダ名順を削除する

## 概要

フィードバック一覧（回答精度評価・チャット満足度）の並べ替えの選択肢から、「追加学習順」「学習先フォルダ名順」を削除する。移植元で NAW-1449 として直された変更を、`client/` に移植する。

## 説明

移植元: `~/Documents/unirita-develop-pj/secuaigent-ref/client`（origin/develop 3260e3a84）。コミット 3d5c7e474（NAW-1449 フィードバックの並べ替えから追加学習順・学習先フォルダ名順を消す）。

- 使わなくなった文言（`FEEDBACK.SORT_BY_ADD_LEARNING`・`FEEDBACK.SORT_BY_FOLDER`）を ja・en から削除する
