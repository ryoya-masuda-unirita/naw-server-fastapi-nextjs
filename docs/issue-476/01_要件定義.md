# 01_要件定義

## 背景

管理コンソール「フィードバック」の並べ替えで、「追加学習順」「学習先フォルダ名順」を選べる。

- チャット満足度タブでは、API がこの 2 つの並べ替えを受け付けず（400）、画面は一覧を空で表示する
- 回答精度評価タブでは、選べるが内部のフォルダ ID の順に並び、画面に出す値の順にならない

移植元は NAW-1449 で、両タブからこの 2 つの選択肢を消した。こちらにも同じ選択肢が残っている。

## 機能要件

| No | 要件 |
|---|---|
| R-01 | 回答精度評価の並べ替えの選択肢は、「更新日時順」「アシスタント表示名順」「精度順」の 3 つだけにする |
| R-02 | チャット満足度の並べ替えの選択肢は、「更新日時順」「チャット名順」「アシスタント表示名順」「満足度順」の 4 つだけにする |
| R-03 | 使われなくなった文言を、日本語・英語から削除する |
| R-04 | 他の並べ替え（更新日時順・アシスタント表示名順・精度順・チャット名順・満足度順）と、昇順・降順の動作は変えない |
| R-05 | #475 で並びが変わった項目（アシスタント表示名順・満足度順）と、削除する選択肢を検証している E2E を、新しい仕様に合わせる |

## 非機能要件

- API の呼び出しは変えない
- 既存のテストが通る

## スコープ外

- server の並べ替えの変更（#475。マージ済み）
- 回答精度評価の server 側の `add`・`folder`（移植元も残している）
- 回答数一覧タブの並べ替え
