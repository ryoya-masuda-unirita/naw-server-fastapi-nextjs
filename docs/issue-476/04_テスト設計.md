# 04_テスト設計

## テスト方針

画面のテスト（Vitest）で、並べ替えの選択肢を確かめる。E2E は、実際の画面と API・DB で並びを確かめる。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| T-01 | 回答精度評価の選択肢 | 並べ替えを開く | 更新日時順・アシスタント表示名順・精度順の 3 つだけ |
| T-02 | チャット満足度の選択肢 | 並べ替えを開く | 更新日時順・チャット名順・アシスタント表示名順・満足度順の 4 つだけ |
| T-03 | 既存の並べ替え | アシスタント表示名順を選ぶ | `sortField=name` で取得し直す（既存のテスト） |
| T-04 | E2E 18-08・18-28・18-29 | 実際の画面で並べ替える | DB の SQL で求めた表示値の順に並ぶ |
| T-05 | E2E 18-10・18-11・18-30・18-31 | － | 画面にない操作として skip |
