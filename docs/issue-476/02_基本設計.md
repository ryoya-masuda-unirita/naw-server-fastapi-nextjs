# 02_基本設計

## 変更対象

| 対象 | 変更 |
|---|---|
| 回答精度評価タブの並べ替えの選択肢 | 「追加学習順」「学習先フォルダ名順」を削除 |
| チャット満足度タブの並べ替えの選択肢 | 同上 |
| 文言（日本語・英語） | 上記 2 つの文言を削除 |
| E2E（フィードバック管理） | #475 と本変更に合わせて、並べ替えの期待値と、成立しなくなった項目の扱いを直す |

## 画面 / API 変更概要

- 並べ替えの項目のドロップダウンから、2 つの選択肢が消える。他の見た目・操作は変わらない
- API は変えない。選択肢が消えるので、チャット満足度で 400 になる操作ができなくなる

## 影響範囲

- 管理コンソール「フィードバック」の 2 タブの並べ替えのみ
- E2E: アシスタント表示名順（精度・満足度）、満足度順の期待値を、SQL で求める表示値の順（表示名・星の数）に変える。追加学習順・学習先フォルダ名順の項目は、画面にない操作として skip にする

## 移植方針

- 移植元の変更（選択肢と文言の削除）をそのまま写す
- E2E は、期待値を DB の SQL で求める既存の方針を保つ。#475 の server の並びに合わせて SQL を直す
- スコープの追加について: E2E の修正は #476 の本文にないが、#475 のマージで E2E の期待が実装と食い違うため、同じ並べ替えの変更として一緒に直す
