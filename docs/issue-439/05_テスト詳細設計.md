## 変更（追加のみ。既存のテストは書き換えない）

| ファイル | 変更（`04` の No） |
|---|---|
| `generative-ai-adapter/embedding-adapter/tests/test_app.py` | `VENDOR` に `"97"` を指定すると `Bedrock` になることを足す（11、13）。既存の「未知の ID」のテストが使う値が、97 と重ならないことを確かめる |
| `generative-ai-adapter/embedding-adapter/tests/test_service_embedding.py` | `Bedrock` が `SUPPORTED_VENDORS` で弾かれず、core の埋め込みのモデルに委譲されることを足す（11） |

| `waha-emulator/tests/test_workflow_config.py` | 学習用・検索用の定義に `VENDOR: Bedrock` が書けること、`onprem/config/workflows.bedrock.example.json` が読めて、回答・検索・学習がすべて Bedrock であることを足す（14） |

`04` の No 15（通し）は、本物のベクトル DB（PostgreSQL）なしで、ワークフロー全体を通すテストが、既存にないため、core のテスト（学習で保存するベクトルと、検索で作る質問のベクトルの次元数が合うこと）で確かめる。

追加するテストには、`bedrock-ext` のコメントを付け、取り外すときに関数ごと削除できるようにする。
