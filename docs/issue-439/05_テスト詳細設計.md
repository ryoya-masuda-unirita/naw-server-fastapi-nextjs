## 変更（追加のみ。既存のテストは書き換えない）

| ファイル | 変更（`04` の No） |
|---|---|
| `generative-ai-adapter/embedding-adapter/tests/test_app.py` | `VENDOR` に `"97"` を指定すると `Bedrock` になることを足す（11、13）。既存の「未知の ID」のテストが使う値が、97 と重ならないことを確かめる |
| `generative-ai-adapter/embedding-adapter/tests/` の埋め込みの委譲のテスト（`service/embedding.py` の対象） | `Bedrock` が `SUPPORTED_VENDORS` で弾かれないことを足す（11）。ファイルは実装時に特定する |
| `generative-ai-adapter/retrieval-adapter/tests/test_app.py` | `VENDOR` に `"97"` を指定すると `Bedrock` になることを足す（12、13） |
| `waha-emulator/tests/test_workflow_config.py` | 埋め込み・検索の定義に `VENDOR: Bedrock` と `${BEDROCK_API_KEY}` が書けることを足す（14） |
| `waha-emulator/tests/` の埋め込み・検索のワークフローのテスト | モックの Bedrock までを通すテストを足す（15）。ファイルは実装時に特定する |
