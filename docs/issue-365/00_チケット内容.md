# フィードバック一覧（満足度タブ）の学習先フォルダでの絞り込みを移植元に揃える

## 概要

`GET /api/admin/feedbackRoom` が `folderId` を無視し、満足度タブの学習先フォルダの絞り込みが全ルームを返す。移植元は `files.room_id` で絞り込む。

## 説明

- 対象の項番: 結合テスト項目書 18-25（`e2e-spec/tests/18-feedback.spec.ts`）
- 移植元 `server/` の該当 Service・Repository を確かめて揃える
- 同じ API の他の絞り込み・並べ替え（`sortField` の `add`・`folder` は移植元でも 422 になる）は移植元どおりに保つ
- 原因・移植元の挙動は `docs/issue-316/ng-フィードバック管理.md` を参照

## その他

目標は移植元の完璧なクローン。
