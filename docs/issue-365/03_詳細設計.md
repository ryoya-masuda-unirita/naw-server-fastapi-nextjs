# 03_詳細設計

## 実装対象ファイル

| ファイル | 変更 |
|---|---|
| `backend/app/schemas/feedback.py` | `FeedbackRoomListRequest` に `folderId: str \| None = None` を追加 |
| `backend/app/repositories/file_repository.py` | `find_room_ids_by_index_id(tenant_id, index_id, session)` を追加（`DISTINCT room_id`、`room_id IS NOT NULL`） |
| `backend/app/repositories/room_repository.py` | `find_feedback_rooms` に `room_ids: Sequence[str] \| None = None` を追加。None なら条件なし、空なら `IN ()` で 0 件 |
| `backend/app/services/feedback_service.py` | `get_feedback_rooms` で `folderId` があればルームIDを引いて渡す。docstring を NumPy 形式に整備 |

既存の呼び出し元（`tests/integration/test_enum_sort_cast.py`）は新引数が省略可能なため変更不要。
