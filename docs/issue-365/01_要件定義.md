# 01_要件定義

## 背景

満足度タブで学習先フォルダを選んでも、フィードバックのルーム一覧が絞り込まれず、学習先のないルームを含む全件が返る。移植元は、選んだフォルダのファイルを持つルームだけを返す。

## 機能要件

- `folderId` を指定すると、そのフォルダ（インデックス）に紐づくファイルを持つ評価済みルームだけが返る
- 該当するルームがない場合は 0 件になる
- `folderId` が空文字の場合は、指定なしと同じ（絞り込まない）
- `assistantId`・`rating` の絞り込みと組み合わせられる
- 総件数・ページ数も絞り込み後の件数になる

## 非機能要件

- 他テナントのファイルは対象にしない

## スコープ外

- `sortField` の許容値（`updatedAt`・`chat`・`name`・`level` のみ。`add`・`folder` は移植元でも 422）の変更
- 他の絞り込み・並べ替えの挙動の変更
