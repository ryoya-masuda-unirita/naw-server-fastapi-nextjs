# 02_基本設計

## 変更対象

- ルーム評価一覧 API（`GET /api/admin/feedbackRoom`）の検索条件と絞り込み

## 画面 / API 変更概要

- クエリパラメータ `folderId`（任意）を受け取る。画面（React の満足度タブ）は既に送っている
- レスポンスの形は変えない

## 影響範囲

- フィードバック管理の満足度タブ
- メッセージ評価一覧（`feedbackMessage`）の `folderId` は別の仕組み（`message_feedbacks.index_id`）で既に動いており、変更しない

## 移植方針

移植元 `FeedbackService.getFeedbackRooms` に合わせ、2 段階で絞り込む。

1. `folderId` が空でなければ、先に `files` から `index_id = folderId` かつ `room_id` が NULL でないファイルのルームIDを重複なしで取る（テナントで限定）
2. ルームの条件に `id IN (取得したルームID)` を足す。取得結果が空なら 0 件にする

判断: `folderId` が空文字のときは移植元（`StringUtils.isNotEmpty`）に合わせて絞り込まない。メッセージ評価一覧は空文字を絞り込みとして扱うが、本 Issue の範囲外のため変えない。
