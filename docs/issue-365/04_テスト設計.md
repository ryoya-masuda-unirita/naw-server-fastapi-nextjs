# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | フォルダでの絞り込み | フォルダ A に評価済みルームのファイル（同ルーム 2 件・room_id が NULL のファイル含む）、フォルダ B に別ルームのファイルがある | A を指定すると該当ルーム 1 件だけ。総件数 1、`indexId` は A |
| 2 | 該当なし | ファイルを持つルームがないフォルダを指定 | 0 件 |
| 3 | 空文字 | `folderId=` | 絞り込まない |
| 4 | 他の絞り込みとの組み合わせ | `folderId` と `rating` | 両方を満たすルームだけ |
| 5 | ファイルのリポジトリ | 重複・NULL・他のフォルダ・他テナント | ルームIDが重複なし、NULL 除外、他フォルダ・他テナントは対象外 |
| 6 | E2E | 項目書 18-25 | OK |
