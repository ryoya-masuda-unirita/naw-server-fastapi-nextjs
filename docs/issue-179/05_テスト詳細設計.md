# 05_テスト詳細設計

## 対象ファイル

`backend/tests/integration/test_assistants.py` の `TestListAdminAssistants`

| No | テストメソッド | 内容 |
|---|---|---|
| 1 | `test_search_by_name`（既存を修正） | `params={"q": ...}` を `params={"search": ...}` に変更する。名前が一致する `assistant` が含まれ、`ZZZ` が含まれないこと |
| 2 | `test_search_by_description_case_insensitive`（新規） | 説明が `"Translation Helper"` のアシスタントを作り、`search="translation"` で取得できること。一致しない `assistant` は含まれないこと |
| 3 | `test_search_empty_returns_all`（新規） | `search=""` のとき、作成済みのアシスタントがすべて返ること |
| 4 | `test_legacy_q_param_is_ignored`（新規） | `q="no-match-keyword"` のとき絞り込まれず、`assistant` が返ること |

## 実行コマンド

```bash
cd backend
uv run pytest tests/integration/test_assistants.py -q
uv run pytest -q
uv run ruff check app/routers/assistants.py tests/integration/test_assistants.py
uv run ruff format --check app/routers/assistants.py tests/integration/test_assistants.py
```
