# 04_テスト設計

## テスト方針

管理者向けアシスタント一覧取得 API の結合テストで、検索パラメータ `search` が効くことと、旧パラメータ名では絞り込まれないことを確認する。既存テストを全件実行し、デグレードがないことも確認する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 名前の部分一致検索 | `search` に既存アシスタントの名前を指定 | 該当アシスタントが返り、一致しないアシスタントは含まれない |
| 2 | 説明の部分一致検索・大文字小文字を区別しない | `search` に説明の一部を、大文字小文字を変えて指定 | 説明が一致するアシスタントが返り、一致しないアシスタントは含まれない |
| 3 | 空文字の指定 | `search` に空文字を指定 | 絞り込まれず全件が返る |
| 4 | 旧パラメータ名の無視 | 旧パラメータ名 `q` に、どのアシスタントにも一致しない文字列を指定 | 絞り込まれず全件が返る（移植元にないパラメータのため） |
| 5 | 回帰 | 既存テスト全件 | すべて成功する |
