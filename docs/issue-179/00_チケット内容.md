# #179 アシスタント一覧の検索がクエリパラメータ不一致で機能しない

## 概要

アシスタント一覧画面の検索欄にキーワードを入力しても、一覧が絞り込まれず全件表示されたままになる。

## 説明

- フロントエンド（frontend-angular）の `assistant-list-api.service.ts` は、検索キーワードをクエリパラメータ `search` として送信している
- バックエンド `backend/app/routers/assistants.py` の `list_admin_assistants` は、検索キーワードをパラメータ名 `q`（`q: str = Query("")`）で受け取っている
- パラメータ名が一致しないため、バックエンドは常に `q=""`（絞り込みなし）として処理し、検索が機能しない

### 発見経緯

Issue #166（E2E テスト自動化）の「15_アシスタントカテゴリ」を実装しているときに見つかった。検索欄に「アシスタント確認用」と入力しても、該当しないはずの既存アシスタント（「汎用アシスタント」など）を含む全件が表示されたままだった。

### Issue 本文の対応方針案

`assistant-list-api.service.ts` のクエリパラメータ名を `search` から `q` に修正する（フロント側の修正案）。

## その他

- `frontend-angular/` は上流 `secuaigent/client` のコピーで、同期のたびに上書きされるため変更しない
- 移植元 Spring Boot の `AssistantController#getAllAssistants` は `@RequestParam(required = false) String search` で受け取っている。そのため Issue 本文の案とは逆に、**バックエンドを移植元に合わせて `search` で受け取る**形で修正する
