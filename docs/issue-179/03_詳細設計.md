# 03_詳細設計

## 変更ファイル

### `backend/app/routers/assistants.py`

`list_admin_assistants` のクエリパラメータ定義を変更する。

```python
# 変更前
q: str = Query(""),
...
q or None,

# 変更後
search: str | None = Query(None),
...
search or None,
```

- 型は他のルーター（`prompt_templates.py` / `groups.py` の `search`）と同じ `str | None = Query(None)` にそろえる
- 空文字（`?search=`）は `search or None` で `None` に正規化し、これまでどおり絞り込まない
- `AssistantService.list_admin_assistants` 以降のシグネチャ（引数名 `search`）は変えない

## 参照した移植元

- `secuaigent/server/src/main/java/com/example/naw/api/AssistantController.java` `getAllAssistants`: `@RequestParam(required = false) String search`
- `secuaigent/server/src/main/java/com/example/naw/service/AssistantService.java` `getAdminAssistants`: `AssistantSpecification.containsSearch(search)` を適用
- `secuaigent/server/src/main/java/com/example/naw/domain/assistant/AssistantSpecification.java` `containsSearch`: `lower(name)` または `lower(description)` に対する `%search%` の LIKE
- `frontend-angular/src/app/features/admin/management/assistant-list/services/assistant-list-api.service.ts` `toAssistantParams`: `params['search'] = search`
