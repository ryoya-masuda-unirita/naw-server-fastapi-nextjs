# 08_動作確認

## 確認環境

- 全自動モードで実行したため、**ブラウザ・実機での確認は行わず、自動テスト（pytest）の結果のみで代替する**
- バックエンドのテスト環境: インメモリ SQLite + fakeredis（ローカルの Postgres / Redis / backend サーバーは使用していない）
- git worktree 上で実行（`backend/.env` なし）

## 確認手順

1. 修正前のルーター（`q` で受け取る版）に一時的に戻し、`uv run pytest tests/integration/test_assistants.py -q -k TestListAdminAssistants` を実行して、検索テストが失敗すること（不具合を再現できること）を確認する
2. 修正後のコードで同じテストを実行する
3. `uv run pytest tests/integration/test_assistants.py -q` を実行する
4. `uv run pytest -q` を全件実行し、`origin/develop`（修正前）での全件実行結果と失敗テストを比較する
5. `uv run ruff check` / `uv run ruff format --check` を変更ファイルに対して実行する
