# 02_基本設計

## 変更対象

- バックエンドの管理者向けアシスタント一覧取得 API（ルーター層のクエリパラメータ定義のみ）
- 同 API の結合テスト

## 画面 / API 変更概要

| API | 変更前 | 変更後 |
|---|---|---|
| `GET /api/admin/assistants` | 検索キーワードを `q`（既定値は空文字）で受け取る | 検索キーワードを `search`（省略可）で受け取る |

- 画面は変わらない。フロントエンドはすでに `search` を送っているため、バックエンドを直せば検索が機能する
- サービス層・リポジトリ層の検索処理（名前・説明の部分一致、大文字小文字を区別しない）はそのまま使う

## 影響範囲

- 管理者向けアシスタント一覧取得 API を `q` で呼んでいる箇所: リポジトリ内では既存の結合テスト 1 件だけ（フロントエンド・E2E から `q` を送る箇所はない）
- アシスタント一覧画面など、この API を検索付きで呼ぶ画面の検索が機能するようになる

## 移植方針

- 移植元 `AssistantController#getAllAssistants` の `@RequestParam(required = false) String search` に合わせ、FastAPI のクエリパラメータ名を `search`（任意、既定値 `None`）にする
- 移植元にない `q` は残さない（互換用の別名も設けない）
