## 確認環境

- macOS（Darwin 27.2.0）、Python 3.14.6、`uv run pytest`（インメモリ SQLite + fakeredis）
- 実行時刻: 2026-11-13 00:11 JST（= 2026-11-12 15:11 UTC、`Pacific/Kiritimati` では 2026-11-13 05:11 +14）

```text
$ TZ=Pacific/Kiritimati python3 -c "import datetime;print(datetime.date.today(), datetime.datetime.now(datetime.timezone.utc).date())"

```

## 確認手順

1. 修正前に `TZ=Pacific/Kiritimati` で対象 5 ファイルの結合テストを実行し、失敗を再現する
2. 修正後に `TZ=Pacific/Kiritimati` で対象 5 ファイル、全件を実行する
3. 修正後に `TZ=UTC` で全件を実行する
4. 修正後に TZ を指定せず（手元の既定 = JST、実行時刻は Issue の失敗時間帯の 0:11・0:15）変更した 5 ファイルを実行する
