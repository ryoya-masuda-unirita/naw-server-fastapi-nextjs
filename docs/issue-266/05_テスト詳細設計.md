# 05_テスト詳細設計

## 実行コマンド（`backend/` で実行）

| 04 No | コマンド |
|---|---|
| 1 | `TZ=Pacific/Kiritimati uv run pytest tests/integration/test_credit_usage.py tests/integration/test_files.py tests/integration/test_tenants.py tests/integration/test_users.py tests/integration/test_groups.py -q` |
| 2 | `TZ=Pacific/Kiritimati uv run pytest -q` |
| 3 | `TZ=UTC uv run pytest -q` |
| 4 | `uv run mypy app tests`、`uv run ruff check`、`uv run ruff format --check` |

`Pacific/Kiritimati` は UTC+14 で、どの時刻に実行してもローカル日付が UTC の日付の翌日になる（日本時間 0:00〜9:00 と同じ状態を常に作れる）。
