## 変更ファイル

すべて `backend/tests/integration/` 配下。`date.today()` を `datetime.now(timezone.utc).date()` に置き換える。

| ファイル | 箇所 | 変更前 | 変更後 |
|---|---|---|---|
| `test_credit_usage.py` | `_create_active_subscription` | `start_date=date.today()` | `start_date=datetime.now(timezone.utc).date()` |
| `test_credit_usage.py` | `test_get_workspace_credit_usage_expired_subscription_is_treated_as_inactive` | `start_date=date.today() - timedelta(days=60)`、`end_date=date.today() - timedelta(days=1)` | UTC の今日を 1 度だけ取り、そこから 60 日前・1 日前を作る |
| `test_files.py` | `_create_active_subscription` | `start_date=date.today()` | `start_date=datetime.now(timezone.utc).date()` |
| `test_tenants.py` | `_create_active_subscription` | `start_date=date.today()` | `start_date=datetime.now(timezone.utc).date()` |
| `test_users.py` | 有効なサブスクリプションを作る関数 | `start_date=date.today() - timedelta(days=2)` | `start_date=datetime.now(timezone.utc).date()`。docstring の「タイムゾーンのずれを避けるためのマージン」の説明を、UTC にそろえる理由に書き換える |
| `test_users.py` | 期限切れサブスクリプションのテスト | `start_date=date.today() - timedelta(days=60)`、`end_date=date.today() - timedelta(days=3)` | UTC の今日を 1 度だけ取り、そこから 60 日前・3 日前を作る |
| `test_groups.py` | 有効なサブスクリプションを作る関数 | `start_date=date.today() - timedelta(days=2)` | `test_users.py` と同じ |

### 期限切れのテストで今日を 1 度だけ取る理由

開始日・終了日の計算で別々に現在日付を取ると、UTC 0 時をまたいだ場合に基準日がずれる。1 度だけ取ってローカル変数に入れ、両方の計算に使う。

### import の整理

置き換えにより `date` を使わなくなるファイルは import から `date` を削除する（`test_tenants.py` は `date(2024, 1, 1)` を使い続けるため残す）。`test_groups.py` で `timedelta` を使わなくなる場合も削除する。最終的な要否は ruff（F401）で確認する。
