# 01_要件定義

## 背景

項目書（移植元 V1.1.0）の 17-16〜17-21 は、学習データ詳細の「設定フィルター（ON/OFF）」と「並べ替え（更新日時・表示名・更新者・学習設定）」を操作する。移植元はその後、学習設定（NAW-1405）と並べ替え（NAW-1427）を画面から外した。このリポジトリも #375・#392 で同じにしたため、テストは操作する UI が見つからず 2 分でタイムアウトして NG になる。

## 機能要件

- 移植元の最新（`origin/develop`）の詳細画面に、これらの UI が本当に無いかを確かめる
- 無ければ、6 項目を「未実施（skip・理由あり）」にして、集計に理由が出るようにする
- 期待値を緩めて通すことはしない
- 不要になった補助コードを削除する
- `docs/issue-316/09_集計結果.md` の件数を整合させる

## 非機能要件

- 通し実行はしない（専用環境を起動しない）。型チェック・lint と、テスト一覧・集計で確認する

## スコープ外

- 17-16〜17-21 以外の項目（同じ原因で古くなっている可能性のある項目は、報告に書くだけにする）
- 学習データ画面（client）の変更
