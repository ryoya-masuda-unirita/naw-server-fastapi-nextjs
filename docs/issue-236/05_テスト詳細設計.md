# 05_テスト詳細設計

## `tests/unit/test_sort.py`

クラス `TestEnumAsString` を追加する。アプリのモデルに依存しないよう、既存のテスト用テーブル `items` に ENUM 列 `kind` を足して使う。

| テスト | 内容 |
|---|---|
| `test_casts_column_to_varchar_on_postgresql` | `enum_as_string(_items.c.kind)` を PostgreSQL 方言でコンパイルすると `CAST(items.kind AS VARCHAR)` になること（No.1） |
| `test_order_by_uses_casted_column` | `build_order_by` の対応表に渡すと、並べ替え句が `CAST(items.kind AS VARCHAR) DESC, items.id DESC` になること（No.1） |

## `tests/integration/test_enum_sort_cast.py`（新規）

各リポジトリのメソッドをテスト用 SQLite セッションで実行し、`do_orm_execute` イベントで発行された文を捕捉する。捕捉した文のうち `ORDER BY` を含むものを PostgreSQL 方言でコンパイルし、`ORDER BY` 以降の文字列を検証する（件数取得の文は ORDER BY を含まないため除外される）。データは不要（0 件でも SQL は発行される）。

| テスト | 呼び出し | 期待（`ORDER BY` 以降の先頭） |
|---|---|---|
| `TestAssistantFindPage.test_type_sort_casts_to_varchar`（`type`・`assistantType`・`serverType`・`server` でパラメータ化） | `AssistantRepository.find_page(sort=[SortOrder(key)])` | `CAST(assistants.type AS VARCHAR) ASC`（No.2） |
| `TestAssistantFindPage.test_type_sort_descending_casts_to_varchar` | `sort=[SortOrder("type", descending=True)]` | `CAST(assistants.type AS VARCHAR) DESC`（No.3） |
| `TestIndexFindPage.test_type_sort_casts_to_varchar` | `IndexRepository.find_page(sort=[SortOrder("type")])` | `CAST(indexes.type AS VARCHAR) ASC`（No.4） |
| `TestGroupAssistantFindPageByGroup.test_type_sort_casts_to_varchar`（`type`・`server`・`assistantType`） | `GroupAssistantRepository.find_page_by_group(...)` | `CAST(assistants.type AS VARCHAR) ASC`（No.5） |
| `TestFeedbackRooms.test_rating_sort_casts_to_varchar` | `RoomRepository.find_feedback_rooms(sort_column="rating")` | `CAST(rooms.rating AS VARCHAR) ASC`（No.6） |
| `TestFeedbackMessages.test_rating_sort_casts_to_varchar` | `MessageFeedbackRepository.find_feedback_messages(sort_column="rating")` | `CAST(message_feedbacks.rating AS VARCHAR) ASC`（No.7） |

テーブル名は各モデルの `__tablename__` に合わせる（実装時に確認）。

フィードバックの 2 一覧は、サービス層の対応表（`level` → `rating`、`accuracy` → `rating`）を経由した `sort_column="rating"` を直接渡す。対応表自体は既存の結合テスト（`test_feedback.py`）で確認済み。
