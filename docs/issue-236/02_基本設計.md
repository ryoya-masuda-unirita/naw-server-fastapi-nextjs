# 02_基本設計

## 変更対象

- 一覧 API の並べ替えの共通処理に、ネイティブ ENUM 列を文字列にして並べるための部品を追加する
- 次の一覧の並べ替えで、ENUM 列をこの部品で文字列にした列に置き換える
  - アシスタント一覧（管理者向け）
  - インデックス一覧
  - グループのアシスタント一覧
  - フィードバックのルーム一覧
  - フィードバックのメッセージ一覧
  - ユーザー一覧（既存の個別の書き方を共通の部品に置き換える。挙動は変えない）

## 画面 / API 変更概要

- API のパラメータ・レスポンスの形式は変えない
- PostgreSQL 上で、種別・評価で並べ替えたときの順序が移植元と同じ文字列順になる

## 影響範囲

- 上記の一覧 API の並べ替え結果の順序のみ
- 絞り込み・件数・ページング・同値時の並び（ID による最終キー）は変えない

## 移植方針

- 移植元は列挙値を varchar に保存し、Spring Data の並べ替えで列をそのまま `ORDER BY` している。移植先では列を文字列に変換してから並べることで、同じ文字列順（データベースの照合順序に従う）を再現する
- 型の変更（ネイティブ ENUM から varchar への変換）は、マイグレーションが必要で影響が大きいため行わない
- 対象のクエリはどれも DISTINCT・GROUP BY を伴わないため、ORDER BY に変換式を置いても PostgreSQL の制約（DISTINCT と ORDER BY 式の整合）には当たらない
