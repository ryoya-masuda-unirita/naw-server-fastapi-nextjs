# 03_詳細設計

## 移植元の根拠（`secuaigent-ref/server`）

| 対象 | Entity の定義 | DDL（liquibase） |
|---|---|---|
| アシスタント種別 | `AssistantEntity.assistantType`: `@Column(name = "type", length = 32)` + `@Enumerated(EnumType.STRING)` | `assistants/changeset-001-init-table.xml`: `type varchar(32)` |
| インデックス種別 | `Index.type`: `@Enumerated(EnumType.STRING)` | `indexes/changeset-001-init-table.xml`: `type varchar(32)` |
| ルームの評価 | `RoomEntity.rating`: `@Enumerated(EnumType.STRING)` | `rooms/changeset-001-init-table.xml`: `rating varchar(32)` |
| メッセージの評価 | `MessageFeedback.rating`: `@Enumerated(EnumType.STRING)` | `message_feedbacks/changeset-001-init-table.xml`: `rating varchar(16)` |

- フィードバック一覧は `FeedbackRoomListRequest.toEntitySortField()`（`level` → `rating`）・`FeedbackMessageListRequest`（`accuracy` → `rating`）で並べ替えキーをエンティティ項目に読み替え、`FeedbackService` で `Pageable` を付けて `findAll(spec, pageable)` する。varchar 列をそのまま `ORDER BY` するため文字列順
- アシスタント・インデックス・グループのアシスタント一覧も Spring Data の `sort` で列をそのまま並べる（#225 で調査済み）

## 変更内容

### `app/core/sort.py`

ネイティブ ENUM 列を文字列にキャストした列式を返す関数を追加する。

```python
def enum_as_string(column: Any) -> Any:
    """ネイティブ ENUM 列を、移植元と同じ文字列順で並べるための列式にする。"""
    return cast(column, String)
```

- docstring に理由（移植元は varchar、こちらはネイティブ ENUM で宣言順に並ぶ）を書く

### 各リポジトリ・サービス

- `assistant_repository.py`・`group_assistant_repository.py`: モジュール定数 `_TYPE_SORT_COLUMN = enum_as_string(Assistant.type)` を作り、対応表の種別キーをこれに置き換える
- `index_repository.py`: 対応表の `type` を `enum_as_string(Index.type)` にする
- `room_repository.py`: `find_feedback_rooms` の `rating` を `enum_as_string(Room.rating)` にする
- `message_feedback_repository.py`: `find_feedback_messages` の `rating` を `enum_as_string(MessageFeedback.rating)` にする
- `user_service.py`: `_SORTABLE_COLUMNS["role"]` を `enum_as_string(User.role)` にし、使われなくなる `String`・`sa_cast` の import を削除する（生成される SQL は同じ `CAST(users.role AS VARCHAR)`）

コメントの「移植元は varchar のため文字列順」という説明は共通関数の docstring に寄せ、各対応表には短く残す。
