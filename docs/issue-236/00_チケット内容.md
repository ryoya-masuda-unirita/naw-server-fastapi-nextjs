# #236 issue-236 アシスタント・インデックス一覧のtype順の並べ替えを移植元と同じ文字列順にする

## 概要

アシスタント一覧・インデックス一覧・グループのアシスタント一覧で `type` による並べ替えを指定すると、移植元と順序が逆になる。

## 説明

### 原因

`assistants.type` などは PostgreSQL のネイティブ ENUM（`sa.Enum(..., name="assistanttype")`）で、`ORDER BY` が ENUM の宣言順になる。移植元は varchar の文字列順で並ぶ。

テスト DB（SQLite）は ENUM を文字列で持つため、結合テストでは差が出ない。

### 対応

- ユーザーの `role` と同じく、並べ替えの列を `CAST(... AS VARCHAR)` で文字列にしてから並べる
- 対象: `backend/app/repositories/assistant_repository.py`・`index_repository.py`・`group_assistant_repository.py`（ほかに ENUM 列で並べ替えている箇所があれば横展開）
