# 03_詳細設計

## 変更ファイル

### `backend/app/services/assistant_category_service.py`

- 見つからない場合の文言の雛形を定数にする
  - `_NOT_FOUND_MESSAGE = "AssistantCategory not found with id:{category_id}"`（移植元 `AssistantCategoryService#getAssistantCategoryByIdAndTenantId`・`#deleteAssistantCategory`）
  - `_NOT_FOUND_MESSAGE_ON_UPDATE = "AssistantCategory not found with id: {category_id}"`（移植元 `#updateAssistantCategory`）
- `_get_category_or_404` にキーワード引数 `not_found_message: str = _NOT_FOUND_MESSAGE` を足し、`detail` を `not_found_message.format(category_id=category_id)` にする
- `update_assistant_category` は `not_found_message=_NOT_FOUND_MESSAGE_ON_UPDATE` を渡す

移植元の根拠:

- `server/src/main/java/com/example/naw/api/AssistantCategoryController.java`: `@GetMapping("/{id}")` の `@PathVariable String id`。`/options` 専用のマッピングは無い
- `server/src/main/java/com/example/naw/service/AssistantCategoryService.java`: `EntityNotFoundException("AssistantCategory not found with id:" + id)`（更新だけ `"... with id: "`）
- `server/src/main/java/com/example/naw/infrastructure/APIControllerAdvice.java`: `EntityNotFoundException` を 404 と `{"timestamp", "message"}` に変換
