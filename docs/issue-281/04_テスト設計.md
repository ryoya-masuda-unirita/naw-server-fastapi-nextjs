# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 単体取得の 404 文言 | 存在しない id を取得する | 404、移植元と同じ文言（id 入り、コロンの後に空白なし） |
| 2 | 更新の 404 文言 | 存在しない id を更新する | 404、移植元と同じ文言（コロンの後に空白あり） |
| 3 | 削除の 404 文言 | 存在しない id を削除する | 404、移植元と同じ文言（コロンの後に空白なし） |
| 4 | `/options` | テナント管理者が `options` を取得する | 単体取得として扱われ 404、本文は `AssistantCategory not found with id:options` |
| 5 | `/options` の認可 | 一般ユーザーが `options` を取得する | 単体取得と同じく 403 |
| 6 | 既存の挙動 | 既存のカテゴリのテスト | すべて通る |
