# 01_要件定義

## 背景

管理コンソール「フィードバック」の「回答精度評価」「チャット満足度」で、並べ替えに「アシスタント表示名順」「学習先フォルダ名順」「満足度順」を選べる。しかし現状は、画面に表示される値ではなく内部の値で並ぶ。

- アシスタント表示名順: アシスタントの内部 ID の順に並ぶ
- 学習先フォルダ名順: 学習先フォルダの内部 ID の順に並ぶ
- 満足度順: 評価名の文字列の順（AVERAGE → EXCELLENT → GOOD → POOR → VERY_GOOD、つまり星 2 → 5 → 3 → 1 → 4）に並ぶ

そのため、複数ページにまたがる一覧で、利用者が見る順序と並びが一致しない。移植元は 2026-11-24 に同じ不具合を直しており、こちらにも同じ不具合がある。

## 機能要件

| No | 要件 |
|---|---|
| R-01 | 回答精度評価をアシスタント表示名順に並べたとき、アシスタントの表示名の昇順・降順で並ぶ（NAW-1448） |
| R-02 | 回答精度評価を学習先フォルダ名順に並べたとき、学習先フォルダ名の昇順・降順で並ぶ（NAW-1451） |
| R-03 | チャット満足度をアシスタント表示名順に並べたとき、表示名の昇順・降順で並ぶ。大文字・小文字を区別しない（NAW-1449） |
| R-04 | チャット満足度を満足度順に並べたとき、星の数の昇順（星 1 → 5）・降順（星 5 → 1）で並ぶ（NAW-1449） |
| R-05 | アシスタントが削除された行・学習先フォルダが無い（または削除された）行も、一覧から落とさない。件数・ページ分割は変わらない |
| R-06 | 同じ並び値の行は、これまでどおり ID の昇順で並び、ページをまたいで重複・欠落しない |
| R-07 | アシスタントや評価での絞り込みと、並べ替えを併用できる |

## 非機能要件

- API の入出力（パラメータ名・許容値・レスポンスの形）は変えない
- 並べ替えのための追加のクエリを増やさない（並べ替えは 1 回の一覧取得の中で行う）
- 既存のテストが通る

## スコープ外

- 追加学習順（`add`）・学習先フォルダ名順（`folder`）の選択肢を画面から消すこと（`client/` の #476）
- 回答精度評価の追加学習順（`add`）の並び（移植元でも変更なし）
- 学習先フォルダを持たない古いデータで、画面に出るフォルダ名と並びが一致しないこと（移植元も既知の制限としている）
- チャット満足度の追加学習順・学習先フォルダ名順（そもそも API が受け付けない。画面側の Issue で扱う）
