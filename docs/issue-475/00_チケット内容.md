# NAW-1448・NAW-1451・NAW-1449 フィードバック一覧の並べ替えを表示値の順にする

## 概要

フィードバック一覧の並べ替えが、画面に表示される値ではなく内部の値（ID・評価名の文字列）の順になっている。移植元で直された 3 件のバグ修正（NAW-1448・NAW-1451・NAW-1449）を、`server/` に移植する。

## 説明

- NAW-1448: 回答精度評価の「アシスタント表示名順」を、アシスタントの内部 ID 順ではなく表示名順にする
