# 05_テスト詳細設計

## 対象ファイル

- `server/tests/integration/test_feedback_sort.py`（新規）: T-01〜T-11
- `server/tests/integration/test_feedback.py`: T-12
- `server/tests/integration/test_enum_sort_cast.py`: ルームの `rating` の文字列順のテストを、星の数順の確認に置き換える

## データ

- テナントと管理者ユーザーを 1 つずつ作る。他テナントの確認用に別テナントも作る
- アシスタント: ID を `a-1`・`a-2`・`a-3` とし、名前を Cherry・Banana・Apple にする（ID の順と名前の順が逆）。大文字・小文字の確認用に `apple`（小文字）と `Banana`（大文字）を加える
- 学習先フォルダ（`Index`）: ID を `f-1`・`f-2`・`f-3`、名前を Cherry・Banana・Apple にする
- メッセージは 1 件ずつ別のルームに作り、`MessageFeedback` に評価とフォルダを付ける。削除済みのアシスタント・フォルダ無しの行も 1 件ずつ作る
- ルームは評価（星 1〜5）ごとに 1 件作る

## 検証

- API（`GET /api/admin/feedbackMessage`・`/api/admin/feedbackRoom`）を呼び、レスポンスの並びを確かめる
- 複数ページは `size=2` で全ページを取り、結合した順序と重複の有無を確かめる
