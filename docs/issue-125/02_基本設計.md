## 状態の持ち方

- 条件（`filter`）・選択（`selectedIds`）は Zustand。移植元の store は root singleton なので、画面を離れても条件を残す。
- 一覧のデータは `useAdminUsers(filter)`（queryKey に `filter`）。表示のスピナー判定は移植元の `isLoading`（読み込みのたびに true）に合わせて `isFetching`。
- ダイアログの開閉と、表示ダイアログに渡す平文（`reveal`）は画面の `useState`。閉じたら `null` に戻す。
