# ユーザー管理 一覧画面をReactに移植する

- Issue: #125（ラベル: `frontend-port`）
- 移植元: `secuaigent/client` の `features/admin/management/user-list/`（参照 worktree `secuaigent-ref`、`origin/develop` 0f29c3da）

## Issue 本文（要約）

ユーザー管理 一覧画面（`/admin/users`）を Angular から React に移植する。一覧・追加・編集・パスワード表示ダイアログは一覧の store を共有して一体で動くため 1 単位。対象は `user-list.component`・`user-list-menu`・`user-add-dialog`・`user-edit-dialog`・`user-password-reveal-dialog`・`user-list.store`・`user-list-api.service`／`mapper`・`utils`。依存する API は `GET/POST /api/admin/users`、`PATCH/DELETE /api/admin/users/{id}`。

## 方針

- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）。
- 土台は #277（ルート・ガード・サイドバー・i18n）・#278（共通 UI）・#279（API の型・パス・api-client・MSW）。`routes/admin/users/user-list.tsx` の仮ファイルを書き換える。
- backend の応答が移植元と違う点は #309 の範囲（backend は直さない）。画面側で吸収できるものは吸収する。
