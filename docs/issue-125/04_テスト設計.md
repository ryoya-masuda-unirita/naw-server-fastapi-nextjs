# 04 テスト設計

自動テストのみ（Vitest + React Testing Library + MSW）。移植元の acceptance spec（ログインキー）と component spec の観点を移した。

| 区分 | 観点 |
|---|---|
| 初期表示 | 行・クレジットの桁区切り・権限表記、ログインキー列はアイコンのみ（値を出さない）、既定の問い合わせ（`sort=name,asc`・`includeUsage=true`・空の `searchText`/`role`）、0 件の表示 |
| 検索 | 入力で `searchText` を付けて取り直す |
| 選択・削除 | 行を選ぶと操作ボタンが替わる、複数選択して一括削除、行メニューから 1 件削除、失敗時のトーストとダイアログを閉じないこと |
| 追加 | 空のまま作成で必須エラー・API を呼ばない、101 文字で最大文字数エラー、作成で trim・初期パスワード表示・閉じると消える、キー発行で `issueLoginKey` とキー表示、失敗時 |
| 編集 | キー未設定は「削除」不可、再発行を選んでも保存まで API を呼ばない・保存で `loginKeyAction`・キー表示、変更しないなら送らず表示ダイアログなし、パスワードリセットで初期パスワード表示、拒否時 |
| 正規化 | 移植元 server の形・現在の backend の形・旧形式・不正な形 |
