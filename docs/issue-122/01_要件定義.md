# 01_要件定義

## 背景

チーム管理は管理コンソールの一画面。テナント管理者・グループ管理者がチーム（グループ）を一覧し、詳細へ移る。テナント管理者はチームを新規作成できる。

## 機能要件

- カード一覧（チーム名・管理者・所属ユーザー・所属アシスタント・所属テンプレート・更新日時）。名前がない項目は「—」、複数は「、」区切り
- 検索（`q`）、並べ替え（更新日時順・チーム名順、昇順・降順）、ページ送り（上: 前後のみ＋件数表示、下: 前後とページ番号。1ページ5件）
- 「閲覧・編集」でグループ詳細のユーザータブ（`/admin/groups/{id}/users`）へ移動
- 「チームを新規作成」ダイアログ（チーム名: 必須・100文字以内）。成功・失敗はトースト（`GROUPS.CREATE_SUCCESS` / `CREATE_FAILED`）。グループ管理者だけの人にはボタンを出さない
- 一覧のカードの名前は、ID から引く対応表（ユーザー・アシスタント・テンプレートの全件）で解決し、名前が足りないチームはグループ内の一覧で補う

## 非機能要件

- 文言は既存の i18n 辞書のキーのみ（キーは足さない）
- 共通 UI（#278）・API パス/型（#279）を使い、共通ファイルの変更は最小限

## スコープ外

- グループ詳細、チームの編集・削除（詳細画面側）
- backend の修正（応答の形の差は画面側で吸収、または docs に記載）
