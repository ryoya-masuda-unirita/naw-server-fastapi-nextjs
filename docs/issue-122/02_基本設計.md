## API

| 操作 | API |
|---|---|
| 一覧 | `GET /api/admin/groups`（`page`（0始まり）・`size`・`q`・`sort`）→ `{ data, total, page, size }` |
| 名前の対応表 | `GET /api/admin/users`・`/api/admin/assistants`・`/api/admin/prompt-templates`（`size=1000`） |
| 名前の補完 | `GET /api/admin/groups/{id}/users`・`/assistants`・`/prompt-templates`（`size=100`） |
| 作成 | `POST /api/admin/groups`（`{ name }`） |

## 移植方針

- NgRx signalStore → UI 状態は Zustand、API 呼び出しは TanStack Query（#124 と同じ）
- MatDialog＋`ng-template` → `Dialog`（共通）。開いている間だけ `GroupAddDialog` を描画し、開くたびに入力を初期化（移植元の `addForm.reset`）
- Angular の `FormGroup` → `useState`。検証は `Validators.required`・`maxLength` と同じ判定、文言は `resolveControlError`
- 詳細な判断は `03_詳細設計.md`
