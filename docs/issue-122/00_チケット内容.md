# チーム管理 一覧画面をReactに移植する

## 概要

グループ（チーム）管理 一覧画面（`/admin/groups`）を Angular（`secuaigent/client` の `features/admin/management/group-list/`）から React（`frontend/`）に移植する。Issue #122。

## 説明

- 対象: `group-list.component`（メイン）・`group-list-filter`・`group-list-cards`・`group-form`（新規作成ダイアログのフォーム）・`group-list.store`・`group-api.service`・名前解決に使う users / assistants / templates の API サービス
- スコープ外: `group-detail/`（詳細の各タブ）・`group-members`（legacy ルート）
- 土台は #277・#278・#279、最初の管理画面は #124（テンプレート管理）。作りはそれに揃える
- 目標は移植元の完璧なクローン（見た目・文言・操作・入力チェック）

## その他

- 移植先は Issue 本文の `routes/app/admin/groups.tsx` ではなく、#277 の仮ファイル `frontend/src/routes/admin/groups/group-list.tsx`（export 名 `GroupListPage` は維持）
