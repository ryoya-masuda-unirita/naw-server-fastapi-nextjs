# 04_テスト設計

## テスト方針

- Vitest + React Testing Library + MSW。ガード・レイアウト込みで `renderApp('/admin/groups')` を描画する
- i18n は未初期化のため `t()` はキーを返す。キーで検証する
- MSW の既定（`mocks/handlers/admin-groups.ts`）は空の応答。テストごとに `server.use` で上書きする

## テスト観点

- 一覧: カードの表示（名前・管理者・所属・更新日時・件数表示）、0 件、初期の取得パラメータ（`page=0`・`size=5`・`sort=updatedAt,desc`）、名前の補完、名前なしは「—」
- 検索: 入力で `q` を付けて再取得
- ページ送り: 下のページ送りで次のページを取得
- 作成: trim して送信／空でエラー・送信しない／100 文字超でエラー・送信しない／失敗時はトーストを出してダイアログを残す
- 権限: グループ管理者だけの人には作成ボタンを出さない
- 遷移: 「閲覧・編集」で `/admin/groups/{id}/users` へ
