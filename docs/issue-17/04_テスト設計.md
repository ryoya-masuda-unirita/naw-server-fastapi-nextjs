# 04_テスト設計

## テスト方針

- Vitest + React Testing Library を使用する
- ユーザー視点の振る舞い（表示・クリック操作・状態変化）を検証し、実装の内部構造には依存しない
- アイコンのみのボタンには `aria-label` を付与し、`getByRole('button', { name: '...' })` で取得できるようにする
- i18n はテスト環境で翻訳キーがそのまま表示される既存の設定（`login.test.tsx` 等）に合わせ、`t('KEY')` の表示検証はキー文字列一致で行う
