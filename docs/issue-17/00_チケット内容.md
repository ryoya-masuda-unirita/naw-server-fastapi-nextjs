# ログイン後の共通レイアウト（user-layout/admin-layout）とダッシュボード遷移の実装

## 概要

Angular 実装（`~/Documents/secuaigent-client`）を参照しながら、ログイン後の共通レイアウト（user-layout / admin-layout）とダッシュボード遷移を実装する。

## 説明

現在 `frontend/src/store/auth-store.ts` はログイン成功時に `window.location.href = ROUTES.APP.DASHBOARD`（`/dashboard`）へ遷移させるが、`frontend/src/routes/index.tsx` に `/dashboard` のルート自体が存在せず、ログイン後の遷移先が実質ない状態。

Angular 側には `user-layout` / `admin-layout` という共通シェル（`SidebarComponent` を `LayoutConfig` で出し分け）が存在するが、React 側の `routes/app/` は空のため、まずは共通レイアウトのみを実装する。

### 実装範囲

1. `components/layouts/` に `AppLayout`（Sidebar + `<Outlet />`）を追加。ロールに応じて Angular の `USER_LAYOUT_CONFIG` / `ADMIN_LAYOUT_CONFIG` 相当の設定を出し分け（`auth-store` の `isAdmin` を利用）
2. サイドバーのユーザーメニュー：ログアウト（既存の `useAuthStore().logout()` に接続）、パスワード設定導線を実装
3. 未実装機能（新規チャット・ライブラリ・管理者コンソール本体・クレジット確認等）に紐づくメニュー項目は、Angular 側が `glossary`/`data-source` を未実装としてコメントアウトしているのと同様に非表示 or プレースホルダーとする
4. `/dashboard` にプレースホルダー画面を追加し、`ProtectedRoute` + `AppLayout` 配下に配置し、ログイン導線を完結させる
5. `routes.tsx` を拡張してレイアウトを適用
6. サイドバー・ユーザーメニュー文言を `ja.json` / `en.json` から移植
7. レイアウトの表示・ロール出し分け・ログアウト導線のテストを追加

### 対象外（次issueへ）

- プロフィール画面
- チャット・ライブラリ・管理者コンソール本体などの個別機能画面
