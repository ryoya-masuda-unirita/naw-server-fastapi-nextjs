# 08_動作確認

**ブラウザ・実機（AWS 上の CloudFront）での確認は行わず、自動テストとコマンドでの検証のみで代替した。** dev 環境は AWS 上に存在しない（Deploy が失敗し続けている）ため、`terraform plan` / `apply` も実行していない（AWS に接続しない）。

## 確認環境

- macOS（darwin arm64）
- Terraform v1.15.8（CI の `deploy-infra.yml` と同じバージョン）、hashicorp/aws v5.100.0（lock ファイルのまま）
- Node.js v24.15.0（CI の `deploy-frontend.yml`・`deploy-infra.yml` と同じメジャーバージョン）

## 確認手順

1. CloudFront Function の単体テスト: `cd infra && node --test cloudfront_functions/functions.test.mjs`
2. Terraform のフォーマット: `cd infra && terraform fmt -check -recursive -diff`
3. Terraform の構文検証: `cd infra && terraform init -backend=false -input=false && terraform validate`
4. frontend の全テスト: `cd frontend && npx vitest run`
5. frontend の lint・型チェック・ビルド: `npm run lint` / `npm run type-check` / `npm run build`
6. 本番ビルドの成果物に、認証 API のベース URL（`/backend`）が入っていることを確認
