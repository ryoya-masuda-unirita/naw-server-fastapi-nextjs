## infra

### CloudFront Function

- ランタイム: `cloudfront-js-2.0`、`publish = true`（`LIVE` ステージを関連付ける）
- コードは `file("${path.module}/cloudfront_functions/xxx.js")` で読み込む。テストから同じファイルを読むため、HCL にインラインで書かない
- 名前: `${var.project_name}-spa-fallback`・`${var.project_name}-strip-backend-prefix`（CloudFront Function 名の制約: 英数字・`-`・`_`、64 文字以内）
- 関数ファイルは CloudFront Functions の形式（トップレベルの `function handler(event)`、`export` なし）。テストは `node:vm` でファイルを評価して `handler` を取り出す

#### spa_fallback.js

```js
function handler(event) {
  var request = event.request;
  var lastSegment = request.uri.substring(request.uri.lastIndexOf('/') + 1);
  if (lastSegment.indexOf('.') === -1) {
    request.uri = '/index.html';
  }
  return request;
}
```

#### strip_backend_prefix.js

```js
var BACKEND_PREFIX = '/backend';
function handler(event) {
  var request = event.request;
  if (request.uri.indexOf(BACKEND_PREFIX + '/') === 0) {
    request.uri = request.uri.substring(BACKEND_PREFIX.length);
  }
  return request;
}
```

ビヘイビアのパスパターンは `/backend/auth/*` に限定する（backend の `/auth/*` 以外をこの経路で公開しない）。プレフィックスを外す処理は `/backend/` で始まる場合だけ行う。

### ビヘイビア

| 順序 | パスパターン | オリジン | 関数 |
|---|---|---|---|
| 1 | `/api/*` | `alb-backend` | なし（変更なし） |
| 2 | `/backend/auth/*` | `alb-backend` | viewer-request: strip_backend_prefix |
| 既定 | `*` | `s3-frontend` | viewer-request: spa_fallback |

`/backend/auth/*` のキャッシュ・転送設定は、削除する `/auth/*` ビヘイビアと同じ（全メソッド許可・クエリ・全ヘッダー・全 Cookie を転送・TTL 0）。

### custom_error_response

403/404/405 の 3 つとも削除する。

## frontend

### api-client.ts

```ts
const API_BASE_URL = import.meta.env.VITE_API_URL ?? '';
const AUTH_API_BASE_URL = import.meta.env.VITE_AUTH_API_URL ?? API_BASE_URL;
const AUTH_API_PATH_PREFIX = '/auth/';

function buildUrl(path, params) {
  const baseUrl = path.startsWith(AUTH_API_PATH_PREFIX) ? AUTH_API_BASE_URL : API_BASE_URL;
  const url = new URL(`${baseUrl}${path}`, window.location.origin);
  ...
}
```

- `/api/auth`（セッション取得）は `/auth/` で始まらないため、`API_BASE_URL` のまま
- テスト環境・ローカル開発では `VITE_AUTH_API_URL` を設定しないため、従来どおり `API_BASE_URL` を使う

### .env.production

`VITE_AUTH_API_URL=/backend` を追加し、CloudFront の `/backend/auth/*` ビヘイビアと対応していることをコメントで書く。
