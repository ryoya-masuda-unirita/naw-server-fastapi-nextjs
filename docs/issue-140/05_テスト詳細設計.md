# 05_テスト詳細設計

## 実行コマンド

```bash
cd backend

# mypy: 設定変更後の対象範囲・エラー件数を確認
uv run mypy app tests

# pytest: 既存テストへの非回帰を確認
uv run pytest tests/unit -q
```

## 対象ファイル

- `backend/pyproject.toml`（変更対象。新規のテストコードは追加しない — 設定ファイルの変更のためユニットテストの対象にならない）
- `backend/tests/unit/test_azure_cost_client.py`（`# type: ignore` 削除後もテスト自体のロジックは変更していないため、既存のテストケースがそのまま通ることを確認する）

## 期待結果

- `uv run mypy app tests`: `Found 2 errors in 2 files (checked 195 source files)`（`app/services/index_service.py:594` と `app/services/message_service.py:1028` のみ）
- `uv run pytest tests/unit -q`: `249 passed`（既存の警告件数に変化がないこと）
