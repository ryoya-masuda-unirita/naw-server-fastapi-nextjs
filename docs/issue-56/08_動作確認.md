# 08_動作確認

## 確認環境

- ローカル PostgreSQL（`docker compose up -d`、`naw-fastapi-postgres` コンテナ、`alembic upgrade head` 実施済み）
- `backend/seed.sql` を投入済み（`test-tenant` テナント、`admin` / `user01` ユーザー、既存フィードバック確認用ルーム3件を含む）
- バックエンドは `uvicorn app.main:app --port 8010` でローカル起動し、`curl` で API を直接叩いて確認した（ポート8001は別プロセスが使用中だったため8010を使用）
- フロントエンド（`frontend-angular`）でのブラウザ操作による確認は**未実施**

## 確認手順・結果

1. `POST /auth/login`（`X-Tenant-ID: test-tenant`, `admin` / `admin@1234`）でトークン取得 → 成功
2. `POST /api/rooms` で確認用ルーム「動作確認ルーム」を作成（`defaultAssistantId` は既存の「汎用アシスタント」）
3. `POST /api/rooms/{roomId}/feedback` に `{"rating": "EXCELLENT"}` を送信
   → **204** を確認
4. 同エンドポイントに不正な `rating`（`"NOPE"`）を送信
   → **422** を確認
5. `GET /api/admin/feedbackRoom`（管理者トークン）を実行
   → **200**。手順3で登録したルームを含む、`rating` 登録済みルーム4件が返り、各アイテムの `userName`（`管理者`）・`room.defaultAssistantName`（`汎用アシスタント`）が正しく解決されていることを確認
6. `GET /api/admin/feedbackRoom?rating=VERY_GOOD` で絞り込み
   → 該当する1件（`フィードバックメッセージ確認用ルーム`）のみが返ることを確認
7. `GET /api/admin/feedbackRoom?sortField=chat&sortOrder=asc` でソート
   → ルーム名の昇順で返ることを確認
