# ルームフィードバックAPIの実装

## 概要

ルーム満足度フィードバック関連APIを FastAPI 側へ移植する。

- `POST /api/rooms/{roomId}/feedback` — ルームへの満足度評価登録
- `GET /api/admin/feedbackRoom` — 管理者向けルームフィードバック一覧取得

移植元（naw-server, Spring Boot）の `RoomController.feedbackRoom` / `RoomService.feedbackRoom`、および `FeedbackController.getFeedbackRooms` / `FeedbackService.getFeedbackRooms` に対応する。

## 説明

### POST /api/rooms/{roomId}/feedback

- リクエストボディ: `rating`（`RoomRating` = `EXCELLENT` / `VERY_GOOD` / `GOOD` / `AVERAGE` / `POOR`）
- ルーム所有者のみ登録可能（既存の `RoomService._get_owned_room_or_404` と同じ権限判定。移植元 `RoomAccessService.canWriteRoom` もオーナーチェックのみで同等）
- 対象ルームの `rating` カラムを更新する（`Room` モデルに既存の `rating: RoomRating | None` を利用、テーブル追加不要）

### GET /api/admin/feedbackRoom

- クエリパラメータ: `page`, `size`, `assistantId`, `rating`, `sortField`（`updatedAt` / `chat` / `name` / `level`）, `sortOrder`
- 想定レスポンス: フィードバック本体情報、ルーム名・デフォルトアシスタントID/名、評価値、ユーザー表示名
- `rating IS NOT NULL` のルームのみ対象（未評価ルームは除外）

### スコープ

- 新規テーブルは不要（既存の `rooms` テーブルの `rating` カラムを使用）
- 移植元の `folderId` 絞り込みおよびレスポンスの `indexId`（ルームに紐づく追加学習フォルダ）は、`files` ドメインが FastAPI 側に未移植のため本Issueでは対象外とする
- `POST /api/rooms/{roomId}/feedback` の権限判定は既存の `RoomService._get_owned_room_or_404`（所有者のみ）を再利用する
