# 05_テスト詳細設計

## テスト対象ファイル

- `backend/tests/integration/test_rooms.py` — `TestFeedbackRoom` クラスを追加（`_headers` ヘルパー・既存 fixture 群を再利用）
- `backend/tests/integration/test_feedback.py` — `TestFeedbackRouter` 内に `TestGetFeedbackRooms` クラスを追加（`admin_headers`・`group_admin_headers`・既存 fixture 群を再利用）

## `test_rooms.py::TestFeedbackRoom`

既存の `room_owner_user` / `another_user_same_tenant` / `room_assistant` fixture、`_headers()` ヘルパーをそのまま使う。

| テストメソッド名 | 対応する 04 No |
|---|---|
| `test_feedback_room_updates_rating` | 1 |
| `test_feedback_room_returns_401_without_token` | 2 |
| `test_feedback_room_returns_404_for_unknown_room` | 3 |
| `test_feedback_room_returns_404_for_other_users_room` | 4 |
| `test_feedback_room_returns_422_for_invalid_rating` | 5 |

`test_feedback_room_updates_rating` は `POST /api/rooms/{roomId}/feedback` で `{"rating": "EXCELLENT"}` を送信後、`session` から `Room` を再取得して `rating == RoomRating.EXCELLENT` を検証する。

## `test_feedback.py::TestFeedbackRouter::TestGetFeedbackRooms`

既存の `tenant_admin_user` / `group_admin_user` / 一般ユーザー fixture、`admin_headers` / `group_admin_headers` fixture、`Room` 用に新規追加する fixture（評価済みルーム複数・未評価ルーム1件・別アシスタントのルーム1件）を使う。

| テストメソッド名 | 対応する 04 No |
|---|---|
| `test_get_feedback_rooms_excludes_unrated_rooms` | 6 |
| `test_get_feedback_rooms_filters_by_assistant_id` | 7 |
| `test_get_feedback_rooms_filters_by_rating` | 8 |
| `test_get_feedback_rooms_sorts_by_updated_at` | 9 |
| `test_get_feedback_rooms_sorts_by_chat` | 9 |
| `test_get_feedback_rooms_sorts_by_name` | 9 |
| `test_get_feedback_rooms_sorts_by_level` | 9 |
| `test_get_feedback_rooms_paginates` | 10 |
| `test_get_feedback_rooms_returns_403_for_general_user` | 11 |
| `test_get_feedback_rooms_returns_401_without_token` | 12 |

`test_get_feedback_rooms_sorts_by_*` は、`rating` の異なるルームを複数作成し、`sortField`／`sortOrder=asc` を指定して呼び出し、レスポンスの `feedbacks.content` の並び順を検証する。

## 実行コマンド

```bash
cd backend
uv run pytest tests/integration/test_rooms.py tests/integration/test_feedback.py -v
```
