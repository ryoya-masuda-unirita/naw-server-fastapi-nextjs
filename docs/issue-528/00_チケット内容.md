# ルートの docker-compose に client を入れて demo の compose を廃止する

## 概要

ルートの `docker-compose.yml` に、client（React の画面）・migrate・seed を入れて、`docker-compose.demo.yml` を廃止する。環境変数は `.env`（`.env.example`）に集める。

## 説明

- ルートの compose には client がない。#213 で Angular の `frontend-angular` を外したあと、React の client は戻されず、画面を見るための `docker-compose.demo.yml`（#336）にだけ入っている
- demo の compose は、ルートの compose と大部分が重なる（postgres・redis・localstack・backend）。違いは、migrate・seed が自動で走ること、client が入っていること、環境変数が compose に直書きであること
- 要件は Issue #528 のとおり。詳細は `01_要件定義.md`

## その他

- スコープ外: `onprem/`・`e2e-explorer/` の compose、backend のイメージを本番用に変えること
