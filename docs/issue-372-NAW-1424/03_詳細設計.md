# 03_詳細設計

## 変更ファイル

- `backend/app/routers/users.py` の `get_users`: `loginIds: list[str] | None = Query(None)` を追加し、`UserService.get_users` へ `login_ids=` で渡す。docstring に引数を追記。
- `backend/app/services/user_service.py` の `UserService.get_users`: キーワード専用引数 `login_ids: list[str] | None = None` を追加。`login_ids` が空でないとき `User.login_id IN (...)` を、ロール条件の後・除外グループ条件の前で検索条件へ足す。件数用クエリは検索条件のサブクエリから作るため件数にも反映され、利用クレジット順の分岐も同じ検索条件を使うため併用できる。docstring に引数を追記。

## 補足

- 移植元は `loginIds` が null または空のときは条件を足さない。同じく `None`・空リストでは足さない。
- テナント条件・`role != SYSTEM` は常に付くため、他テナント・SYSTEM のログイン ID を指定しても返らない。
- DB のスキーマ変更・シードデータの追加はなし。
