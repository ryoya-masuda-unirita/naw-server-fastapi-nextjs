# #372 issue-372 NAW-1424 ユーザー一覧 API にログイン ID の完全一致で絞る loginIds を足す

## 概要

`GET /api/admin/users` に、ログイン ID の完全一致で絞り込む任意のクエリ `loginIds`（複数指定可）を足す。空・未指定なら無効。`totalCredits` ソートと併用しても絞り込みが効くこと。

## 説明

### 根拠（移植元）

- NAW-1424 e14bf755（`UserController.getUsers`、`UserService.buildUserSpecification` の `loginId` IN 条件）
- テスト: `UserIT`・`UserServiceTest`・`UserControllerTest`
- 移植先: `backend/app/routers/users.py` の `get_users`、`backend/app/services/user_service.py` の `get_users`
- frontend の学習データ更新者名の引き当て（NAW-1424）が依存する

## その他

- Issue 本文は `GET /api/users` と書かれているが、移植元・移植先とも実際のパスは `GET /api/admin/users`（管理者専用）。
