# 04_テスト設計

## テスト方針

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 完全一致 | 2 件のログイン ID を指定。そのうち 1 件を含むだけの別のログイン ID のユーザーもいる | 指定した 2 件だけが返り、件数も 2 |
| 2 | 未指定 | `loginIds` を付けない | 絞り込まれず全員が返る |
| 3 | 他テナント | 他テナントのユーザーのログイン ID と自テナントの管理者を指定 | 自テナントの管理者だけが返る |
| 4 | SYSTEM ロール | SYSTEM ユーザーのログイン ID と管理者を指定 | 管理者だけが返る |
| 5 | 併用 | 利用量の付与・利用クレジット順の並べ替えと併用 | 指定したユーザーだけが返る |
| 6 | 条件の生成 | サービスに 2 件のログイン ID を渡す | ログイン ID の IN 条件が検索に付く |
| 7 | 空 | サービスに `None`・空リストを渡す | IN 条件が付かない |
