# 02_基本設計

## 変更対象

- ユーザー一覧取得の API とそのビジネスロジック（管理者向けユーザー管理）。

## 画面 / API 変更概要

- `GET /api/admin/users` に任意のクエリ `loginIds`（文字列、複数指定可）を追加する。
- 他のクエリ・レスポンスの形式は変えない。

## 影響範囲

- 既存の呼び出し（`loginIds` なし）は結果が変わらない。
- 利用量付与・利用クレジット順の並べ替え・除外グループとの併用で、同じ絞り込み条件が効く。

## 移植方針

- 移植元は検索条件を組み立てる箇所に、`loginIds` が指定されたときだけログイン ID の IN 条件を足している。移植先も同じ箇所（テナント・SYSTEM 除外・検索文字列・ロール・除外グループと同じ条件組み立て）に足す。
- 移植先は既存の呼び出しを壊さないよう、サービスへは名前付き（キーワード専用）の任意引数で渡す。
