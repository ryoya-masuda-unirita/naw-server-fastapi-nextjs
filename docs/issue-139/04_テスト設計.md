# 04_テスト設計

## テスト方針

本 Issue はソースコード変更を伴わない現状調査タスクのため、既存のテストスイート（`pytest`）が調査前後で変わらず成功することを確認し、ドキュメント追加のみで回帰がないことを担保する。あわせて、調査そのものである `mypy` の実行結果が再現可能であることを確認する。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | mypy 実行の再現性 | `cd backend && uv run mypy app tests` を実行する | エラー件数・内訳が `03_詳細設計.md` の記載（435件・37ファイル）と一致する |
| 2 | 既存テストへの非回帰 | `cd backend && uv run pytest tests/unit -q` を実行する（ソース変更なしのため疎通確認目的） | 既存のテストが調査前と同じ結果（全件成功）になる |
