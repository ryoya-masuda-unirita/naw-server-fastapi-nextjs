# 02_基本設計

## 比べ方

- 移植元は Java なので、POI・PDFBox の jar（`~/.m2` にあるもの。`spring-ai 1.1.7` → Tika 3.3.0 が引く POI 5.5.1・PDFBox 3.0.7）で、各プロセッサの抽出部分をそのまま写した `Extract.java` を作り、移植先のプロセッサと同じファイルで実行する（`docs/issue-494/comparison/`）
- 移植元のリポジトリ（`secuaigent-ref`）は読むだけで、ビルドしない

## サンプル

- Word: 見出し・タブ・改行・内部リンク・変更履歴（挿入・削除）・コンテンツコントロール・フィールド・箇条書き・表・ヘッダー・フッター・サロゲートペア・半角カナ
- Excel: 数値（整数・小数・指数）・日付・真偽・数式・結合セル・空白・複数シート・飛び地のセル
- PowerPoint: タイトル・箇条書き・空行・表・グループ内の文字・段落内の改行・ノート
- PDF: reportlab（日本語の CID フォント、表のように並べた文字、複数ページ）と Chromium（日本語の本文・表・箇条書き・2 段組み）

## 揃え方（結果を見て決めた）

- Word: 段落の文字を、変更履歴の挿入・コンテンツコントロールを含め、削除を除いて集める
- PowerPoint: 改行を垂直タブから `\n` にする
- PDF: 本文の取り出しを pypdf から pypdfium2（描画で使っているものと同じ）にする。暗号化の判定・画像の取り出しは pypdf のまま
