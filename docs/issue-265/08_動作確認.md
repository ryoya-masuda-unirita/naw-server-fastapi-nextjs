### 2. 全件テスト

JST（実行時刻 2026-11-13 0 時台）で実行した結果:

```
$ uv run pytest -q -p no:warnings
FAILED tests/integration/test_credit_usage.py::TestCreditUsageRouter::TestGetMyCreditUsage::test_get_my_credit_usage_with_active_subscription
FAILED tests/integration/test_credit_usage.py::TestCreditUsageRouter::TestGetWorkspaceCreditUsage::test_get_workspace_credit_usage_with_active_subscription

6 failed, 1292 passed in 67.12s (0:01:07)
```

この 6 件は今回の変更と無関係で、origin/develop（`5479c81`）でも同じ 6 件が失敗する（`6 failed, 59 passed`）。テストが契約の開始日を `date.today()`（ローカル日付）で作るため、JST の 0〜9 時はローカル日付が UTC の日付より 1 日進み、契約が「未開始」と判定される時刻依存の失敗である。タイムゾーンを UTC にして全件を実行すると、すべて通る:

```
$ TZ=UTC uv run pytest -q -p no:warnings
1298 passed in 64.46s (0:01:04)
```
