# #265 issue-265 ログインに失敗回数ロックを移植する

## 概要

ログイン（`POST /auth/login`）に、失敗回数によるロックがない。パスワードを何回でも試せる。

## 説明

移植元は `service/LoginAttemptService.java` でログインの失敗を数え、上限に達すると `TooManyLoginAttemptsException`（`APIControllerAdvice` で応答）でロックする（`service/AuthService.java`）。失敗記録は、パスワード再設定と同じ `password_mismatch_histories` を使う。

### 対応

- 移植元の `LoginAttemptService` / `AuthService` / `APIControllerAdvice` / 設定値を確認し、回数・期間・応答（ステータス・メッセージ）・記録を消す条件を移植する
- 失敗記録は、#248 で作った `backend/app/core/password_mismatch_store.py`（Redis）を共用する。ログイン側は期間を区切らず数えるなど移植元の数え方が違う場合は、保持期間（有効期限）を見直す（モジュールの docstring に注記あり）
- パスワード再設定のロックとの相互作用（同じ記録を数えるか）も移植元に揃える
