# 04_テスト設計

## テスト方針

自動テスト（Vitest + React Testing Library + MSW）で確認する。ブラウザ・実機確認は行わない。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | SSE の行の解釈 | data 行・コメント・`[DONE]`・不正な JSON・CRLF・行の途中で切れたチャンク | 完成した行だけを返し、残りは次のチャンクへ持ち越す |
| 2 | チャートの変換 | line/bar/pie、タイトルの有無、系列の長さ不一致、負値・合計 0、未対応のバージョン、不完全な JSON | 正しいオプションにする。不正なものは null |
| 3 | Markdown の変換 | 見出し・強調・表、改行、コードの class、mermaid、インデント、危険な HTML | 移植元と同じ HTML。危険な属性・script は取り除く |
| 4 | MarkdownView | チャートの差し替え・不正 JSON・本文の更新・アンマウント・無効化、mermaid の初期化と失敗 | 差し替え／破棄が正しく行われ、失敗しても画面が残る |
| 5 | SSE 受信 | 各イベント、チャンク分割（マルチバイト）、改行なしの最終行、既定値、`message_content` なし、HTTP エラー | ハンドラーが呼ばれ、最終の Message を返す。異常はエラー |
| 6 | 接続先の切り替え | naw / local | naw は Accept・X-Tenant-ID・Cookie あり。local は X-Server-Auth-Key のみ（Cookie・X-Tenant-ID なし） |
| 7 | messages 取得 | NAW・SECURE・空・403・500・本文取得の失敗 | メッセージ化／`loadError`／ERROR とトースト |
| 8 | 送信 | ストリーミング、2 通目の親、tools・テンプレート・ライブラリ、失敗、ルーム名の自動変更、reasoning、ライブラリ窓口、履歴、SECURE（正常・接続情報不正・トークン失敗） | 状態・リクエストが仕様どおり |
| 9 | 再生成・編集・版 | 再生成・web 検索・失敗、編集で版が増える・切り替え・失敗で復元 | 仕様どおり |
| 10 | 削除・評価 | 配下の削除と版の位置、失敗、評価の楽観更新とロールバック | 仕様どおり |
| 11 | rooms | ページ読み込み、続き、失敗、保存済みの並び順、作成（3 種類の応答）、名前変更、ピン、一括ピン、削除、一括削除、並び保存、評価、検索 | 仕様どおり |
| 12 | useChatActions | 一覧の受け渡し、新規ルームのアシスタント名、評価後の query 無効化・再取得 | 仕様どおり |
| 13 | 移植した util | thread・history・endpoint（移植元 spec を移植）、reasoning・room-name・share-url・room-list-mapper・assistants mapper | 移植元と同じ結果 |
