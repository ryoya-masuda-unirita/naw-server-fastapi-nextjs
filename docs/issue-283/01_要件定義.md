# 01_要件定義

## 背景

チャット画面（#284 以降）は、AI の回答を Markdown・グラフ・図で表示し、SSE で逐次受信し、ルーム一覧とメッセージの状態を共有して動く。移植元ではこれらが `shared`（Markdown・チャート描画）と `features/chat/services`（messages・rooms・SSE）に分かれている。画面の移植に先立ち、React で使う土台を揃える。

## 機能要件

1. Markdown 描画
   - AI の回答（Markdown）を HTML で表示する。GFM（表・取り消し線など）を使える。単独の改行は改行にしない
   - 先頭行のインデントは全行から取り除く（移植元の描画ライブラリと同じ挙動）
   - 本文が更新されても（ストリーミング中）描画し直せる
2. チャート描画
   - ` ```chart:line ` / ` ```chart:bar ` / ` ```chart:pie ` のコードブロックを SVG のグラフにする
   - JSON が未完成・不正・未対応のバージョン・値が不正なときは、グラフにせず元のコードブロックを残す
   - 本文の更新ごとに前のグラフを破棄して描き直し、画面から外れたら破棄する。描画は 1 フレームに 1 回へ集約する
3. mermaid 描画
   - ` ```mermaid ` のブロックを図にする（`securityLevel: strict`）。描画に失敗しても画面は壊さない
4. SSE 受信
   - `POST /api/messages/content` の SSE を読み、`reasoning_delta`・`text_delta`・`library_title_delta`・`library_content_delta`・`message_stop`・`message_content` を所定のハンドラーへ渡す
   - チャンクの境目で行・マルチバイト文字が分かれても正しく読む。最後の行が改行で終わっていなくても読む
   - 最終の `message_content` が届かなければエラーにする
   - 送信先を NAW サーバーとローカルサーバー（SECURE。絶対 URL・アクセスキー・Cookie なし・`X-Tenant-ID` なし）で切り替えられる
5. messages の状態と操作（移植元 `MessageService`）
   - 一覧の取得（本文はアシスタントごとに NAW／ローカルから取得。失敗は ERROR のメッセージとトーストで知らせる。403 は `forbidden`）
   - 送信（楽観的に追加 → 作成 API → SSE）、再生成・やり直し・web 検索で再回答、編集（版が増える）、版の切り替え、削除（配下も消える）、評価（失敗したら戻す）
   - 会話履歴を送る設定のアシスタントには履歴を付ける。SECURE は接続情報の不正・トークン取得失敗を ERROR とトーストで知らせる
   - 最初のメッセージで、仮のルーム名を内容から作った名前に変える
   - ライブラリ生成中は、途中経過をビューワーへ流す窓口を用意する
6. rooms の状態と操作（移植元 `RoomsService`）
   - 20 件ずつの読み込み・検索・作成・名前変更・ピン留め／解除・一括ピン更新・並び替え・削除・一括削除・評価
   - 一覧を読み直しても保存した並び順を保つ。ピン解除は未ピンの新しい順の位置に戻す
7. アシスタント一覧（`['assistants']` の query）を取得する hook

## 非機能要件

- API の応答の形は backend の実際の応答に合わせて読める（`docs/issue-279/api-backend-diff.md`）
- 追加するライブラリは移植元の版に合わせ、`package.json` への追加を最小限にする
- 他の画面のエージェントが並行して触る共通ファイル（`routes/index.tsx`・`lib/constants/*`・`sidebar.tsx`・`index.css`・`public/i18n/*`）は変更しない
- 画面（ページ・ダイアログ）は作らない。#284 以降が使う部品と状態だけ

## スコープ外

- チャット画面そのもの（#284）、アシスタント・テンプレート選択（#286）、添付・検索・共有（#287）、ビューワー・共有閲覧（#288）、SECURE の local への送信の結合確認（#289）
- 移植元の `enableMock`（モック応答）。React の MSW はテストだけで使う方針のため
- PDF 出力（`printHtmlContent`）
- ngx-markdown のうち、移植元が使っていない機能（katex・clipboard・emoji・Prism による構文ハイライト）
