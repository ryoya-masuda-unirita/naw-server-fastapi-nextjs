# 04_テスト設計

ドキュメントだけの変更のため、自動テストはない。次を確かめる。

| 区分 | 観点 |
|---|---|
| リンク | 全 README の相対リンクの先が実在する。今回の変更で、壊れるリンクが増えていない |
| 実行できること | 変更した手順のコマンドが、稼働中の環境で動く（基本の質問・履歴付きの質問・ログ・途中経過ファイル） |
| 古い記述 | 実行できない手順、存在しないコンテナ名、「未移植」「後続の Issue」が、残っていない |
| 重複 | 同じ起動手順・同じ質問のコマンドが、「正」とする場所以外に、残っていない |
| 残すもの | 「Codex 運用」の本文が変わっていない。ホストでの動かし方など、ほかにない内容が消えていない |
| 範囲 | 変更が README だけで、コードと `docs/issue-*`（このチケットの分を除く）に及んでいない |
| 移動 | チャット README が履歴付きで移り、元の場所と空のディレクトリが残っていない |
