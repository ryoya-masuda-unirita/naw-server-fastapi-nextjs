## 実行して確かめる手順（稼働中の `onprem` に対して）

```bash
# onprem README の基本の curl
curl -N --max-time 60 -H "X-SERVER-AUTH-KEY: onprem-local-key" \
  -F 'textData={"assistantId":"onprem-chat","messageId":"m-509-1","userInput":"こんにちは"};type=application/json' \
  http://localhost:18090/api/messages/content
# 生成AIアダプタ README に残す、履歴付きの curl（messageId は変える）
curl -N --max-time 60 -H "X-SERVER-AUTH-KEY: onprem-local-key" \
  -F 'textData={"assistantId":"onprem-chat","messageId":"m-509-2","userInput":"こんにちは","historyMessages":[{"type":"USER","content":"前の質問"},{"type":"ASSISTANT","content":"前の回答"}]};type=application/json' \
  http://localhost:18090/api/messages/content
docker compose -f onprem/docker-compose.yml -p naw-onprem logs waha-emulator   # アダプタのログ
docker compose -f onprem/docker-compose.yml -p naw-onprem exec waha-emulator ls /app/data/stream-output
```

**稼働中の環境は、`onprem-chat` を Bedrock に送る設定だった**（実行して分かった）。実行すると、実際の LLM にリクエストが送られ、会話の記録も増える。echo での確認ではない。
