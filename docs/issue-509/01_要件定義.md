# 01_要件定義

## 背景

README が増え、同じ内容が複数の README に書かれ、古くなったり、実行できなくなったりしている。読む人が、目的の手順に 1 回のリンクでたどり着け、書かれた手順がそのまま動く状態にする。#508 では、ルートの入口・構成表と古いパスだけを直した。

## 現状の確認結果（#508 のあとの `develop`。読み取りと grep で確認した）

| 区分 | 内容 |
|---|---|
| 実行できない | 生成AIアダプタの README の「Docker で通して確かめる」は、エミュレーターのディレクトリで compose を起動する手順だが、そこに compose はない（#483 で廃止）。ログの見方に書かれたコンテナ名も存在しない。構成の節の「いま移植したのは上 2 つ」も、4 つとも移植済みで古い |
| 古い | ルート README の「部品ごとの担当」と Waha! エミュレーターの節に、検索・埋め込みのアダプタは「未移植」「後続の Issue で移植」と書かれている（#299・#300 で移植済み） |
| 重複 | エミュレーターの Docker での起動手順と `curl` が、オンプレの README・エミュレーターの README・生成AIアダプタの README にある。ルートに Waha! エミュレーターの組み合わせ表と E2E 探索の実行コマンドがあり、それぞれの README と重なる。2 つの E2E の README の冒頭「何のプロジェクトか」は前半が同文 |
| 食い違いなし | エミュレーターの `.env.example` の冒頭は正しい（ホスト用。Docker では `onprem/.env`）。食い違っているのは、生成AIアダプタの手順の側 |
| 参照 | ルート README へのアンカー参照はない（grep で確認）。共通部品の README は、ほかから参照されていない。**チャットの README は、共通部品の README の 1 行（文中のパス）と、`client/vitest.e2e-local.config.ts` のコメント 1 行から参照されていた**（設計のときに、grep の結果を読み流して見落とした。実装で直した） |

## 機能要件

| No | 要件 |
|---|---|
| F1 | 生成AIアダプタの README の実行できない手順・古い記述を直す。**実際に実行して確かめた手順だけ**を残す |
| F2 | Waha! エミュレーターの Docker での起動手順と `curl` は、オンプレの README を「正」とし、ほかの README は、1 回のリンクにする（ホストで動かす手順は、エミュレーターの README に残す。ほかにない内容のため） |
| F3 | ルート README の Waha! エミュレーターの節・E2E 探索の節を、要約とリンクにする（詳細は各 README） |
| F4 | ルート README の「未移植」「後続の Issue」の記述を直す |
| F5 | 2 つの E2E の README の冒頭の同文を短くし、ルート README の概要へリンクする（各モジュール固有の説明は残す） |
| F6 | 共通部品の README の扱いを決めて実施する（案: 分割せず、先頭に目次を付ける） |
| F7 | チャットの README の置き場所を決めて実施する（案: 実装のある場所へ移す。README 内の「ここにはこの README だけを置く」の注記を直す） |
| F8 | アシスタントの通信経路・部品ごとの担当の置き場所を決める（案: ルートに残す） |
| F9 | 「Codex 運用」の節は残す。位置を、関連ドキュメントとして末尾にまとめる |
| F10 | 全 README の相対リンクの先が実在することを機械で確かめ、結果を残す |

## 非機能要件

- ドキュメントだけを変える（コードは変えない）
- 変更した箇所に書いたパス・コマンドは、実在・実行を確かめる（オンプレの手順は、稼働中の環境に対して実行して確かめる。**稼働中の環境は、LLM が echo ではなく Bedrock の設定だった**。実行すると、実際の LLM にリクエストが送られる。08 に書く）
- 過去の記録（`docs/issue-*`）は書き直さない

## スコープ外

- コードの変更（ただし、チャット README の移動で古くなる、コードのコメント 1 行の参照パスの修正だけは行った。動作は変わらない）
- `docs/issue-*` の過去の記録の書き直し。`docs/issue-163/` にある `25DA61_結合テスト項目書_md/` の複製も触らない
- ルートの `25DA61_結合テスト項目書_md/`（`e2e-spec` が読み込む）
- ルート README の見出し・入口・構成表、古いパスの修正（#508 で済み）
- ローカルに残っている Terraform の tfstate（README の問題ではない）
