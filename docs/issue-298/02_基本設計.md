| 対象 | 内容 |
|---|---|
| 生成AIアダプタ（新設） | 移植元と同じ 4 つの分け方の uv ワークスペース。今回は core と生成AIアダプタの 2 パッケージ。アダプタは core に依存する（移植元の依存の向きと同じ） |

server-local・backend・frontend のコードは変更しない。

## 画面 / API 変更概要

画面・HTTP API の変更はない。エミュレーターの servicerun API（パス・パラメータ・応答）は #274 のまま。変わるのは、execute で動くワークフローの中身と、出力の形（`RetrievalAnswer` に画像説明の空配列が入る）と、途中経過ファイルに書かれるイベントの種類（回答本文の差分から、推論の差分に変わる）。

### アダプタの呼ばれ方

アダプタは Waha! の呼び方に合わせた順序で使う: プロパティを渡す → 出力モードを渡す → 列の定義を渡す → ビュー名（出力ファイル名）を渡す → 実行前の準備 → レコードを書く。レコードの書き込みの中で、通常チャットか RAG のどちらかが動き、出力ファイルが書かれる。

### 入力スロットとアダプタの列・プロパティの対応

| 入力 | アダプタへの渡し方 |
|---|---|
| 質問 | ユーザー列（文字） |
| 添付ファイル | ユーザー列（FILE）。通常チャットだけ。ない場合は「ファイルなし」の印 |
| 履歴 | 会話履歴列（FILE）。ない場合は印 |
| textData | プロパティ「SecuAiGent textData JSON file path」（ジョブごとの一時ファイルに書いて渡す） |
| execute の streamfilepath | プロパティ「推論出力先ファイルパス」 |
| 設定の ragContextJson | RAG Context JSON パスの列（FILE）。RAG だけ |

### サービス ID とワークフローの対応

本物の Waha! の対応（管理コンソールで登録するサービス）はどちらのリポジトリにもない。そこで、エミュレーターの設定ファイル（JSON）に、サービス ID ごとの「出力モード・プロパティ・（RAG の）入力 JSON」を書く。決め方は次のとおり。

- 根拠: 移植元の生成AIアダプタ自体が出力モード（回答・チャット用_回答・チャット用_コンテクスト）とプロパティで動きを変える設計で、サービス = 出力モード + プロパティの組と読める。server-local はアシスタント ID をサービス ID として渡す
- 書いていないサービス ID は既定の定義で動く。設定ファイルがなければ、従来の環境変数（echo・Azure OpenAI）から既定の定義を作る（#274 の使い方を壊さない）
- プロパティは移植元の名前で書き、API キーなどは環境変数の参照で書ける
- 出力先・途中経過・textData のパスはジョブごとにエミュレーターが決めるため設定させない
- 不正な設定は起動時に失敗させる

## 影響範囲

- エミュレーターの LLM 設定のうち、API バージョンの環境変数を廃止する（移植元の SDK の既定に固定されるため）
- エミュレーターの途中経過ファイルに、回答本文の差分は書かれなくなる。移植元アダプタは本文を書かず、server-local も回答本文は出力ファイルから確定するため、SECURE の回答の表示は変わらない。推論の差分は server-local の SSE にそのまま届く
- ライブラリ生成（createLibrary）は、エミュレーターが拒否するのをやめ、アダプタに任せる（SecuAiGent では textData の項目として処理される）
- server-local・backend・frontend の動作に影響はない

## 移植方針

- 移植元のクラス・メソッドの構造と挙動をそのまま移す（命名は Python に合わせる）。迷ったら移植元のコードを正とする
- Spring AI・Apache Tika・Azure SDK・Gson など Java のライブラリに依存する部分は、同じ入出力になるように Python の標準的な手段で書き換える。再現できなかった差は 03 に列挙する
- Waha! 固有の受け口（番号付きプロパティ・ColumnData・出力ファイル）は、同じ形を保ったままエミュレーターから呼ぶ
- core はアダプタに依存させない（移植元と同じ）
- 移植元の Java のテストを、振る舞いの根拠として Python のテストに移す。Spring の内部を見るテストは、送信する HTTP リクエストを見るテストに置き換える
