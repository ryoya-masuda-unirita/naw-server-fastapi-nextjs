# チーム（グループ）管理APIの実装

## 概要

NAW-XXXX（複数チケットにまたがる機能）の一部移植。チーム（Group）管理APIをFastAPIで実装する。

## 説明

### 背景

issue-20の動作確認（Playwright）で、ログイン後のダッシュボードが `GET /api/assistants` 等を呼び出し404になることを確認した。次のステップとしてアシスタント管理API実装を検討したが、Spring Boot側の `GET /api/assistants` はユーザーが所属する **Group（チーム）** に紐づくアシスタントのみを返す仕様であり、Groupドメインがこのリポジトリにまだ存在しないことが判明した。

Group エンティティは Assistant・PromptTemplate（いずれも本リポジトリ未実装）ともM2M関連を持つため、まずGroup自体のCRUD・ユーザー所属管理のみを本チケットのスコープとし、Assistant・PromptTemplateとの紐付けは各ドメイン実装後の別チケットで対応する。

### やること（今回のスコープ）

移植元 `~/Documents/naw-server` の `GroupController` のうち、以下のエンドポイントをFastAPIに移植する。

- `GET /api/groups`（一般ユーザー向け：`isBelonged`パラメータでの自分の所属グループ一覧含む）
- `GET /api/admin/groups`（管理者向け一覧、検索・ページネーション）
- `GET /api/admin/all-groups`（テナント全グループ一覧）
- `GET /api/admin/groups/{id}`（詳細取得）
- `POST /api/admin/groups`（作成）
- `PATCH /api/admin/groups/{id}`（更新）
- `DELETE /api/admin/groups/{id}`（削除）
- `GET /api/admin/groups/{groupId}/users`（グループ所属ユーザー一覧、検索・ページネーション。`includeUsage`によるクレジット利用量はビリング機能未実装のためスコープ外）
- `POST /api/admin/groups/{groupId}/users`（ユーザー追加）
- `DELETE /api/admin/groups/{groupId}/users/{userId}`（ユーザー削除）
- `PATCH /api/admin/groups/{groupId}/users/{userId}`（グループ内管理者フラグ更新）

### スコープ外（後続チケット）

- `POST/DELETE /api/admin/groups/{groupId}/assistants`・`GET /api/admin/groups/{groupId}/assistants`（Assistantドメイン未実装のため）
- `POST/DELETE /api/admin/groups/{groupId}/prompt-templates`・`GET /api/admin/groups/{groupId}/prompt-templates`（PromptTemplateドメイン未実装のため）
- `includeUsage`によるクレジット利用量表示（ビリング機能未実装のため）
