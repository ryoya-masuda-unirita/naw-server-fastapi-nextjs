# 08_動作確認

## 実施内容

- ローカル PostgreSQL（`naw-fastapi-postgres`）に対して `alembic upgrade head` を実行
- `backend/seed.sql` を再投入し、`feedbackUser` 用の確認データを投入
- `uvicorn app.main:app --host 127.0.0.1 --port 8002` でAPIを起動
  - `8001` は使用中だったため、確認用に `8002` を使用

## 確認コマンド

### 1. 管理者ログイン

```bash
curl -s -X POST http://127.0.0.1:8002/auth/login \
  -H 'Content-Type: application/json' \
  -H 'X-Tenant-ID: test-tenant' \
  -d '{"username":"admin","password":"admin@1234"}'
```

結果:
- `loginStatus: SUCCESS`
- 管理者トークンを取得できた

### 2. 一覧取得

```bash
curl -s 'http://127.0.0.1:8002/api/admin/feedbackUser' \
  -H 'Authorization: Bearer <admin-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

結果:
- `totalElements=3`
- `user01` は `isResponded=true`, `feedbackMessageCount=1`
- `user01` の `feedbackRoomCount` は `excellent=1`, `good=1`
- `user02` は `isResponded=false`, 各件数0

### 3. 絞り込み確認

```bash
curl -s 'http://127.0.0.1:8002/api/admin/feedbackUser?responseStatus=has_response&satisfaction=star5' \
  -H 'Authorization: Bearer <admin-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

結果:
- `user01` のみ返却された
- `responseStatus` と `satisfaction` の複合絞り込みが機能した

### 4. ソート確認

```bash
curl -s 'http://127.0.0.1:8002/api/admin/feedbackUser?sortField=count&sortOrder=asc' \
  -H 'Authorization: Bearer <admin-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

結果:
- `feedbackMessageCount=0` の `user02` が先頭になった
- 件数昇順ソートが機能した

### 5. 権限確認

```bash
curl -s -o /tmp/issue52_general_feedback.json -w '%{http_code}' \
  'http://127.0.0.1:8002/api/admin/feedbackUser' \
  -H 'Authorization: Bearer <user01-token>' \
  -H 'X-Tenant-ID: test-tenant'
```

結果:
- HTTPステータス `403`
- 一般ユーザーではアクセスできないことを確認
