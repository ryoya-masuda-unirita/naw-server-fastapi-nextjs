# フィードバックユーザー一覧取得APIの実装

## 概要

管理者向けに、どのユーザーがどれだけメッセージフィードバックをしているか、ルームの満足度評価（星評価）別件数とあわせて一覧取得するAPIを実装する。
移植元（naw-server, Spring Boot）の `FeedbackController.getFeedbackUser` / `FeedbackService.getFeedbackUsers` に対応する。

## 説明

### 対象エンドポイント

- `GET /api/admin/feedbackUser` — フィードバックユーザー一覧取得（ページング・ソート・絞り込み対応）
  - クエリパラメータ: `page`, `size`, `responseStatus`（`has_response`/`no_response`）, `satisfaction`（`star1`〜`star5`）, `sortField`（`updatedAt`/`name`/`count`/`review1`〜`review5`）, `sortOrder`（`asc`/`desc`）
  - レスポンス: ユーザーごとの表示名・フィードバック済みメッセージ件数・ルーム満足度評価（EXCELLENT/VERY_GOOD/GOOD/AVERAGE/POOR）別件数

### スコープ

新規テーブルは不要（既存の `users` / `message_feedbacks` / `rooms` を使用）。
`FeedbackController` の他2エンドポイント（`feedbackMessage`, `feedbackRoom`）は、`folderId` 絞り込みが未移植の `File`/インデックス機能に依存するため、本issueでは対象外とし別issueで検討する。
