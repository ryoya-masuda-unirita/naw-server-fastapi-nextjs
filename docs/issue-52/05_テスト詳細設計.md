## テストクラス構成（04のテストケース番号を対応させる）

```python
class TestFeedbackRouter:
    class TestGetFeedbackUsers:
        # No.1-2
        async def test_returns_feedback_message_count_and_room_rating_counts(self, client, ...):
            """フィードバック済みメッセージ件数とルーム満足度別件数が正しく集計されること"""
        async def test_user_without_feedback_returns_zero_counts(self, client, ...):
            """フィードバック・評価ともにないユーザーは件数0・isResponded=falseで返ること"""

        # No.3-4
        async def test_filters_by_response_status_has_response(self, client, ...):
            """responseStatus=has_responseでフィードバック済みユーザーのみ絞り込まれること"""
        async def test_filters_by_response_status_no_response(self, client, ...):
            """responseStatus=no_responseで未フィードバックユーザーのみ絞り込まれること"""

        # No.5
        async def test_filters_by_satisfaction_star5(self, client, ...):
            """satisfaction=star5でEXCELLENT評価を持つユーザーのみ絞り込まれること"""

        # No.6
        async def test_sorts_by_feedback_count_ascending(self, client, ...):
            """sortField=count&sortOrder=ascでフィードバック件数の昇順に並ぶこと"""

        # No.7
        async def test_paginates_results(self, client, ...):
            """page/sizeでページングされ、totalElementsが全体件数を示すこと"""

    class TestGetFeedbackUsersPermission:
        # No.8-9
        async def test_general_user_returns_403(self, client, ...):
            """一般ユーザーはアクセスできないこと"""
        async def test_group_admin_can_access(self, client, ...):
            """グループ管理者はアクセスできること"""

    class TestTenantIsolation:
        # No.10
        async def test_other_tenant_users_are_excluded(self, client, ...):
            """別テナントのユーザー・フィードバックが結果に含まれないこと"""
```

## 前提フィクスチャ（想定）

- `feedback_tenant` / `other_tenant`：テスト用テナント
- `tenant_admin_user`：テナント管理者（`role=ADMIN`）
- `group_admin_user`：グループ管理者（`GroupUser.is_admin=True`）
- `general_user`：一般ユーザー（管理者権限なし）
- `responded_user` / `unresponded_user`：フィードバック集計テスト用の対象ユーザー
- `feedback_assistant`：メッセージ作成に使うアシスタント
- `owned_room`（`rating`を`EXCELLENT`/`GOOD`等に設定したルーム複数）
- `owned_message` / `owned_message_feedback`（`responded_user`のフィードバック実績データ）
