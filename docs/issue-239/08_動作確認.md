## 確認環境

- ブラウザ・実機での確認は行わず、自動テストのみで代替した（全自動モード。ローカルの Postgres・Redis・backend サーバーは起動していない）

1. 共通の仕組みとスキーマごとの文言の単体テストを実行（`uv run pytest tests/unit/test_validation_messages.py tests/unit/test_request_validation_messages.py`）

3. 全件のテストを実行（`uv run pytest`）
4. `uv run mypy app tests`・`uv run ruff check`・`uv run ruff format --check` を実行
