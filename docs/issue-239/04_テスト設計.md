# 04_テスト設計

## テスト方針

- 共通の仕組みは、置き換えの規則（どのエラーをどの文言にするか・置き換えないもの）を単体テストで網羅する
- スキーマごとの文言は、01 で「揃える」とした主要な項目について、制約の種類ごとに最低 1 件ずつ確かめる（必須の欠落・null、文字数、範囲、日時の形式、独自チェックの文言の変更）
- API を通した確認として、本文（JSON）・multipart の `textData`・クエリのモデル・クエリパラメータの 4 経路で、400 の `message` が移植元の文言になることを確かめる
- 制約そのもの（受け付ける値）と OpenAPI のスキーマが変わらないことを確かめる
- 変わる文言を確かめていた既存テストは新しい文言に直し、それ以外の既存テストは全件成功すること

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | 欠落 | 必須の文言を指定した項目が無い | 指定した必須の文言 |
| 2 | null | 必須の文言を指定した項目が null | 指定した必須の文言 |
| 3 | 空文字・空配列 | 空白不可・空不可を指定した項目が空 | 指定した必須の文言 |
| 4 | null 不可と空文字 | null 不可だけを指定した項目が空文字で弾かれる | 置き換えない（英語のまま） |
| 5 | 文字数 | 上限を超える | 文字数の文言 |
| 6 | 範囲 | 下限未満・上限超過 | 最小値・最大値の文言 |
| 7 | 日時の形式 | 日時として読めない値・空文字 | 形式の文言・必須の文言 |
| 8 | 独自チェック | 独自チェックで弾く | 独自チェックの文言のまま |
| 9 | 指定なし | 文言を指定していない項目・型違いの値 | 置き換えない（英語のまま） |
| 10 | 入れ子 | 入れ子のモデル・配列の要素のエラー | 入れ子のモデルの指定で置き換わる。外側の指定では置き換えない |
| 11 | 別名 | 別名（`AliasChoices` を含む）の項目の欠落 | 指定した必須の文言 |
| 12 | 複数エラー | 2 項目でエラー | 最初の 1 件の文言（置き換え後） |
| 13 | スキーマごとの文言 | 01 の「揃える」の主要項目 | 移植元と同じ文言 |
| 14 | API（本文） | ボディの入力エラー | 400・移植元の文言 |
| 15 | API（multipart） | `textData` の入力エラー | 400・移植元の文言 |
| 16 | API（クエリのモデル） | トークン使用量・フィードバック一覧の入力エラー | 400・移植元の文言 |
| 17 | API（クエリパラメータ） | ライブラリ一覧のページ番号・件数 | 400・移植元の文言 |
| 18 | 制約・スキーマ不変 | 上限ちょうど・範囲内の値、OpenAPI の最大長 | 受け付ける・スキーマに最大長が残る |
| 19 | 回帰 | 既存テスト全件 | 成功 |
