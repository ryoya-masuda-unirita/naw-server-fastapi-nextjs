## `backend/tests/unit/test_request_validation_messages.py`（新規）

`pytest.mark.parametrize` で（スキーマ, 入力, 期待する文言）を並べ、`model_validate` の 1 件目の文言を `validation_error_message` で取り出して確かめる。

| 対象 | 主な入力 | 期待する文言 |
|---|---|---|
| アシスタントカテゴリ | name 欠落 / 17文字、description 256文字 | カテゴリ名は必須です / カテゴリ名は16文字以内で入力してください / 説明は255文字以内で入力してください |
| アシスタント作成 | type 欠落、endpoints 空、endpoints[0].id 欠落、model 欠落、name null / 33文字、description 1001文字 | 01 の表の文言 |
| アシスタント更新 | name 空白のみ | アシスタント表示名は空白にできません。 |
| ツール設定 | name 欠落 | 空白は許可されていません |
| メッセージ作成 | assistantId 欠落 / 空文字 | 空要素は許可されていません |
| 回答の生成 | userInput 欠落 | null は許可されていません |
| フィードバック 3種 | sortField・sortOrder 不正 | 移植元の文言 |
| ライブラリ更新 | name 欠落 / 256文字 | ライブラリ名は必須です / ライブラリ名は255文字以内で入力してください |
| タグ作成・更新・削除 | name 欠落 / 256文字、ids 空 | タグ名は必須です / タグ名は255文字以内で入力してください / 削除対象のIDを1件以上指定してください |
| LLM チャット | deployName 欠落、temperature -0.1 / 1.1、messages 空、role 欠落、content null | 01 の表の文言 |
| LLM 埋め込み | deployName 欠落、input 空白のみ、dimensions 0 / 32768 | 01 の表の文言 |
| パスワードリセット | loginId・oldPassword・newPassword 欠落 | 各項目の文言 |
| ユーザー作成 | loginId 欠落、name null、role null | 空白は許可されていません / null は許可されていません |
| テナント管理の更新 | maxUsageBasedCreditsPerMonth -1 | maxUsageBasedCreditsPerMonth は 0 以上である必要があります |
| トークン使用量 | from 欠落 / 不正 / 空、to 不正、from > to、32日、page -1、size 0 / 101、orderBy 不正 | 01 の表の文言 |

受け付ける値が変わらないこと（No 18）として、上限ちょうど（カテゴリ名 16 文字など）が通ることも同じファイルで確かめる。
