# #248 issue-248 パスワード再設定に失敗回数ロックと必須チェックを移植する

## 概要

パスワード再設定（`POST /auth/password/reset`、未認証で呼べる）が、移植元と次の点で違う。

1. 失敗回数によるロックがない。移植元は `PasswordResetAttemptService` で失敗回数を数えてロックする（`service/PasswordResetService.java`）。backend では旧パスワードを回数無制限に試せる
2. `loginId` などの必須チェックがない。移植元は `PasswordResetRequest` の 3 項目に `@NotBlank` があり、空なら 400（「ログインIDの入力は必須です。」など）。backend は `loginId: ""` で 403 `User not found` を返す

## 説明

- 移植元の `PasswordResetAttemptService`（回数・ロック時間・保存先・解除の条件・ロック中の応答）を確認し、backend に移植する。ログイン失敗のロック（`LoginAttemptService` 相当）が backend にどう実装されているかも確認し、仕組みを揃える
- `@NotBlank` とメッセージを移植する
