# 08_動作確認

## 確認環境

- macOS（ローカル）、Python は `backend/` の uv 環境
- DB はインメモリ SQLite、Redis は fakeredis（テストの fixture）
- **ブラウザ・実機確認は行わず、自動テストのみで代替した**（ローカルの Postgres / Redis / backend サーバーは他の作業と共有のため起動・変更していない）

## 確認手順

```bash
cd backend
uv run pytest tests/unit/test_password_mismatch_store.py tests/unit/test_auth_schemas.py \
  tests/unit/test_auth_service.py::TestAuthServicePasswordReset \
  tests/unit/test_config.py::TestPasswordResetSettings tests/integration/test_auth.py -v
uv run pytest
uv run mypy app tests
uv run ruff check .
uv run ruff format --check .
```
