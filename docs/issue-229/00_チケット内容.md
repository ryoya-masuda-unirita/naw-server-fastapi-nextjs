# #229 issue-229 React（frontend/）のログイン画面にテナントID入力を移植し、X-Tenant-IDヘッダを送る

## 概要

#223（frontend-angular 削除・dev のフロントを React に切り替え）のマージ前提。backend の `POST /auth/login`・`GET /api/auth` ほかは `X-Tenant-ID` ヘッダが必須だが、React（frontend/）のログイン画面にはテナントID入力欄がなく、送る仕組みもないため、React からはログインできない。

## 説明

#193 で frontend-angular に入れた方式（ログイン画面でテナントIDを明示入力 → `sessionStorage` に保存 → 以降の API リクエストで `X-Tenant-ID` ヘッダを送信。サブドメイン（hostname）からの判定はしない）を React に移植する。
