# 04_テスト設計

## テスト方針

- Vitest + React Testing Library + MSW で、backend を起動せずに確認する。
- ヘッダの付与は、MSW のハンドラでリクエストヘッダを記録して検証する。
- ブラウザでの実機確認は行わない（自動テストで代替）。

| No | 観点 | 条件 | 期待結果 |
|---|---|---|---|
| 1 | API クライアント | テナントIDを保存済みで GET する | `X-Tenant-ID` に保存値が付く |
| 2 | API クライアント | テナントIDを保存済みで POST する | `X-Tenant-ID` に保存値が付く |
| 3 | API クライアント | テナントID未保存でリクエストする | `X-Tenant-ID` が付かない |
| 4 | API クライアント | テナントIDを保存 → 削除する | 保存で読み出せ、削除後は空になる |
| 5 | 認証ストア | テナントIDを指定してログインする | ログインリクエストに `X-Tenant-ID` が付き、ボディにテナントIDが含まれない |
| 6 | 認証ストア | ログイン成功後 | テナントIDが保存されたままになる |
| 7 | 認証ストア | ログイン失敗 | テナントIDが削除され、エラーになる |
| 8 | 認証ストア | パスワードリセットが必要なユーザーでログイン | テナントIDが保持される |
| 9 | 認証ストア | テナントID保存後にセッション確認を行う | セッション確認リクエストに `X-Tenant-ID` が付く |
| 10 | 認証ストア | ログアウト | テナントIDとユーザー情報が削除される |
| 11 | ログイン画面 | 初期表示 | テナントID・ユーザーID・パスワード欄と送信ボタンが表示される |
| 12 | ログイン画面 | テナントID・ユーザーID・パスワードを入力して送信 | 入力したテナントIDが `X-Tenant-ID` としてログインリクエストに付く |
| 13 | ログイン画面 | テナントID未入力で送信 | ログインリクエストが送られない |
| 14 | ログイン画面 | 認証エラー | エラーメッセージが表示される（既存） |
| 15 | 回帰 | 既存テスト全件 | すべて成功する |
