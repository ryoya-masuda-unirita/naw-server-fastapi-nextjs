# 就業規則（抜粋）

株式会社サンプル商事（架空の会社。動作確認用のサンプル文書）

## 第10条 勤務時間

1. 所定の勤務時間は、午前9時から午後6時までとし、休憩時間は正午から午後1時までの1時間とする。
2. フレックスタイム制の適用者は、午前11時から午後3時までをコアタイムとする。

## 第15条 年次有給休暇

1. 入社後6か月を経過した従業員には、10日の年次有給休暇を付与する。
2. 年次有給休暇を取得する場合は、原則として3営業日前までに所属長へ申請する。
3. 未使用の年次有給休暇は、翌年度に限り繰り越すことができる。

## 第22条 在宅勤務

1. 在宅勤務は、所属長の承認を得た場合に週3日まで認める。
2. 在宅勤務中は、会社が貸与した端末と VPN を使用し、私有端末で業務データを扱ってはならない。
