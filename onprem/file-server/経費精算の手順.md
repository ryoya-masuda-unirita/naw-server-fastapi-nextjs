# 経費精算の手順

株式会社サンプル商事（架空の会社。動作確認用のサンプル文書）

## 対象

業務のために立て替えた交通費・宿泊費・会議費・消耗品費。

## 手順

1. 経費精算システムに、支払日・金額・支払先・用途を入力する。
2. 領収書を撮影して添付する。1 万円以上の支出は、原本を総務部へ提出する。
3. 所属長が承認すると経理部へ回付される。
4. 月末締めで、翌月 25 日の給与と同時に振り込まれる。

## 注意

- 申請期限は支払日から 60 日以内。期限を過ぎたものは精算できない。
- 1 人あたり 5,000 円を超える会議費は、事前に所属長の承認を得る。
- タクシーの利用は、深夜（22 時以降）または荷物が多い場合に限る。
